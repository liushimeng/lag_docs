# 批次 89 · 真实数据口径卡与异常告警层 — 方案设计

> 2026-11-06 · 职责线 2（`ServerGo/citychrome/` + `ServerGo/api/`）＋ 职责线 1（`ClientWeb/`）。
> 落地《虚拟城市模拟系统·自迭代优化规范》**§三.2 第 4 条**（「可读可解释：关键指标附口径说明与计算式，
> 异常值给出告警标记」）与 **§五.2 归一化层**（「单位换算 … 异常值剔除」），
> 并把「看板与 Agent 消费的数据同源同口径」（§三.2 第 3 条）落到**逐条报价**粒度。

---

## 1. 背景与缺口

批次 65~88 已把「真实世界信息 → 城市」的**采集 → 归一化 → 事件 → 注入 → 反馈**主链路打通，
看板也统一为「虚拟城市 - 实时看板」。但**读数本身仍不可解释**：

| 规范条款 | 现状 | 缺口 |
| --- | --- | --- |
| §三.2「关键指标附口径说明与计算式」 | `RealtimeQuote` 只有 `symbol/name/price/change_pct/currency/updated_at/source` | 无单位、无口径、无计算式、无原文链接 |
| §三.2「异常值给出告警标记」 | 看板只有涨跌红绿徽章 | 幅度异常 / 陈旧 / 跳变**无任何标记** |
| §三.2「看板与 Agent 消费的数据同源同口径」 | 看板读 `Feed`；City-Human 工具 `realworld_info` 读 `FeedCompactJSON` | 两边**字段不同构**：Agent 侧拿不到单位/置信度/异常 |
| §五.2「单位换算 … 异常值剔除」 | `validQuote` 只做「价 > 0 且涨跌幅 ∈ [-100,100]」 | 无单位口径、无异常判定、无剔除留痕 |

**本批次目标**：为**每条真实报价**补齐「单位 + 口径卡 + 计算式 + 原文链接 + 置信度 + 异常标记」，
并把同一份派生结果同时供给**看板**与**Agent 工具**（同源同口径）。

## 2. 总体架构（新增 3 个纯概念，零 IO、零 RNG）

```
                 ┌────────────────────── ServerGo/citychrome ──────────────────────┐
 采集(Chrome) → │ FeedStore(存储层：只存原始值，不掺派生量)                       │
                 │        ↓ Snapshot()                                         │
                 │ DeriveQuoteQuality(Feed, now, tiers) → Feed'  ← 纯函数        │
                 │        │  每条 quote 填 unit / confidence / anomaly           │
                 │        └→ DeriveAnomalies(Feed, now, tiers) → []Anomaly        │
                 │ MetricSpecs() → []MetricSpec（静态口径卡注册表）              │
                 └───────────┬──────────────────────────┬───────────────────────┘
                             │                          │
        WS game.realtime_feed │                          │ HTTP /realtime_board + /dashboard
                             ▼                          ▼
                    前端看板（报价行/口径卡/告警）   City-Human 工具 realworld_info（同一口径）
```

**纪律**：
- **派生量不进存储层**：`FeedStore` 仍只存原始值；`unit/confidence/anomaly` 在**出口**派生（`Service.Feed()`），
  避免「快照时刻的置信度」被冻结在采集时刻（置信度随时间衰减）。
- **纯函数**：`DeriveQuoteQuality` / `DeriveAnomalies` / `MetricSpecs` 零 IO、零 RNG、零全局可变态，
  时刻一律入参（对齐 `market_hours.go` 文件头纪律）。
- **口径单一事实来源**：异常阈值、单位、权威度、口径文案全部集中在 `metric_spec.go` 一处，
  **禁止**在前端或 Agent 侧另立阈值（否则重演批次 88 「stale 两套口径」返工）。

## 3. 数据契约（前后端逐字一致；**改一侧必须双侧同步**）

### 3.1 `RealtimeQuote` 新增 4 字段

```go
type RealtimeQuote struct {
    // …既有 7 字段一字不动…
    Unit       string  `json:"unit"`                // 计量单位(见 §3.3 取值表)
    SourceURL  string  `json:"source_url"`          // 采集源页面链接(免登录可浏览)
    Confidence float64 `json:"confidence"`          // 0..1 置信度(§4.3)
    Anomaly    string  `json:"anomaly,omitempty"`   // ""|high|low|stale|jump(§4.2)
}
```

⚠️ **`omitempty` 只用于 `anomaly`**（空值有语义 = 无异常）；`unit`/`source_url`/`confidence`
恒有值（缺省 `""`/`""`/`0`），**不得**加 `omitempty`（批次 84 教训：空值有语义字段会静默丢失）。

### 3.2 `MetricSpec`（口径卡）

```go
type MetricSpec struct {
    ID        string `json:"id"`         // "a_share.index.sh" —— 唯一 id
    Category  string `json:"category"`   // a_share|hk|us|metal|futures|crypto|macro|news
    Indicator string `json:"indicator"`  // 指标名("上证指数")
    Unit      string `json:"unit"`       // 计量单位(与 RealtimeQuote.unit 同取值表)
    Caliber   string `json:"caliber"`    // 口径说明(一句话:这个数到底是什么)
    Formula   string `json:"formula"`    // 计算式(如 "change_pct = (price - prev_close) / prev_close * 100")
    Source    string `json:"source"`     // 来源站点名
    SourceURL string `json:"source_url"` // 来源站点/接口地址
    Refresh   string `json:"refresh"`    // 刷新档位说明(如 "交易时段 600s / 休市 7200s")
    Keywords  []string `json:"-"`        // 匹配关键词(不序列化;前端不消费)
}
```

### 3.3 单位取值表（`unit`）

| unit | 含义 | 典型指标 |
| --- | --- | --- |
| `point` | 指数点位 | 上证指数 / 恒生指数 / 纳斯达克 / 美元指数 |
| `cny` | 人民币金额 | A 股个股 |
| `hkd` | 港币金额 | 港股个股 |
| `usd` | 美元金额 | 美股个股 / BTC / ETH |
| `cny_per_g` | 人民币/克 | 沪金 / 沪银 |
| `usd_per_oz` | 美元/盎司 | 伦敦金 / COMEX 黄金 / 白银 |
| `usd_per_bbl` | 美元/桶 | WTI / 布伦特原油 |
| `cny_per_t` | 人民币/吨 | 沪铜 / 螺纹钢 |
| `pct` | 百分比 | LPR / CPI |
| `cny_trillion` | 万亿元 | GDP |
| `text` | 文本 | 财经快讯 |

**类目兜底**（无口径卡命中时）：`a_share→cny`、`hk→hkd`、`us→usd`、`metal→usd_per_oz`、
`futures→usd_per_bbl`、`crypto→usd`、`macro→text`、`news→text`。

### 3.4 `Anomaly`（异常清单）

```go
type Anomaly struct {
    Category   string  `json:"category"`    // 行情类目
    Symbol     string  `json:"symbol"`      // 站点口径代码
    Name       string  `json:"name"`        // 显示名
    Kind       string  `json:"kind"`        // high|low|stale|jump
    Severity   int     `json:"severity"`    // 1..3
    Value      float64 `json:"value"`       // 触发值(change_pct 或跳变幅度 %)
    Detail     string  `json:"detail"`      // 触发依据(含阈值与实测值)
    ObservedAt int64   `json:"observed_at"` // Unix 秒
}
```

### 3.5 出口装配

| 出口 | 新增字段 |
| --- | --- |
| WS `game.realtime_feed` | `RealtimeQuote` 内 4 字段（帧形状不变，**不加顶层字段**） |
| HTTP `GET /api/virtual_city/realtime_board` | `data.metric_specs[]`、`data.anomalies[]` |
| HTTP `GET /api/virtual_city/dashboard` | `data.dashboard.metric_specs[]`、`data.dashboard.anomalies[]` |
| City-Human 工具 `realworld_info` | 每条 quote 追加 `单位/置信度/异常` 三元组（见 §6） |

> `metric_specs` 是**静态**目录 ⇒ 不进 WS 高频帧（与批次 77 `missions` / 批次 78 `stats`
> 同一约定：只随 HTTP 快照回读）。

## 4. 判定口径（纯函数，可单测）

### 4.1 口径卡注册表 `MetricSpecs()`

- 静态切片，包级只读；`MetricSpecs()` 返回**副本**（对齐 `DashboardDimensions()` 的副本纪律）。
- 覆盖 **7 个行情/宏观类目共 ≥20 条**口径卡（每类目 2~4 条核心指标）。
- `LookupMetricSpec(category, symbol, name)` → 命中口径卡（先按 `ID` 精确，后按 `Keywords` 模糊，
  大小写不敏感；同长度多命中取首个）。

### 4.2 异常判定 `DeriveAnomalies(feed, now, tiers)`

| kind | 判定式 | severity |
| --- | --- | --- |
| `stale` | `age_seconds > 2 × tiers.Seconds(category, now)` | 2（固定） |
| `high` | `change_pct ≥ 阈值(cat)` | `1 + min(2, floor(change_pct/阈值))`（上限 3） |
| `low` | `change_pct ≤ -阈值(cat)` | 同上（按 `|change_pct|`） |
| `jump` | `|price - prev| / prev × 100 ≥ 2 × 阈值(cat)`，`prev` = 同 symbol 历史最后一点 | 3（固定） |

- **阈值表（单一事实来源，在 `metric_spec.go`）**：
  `a_share 3.0` / `hk 4.0` / `us 3.5` / `metal 2.0` / `futures 3.0` / `crypto 5.0` / `macro 1.0`（单位：%）。
- **`stale` 口径必须复用批次 88 的 `tiers.Seconds(cat, now)`** —— 与调度器真实轮转间隔、
  `realworld_info` 的 `stale` 字段**同一表达式**，禁止另立口径（批次 88 返工教训）。
- **优先级**：`jump` > `stale` > `high/low`（一条报价最多一个 `anomaly` 标记，取最严重者）。
- 历史点不足 2 ⇒ 不判 `jump`；`prev ≤ 0` ⇒ 不判 `jump`。
- 报价集合为空 ⇒ 返回空切片（非 nil）。

### 4.3 置信度 `Confidence`（0..1，保留 3 位小数）

```
freshness = clamp01(1 - age_seconds / (2 × tiers.Seconds(cat, now)))
authority = sourceAuthority(quote.source)        // 静态表，见下
penalty   = 1.0（无异常）| 0.8（high/low）| 0.2（stale）| 0.3（jump）
confidence = round3(clamp01(freshness × authority × penalty))
```

**`sourceAuthority` 静态表**（源名 → 权重）：

| 源名包含 | authority |
| --- | --- |
| `腾讯` / `新浪` / `东方财富` / `交易所` / `纳斯达克` / `路透` / `bloomberg` | 1.0 |
| `财联社` / `华尔街见闻` / `第一财经` / `同花顺` | 0.9 |
| 其它已知名 | 0.75 |
| 未知 / 空 | 0.6 |

- `tiers.Seconds` 为 `news`/`macro` 时同样适用（macro 档 86400 ⇒ 新鲜度衰减慢）。
- **陈旧即低置信**：`age ≥ 2×档位` ⇒ `freshness ≤ 0` ⇒ `confidence = 0`（与 `stale` 判定自洽）。

### 4.4 `DeriveQuoteQuality(feed, now, tiers) Feed`

- 返回**新 Feed 副本**，为每条 quote 填 `unit`（命中口径卡优先、类目兜底）、`source_url`
  （命中口径卡优先、空则留空）、`confidence`、`anomaly`（取 §4.2 最严重项）。
- **不改动 `FeedStore` 内部存储**（派生量不进存储层）。
- `now`/`tiers` 一律入参 ⇒ 可确定性单测。

## 5. 口径卡内容骨架（每条 8 字段齐全）

示例（`a_share.index.sh`）：

| 字段 | 值 |
| --- | --- |
| `indicator` | 上证指数 |
| `unit` | `point` |
| `caliber` | 沪市全部 A 股的加权综合指数，反映沪深两市整体走势 |
| `formula` | `change_pct = (price − prev_close) / prev_close × 100` |
| `source` | 腾讯财经 |
| `source_url` | `https://qt.gtimg.cn/q=sh000001` |
| `refresh` | 交易时段 600s / 休市 7200s |

> 其余类目按同一骨架补齐（恒生指数 / 纳斯达克 / 伦敦金 / WTI 原油 / BTC / LPR / CPI / GDP / 财经快讯 …）。

## 6. Agent 侧同源同口径（§三.2 第 3 条）

`realworld_info` 的 `op=overview|quotes` 输出中，每条 quote 追加三字段（**保持既有字段名与顺序不动**，
只在行尾追加，避免破坏既有 Agent 提示词解析）：

```
symbol=sh000001 name=上证指数 price=3245.67 change_pct=+0.82 unit=point confidence=0.94 anomaly=
```

- `unit` 为口径卡单位；`confidence` 保留 2 位小数；`anomaly` 空串 = 无异常。
- `op=history` / `op=news` / `op=sources` **不变**。

## 8. 零回归红线

- **零 RNG**：全部派生量为纯函数；
- **零契约破坏**：`RealtimeQuote` **只加字段不改名不删字段**；WS 帧**不加顶层字段**；
  `realworld_info` 只在行尾追加；
- **既有单测不破**：`citychrome` / `config` / `game/virtual_city` 既有断言不改语义；
- **口径单一**：阈值/单位/权威度只在 `metric_spec.go` 一处，前端**不复制阈值**（前端只渲染后端给的 `anomaly`/`confidence`）；
- **单文件 ≤1800 行**（§4）：`metric_spec.go` 数据多，若超限按类目拆 `metric_spec_batch89_{cat}.go`；
- **`go test ./...` 与 `tsc --noEmit` + `npm run build` 必须通过**。

## 9. 验收标准

1. `go test ./citychrome/... -count=1` 全绿，且新增单测覆盖：
   - 口径卡副本语义（改动返回值不污染包级目录）；
   - `DeriveQuoteQuality` 的 unit 命中/兜底、confidence 上界 1 下界 0、
     `age ≥ 2×档位 ⇒ confidence == 0`；
   - `DeriveAnomalies` 的 4 类 kind 触发 + 优先级 + 阈值边界（恰好等于阈值**不**触发）；
   - `stale` 阈值恒等于 `2 × tiers.Seconds(cat, now)`（配置档位非默认时同样成立）；
   - `DeriveQuoteQuality` **不修改**入参 Feed（纯函数）。
2. `go build -o LsmAgentGame main.go` 成功。
3. `tsc --noEmit` + `npm run build` 成功；新增前端单测（若有 vitest）覆盖口径卡渲染与异常徽章。
4. 活体验收（CDP）：看板「实时」子 Tab 内报价行可见单位/置信度/异常徽章，
