## 2. 关键设计决策（含收口裁定）

| # | 决策 | 理由 |
| --- | --- | --- |
| D1 | **派生量不进存储层**：`FeedStore` 只存原始值，`unit/confidence/anomaly/spec_id` 在 `Service.Feed()` 出口派生 | 置信度随时间衰减，冻结在采集时刻会失真（休市时段读数越来越假） |
| D2 | **`stale` 口径复用批次 88 的 `IntervalTiers.Seconds`**：`age > 2 × 档位` | 与调度器真实轮转间隔、`realworld_info` 的 stale 字段**同一表达式**（批次 88 返工教训：禁止另立口径） |
| D3 | **异常阈值唯一**：`a_share 3.0 / hk 4.0 / us 3.5 / metal 2.0 / futures 3.0 / crypto 5.0 / macro 1.0`（%），全在 `metric_spec.go` | 前端与 Agent **不复制阈值**，只渲染后端判定结果 |
| D4 | **阈值边界 = 严格超过**（`>`，恰好等于不触发） | 原方案 §4.2 写 `≥` 与 §9.1 验收条款「恰好等于不触发」自相矛盾，收口取后者：阈值是抖动区，取等号会反复触发/反复不触发的告警抖动 |
| D5 | **严重度公式修正为 `1 + min(2, floor(ratio − 1))`** | 原式 `1 + min(2, floor(ratio))` 使 **`severity=1` 永不可达**（触发条件本身要求 ratio>1），且 ratio=2.0 档位差一档。修正后三档全可达：ratio∈(1,2)→轻微、=2→中等、≥3→严重 |
| D6 | **新增 `RealtimeQuote.spec_id`**：后端派生时写入口径卡 id，前端优先按 id 精确关联 | `MetricSpec.Keywords` 是 `json:"-"` 不下发 ⇒ 后端已命中、前端匹配不上（站点名「沪指」vs 指标名「上证指数」）⇒ 批次核心价值打折。**实测已验证**：站点口径代码 `000001` 命中 `a_share.index.sh` |
| D7 | **`Anomaly.value` 单位随 kind 变**：`stale` = 陈旧秒数，其余 = 幅度 % | 「触发量」本身；前端按 kind 分支渲染，stale **不追加 `%`** |
| D8 | **Agent 侧不新增 op**：口径卡目录并入既有 `op=sources` 的 `calibers` 数组 | `vcplayer/prompt.go`（系统提示词前缀）**零改动**（§14.3 prompt cache 纪律）；`tools.go` 只加 1 句描述 |
| D9 | **口径卡目录不按 category 过滤** | 口径卡是全局静态目录；按类目过滤会让 Agent 用 `spec=` 反查时查不到口径，反而破坏「同源同口径」 |
| D10 | `spec_id` / `anomaly` 用 `omitempty`，`unit`/`source_url`/`confidence` **不用** | 空值有语义字段（无口径卡 / 无异常）允许缺省；恒有值字段加 `omitempty` 会静默丢失（批次 84 教训） |

## 3. 契约（前后端逐字一致）

```jsonc
// RealtimeQuote（+5 字段，既有 7 字段一字未动）
{ "symbol":"000001","name":"上证指数","price":3649.18,"change_pct":-1.1038,
  "currency":"CNY","updated_at":1793956118,"source":"腾讯行情",
  "unit":"point","source_url":"https://qt.gtimg.cn/q=sh000001",
  "confidence":0.999,"anomaly":"low","spec_id":"a_share.index.sh" }

// MetricSpec（9 字段）
{ "id":"a_share.index.sh","category":"a_share","indicator":"上证指数","unit":"point",
  "caliber":"上海证券交易所全部 A 股的加权综合指数,……","formula":"change_pct = (price - prev_close) / prev_close * 100",
  "source":"腾讯行情","source_url":"https://qt.gtimg.cn/q=sh000001","refresh":"交易时段 600s / 休市 7200s" }

// Anomaly（8 字段）
{ "category":"a_share","symbol":"399006","name":"创业板指","kind":"low","severity":1,
  "value":-3.957,"detail":"跌幅 3.96% > 阈值 3.00%(类目 a_share)","observed_at":1793956118 }
```

**出口**：WS `game.realtime_feed`（帧形状不变，仅报价内多 5 字段）｜`GET /api/virtual_city/realtime_board` 的
`data.metric_specs[]` + `data.anomalies[]`｜`GET /api/virtual_city/dashboard` 的 `data.dashboard.metric_specs[]` + `data.dashboard.anomalies[]`
｜Agent 工具 `realworld_info` 的 quote 行追加 `unit/confidence/anomaly/spec=` 四元组，`op=sources` 追加 `calibers[]`。

## 7. 已知限制（如实标注）

1. **节假日不感知**（继承批次 88）：各市场节假日按普通交易日处理。
2. **`stale` 只判「超 2× 档位」**：`anomalies` 只在 HTTP 快照/手动刷新时回读（WS 帧不携带），两次刷新之间清单不自动变化（§3.5 约定）。
3. **`jump` 依赖自采价环**（≤48 点）：环内不足 2 点不判跳变；同秒合并回退取倒数第二点。
4. **口径卡 `source_url` 是采集源入口页**（如 `https://qt.gtimg.cn/q=sh000001`），非逐条数据的永久深链（采集源按 mission 轮转，无稳定 per-symbol 深链）。
5. **未登记口径卡的标的**回退类目兜底单位 + `authority 0.6` + 前端「暂无口径卡」降级（**不崩、不编造口径**）；当前 LME 伦铜/伦镍、外汇储备等未登记。
6. **`op=sources` 固定携带 25 条口径卡**（≈5 KB JSON）：Agent 主动调用 `sources` 时会增加上下文消耗；如需收敛，可后续改为按需返回。
7. **`Service.Feed()` 每次出口做一次 O(报价数 × 口径卡数) 派生**（当前量级 ~10⁴ 次字符串比较，可接受）；类目/口径卡数量级跃升时需加索引缓存。
8. **`spec_id` 跨类目不硬取**：若后端下发的 `spec_id` 指向的卡不在该行类目目录内，前端不跨类目取用，继续走兜底链（避免把别类目的口径贴到本行）。
