> 居民的行为金融偏差 → 集体行为（羊群/杠杆）→ 泡沫 → 破裂 → 反馈到居民下一轮决策。

---

## 1. 为什么这一批是「重要功能」

《社交资本与信用体系设计》§11.1 的诊断原文：

> 「当前市场周期由骰子驱动，玩家行为不影响宏观。」

在此之前，本作的经济是**单向**的：经济引擎产生周期 → 居民承受周期。
本批把回路接上：**居民自己的决策（追高、跟风、加杠杆）会造出泡沫，泡沫会破裂，
破裂的损失按「谁最后加杠杆」分配**——这正是真实世界每一轮泡沫的共同结构，
也是本作作为「经济模拟器」而非「数值游戏」的分水岭。

同时，《行为金融与投资心理机制设计》整本 1373 行在后端 **grep 命中全为 0**：
认知（`Cognition`）作为后端已存在的一等资源，此前只被用于副业门槛（`actions.go::GateCognition`），
**从未与任何行为机制接线**（§130「声明了却从不接线」）。

## 2. 三层结构

```
   ┌─ ① 行为偏差引擎 (bias.go) ─────────────────────────────┐
   │  居民自身的非理性：追高、割肉不舍、跟风、心理账户       │
   │  认知检定（Cognition ≥ 阈值）⇒ 效果减半且被识破         │
   └───────────────────────────┬──────────────────────────────┘
                               │ 交易行为
                               ▼
   ┌─ ② 羊群效应 (herding.go) ───────────────────────────────┐
   │  每回合末广播「本回合操作摘要」（只含方向/人数）         │
   │  跟随多数 ⇒ 羊群指数↑；逆势且获利 ⇒ 认知 +2            │
   └───────────────────────────┬──────────────────────────────┘
                               │ 汇总为全体居民统计量
                               ▼
   ┌─ ③ 集体杠杆泡沫 (bubble.go) ────────────────────────────┐
   │  市场杠杆率 / 资产换手率 / 现金占比 三个集体指标          │
   │  复苏 → 过热 → 破裂 → 衰退 → 复苏（反身性回路）         │
   └───────────────────────────┬──────────────────────────────┘
                               │ 破裂冲击（资产价 -20%~-40%）
                               ▼
                    居民资产缩水 → 杠杆者爆仓 → 下一轮决策更保守
```

配套：④ **资产流动性价差表**（`liquidity.go`）——「流动性是资产的一种隐性成本」，
让「涨了 20% 但变现要吃掉 10% 价差」成为可感知的现实。

## 3. ① 行为偏差引擎

### 3.1 偏差目录（`bias.go::biasDefs`）

| Code | 名称 | 类别 | 认知阈值 | 挂钩 | 通过效果 | 未通过加重 |
|---|---|---|---|---|---|---|
| `loss_aversion` | 损失厌恶 | exit | 5 | 卖出**亏损**持仓 | 成交价 ×0.92 | ×0.85 |
| `disposition_effect` | 处置效应 | exit | 5 | 卖出**盈利**持仓 | 成交价 ×0.97 | ×0.94 |
| `overconfidence` | 过度自信 | entry | 4 | 买入金额 | ×1.15 | ×1.30 |
| `anchoring` | 锚定效应 | entry | 5 | 买入成交价 | ×1.10 | ×1.20 |
| `herd_follow` | 羊群跟风 | entry/exit | 额外成本 | ×1.10 | ×1.20 |
| `mental_account` | 心理账户 | spend | 4 | 消费上限 | ×1.5 | ×2.0 |
| `sunk_cost` | 沉没成本 | invest | 5 | 教育/副业投入 | ×1.30 | ×1.50 |
| `gamblers_fallacy` | 赌徒谬误 | entry | 5 | 连败 2 次后买入额 | ×1.50 | ×1.80 |
| `hyperbolic_discount` | 双曲贴现 | spend | 4 | 延期支付分支 | 3 个月后 ×1.3 | — |

**认知检定**（§4.1，阈值判定**非掷骰**）：

```go
// 认知 ≥ 阈值 ⇒ 通过：效果偏离 1 的部分砍半，且「已被识破」
// 认知 < 阈值 ⇒ 未通过：全额（Exaggerated），且**不得**告知玩家/Agent 偏差名
```

- 检定**不消耗**认知点；「主动反思」才消耗。
- 未通过时**不显示偏差名称**（教学设计：玩家到复盘才知道踩了什么坑）。
  ⇒ **Agent 上下文同样不得泄漏**（否则 LLM 会自我修正，机制失效）。

### 3.2 心魔画像（偏差组合）

每个座位在开局时按 `seat` 派生确定性伪随机抽 **2~3 个 code** 组成 `BiasProfile`
（同 seat 每次可复现，禁用全局随机）。画像决定了「这个居民天生有哪些非理性倾向」，
认知检定决定「他能不能意识到」。

### 3.3 主动反思（§4.3）

| 操作 | 消耗 | 效果 |
|---|---|---|
| 反思·轻度 | 认知 −1 | 解除 1 张当前生效偏差的剩余效果 |
| 反思·深度 | 认知 −2 | 解除全部当前生效偏差 + 本回合免疫 |
| 反思·预习 | 认知 −1 | 下一回合偏差一律视为「通过」 |

限制：**每回合最多 1 次**；`Cognition ≤ 1` 不可执行（防认知归零的恶性循环）。

### 3.4 偏差免疫进度（§4.4-2）

`BiasImmunity[code] ∈ [0,1]`：复盘揭示 +0.10 / 局内成功抵抗 +0.15 / 踩坑未抵抗 −0.05。
**≥ 0.80 ⇒ 该偏差本回合不生效**（等价于「触发概率减半」的确定性实现；
不引入未使用的随机分支，写在注释里说明取舍）。

### 3.5 月度机制

- **储蓄纪律奖励**：连续 3 个月正储蓄 ⇒ 第 4 个月起获「月结余 × 2%」现金；中断归零。
- **延期支付**：`DeferredPayments{AmountCNY, DueMonth, Remaining}`，到期扣 `×1.3`；
  现金不足则扣到 0 并记违约（不产生负数）。
- **延迟满足指数**（年度）：`延期次数 / (延期 + 即时)`；≥0.6 ⇒ 认知 +1；≤0.3 ⇒ 复盘重点。
- **跨局认知继承 30%**：本局认知的 30% 向下取整带入下局开局。
- **心理账户标签**：六类（工资/投资收益/副业/意外之财/礼金/退款），
  **不影响购买力**（钱仍是钱），只用于行为追踪；`mental_account` 偏差**只**在动用
  「意外之财」标签资金消费时生效；玩家可「合并账户」⇒ 效果立即消失。

### 3.6 指数

- **锚定指数** = Σ(|决策价 − 当前公允价| / |买入价 − 当前公允价|)（分母为 0 的项跳过）。
- **羊群指数** = 跟风次数 / (跟风 + 逆势 + 中性决策)。

## 4. ② 羊群效应

- **每回合末**统计各玩家的操作方向（buy / sell / hold），产出
  `TurnSummary{Month, Buy, Sell, Hold, Majority}`，作为**事件**广播（**只含方向与人数，绝不含金额**）。
- **跟风判定口径**（引擎可判定）：每次买入/卖出发生时，取「近 3 回合市场多数方向」；
  与之同向 ⇒ 跟风；相反 ⇒ 逆势；无多数 ⇒ 中性。
- **逆势奖励**（§3.4-3）：同向人数 ≥3 时，逆势且该回合净值变动 >0 ⇒ 认知 **+2**
  （普通获利认知奖励是 +1，**同处叠加不重复发放**）。
- **Agent 侧**：把「本回合多数方向 + 人数分布」注入 Agent 上下文，制造社交压力；
  LLM 自行决定是否跟风（**不硬编码 80%/70%/50% 的跟风概率**——
  文档中的概率描述的是「被编程的 AI 玩家」，本作用 LLM 的上下文压力来达成同样效果，
  且更真实）。

## 5. ③ 集体杠杆泡沫

### 5.1 三个集体指标（每月末统计，§11.1）

| 指标 | 计算 | 阈值 |
|---|---|---|
| 市场杠杆率 | Σ居民总负债 / Σ居民总净资产 | > 60% ⇒ 信贷过热 |
| 资产换手率 | 本回合成交资产数 / Σ居民持有资产数 | > 30% ⇒ 投机过热 |
| 现金占比 | Σ居民现金 / Σ居民总资产 | < 10% ⇒ 流动性紧张 |

### 5.2 状态机（与既有四阶段周期**正交**的独立 `BubbleState`）

```
   none ──杠杆率>0.60──▶ overheat ──持续≥2月 或 杠杆率>0.80──▶ burst
     ▲                                                            │
     └────────────── recession（强制 2~4 月）◀────────────────────┘
```

| 状态 | 资产价格 | 利率 | 居民体感 |
|---|---|---|---|
| none | 既有周期 | 既有周期 | 常态 |
| overheat | 月涨幅系数 **×1.5** | 上行压力 **+0.20 个百分点** | 赚钱容易，容易加杠杆 |
| burst | **一次性 −20% ~ −40%** | 高 | 杠杆者爆仓 |
| recession | 阴跌 | 下降 | 现金为王 |

- burst 的跌幅按触发时杠杆率线性映射：0.60 → 20%，0.80+ → 40%。
- burst 时**负债/总资产 > 1.0** 的居民进入既有清算流程（复用 `settlement.go::liquidate`）。
- recession 持续 2~4 月（**确定性**规则，禁用全局随机），随后回 `none`。
- **破裂播报**（§11.3 原文结构，实际数字代入）：
  > 「本次市场破裂的直接原因是：全场居民平均杠杆率达到 **{X}%**，资产价格被信贷推高至脱离基本面。
  > 最先加杠杆的居民获得了最高收益，最后加杠杆的居民承担了最大损失。
  > 这就是真实世界中每一轮泡沫的共同结构。」

## 6. ④ 资产流动性价差表（§7.2 / §7.3）

| 资产类型 | 买卖价差 | 流动性 |
|---|---|---|
| 现金 | 0% | 极高 |
| 股票 | 2% | 高 |
| 债券 / 理财 | 3% | 高 |
| 贵金属 | 5% | 中 |
| 房产 | 8%–12%（取 10%） | 低 |
| 企业股权 | 15%–25%（取 20%） | 极低 |
| 收藏品 / 另类 | 20%–30%（取 25%） | 极低 |

- 修正：繁荣期 **×0.7**、衰退期 **×1.8**、破产清算额外 **×0.7**。
- **成交价口径**：中点成交 —— 买方付 `评估价 × (1 + spread/2)`，卖方收 `评估价 × (1 − spread/2)`。
- 股票的**微观结构阶段价差**（`stockSpreadForPhase`，过热 0.20% / 扩张 0.04% …）与本条
  **资产流动性价差**（2%）**叠加**，不互相覆盖。

## 8. 验收标准

1. 认知检定两条分支（通过 ⇒ 效果减半 + 识破；未通过 ⇒ 加重 + 不识破）均有单测。
2. 反思三档效果 + 「每回合 1 次」+「认知 ≤1 禁用」均有单测。
3. 储蓄奖励与中断重置、延期支付到期 ×1.3、延迟满足指数年度结算有单测。
4. 三项集体指标计算、泡沫状态机迁移（none→overheat→burst→recession→none）有单测。
5. 价差表应用（买方价 / 卖方价）、繁荣/衰退修正有单测。
6. 羊群指数、多数方向判定、逆势奖励有单测。
7. **Agent 上下文在检定未通过时不出现偏差名** —— 需有单测或断言（§130 教训）。
8. `cd ServerGo && go build -o LsmAgentGame main.go` + `go test ./...` 全绿，
   既有 **I1 记账守恒** 单测不得回归。

### 9.6 「因故未实现」登记项（与 §6 设计取舍的差异，全部显式说明）

1. **跨局认知继承的持久化**：引擎侧机制完整（终局报告披露可带入值），但「上局残留注入下局开局」
   需要跨房间持久化载体（DB 字段 / manager 级 user→认知映射）——`VirtualCityRoom` 无重开路径、
   Manager 无 per-user 状态，故**未接 DB**。已由 `finalReport` 暴露该值，调用方可落库。
2. **§7.3「挂单超 5 回合未成交自动降价 10%」**：`listing.go` 的过期逻辑分散在 listing 状态机内，
   改动面超出本批次；**未实现**（其余三条周期/清算修正均已实现，
   「破产清算 −30%」由既有 `liquidationDiscount=0.7` 覆盖，未重复施加）。
3. **心理账户「消费上限放宽」的落点**：文档写「单笔消费上限 ×1.5」，引擎无消费硬上限；
   改为**等价的冲动放大**（点 ¥5000 实扣 ¥7500）——效果对玩家完全可见，
   且不会像硬上限那样阻断正常消费。
4. **羊群「跟风概率」的引擎侧强制执行**：引擎不做 Agent 的买卖决策（由 LLM 决定），
   故 `herdFollowProbability` 以**社会规范基线**注入 Agent 上下文（`HerdBrief`），而非引擎强制改写决策。
5. **`DamageExtra`（羊群 10%/20% 跟风加成）**：实现为**进出双头的额外滑点成本**
   （记账类别 `CatBiasCost`，I1 守恒），而非文档 §1 表的「下跌后亏损额外 +10%」条件罚金
   （后者需按未来价格条件触发，引擎无此机制）。
6. **确认偏误 / 框架效应 / 主动探索奖励**（§3.5 等卡）未实现 —— 任务书只要求 9 条偏差目录。
7. **`bias_profile[].effect` 的语义**：该字段是**认知检定后的有效乘子**
   （契约示例写 `×0.92` 是未检定值；检定通过时是减半后的值，如 `×0.96`）；
   未识破的偏差 `name_cn` / `effect` / `explanation` **置空**（「不显示偏差名」的实现）。
