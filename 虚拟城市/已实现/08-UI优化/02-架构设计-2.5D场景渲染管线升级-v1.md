## 1. R3F 场景图

### 1.1 当前场景树（v1）

```
<Canvas shadows dpr=[1,2] camera={[14,12,14] fov=45}>
  <color attach="background" args=['#0b0f16'] />
  <ambientLight intensity={0.7} />
  <directionalLight castShadow position={[10,16,8]} intensity={1.15} />
  <Ground />            // 40x40 plane + gridHelper [20 divisions]
  {8 × <DistrictBlock />}  // 8x8 plane + 4-6 box buildings + hover card
  <Roads />             // 7 × planeGeometry (dark thin strip)
  {12 × <AgentToken />}  // cylinder + billboard avatar + html tag
  <OrbitControls ... />
  <CameraReporter />     // writes viewRef every frame
  <FocusController />    // lerps OrbitControls.target
</Canvas>
```

### 1.2 升级后场景树（v2）

```
<Canvas shadows dpr=[1,2] camera={[14,12,14] fov=45}>
  <color attach="background" args=['#0b0f16'] />
  <fog attach="fog" args=['#0b0f16', 28, 60]} />            // 新增：远景雾化
  <ambientLight intensity={0.7} />
  <directionalLight castShadow position={[10,16,8]} intensity={1.15} />
  <hemisphereLight args={['#7a93b8', '#1a1f2a', 0.35]} />   // 新增：天/地反弹

  <Ground />              // 40x40 plane + RepeatWrapping asphalt texture (×5)
  {8 × <DistrictBlock />} // 8x8 plate texture + <BuildingMesh /> buildings + hover card
  {7 × <Road from={d.center} to={[0,0]} kind="main"|"side" />}  // 新组件：4 层道路 + 路灯阵列
  {8 × <DistrictStreetProps />}                                // 新组件：每城区 prop 布点协调
  <StreetPropsLayer />     // 新组件：主干道沿线移动车辆 + 行人
  {12 × <AgentToken />}   // 不变

  <OrbitControls ... />   // 不变
  <CameraReporter />       // 不变
  <FocusController />      // 不变
</Canvas>
```

**重要**：`<GridHelper>` **被删除**，由 `Ground` 的贴图 + `Roads` 的沥青质感共同消除"棋盘感"。

### 1.4 组件拆分原则

- **组件目录隔离**：`props/` 子目录只放道具类组件，避免 `components/wealth/` 一级目录文件膨胀。
- **单一职责**：每个 prop 组件只负责一种道具渲染。
- **协调组件**：`StreetPropsLayer` / `DistrictStreetProps` 负责布点，不渲染具体 mesh。
- **可重用**：`BuildingMesh` 应被 `DistrictBlock` 与 `StreetPropsLayer` 共用。

## 2. 资产加载管线

### 2.1 资产 URL 映射（`ClientWeb/src/assets/images/wealth/index.ts` 新增 4 个 helper）

```ts
// 现有（不动）
export const WEALTH_BANNER: string = ...;
export function professionAvatar(id: string): string { ... }
export function districtTexture(id: string): string { ... }
export function goodsIcon(id: string): string { ... }

// 新增（P0-B 阶段）
const facadeImgs = import.meta.glob<string>('./facades/*.png', { eager: true, import: 'default' });
const roofImgs   = import.meta.glob<string>('./roofs/*.png',   { eager: true, import: 'default' });
const streetImgs = import.meta.glob<string>('./streets/*.png', { eager: true, import: 'default' });
const propImgs   = import.meta.glob<string>('./props/**/*.png', { eager: true, import: 'default' });

/** 城区楼宇立面贴图 URL（缺失 = ''）。 */
export function districtFacadeUrl(districtId: string, variant: 'base' | 'mid'): string {
  return facadeImgs[`./facades/${districtId}_${variant}.png`] ?? '';
}

/** 城区楼顶贴图 URL（缺失 = ''）。 */
export function districtRoofUrl(districtId: string): string {
  return roofImgs[`./roofs/${districtId}.png`] ?? '';
}

/** 街道铺装贴图 URL（缺失 = ''）。 */
export function streetTileUrl(name: StreetTileName): string {
  return streetImgs[`./streets/${name}.png`] ?? '';
}

/** 街景道具贴图 URL（缺失 = ''）。 */
export function propUrl(category: PropCategory, variant: string): string {
  return propImgs[`./props/${category}/${variant}_${category}.png`] ?? '';
}
```

`StreetTileName` / `PropCategory` 是字面量联合类型，写在 `index.ts` 内。

### 2.2 纹理加载模式（与现有 DistrictBlock 一致）

每个 `BuildingMesh` / `Road` / prop 组件按现有 `DistrictBlock.tsx:88-111` 的模式加载纹理：

```tsx
useEffect(() => {
  if (!url) return;
  let disposed = false;
  const loader = new THREE.TextureLoader();
  loader.load(
    url,
    (tex) => {
      if (disposed) { tex.dispose(); return; }
      tex.colorSpace = THREE.SRGBColorSpace;
      tex.wrapS = tex.wrapT = THREE.RepeatWrapping;   // 路面/立面平铺用
      tex.repeat.set(repeatX, repeatY);
      setTexture(tex);
    },
    undefined,
    () => { /* onError: 保持 null → 兜底 */ }
  );
  return () => { disposed = true; };
}, [url, repeatX, repeatY]);
```

### 2.3 纹理共享与内存

- 同一张贴图被多个 mesh 引用时，`THREE.TextureLoader` 默认不缓存（每次 `load` 都是新实例）。
- **P1-C 阶段优化**：若某张贴图出现 ≥ 4 次复用，提取到 module-level `useTexture` 共享缓存（参考 R3F 文档的 `useTexture.preload`）。
- 共享纹理占内存仅 1 份；非共享按 mesh 数累加。

### 2.4 纹理 dispose 策略

- 组件 unmount → `disposed = true` flag 防止 setState on unmounted。
- `tex.dispose()` 仅在 disposed 后仍被 loader 返回的孤儿纹理上调用（避免内存泄漏）。
- 当前代码已采用此模式（DistrictBlock:90-95）。

## 3. Mesh 预算与贴图内存预算

### 3.1 Mesh 预算表

| 类别 | 当前 (v1) | 升级 (v2) | 备注 |
|------|-----------|-----------|------|
| Ground | 2 (plane + gridHelper) | 1 (plane only) | gridHelper 删除 |
| District plates | 8 | 8 | 不变 |
| District buildings | ~48 (8 × ~6) | ~48 (复用) | mesh 数不变，材质升级为 6 面贴图 |
| District rings (hover/select) | 8 | 8 | 不变 |
| Roads (main plane) | 7 | 7 × 4 = 28 | Road 拆 4 层（车道+中线+两侧人行道） |
| Street props (lamps, trees) | 0 | ~40 | 8 城区 × ~5 |
| Street props (vehicles, signs) | 0 | ~20 | 主干道沿线 |
| Tokens | ~12 | ~12 | 不变 |
| CameraReporter / FocusController | 0 (返回 null) | 0 | 不变 |
| **合计** | **~85** | **~165** | 远低于 250 上限 |

### 3.2 贴图内存预算（按 1024×1024 RGBA = 4 MB 估）

| 类别 | 数量 | 内存 |
|------|-----|------|
| 城区俯视底板 (existing) | 8 × 1024² | 32 MB |
| 城区立面 facade | 16 × 512×1024 | 16 MB |
| 城区屋顶 roof | 8 × 512×512 | 8 MB |
| 街道贴图 | 6 × ~512² | ~6 MB |
| 街景道具贴图 | 17 × ~256²-384² | ~6 MB |
| **合计** | — | **~68 MB** |

> **68 MB > 24 MB 计划上限**，需在 P2 阶段优化：
> - 城区俯视底板缩到 512×512（4 MB × 8 = 32 MB，节省 16 MB）；
> - 立面贴图缩到 256×512（节省 8 MB）；
> - 共降至 ~44 MB。
>
> 或：在 Chrome DevTools Memory 面板实测后再决定是否降级（实际 R3F 纹理以压缩 GPU 格式存储，CPU 端占用小）。

### 3.3 性能护栏

- **prop 默认 `castShadow={false}`**（仅 `Tree` 保留 castShadow，因为树影是城市真实感的重要组成）。
- **地面 `receiveShadow`** 不变。
- **建筑 `castShadow={true}`** 不变（楼栋是阴影主投射物）。
- 阴影贴图保持 1024² 不升（已足够覆盖 40×40 区域）。
- DPR 维持 `[1, 2]`，低端机降级 1（已支持）。

## 4. 阴影、雾、灯光调整

### 4.1 灯光调整

```tsx
// v1
<ambientLight intensity={0.7} />
<directionalLight castShadow position={[10,16,8]} intensity={1.15} shadow-mapSize-width={1024} shadow-mapSize-height={1024} />

// v2（追加 hemisphereLight 提供天/地反弹，不动 directional / ambient 数值）
<hemisphereLight args={['#7a93b8', '#1a1f2a', 0.35]} />
```

`hemisphereLight` 不投阴影，只为整体氛围补光。

### 4.2 Fog（新增）

```tsx
<fog attach="fog" args={['#0b0f16', 28, 60]} />
```

- `near=28` 距离相机 28 单位开始雾化。
- `far=60` 距离 60 单位完全融入背景色。
- 颜色 `#0b0f16` 与 `<color attach="background" />` 一致，保证远景自然消失。

### 4.3 不动的部分

- `OrbitControls`（maxPolarAngle / minDistance / maxDistance / target）。
- `CameraReporter` / `FocusController`（每帧 viewRef 覆写）。
- Token lerp 速度（0.06）。
- hover 卡距离因子（distanceFactor={16}）。

## 5. 降级策略

### 5.1 资产缺失降级矩阵

| 资产 | 缺失时回退 | 视觉效果 |
|------|----------|---------|
| `districts/<id>.png` | 纯色 `#def.color` | 城区底板无贴图（与原 v1 相同） |
| `facades/<id>_<variant>.png` | 纯色 + emissive | 楼栋侧面无窗/门，仅有主色 |
| `roofs/<id>.png` | 纯色 | 楼顶与侧面同色（接近 v1） |
| `streets/asphalt_main.png` | 纯色 `#1f2733` | 主干道路面无沥青纹理 |
| `streets/asphalt_side.png` | 纯色 `#252e3a` | 次干道路面无纹理 |
| `streets/sidewalk_*.png` | 浅灰纯色 `#2a3340` | 人行道无颗粒 |
| `streets/crosswalk.png` | 跳过绘制 | 不出现斑马线（路仍可用） |
| `streets/centerline.png` | 跳过绘制 | 不出现中央线 |
| `props/streetlamp/*.png` | pole + lamp head 用纯色几何体 | 路灯无贴图 |
| `props/tree/*.png` | 棕圆柱 + 绿球 | 树退化为简单几何 |
| `props/vehicle/*.png` | 小盒子 + 主色 | 车辆退化为小色块 |
| `props/pedestrian/*.png` | 跳过绘制 | 无行人（视觉最弱） |
| `props/sign/*.png` | 小色板 + pole | 标识牌无图案 |
| `props/rooftop/*.png` | 小盒子 + 灰色 | 屋顶杂物退化为色块 |

### 5.2 渲染不崩保证

- 所有贴图 URL 缺失返回 `''`，组件内 `if (!url) return null` 或回退几何。
- `useEffect` 内的 `loader.load` 即使网络失败也仅 `onError` 静默（保持 `tex=null`），不抛错。
- `import.meta.glob` 在构建时静态解析，缺失文件不报错。

### 5.3 R3F 极端低端机降级（CLAUDE.md §13 P2）

- 检测 `navigator.deviceMemory < 4` 或 `hardwareConcurrency < 4` → DPR 强制 1，prop 全 castShadow=false。
- 暂不在 P1 阶段实现（与 v1 行为对齐）。
