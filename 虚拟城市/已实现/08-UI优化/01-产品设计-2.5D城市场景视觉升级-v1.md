## 1. 现状问题清单

| # | 问题 | 现状代码 | 玩家主观感受 |
|---|------|---------|------------|
| 1 | **地面"黑线"** | `WealthCityMap.tsx:56` `<gridHelper args={[40, 20, '#2a3342', '#1d2530']}>` — 40×40 地面被 20×20 网格线（每 2 单位一根）切碎，且会穿过 8 个城区底板 | "地图像棋盘"、"网格太密了" |
| 2 | **楼宇纯色** | `DistrictBlock.tsx:158-176` `boxGeometry` + `meshStandardMaterial color={def.color}` | "楼都是色块"、"分不清哪个区是哪个区" |
| 3 | **道路纯色** | `WealthCityMap.tsx:62-89` 7 条路全是 0.8 宽 `#232b38` plane | "没有街道"、"路面像水泥" |
| 4 | **没有街道道具** | 整个场景只有 ground + 8 区 + 7 路 + token | "城市太空"、"不像真的城" |
| 5 | **楼顶没有变化** | 顶面与侧面同色（实际是 box 的同一个材质） | "楼都是平顶方块" |

### 截图级现状描述
- 俯视 45° 角看上去是一张深色 40×40 平面 + 8 个圆角色块（每个色块代表一个城区）。
- 城区内有 4-6 个稍微凸起的同色 box（高矮不一 = 房价指数映射）。
- 城区之间是 7 条深色细条（道路）。
- 整个画面没有路灯、树、车、行人、路面标识。
- 地面有规则的灰色横竖线穿过所有城区。

## 2. 升级目标与风格关键词

### 2.1 三个核心目标

1. **消除"棋盘感"** — 黑线消失，地面呈现真实沥青质感。
2. **楼宇可识别** — 立面有窗、门、纹理；屋顶有瓦片/设备；金融 CBD vs 老城区 一眼可分。
3. **街道真实感** — 主干道有人行道、车道线、斑马线、路灯；商业区沿街有树；移动车辆增加生气。

### 2.2 风格关键词

| 关键词 | 中文释义 | 视觉表现 |
|--------|---------|---------|
| `low-poly stylized` | 低多边形风格化 | 楼栋为简单几何体但有贴图细节 |
| `warm cohesive palette` | 暖色统一调色板 | 8 城区虽有主色差异但都在暖色域 |
| `cel shading` | 卡通明暗 | 阴影边界清晰，无渐变软阴影 |
| `isometric three-quarter view` | 等距三分之四视角 | 与现有相机角度一致（45° 俯视） |
| `modern Chinese urban scene` | 现代中国城市景观 | 借鉴上海陆家嘴 + 北京胡同混搭 |

### 2.3 与现有视觉风格的延续

- 整体仍保持「Q 版游戏感」（既不是写实也不是抽象极简）。
- 暗色主题（`.wealth-bg #10151d`）保持不变，资产在暗背景下呈现。
- Token 圆柱 + 名牌样式保持不变（不在本期改动范围）。
- 周期色（recovery/boom/recession/depression）的 4 个徽章色 + 楼栋高度映射保持不变。

## 3. UI mockup（文字描述）

### 3.1 整体俯视（默认相机）

```
  [科技园]————[金融CBD]————[商业中心]
       |          ★          |
       |       (玻璃幕墙)     |
       |          ★          |
  [工业区]——————*——————[滨河新区]
       |       (沥青路面)     |
       |          ★          |
       |       (移动车辆)     |
  [老城区]————[居住区]————[郊区]
                 |
              (人行道+树)
```

- **地面**：深沥青色（#1f2733），没有可见网格线。
- **主干道**：宽 1.2，含中央虚线（centerline.png 平铺）。
- **次干道**：宽 0.8，单实线。
- **每条路两侧**：人行道（比车道略高 0.02）。
- **每条路沿线**：每 2.5 单位一根路灯（pole + 灯头 + 微光晕）。
- **每城区周围**：2 棵树 + 1 根路灯 + 1-2 件楼顶杂物。

### 3.2 镜头放大到金融 CBD（zoom in）

- 视角：相机距离 8，原点 → finance (0,0)。
- 可见 4-6 栋玻璃幕墙高楼（蓝色调）整齐排列。
- 立面有 5-7 行窗户（横向 repeat 平铺）。
- 顶部是深蓝色屋顶，偶有 AC 外机轮廓。
- 主干道上有 1 辆移动的出租车（sedan 俯视 sprite）。

### 3.3 镜头切到老城区

- 视角：相机距离 10，原点 → oldtown (2, -12)。
- 4-6 栋灰色瓦顶两层小楼（砖黄主色），立面有木质窗格。
- 屋顶是斜顶瓦片纹理。
- 街边有 2 棵阔叶树，1 个行人 sprite。
- 道路比金融区窄，路面仍有沥青质感但颜色偏暖灰。

### 3.4 hover 信息卡

无变化：复用现有 `.wealth-district-card`（区名 / 房价 / 月租 / β / 在区玩家数）。
街景道具不参与 hover。

### 4.1 唯一新增的视觉：图例 (legend)

- 位置：地图右下角（绝对定位 div，`.wealth-city-prop-legend`）。
- 内容：4 行，每行一个色块 + 名称（路灯 / 树 / 车辆 / 行人）。
- 名称语言：复用 `wealth.map.legend.lamp/tree/vehicle/pedestrian`（**本设计文档先列出，落地时通过讨论决定是否真正引入 i18n 键**；最低风险路径是首版只用 emoji + 中文硬编码）。

## 5. 玩家可感知的验收清单

### 5.1 黑线消失
- [ ] 默认相机下，地面没有可见网格线穿过城区底板。
- [ ] 在最低 DPR（1.0）下也没有可见锯齿状的网格。

### 5.2 楼宇贴图
- [ ] 8 城区楼栋立面有窗户 / 门 / 招牌细节。
- [ ] 屋顶与侧面纹理不一致（屋顶是瓦片/平台，立面是墙体）。
- [ ] 资产缺失 → 楼栋回退纯色（保留 `emissive` 暖光），**不崩**。

### 5.3 道路贴图
- [ ] 主干道中心有白色虚线或黄色实线（centerline）。
- [ ] 道路两侧有比车道略高的人行道。
- [ ] 路面有沥青纹理（不是纯色）。
- [ ] 7 条路各有独立的「from → to」路径，从 finance(0,0) 辐射出去。

### 5.4 街道道具
- [ ] 每个城区周围有 ≥ 2 棵树 + 1 根路灯。
- [ ] 主干道沿线有路灯（每 2.5 单位 1 根）。
- [ ] 至少 3 条主干道上有移动车辆（轿车 / 公交 / 出租车）。
- [ ] 至少 2 个城区有 1 个行人 sprite。
- [ ] 楼顶有 ≥ 1 个 AC / 水塔 / 天线。

### 5.5 性能与稳定性
- [ ] Chrome 桌面：单帧 ≤ 16 ms（Performance 面板）。
- [ ] 中端 Android：单帧 ≤ 33 ms（dpr=1 兜底）。
- [ ] 删除任一资产 PNG → 视觉降级到对应兜底（不崩）。
- [ ] `npm run build` 通过；`tsc --noEmit` 干净。

### 5.6 对比度与可达性
- [ ] 图例文字与背景对比度 ≥ 4.5:1（CLAUDE.md §26）。
- [ ] hover 卡文字不变（已满足）。
- [ ] 暗色主题下 props 在弱光环境仍可识别（emissive 辅助）。

### 5.7 交互回归
- [ ] 选中描边（ring）仍可见，未被贴图覆盖。
- [ ] Hover 信息卡弹出/消失正常。
- [ ] 小地图视野框跟随相机移动。
- [ ] 点击小地图 / 面板 → 相机平滑聚焦。
- [ ] Token lerp 动画仍 1s 到位。
