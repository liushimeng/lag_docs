## 2. 架构总览（数据流）

```
真实金融网站 → go-web-debug-tool → citychrome.FeedStore（批次 65）
                                        │  Feed() / Snapshot() 纯内存读
                                        ▼
                        main.go 装配层 adapter（唯一 import 两侧的位置）
                          Feed → []virtual_city.ExoQuote（中性结构）
                                        │  Manager.SetExoSource(fn)
                                        ▼
              game/virtual_city/exogenous.go（纯函数，无 IO，不 import citychrome）
                ComputeExoSignal(quotes, now) → ExoSignal{Sentiment, StockBias,
                                                    GoldBias, Active, Source}
                                        │  trySettle 锁内 refreshExoLocked()
                                        ▼
              MarketState.MonthStep：stock/gold 漂移 += 偏置（inactive ⇒ +0.0）
                                        │
                ┌───────────────────────┼──────────────────────────┐
                ▼                       ▼                          ▼
        view.go market.exo_anchor   game.month.market_changes   vcplayer prompt
        （game.state 全量）          .exo_sentiment               「■ 外盘情绪锚」
                ▼                       ▼                          ▼
        MarketPanel 锚行 +          MonthTicker（可选展示）      居民月度决策参考
        RealtimeBoard 总览锚卡
```

**关键决策**：
1. **引擎纯度**：`game/virtual_city` 不 import `citychrome`；`ExoSource func() []ExoQuote`
   依赖反转注入（同 `SetLinePoolSource`/`SetSeatHydrator` 范式）。Feed→ExoQuote 的
   映射 adapter 放 **main.go 装配层**（两侧都已 import，零环）。
2. **微偏置而非主导**：锚只给 ±0.3%（股票）/±0.2%（黄金）月漂移封顶——真实行情是
   「锚」不是「驱动」；游戏内周期仍由 PhaseTable + 批次 62 泡沫反身性主导。
3. **零回归硬契约**：`Active=false`（通道离线/数据过期/空 feed）⇒ `StockBias=GoldBias=0.0`
   ⇒ MonthStep 浮点表达式逐位一致（偏置项以独立加法项 `+ bias` 形式插入，`x+0.0` IEEE
   恒等；**不得**消费额外 RNG 调用，防固定 seed 流偏移）。
4. **确定性**：`ComputeExoSignal` 无随机、无时钟依赖（`now` 作入参）、同输入同输出，
   可全量单测。行情数据本身有噪声——情绪分用 `tanh` 饱和，抗单票极端值。
5. **prompt 口径修正**：批次 65 写死的「真实数据…不影响游戏内市场机制」改为
   「真实行情每月以微弱偏置锚定游戏内股票/黄金（±0.3% 封顶），其余机制不受影响」。

## 3. 后端设计

### 3.1 新文件 `ServerGo/game/virtual_city/exogenous.go`（纯函数）

```go
// ExoQuote 中性真实报价（装配层从 citychrome.Feed 映射；引擎不感知来源）。
type ExoQuote struct {
    Category   string  // "a_share"|"hk"|"us"|"metal"|"crypto"
    ChangePct  float64 // 百分数口径（0.82 = 0.82%），同批次 65 契约
    UpdatedAt  int64   // Unix 秒
}

// ExoSignal 外盘情绪锚（SettleMonth ④ 市场漂移消费）。
type ExoSignal struct {
    Sentiment  float64 // [-1,+1] 风险偏好分（tanh 饱和）
    StockBias  float64 // 月漂移加法项，封顶 ±0.003（±0.3%）
    GoldBias   float64 // 月漂移加法项，封顶 ±0.002；与 Sentiment 反向（避险）
    Active     bool    // false ⇒ 两 bias 恒 0.0（零回归）
    Source     string  // "真实外盘" 展示口径
    UpdatedAt  int64   // 参与计算的最新报价时间
}

func ComputeExoSignal(quotes []ExoQuote, now int64) ExoSignal
```

**情绪分公式**（确定性，写死常量于文件顶部）：

```
eqAvg  = mean(change_pct of a_share/hk/us 各类目均值)   // 缺类目跳过，≥1 个才参与
riskAvg = mean(change_pct of crypto)                     // 风险偏好
goldAvg = mean(change_pct of metal)                      // 避险反向

Sentiment = clamp(tanh( (0.60*eqAvg + 0.25*riskAvg - 0.15*goldAvg) / 2.2 ), -1, +1)
StockBias = Sentiment * 0.003
GoldBias  = -Sentiment * 0.002      // 真实风险避险 ⇒ 游戏黄金反向微动
```

**Active 判定**：全部报价 `UpdatedAt` 过期（`now - updated_at > 72h`）或 quotes 为空 ⇒
`Active=false`（两 bias 精确 0.0）。类目缺省只降权不置 inactive（如 crypto mission 未
完成时仅用股票类目）。

### 3.2 `MarketState` 扩展（market.go）

```go
// 批次66 外盘情绪锚（exogenous.go 计算；inactive ⇒ 0.0 零回归）。
StockExoBias float64 `json:"stock_exo_bias"`
GoldExoBias  float64 `json:"gold_exo_bias"`
```

`MonthStep` 唯一改动点（表达式形态受零回归契约约束）：

```go
// 改前: raw := oldIdx * (1 + p.StockAnnual/12*mult + extra + σN)
raw := oldIdx * (1 + p.StockAnnual/12*mult + extra + m.StockExoBias + σN)
// 改前: m.GoldPrice *= 1 + p.GoldAnnual/12 + σN
m.GoldPrice *= 1 + p.GoldAnnual/12 + m.GoldExoBias + σN
```

⚠️ 与批次 62 `applyBubbleDrift` 的关系：bubble 每月**覆写** `DriftMultiplier/DriftExtra`，
外盘锚用**独立字段**，不参与覆写链（bubble 内生、外盘外生，语义正交）。
房指数不吃外盘锚（房产是本地市场，真实感口径）。

## 5. 验收标准（可判定）

1. `go build` + `go test ./...` 零 FAIL。新增单测：
   - `ComputeExoSignal`：空/过期 ⇒ Active=false 且 bias==0.0（精确）；符号映射
     （股票涨 ⇒ StockBias>0、GoldBias<0）；tanh 饱和与封顶（极端 change_pct 不出界）；
     缺类目降权路径。
   - **零回归**：固定 seed 两次 `MonthStep`——一次 `StockExoBias=0`，一次走
     `ComputeExoSignal(nil)`——逐位相等；再验 bias=+0.001 时股票漂移严格高于 0 基线。
   - `trySettle` 注入链：SetExoSource 返回报价 ⇒ 月结后 `SettleResult.ExoSentiment` 有值；
     返回 nil ⇒ 全零。
   - prompt：`ExoBrief` 非空含「外盘情绪锚」；空串整段省略。
   - config `market_linkage_enabled=false` ⇒ 全零（运维回退路径）。
2. `tsc --noEmit` + `npm run build` 通过。

## 6. 风险与回退

| 风险 | 缓解 |
|---|---|
| 固定 seed 存量对局被外盘扰动 | bias 独立加法项 + inactive 恒 0.0；存量房 ExoSource 可 nil |
| 外盘噪声盖过游戏内周期 | 封顶 ±0.3%/月 ≪ PhaseTable 年化/12 与批次 62 覆写量级 |
| Feed 冷启动无数据 | Active=false ⇒ prompt 段省略、前端灰卡，看板已有「采集中」范式 |
| 锁内读 ExoSource 潜在死锁 | 契约：ExoSource 必须纯内存快照、禁止回调房间；main.go adapter 仅读 FeedStore.Snapshot |
| 运维想关 | `city_chrome.market_linkage_enabled=false` 一键回退全零 |
