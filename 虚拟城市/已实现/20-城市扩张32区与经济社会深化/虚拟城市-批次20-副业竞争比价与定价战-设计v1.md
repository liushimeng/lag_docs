## 1. 机制总览

每位焦点居民的副业（delivery 跑腿配送 / content 内容创作 / tutoring 家教 / freelance 自由接单）
新增**定价档位**选择；同一品类有多名经营者时按**客群份额**切分市场收入：

```
档位 t ∈ {低价 Low, 中价 Mid, 高价 High}
客群权重 w(t) = {低价 0.50, 中价 0.30, 高价 0.20}   ← 低价档覆盖最大客群（§8.4 50/30/20）
收入乘数 m(t) = {低价 0.75, 中价 1.00, 高价 1.25}   ← §8.3 收入区间中值比（跑腿 2000/2750/3500 ≈ 0.73/1/1.27，取整）

同品类经营者集合 O_k（存活 + SideBusiness.Kind==k）：
份额 s_i = w(t_i) / Σ_{j∈O_k} w(t_j)          ← 归一化：独占 = 1.0（无竞争不惩罚）
月副业收入 = round( BaseIncome × m(t_i) × s_i × BrassSideFactor × variance )
variance = 0.85 + rand×0.3                     ← 保持既有分布，rand 消耗次数不变（零偏移）
```

**囚徒困境验证锚点**（n=2，写进单测表）：

| 我方\对方 | 中价 | 低价 |
|---|---|---|
| 中价 | 各 0.50×Base | 我 0.375 / 对方 0.469 |
| 低价 | 我 0.469 / 对方 0.375 | 各 0.375×Base |

- 双低 0.375 < 双中 0.50 → **集体降价集体受损**（§8.4「所有人都降价则所有人都赚得少」✅）；
- 对手降价时我守中(0.375)=我跟进(0.375)——跟进不改善、单方面守中也不吃亏 →
  「中价」是弱占优协调点；被拖入价格战后**双方都回不到 0.50 除非协调回中价**（协调失败型价格战，教育价值同构）；
- 高价是「利基策略」：对手中价时切高价 → Σw=0.3+0.2=0.5，我方份额 0.2/0.5=0.4，实收 1.25×0.4=0.50
  ——与守中持平（不亏但无超额利润）；对手也升高价时 Σ=0.4、s=0.5、实收 0.625 > 双中 0.50 →
  「差异化共谋高价最优、但单方面被低价方蚕食」的紧张感保留 ✅。

> 📝 勘误（实施回填）：初稿「对手中价切高价 0.3125（Σ=0.8）」把低+中的权重和误代入高+中组合，
> 正确算例如上（BE-2 实施时按规范公式 s=w/Σw 实现并回检出本处，公式与四象限表本身无误）。
> 博弈定性由「囚徒困境」修正为「协调失败型价格战」：背叛不严格占优，但集体降价仍集体受损。

**档位规则（§8.3 裁剪，全部确定性）**：

| 品类 | 高价档约束 |
|---|---|
| delivery | 高价 → 每月额外精力 -1（体力透支，settlement 内扣） |
| content | 高价 且 Cognition<3 → 收入 ×0.5（涨粉慢，月结内乘，不拒绝定价） |
| tutoring / freelance | 高价要求 Cognition ≥ def.GateCognition+1，否则动作拒绝 |
| 全部 | 低价档无门槛；档位切换每月≤1 次（同月二次 set_side_price 拒绝） |

// player.go SideBusiness 扩展（追加字段，JSON 兼容旧档）

func sideMarketShares(w *World) map[string]map[int]float64 // kind → seat → s_i

**中价默认 = 旧行为**：全员 PriceTier 零值(中价)、无竞争(s=1)、m=1 → 公式退化为
`Base×BrassSide×variance`，与 `settlement.go:368-377` 现状逐分不差（回归零偏移硬约束）。
