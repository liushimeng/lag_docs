# A. 市长选举启用（中等 · 引擎已完备，补「接线」与「可见」）

`civic_election.go`（199 行，阶段 8）引擎完整：30/40/30 得票模型、48 月一届、市长津贴

# B. 股票交易微观结构（中等 · N17-1..4 四件套）

## B1. 范围与动机

真实金融系统需求（限价体系/换手限制/熔断是 A 股基础设施）。作用域 = **stock_index 资产一类**，
不影响 gold/bond/fund/可转债既有路径。全部确定性或既有 rand 通道，无新增 rand 消耗。

## B2. 四机制数值契约（新文件 `ServerGo/game/wealth/market_microstructure.go`，纯函数+状态小改）

### B2-1 涨跌停板（±10%）

`market.go:135` 月度指数更新尾部追加 clamp：

```
Δ = newIdx/oldIdx − 1；|Δ|>0.10 → newIdx = oldIdx × (1 ± 0.10)（保号截断）
```

下限 0.01 兜底保留。历史 seed 对局：现 σ 月波动 p99 <10%，预期绝大多数零偏移，
但**不承诺逐分不差**（政策类变更），在验收里以「统计带内」断言替代（同批次 11 处理先例）。

### B2-2 买卖价差（bid/ask spread，按市场阶段）

| 阶段 | 价差 |
|---|---|
| overheated 过热 | 0.20% |
| expansion 扩张 | 0.04%（取流动性最好） |
| recession 衰退 | 0.08% |
| panic 恐慌 | 0.15% |

```
买价 unitBuy  = idx × (1 + sp/2)（每股份 1 元面值口径下 = 单价上浮）
卖价 unitSell = idx × (1 − sp/2)
```

`actBuyAsset/actSellAsset` 的 stock_index 分支改用新价（helper：
`w.Market.StockBuyUnit()/StockSellUnit()`）；Agent 工具与前端报价同步展示双边价。
价差计入成交成本语义，**Ledger 金额=实付/实收**，不新增科目。

### B2-3 T+1（月度节拍下的「当日」= 当月）

```go
// player.go 追加：
StockT1Locked int64 // 当月新买入份数（卖出冻结量）
// 买入：units 记入 StockT1Locked；月末 settlement 开头清零（新月解冻）
// 卖出：可卖量 = 持仓 − StockT1Locked；不足 → 35044
```

- 语义：当月买入不可当月卖出（T+1 在月粒度模拟下的投影），文档注释写明投影口径；
- 既有资产转让（listing 侧股票过户）不受 T+1 约束（挂牌成交视既月持仓转移）——评审点，先按「受约束」实现，
  卖家可卖量同样扣 T1（更严格更安全）。

### B2-4 熔断（月度跌幅 ≥15%）

```
月结涨跌停 clamp 前取原始 Δ_raw：Δ_raw ≤ −0.15 → World.Market.BreakerUntilMonth = w.Month+1
（下全月禁买禁卖 stock_index，event：「熔断：指数单月下跌 x%，全市场股票交易暂停 1 个月」）
```

- 熔断期内 buy/sell stock_index → `35043`；其它资产不受影响；
- 同月重复触发只延长不叠加；到期自动解禁（比较 `w.Month > BreakerUntilMonth` 口径：
  `BreakerUntilMonth` 存「最后一个禁止月」）。
