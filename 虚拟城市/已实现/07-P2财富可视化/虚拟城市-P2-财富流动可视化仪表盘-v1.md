## 3. 核心算法

### 3.1 基尼系数计算

```go
// ComputeGini 计算基尼系数。
// 公式: G = (2 * Σ(i * y_i)) / (n * Σ(y_i)) - (n + 1) / n
// 其中 y_i 为排序后的个体财富，i 为排名(1-based)
func ComputeGini(wealths []int64) float64 {
    if len(wealths) == 0 {
        return 0
    }
    sort.Slice(wealths, func(i, j int) bool { return wealths[i] < wealths[j] })
    n := float64(len(wealths))
    var sumY, sumIY float64
    for i, w := range wealths {
        sumY += float64(w)
        sumIY += float64(i+1) * float64(w)
    }
    if sumY == 0 {
        return 0
    }
    return (2*sumIY)/(n*sumY) - (n+1)/n
}
```

### 3.2 洛伦兹曲线

```go
// ComputeLorenzCurve 计算洛伦兹曲线点集。
// 返回 [{人口累计比例, 财富累计比例}, ...]
func ComputeLorenzCurve(wealths []int64) [][2]float64 {
    sort.Slice(wealths, func(i, j int) bool { return wealths[i] < wealths[j] })
    total := int64(0)
    for _, w := range wealths {
        total += w
    }
    points := make([][2]float64, len(wealths)+1)
    points[0] = [2]float64{0, 0}
    cumW := int64(0)
    for i, w := range wealths {
        cumW += w
        points[i+1] = [2]float64{
            float64(i+1) / float64(len(wealths)),
            float64(cumW) / float64(total),
        }
    }
    return points
}
```

### 3.3 财富金字塔

```go
// ComputeWealthPyramid 计算财富金字塔。
// 分层: 生存圈(<50万) / 积累圈(50-200万) / 自由圈(>200万)
func ComputeWealthPyramid(players []*Player, market *MarketState) []WealthLayer {
    layers := []WealthLayer{
        {Name: "生存圈", Count: 0, TotalWealth: 0},
        {Name: "积累圈", Count: 0, TotalWealth: 0},
        {Name: "自由圈", Count: 0, TotalWealth: 0},
    }
    thresholds := []int64{500000, 2000000}
    var total int64
    for _, p := range players {
        if p == nil || !p.Alive {
            continue
        }
        nw := p.NetWorth(market)
        total += nw
        idx := 0
        if nw >= thresholds[0] {
            idx = 1
        }
        if nw >= thresholds[1] {
            idx = 2
        }
        layers[idx].Count++
        layers[idx].TotalWealth += nw
    }
    for i := range layers {
        if total > 0 {
            layers[i].WealthPct = float64(layers[i].TotalWealth) / float64(total)
        }
        if layers[i].Count > 0 {
            layers[i].AvgWealth = layers[i].TotalWealth / int64(layers[i].Count)
        }
    }
    return layers
}
```

#### 13.2.5 性能预算（§10.2 强化）

- `ComputeSociety` 包含 12 玩家排序: O(n log n) ≤ 12×log12 ≈ 40 比较,< 1µs。
- `RecordFlowStat` 扫本月 Ledger ≤ 100 条(12 玩家每月流水上限),< 50µs。
- JSON 序列化 LorenzPoints 12+1=13 点 × 2 浮点 = ~300 字节,可忽略。
- 月结总开销增加 < 0.1ms,**对 month_ms 不构成可见影响**。
