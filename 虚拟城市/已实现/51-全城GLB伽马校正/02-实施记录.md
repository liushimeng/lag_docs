## 3. 核心校验（V5）与出图判读（V6）

### 3.1 逐材质断言：`new == srgb_to_linear(old)`

重导前先 `cp -r ClientWeb/src/assets/models /tmp/glb_backup`，重导后**逐材质**
把库中 `baseColorFactor` 与备份的 `srgb_to_linear(备份值)` 比对（容差 2e-3）：

```
✔ 线性化正确: 529 个材质槽
✗ 不匹配: 0
? 新增材质（旧无）: 0
```

**529/529 精确命中，0 不匹配，0 新增** —— 这是本批最硬的一条判据：
它证明换算既**没有漏**（没有哪个材质还留着 sRGB）也**没有过头**
（没有哪个材质被换算两次）。

### 3.2 出图判读：改造前 / 改造后并排

## 5. 本批的三个工程教训

### 5.1 「跨 N 批次的欠账」需要一个**必须重跑全量**的理由才会被偿还

gamma 缺陷从批次 44 发现到批次 51 偿还，跨了 **6 个批次**。它挂着的三个原因
（方案 §1.5）都不是技术难度，而是**没有触发器**：
「改一处要重导 72 件 + 重判 6 个批次的出图」听起来就不划算，于是每批都
诚实地把它登记进遗留表，然后继续做别的。

真正让它落地的不是决心，而是**批次 50 顺手把 `CITY_PALETTE` 扩到了 11 个族的
新语义键、全城模型数从 69 涨到 72**，使得「全量重导」这件事第一次有了一个
具体、可预算、可固化成脚本的形状（`reexport_all_glb.sh`）。

> 判据：遇到「改了会有全局连锁反应」的欠账时，
> **先找出能触发全量重做的那件事，把它排进队列** ——
> 长期欠账不会因为「记下来了」而消失，只会因为「终于有事要动全量」而被顺手偿还。

### 5.2 一个**只存在于资产、没进脚本**的修正，是一颗定时炸弹

`nature/oak_tree.glb` 的直立修正在批次 29 落地，但**只改了资产、没改生成器**。
它在库里躺了 20 多个批次没人发现，直到某个必须重跑全量的操作把它炸出来。

如果当时没有 `verify_glb_aabb.py`（或它没有「直立/贴地/尺寸」这三条判据），
这次重导会把一个**已经正确的资产悄悄替换成错的** —— 而 git diff 只会显示
「二进制文件变更」，评审时看不出任何东西。

处置：本批至少把旧脚本标注废弃 + 把正确路由写进重导驱动。
但根治要加**「脚本可复现性」判据**（重跑脚本 → 比对包围盒），
代价是每次门禁跑 N 次 Blender（72 件 × 约 5 s ≈ 6 min），见 §6 L1。

### 5.3 换算必须收敛到**一个函数**，不能散在 72 个脚本里

`srgb_to_linear` 加在 `_hex_to_rgb`（唯一被 `make_material` 调用的换算入口）里，
于是**72 个生成器一行未改**。如果当初把换算写进每个 build 脚本的
`make_material` 调用点，就要改 72 处、且以后每加一个新脚本都会成为
「忘了换算」的新缺口。

同时 `_hex_to_rgb(hex, linear=False)` 保留了取原始 sRGB 的能力，
供「明确知道自己要 sRGB」的诊断脚本使用 —— 换算不是不可逆的。

## 6. CDP 实机验收（V7–V8）

| 项 | 结果 |
|---|---|
| 城市日景 | ✅ 对比度正常：楼顶是深色沥青瓦、树冠是饱和秋金、红瓦坡屋顶是深赭 —— 不再有「整城惨白」 |
| 城市夜景 | ✅ 楼体压暗、窗灯暖黄、街灯光锥清晰；**夜景没有因 emissive 线性化而塌一层** |
| 车站夜景 | ✅ `RailStation_Sign` 蓝色站名牌、站台灯、出入口塔均清晰可辨 |
| 自发光材质 | ✅ 13 个全部在场景中，emissive 值 = `线性色 × 强度`，与 `srgb_to_linear` 口径自洽 |
| DC | 日 948 / 夜 998（本批**不涉及几何**，DC 不应变化，实测与批次 50 同量级） |

**关于「夜景是否被压暗」**：13 个自发光材质里最深色的几个
（`RailStation_Sign` 蓝 0.003/0.020/0.083、`HeliPad_TLOF_Green` 绿 0.014/0.302/0.083）
换算后确实暗了 3~4 倍，但**实机夜景判读通过** —— 因为它们靠
`emissiveIntensity` 1.5~3.0 拉起来，而底色本身很暗、乘完仍落在可见范围。
**故本批不调任何 `litMaterials` 目标值**（批次 41~50 调的值继续有效）。
