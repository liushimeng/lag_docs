## 1. 一句话摘要

新增 `PolicyToolbox`：央行**六件套**货币政策工具（SLF / MLF / 降准 / 升准 / OMO / 信贷窗口指导），每件工具直接改写 `World.CB` 状态、追加 12 月滚动历史、并经 `w.emitEvent("policy", -1, ...)` 向全房播报。纯引擎层（§92a 无锁、无 goroutine、无 IO）。

**定位边界**：本阶段工具箱**仅供引擎层调用与单测验证**；央行行长 Bot（`AgentClassCityBanker`）基于菲利普斯曲线输出驱动工具箱的完整决策链是**阶段 4+ 待办**（`policy_toolbox.go` 头注释 L8–9 原文）。

## 2. 设计动机

P1 央行引擎（`central_bank.go`）的 `MonthlyDecision` 步骤 f 只有「±25bp 调政策利率」一件工具、步骤 i 只有固定 ±5 万的 OMO。阶段 3 把工具面扩展到真实央行六件套，为阶段 4 的 LLM 央行行长（读宏观 → 选工具 → 定幅度 → 写公告）提供受参数约束的执行原语——Bot 只能通过本工具箱动央行状态，不能裸改字段。

## 5. `ApplyInstrument` 主入口（L128–165）

```
ApplyInstrument(w *World, act PolicyAction) error
  ├─ nil 守卫: tb/tb.CB/w/w.CB 任一 nil → error（L129–134）
  ├─ switch act.Instrument 派发到 applySLF / applyMLF / applyRRR / applyOMO / applyCreditWindow
  │   └─ 未知工具 → "unknown instrument" error（L152–153）
  ├─ History 追加 + 裁剪到最近 12 月（L157–160）
  └─ w.emitEvent("policy", -1, "央行[<工具>|<倾向>] <描述>")（L163，全房事件 seat=-1）
```

返回 error 仅用于参数非法（nil、未知工具、RRR 步长为零）；正常操作总是成功并播报。

## 6. 六件工具实现细节

### 6.1 `applySLF`（L168–175）

`SLFRate = clamp(PolicyRate + 0.5% + Magnitude, PolicyRate, PolicyRate + 2%)`。走廊上限永远 ≥ 政策利率，抬升幅度受 `SLFMarkupMax` 约束。

### 6.2 `applyMLF`（L179–189）

- `PolicyRate = clamp(old + Magnitude, 0.5%, 10%)`；
- 联动再贴现：`RediscountRate = PolicyRate + 0.5%`；
- 联动走廊：`SLFRate < PolicyRate` 时重置为 `PolicyRate + SLFCorridorWidth`（走廊上限不得低于锚）；
- 返回描述直接拼出 `LPR1Y()/LPR5Y()` 派生值（方法调用，非字段）。

### 6.3 `applyRRR`（L193–216）——唯一返回 error 的工具

- **方向归一**：降准工具 Magnitude>0 自动取负（L196–198）、升准工具 <0 自动取正（L199–201）——调用方符号写反不产生反向操作；
- **步长量化**：`steps = round(|Magnitude| / 0.25%)`，steps==0 → error「not a multiple of 0.25% step」（L202–205）；
- `ReserveRatio = clamp(old ± steps×0.25%, 5%, 20%)`；
- **三联动**：`MultiplierCeiling = 1/r`（L212）、`Reserves = r × M1`（L213）——降准立即放大货币创造上限。

### 6.4 `applyOMO`（L219–240）

- `frac = clamp(Magnitude, -5%, +5%)`；
- 投放（frac ≥ 0，逆回购）：`GovBondsHeld += amount`、`Reserves += amount`（央行买国债扩表）；
- 回收（frac < 0，正回购）：卖出国债 **受持有量约束**（`amount = min(amount, GovBondsHeld)`，L230），`Reserves = max(0, Reserves - amount)`；
- 重算 `BaseMoney = M0 + Reserves`、`MoneyMultiplier = M2 / BaseMoney`。

### 6.5 `applyCreditWindow`（L244–251）

- `CreditWindowFactor = clamp(old + Magnitude, 0.5, 1.5)`；
- 联动当月额度：`LoanQuotaFactor = clamp(LoanQuotaFactor × CreditWindowFactor, LoanQuotaMin=0.5, 1.0)`（L248）——窗口收紧立即压缩商业银行可贷额度（`MonthlyDecision` 下月重算会覆盖，见央行公告文档 §联动）。
