## 3. 季度公告：MonthlyDecision 步骤 l（L344–348）

`MonthlyDecision`（L234–349）既有的 a–k 步骤（基础货币 → 货币统计 → 乘数 → M2 增速 → CPI → 逆周期调息 → LPR → 信贷约束 → OMO → 资产负债表 → 快照）全部不动，尾部追加：

```go
// l. 季度央行公告(v2.12 阶段3):每 3 月生成一次文本公告追加到事件流。
// 本阶段为文本拼接占位;完整 LLM 接入在阶段 4 政府财政子系统完成(§197)。
if w.Month%3 == 0 {
    w.emitEvent("policy", -1, "央行公告: "+GenerateCentralBankStatement(w, w.Month))
}
```

节奏语义：

- **触发**：`w.Month % 3 == 0` → 第 3、6、9、12… 月各一条（游戏内「季度」）；
- **频道**：`"policy"` 事件、`seat=-1` 全房播报——与调息事件（L335–342）、工具箱事件（`ApplyInstrument`）同频道，前端事件流零改动即可展示；
- **前缀**：固定 `"央行公告: "`（单测以 `strings.HasPrefix` 锚定此前缀）；
- 与步骤 f 的月度调息事件并存：月度小幅调息照旧播报，季度公告是聚合快照。

## 4. `GenerateCentralBankStatement`（L429–440）

```go
func GenerateCentralBankStatement(w *World, month int) string {
    if w == nil || w.CB == nil {
        return ""
    }
    return fmt.Sprintf("央行%d月: LPR %.2f%%/%.2f%% CPI %.1f%% 准备金率 %.1f%% 货币乘数 %.1f",
        month, w.CB.LPR1Y()*100, w.CB.LPR5Y()*100, w.CB.CPI*100,
        w.CB.ReserveRatio*100, w.CB.MoneyMultiplier)
}
```

示例输出（初始状态，12 月）：`央行12月: LPR 3.00%/3.50% CPI 2.0% 准备金率 10.0% 货币乘数 0.9`。

实现要点：

- **nil 安全**：`w`/`w.CB` nil → 空串（不 panic）；
- **方法调用陷阱**（L432 注释）：`LPR1Y`/`LPR5Y` 是**方法非字段**，格式化时必须调用——直接取字段值会得到零值；
- 指标选取五项：双 LPR（1Y/5Y）、CPI、准备金率、货币乘数——覆盖价格端（利率/通胀）与数量端（准备金/乘数）；
- 本阶段不含：SLF 走廊、失业率、菲利普斯倾向（Phase 4 LLM 公告可扩充素材，`EvaluatePhillips(w).Description` 即现成上下文）。
