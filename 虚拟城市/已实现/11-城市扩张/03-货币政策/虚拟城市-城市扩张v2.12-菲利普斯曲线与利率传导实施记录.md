## 2. phillips_curve.go（122 行）

### 2.1 输入 / 输出类型

```go
// L36–41 输入(月度宏观快照;nil 安全回落自然率/目标值)
type PhillipsInput struct {
    UnemploymentRate    float64 // World.Labor.Unemployment
    CPIYoY              float64 // World.CB.CPI
    CapacityUtilization float64 // 产能利用率代理 = MoneyMultiplier/MultiplierCeiling
    WageGrowth          float64 // World.Labor.WageGrowthYoY
}
// L44–48 输出
type PhillipsOutput struct {
    Stance      string  // dovish / neutral / hawkish
    RateBias    float64 // 利率建议(小数;+加息/−降息;clamp ±5%)
    Description string  // 人读摘要(事件流 / 央行行长 Bot 上下文)
}
```

### 2.2 `CollectPhillipsInput`（L56–77，nil 安全）

| 输入 | 来源 | nil 回落值 |
|------|------|------------|
| 失业率 | `w.Labor.Unemployment` | `UnemployNatural` = 5%（`labor.go:18`） |
| CPI | `w.CB.CPI` | `TargetCPI` = 2%（`central_bank.go:39`） |
| 产能利用率 | `w.CB.MoneyMultiplier / MultiplierCeiling` | `TargetUtil` = 85%（`central_bank.go:48`） |
| 工资增速 | `w.Labor.WageGrowthYoY` | 3% 基线 |

### 2.3 `EvaluatePhillips` 4 规则（L88–122，switch 优先级自上而下）

| 规则 | 条件 | Stance | RateBias |
|------|------|--------|----------|
| r1 | CPI > 5%（`PhillipsHawkCPI`） | hawkish | +3%（`PhillipsHawkBias`） |
| r2 | 失业率 > 8%（`PhillipsDovishUnemploy`） | dovish | −3%（`PhillipsDovishBias`） |
| r3 | CPI ∈ [2%,3%] 且 U ∈ [4%,6%]（双中性带） | neutral | 0 |
| r4 | 其余 | 见下 | 线性插值 |

r4 线性插值（L105–114）：

```
bias = (CPI − 2%) − (U − 5%)        // 通胀缺口推动加息,失业缺口推动降息(单位增益)
RateBias = clamp(bias, ±5%)          // PhillipsBiasMax
|RateBias| ≤ 0.5% → neutral;  > +0.5% → hawkish;  < −0.5% → dovish   // PhillipsStanceBand
```

**优先级语义**：r1 先于 r2——滞胀情形（高通胀 + 高失业）按通胀目标制央行惯例先稳物价（L87 注释）。`Description`（L117–121）拼出四输入 + 结论一行摘要，直接可进事件流或 Bot 上下文。

### 2.4 阈值常量（L14–33）

`PhillipsHawkCPI=0.05`、`PhillipsHawkBias=0.03`、`PhillipsDovishUnemploy=0.08`、`PhillipsDovishBias=-0.03`、中性带 `PhillipsNeutralCPILo/Hi=0.02/0.03`、`PhillipsNeutralUnempLo/Hi=0.04/0.06`、`PhillipsBiasMax=0.05`、`PhillipsStanceBand=0.005`。

## 3. interest_transmission.go（201 行）

### 3.1 传导总链（头注释 L9–17 数值标定）

```
MLF(政策利率锚) ──+0.1%基准+0.2%流动性溢价──▶ SHIBOR(银行间)
SHIBOR ──+紧迫加点(0.2%×CreditTightness)──▶ 商业银行资金成本
资金成本 ──存款=成本−NIM/2 / 贷款=成本+1%──▶ 零售利率(存/贷)
零售利率 ──40/30/30 加权+敏感度──▶ 实体经济有效借贷利率
```

以真实 MLF=2.4% 为例：SHIBOR 2.7% → 存款 1.95%（NIM 1.5%）→ 零售贷款 3.7%。引擎内锚 = `World.CB.PolicyRate`（初始 3%），公式一致、数值随状态浮动。

### 3.2 系数常量（L24–43）

| 常量 | 值 | 用途 |
|------|----|------|
| `SHIBORBaseSpread` | 0.001 | MLF→SHIBOR 基准加点 |
| `LiquidityPremium` | 0.002 | 流动性溢价 |
| `InterbankStressSpread` | 0.002 | 紧迫加点上限（×`CreditTightness`） |
| `DefaultNIM` | 0.015 | 净息差缺省（`CentralBankState.NIM` 未初始化时回落） |
| `RetailRiskPremium` | 0.01 | 零售贷款风险溢价 |
| `ConsumerSpread` | 0.025 | 消费贷 LPR 加点（区别于 P0 固定 `ConsumerRate=10%`） |
| `HousingDemandSensitivity` | 0.08 | 每 +1% 利率购房意愿 −8% |
| `ConsumerCreditSensitivity` | 0.06 | 消费信贷 −6%/+1% |
| `InvestmentDemandSensitivity` | 0.05 | 企业投资 −5%/+1% |

### 3.3 四个单步函数（均返回 `(float64, string)` = 输出利率 + 人读摘要）

| 步 | 函数 | 行 | 公式 |
|----|------|----|------|
| 1 | `CentralToInterbank(w, mlfRate)` | L85–89 | `SHIBOR = mlf + 0.1% + 0.2%` |
| 2 | `InterbankToCommercial(w, shibor)` | L94–102 | `成本 = shibor + 0.2% × CreditTightness`（基准 tightness=0 → 成本=SHIBOR） |
| 3 | `CommercialToRetail(w, fundingCost)` | L107–113 | `存款 = 成本 − NIM/2`；`贷款 = 成本 + 1%`（返回贷款；伴生 `retailDepositRate` L116–118） |
| 4 | `RetailToMacro(w, retailLoanRate)` | L133–155 | 见 §3.5 |

### 3.4 `TransmissionStep` 留痕结构（L58–65）与派发器

```go
type TransmissionStep struct {
    Index       int     // 0..3
    Name        string  // Step* 常量
    InRate, OutRate float64
    DepositRate float64 // 仅 retail 步填充
    Description string
}
```

命名说明（L55–57 注释）：任务规格中单步函数名与切片元素类型同名冲突（Go 不允许），类型保留 `TransmissionStep` 进导出签名，单步派发函数命名 `RunTransmissionStep(w, idx, rate)`（L161–178）——idx 0..3 对应四步，越界返回零值 + 错误描述字符串（纯函数不 panic）。步骤名常量：`StepCentralToInterbank` = `"MLF→SHIBOR"`、`StepInterbankToCommercial` = `"SHIBOR→资金成本"`、`StepCommercialToRetail`、`StepRetailToMacro`（L46–51）。

### 3.5 `RetailToMacro` 第 4 步细节（L133–155）

- 三类利率实取：`mortgage = w.CB.MortgageRate()`、`consumer = w.CB.ConsumerLoanRate()`、`business = w.CB.BusinessRate()`（nil 时回落 P0 初值口径）；
- **有效借贷利率 = 40% 房贷 + 30% 消费贷 + 30% 经营贷**（存量结构权重，L142）；
- 相对初始基准利差 `gap = effective − baseline`（baseline 用 P0 初值常量拼算，L145–146）；
- 需求意愿变化：`购房 = −gap × 0.08`、`消费信贷 = −gap × 0.06`、`投资 = −gap × 0.05`（利差为正即三项全降）。

### 3.6 `TraceTransmission` 完整链（L183–201）

`w`/`w.CB` nil → 返回 nil。否则串联四步 + 存款伴生值，返回 `[]TransmissionStep{4}`。锚点 `mlfAnchor(w)`（L76–81）= `w.CB.PolicyRate`（nil 回落 `InitialPolicyRate`）；NIM 缺省 `nimOf(w)`（L68–73）= `DefaultNIM`。

### 3.7 `ConsumerLoanRate` 新方法（L123–128）

```go
func (cb *CentralBankState) ConsumerLoanRate() float64 {
    return cb.LPR1Y() + ConsumerSpread + cb.CreditSpread   // 1Y LPR + 2.5% + 信贷加点
}
```

方法挂在 `CentralBankState` 但**定义在本文件**（不动 `central_bank.go`，L120–122 注释）。区别于 P0 固定 `ConsumerRate = 0.10`（`central_bank.go:33`，保留未删）：消费贷利率从「常量」升级为「随政策传导的派生量」。
