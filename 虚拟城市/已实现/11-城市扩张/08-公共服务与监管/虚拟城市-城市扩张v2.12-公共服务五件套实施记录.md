## 1. 定位与范围

阶段 8「公共服务 + 监管体系 + 市长选举」（最终阶段）的第一块交付：**公共服务
五件套**——教育质量 / 医疗质量 / 养老水平 / 住房可负担性 / 就业服务，外加
`EducationSystem`（代际效应）与 `HealthcareSystem`（医疗保障因子）两个投入
存量子系统。全部落在 `PublicServices`（public_services.go:56-72），挂
`World.PublicSvc`，月步由 settlement ⑨G 驱动。

本文件**不含**：四大监管聚合（见《四大监管体系实施记录》）、市长选举
（见《市长选举机制实施记录》）、regulators 子包解耦（见《监管子包解耦设计》）。

## 2. 五指标模型与月度累积（MonthlyStep，public_services.go:103-134）

### 2.1 三质量：财政支出占比 × 系数累积

教育 / 医疗 / 养老三项质量按**当月财政是否在花钱**门控累积：

```go
if t := w.Treasury; t != nil && t.LastMonthExpense > 0 {
    ps.EduQuality    = clamp01(ps.EduQuality    + FiscalBudget.Education*PublicSvcQualityGain)
    ps.MedQuality    = clamp01(ps.MedQuality    + FiscalBudget.Healthcare*PublicSvcQualityGain)
    ps.PensionLevel  = clamp01(ps.PensionLevel  + FiscalBudget.Pension*PublicSvcQualityGain)
    // 投入存量镜像（万元）。
    ps.Edu.PublicEduStock = float64(t.EduCapital) / 1e4
    ps.Med.PublicMedStock = float64(t.HealthCapital) / 1e4
}
```

常量（public_services.go:30-54）与阶段 4 `FiscalBudget`（fiscal_policy.go:29-35，
五分法 0.30/0.25/0.20/0.15/0.10）交叉得到月增速：

| 指标 | 预算份额 | 月增速 = 份额 × `PublicSvcQualityGain`(0.01) | 满格时长 |
|------|---------|--------------------------------------------|---------|
| EduQuality | 教育 30% | **+0.003/月** | ≈ 334 月（28 年） |
| MedQuality | 医疗 25% | **+0.0025/月** | 400 月 |
| PensionLevel | 养老 20% | **+0.002/月** | 500 月（超出 420 月对局，全程不满格） |

- 节奏标定：420 月（35 年）标准对局内教育恰好在后期接近满格——「长期主义
  财政」才有满格公共服务，与阶段 4 财政纪律（支出上限 = min(现金×5%,
  上月收入×110%)）形成正反馈。
- **门控语义**：`LastMonthExpense > 0`（treasury.go:54，⑨E 记账）——财政当月
  零支出（紧缩或无税基）则三质量**零增长但不衰减**；无惩罚性下滑，避免与
  阶段 4 紧缩机制双重惩罚。
- `clamp01` 出口统一夹取 [0,1]（与阶段 7 society_stats.go 同款特化）。
- 首月边界：开局 `LastMonthExpense=0`（treasury.go:36 注释同款退化防护），
  首个 ⑨E 之后才开始累积。

### 2.2 投入存量镜像（万元口径）

`PublicEduStock` / `PublicMedStock` 只读镜像 `Treasury.EduCapital` /
`HealthCapital`（treasury.go:65-66，阶段 4 财政直发累计）÷ 1e4。快照下发
`edu_stock_wan` / `med_stock_wan`（view.go:263-264）——「质量（累积速率）」
与「存量（累积总额）」两个维度并行可观测。

### 2.3 MonthsRun / LastStepMonth

§130 接线验证字段：`MonthsRun` 累计月步次数、`LastStepMonth` 最近月步主钟月份，
`TestPublicServices_WiredIntoSettleMonth` 直接断言（public_services_test.go:254-277）。

## 3. 住房可负担性：房价收入比映射（public_services.go:136-161）

`computeHousingAfford` 纯函数，零 rand：

```
中位房价  = medianOf(16 城区 Market.HousePrice(d.ID))
中位收入  = medianOf(存活玩家 monthlyIncomeEstimate() × 12)   // 年化
ratio     = 中位房价 ÷ 年化中位收入
afford    = clamp01(1 − ratio / HousingRatioDivisor)          // 分母 = 20
```

- **`HousingRatioDivisor = 20.0`**（public_services.go:34-36）：ratio ≥ 20
  （房价 = 20 年收入，国际公认的"完全不可负担"线）→ afford = 0；ratio = 0 → 1。
- 中位数而非均值：双中位（房价中位 ÷ 收入中位）对 12 座位小样本稳健，不受
  极端首富 / 贫民窟城区拉偏。
- 边界：无玩家收入 / 无市场 / 中位 ≤ 0 → 0（`TestPublicServices_HousingAfford`
  对拍两种场景）。
- `medianOf`（public_services.go:216-227）：输入副本排序（不改调用方切片），
  偶数取中两点平均，n=0 → 0。
- 数据源对齐：`DistrictDefs` / `DistrictCount=16` 为阶段 2 契约；
  `monthlyIncomeEstimate()`（player.go:422）与消协口径同源。

## 4. 就业服务：FirmSector 直读（public_services.go:129-133）

`Employment = clamp01(w.Labor.Employment)`——就业服务**不另建模型**，直读
劳动市场月步产出。设计纠偏记录：任务卡曾写「读 `SocietyStats.EmploymentRate`」，
**该字段不存在**——就业率唯一权威源是 `FirmSector`（labor.go），本文件按
实际代码落地并在 MonthlyStep 注释（public_services.go:100-102）留档。
`Labor == nil`（economy 未开）→ 0。

## 5. EducationSystem：教育代际效应（AnnualEduStep，public_services.go:163-194）

年度步（挂 `AnnualAdjust` 尾部，非月步）——「教育质量」影响的是**下一代
资源**，以 `Cognition`（资源 K，整数字段）为载体：

- **门槛**：`EduIncomeGateCNY = 15_000`（月收入 > 1.5 万才能负担私立教育，
  `monthlyIncomeEstimate()` 口径）；
- **速率**：`EduCognitionAnnualGain = 0.1`/年 → 语义 = **10 年 Cognition +1**；
- **上限**：`CognitionCap = 10`（与既有 clamp 口径一致；达上限清零累积不进位）；
- **累积器**：`accrual map[int]float64`（座位 → 进度 0..1），满 1.0 进位
  `p.Cognition++` 并扣除 1.0（负数钳 0）。

### 5.1 ε 容差 bug（测试捕捉的真 bug #1）

浮点累积 `0.1 × 10 = 0.999…9`，严格 `>= 1.0` **永不成立** → 10 年后
Cognition 永不 +1。`TestEducation_CognitionBoost`（public_services_test.go:75-94）
连续 10 年调用后断言 `Cognition == 6` 直接失败。修复（public_services.go:183）：

```go
if ps.Edu.accrual[p.Seat] >= 1.0-1e-9 {   // ε 容差 1e-9
```

教训入库：**浮点进度条进位判定必须带 ε 容差**（同型风险：阶段 6 基金评级
严格大于阈值口径是刻意为之，两处语义不同需区分）。

### 5.2 存活与门槛过滤

仅 `p.Alive` 且收入超门槛的座位累积；死亡座位进度保留在 map（复活场景不
清档——引擎当前无复活路径，留 nil-safe 余量）。

## 6. HealthcareSystem：医疗因子查询（public_services.go:196-213）

两个**查询函数先行**（§130「声明了必须接线」的反向应用：查询函数本身
不接线不违规，消费方接线在 v2.13）：

| 函数 | 触发门槛 | 因子 | 语义 | 接线目标（v2.13） |
|------|---------|------|------|------------------|
| `MedInjuryFactor()` | MedQuality > 0.5 | **0.8** | 意外受伤概率 −20% | `insurance.go::rollAccident` |
| `MedPremiumFactor()` | MedQuality > 0.7 | **0.9** | 健康险保费 −10% | `insurance.go` 定价路径 |

**为什么不现在接入**：`rollAccident` 在既有 rand 分支路径上，接入即改写
固定种子存量对局的随机数消费序列 → 全量回归偏移。阶段 8 纪律是**零 rand
消费、零存量偏移**（文件头注释 public_services.go:15-16），故只下发快照
（MedQuality 已在 view 可观测），实际乘子 v2.13 单独评审接入。

## 7. 确定性与守卫清单

- 零 rand：全文件无 `w.Rand` 调用（grep 验证）——同种子对局逐字节一致，
  `TestPublicServices_Deterministic` 双世界 3 月对拍锁定；
- nil 守卫：`ps == nil || w == nil` 直接 return；`ps.Edu` / `ps.Med` 为 nil
  时惰性重建（防直接构造的 World 解引用，public_services.go:107-112）；
- 排序确定性：medianOf 副本排序；无 map 遍历进输出。
