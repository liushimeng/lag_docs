## 1. 定位与范围

阶段 6 交付「同业存单（NCD）市场」：**3 家城商行 × 4 档期限 = 12 只挂牌存单**的
银行间短期融资工具。这是**玩家可交易**资产（申赎/二级卖出）中风险最低的一档 ——
利率锚 SHIBOR、面值交割、线性计息，与股票/基金/可转债构成完整的虚拟资本市场谱系。

- 纯引擎层：无锁、无 goroutine、无 IO、**零 rand 消费** —— 估值线性计息、
  利率由 SHIBOR 传导链决定（固定种子存量对局回归零偏移）。
- 资金流全走 `w.Pay`（I1 守恒）：申购 `seat → bank`（CatBuy）、二级卖出与到期兑付
  `bank → seat`（CatSell）。

## 2. 挂牌结构（3 行 × 4 档）

`NewCDMarket()`（interbank_cd.go:104-116）构造 12 只挂牌标的，ID 形如
`CD-A-1M` / `CD-B-12M`（发行行末字符 + 期限档）：

| 项 | 值 |
|----|----|
| 发行行（`CDIssuerNames`） | 城商行A / 城商行B / 城商行C（顺序固定） |
| 期限档（`CDTenures`） | 1 / 3 / 6 / 12 月（顺序固定 = 下发序） |
| 单只存量（`cdOutstandingWan`） | 1M 800 万 / 3M 1500 万 / 6M 2000 万 / 12M 3000 万（静态） |
| 挂牌存量合计 | 3 行合计 21,900 万元（快照 `TotalOutstandingWan`） |

## 3. 利率定价：SHIBOR 期限结构（阶段 3 传导链复用）

```
票面利率(t) = SHIBOR(t) + 30bp                    // CDCouponSpread = 0.0030
SHIBOR(t)   = SHIBOR_1Y − 期限贴水(t)              // t ∈ {1M:30bp, 3M:20bp, 6M:10bp, 12M:0}
SHIBOR_1Y   = CentralToInterbank(w, mlfAnchor(w))  // 阶段3 interest_transmission.go 第1步传导
```

- `shiborForTenure`（interbank_cd.go:90-101）取 `interest_transmission.go:76` 的
  `mlfAnchor` + `:85` 的 `CentralToInterbank` —— MLF 锚 → SHIBOR_1Y；减期限贴水得
  各期限点，负值兜底 0。曲线正常**向上倾斜**（短端贴水）。
- 默认 PolicyRate 3% 时：SHIBOR_1Y = 3.3%；CurRate[12]=3.6%、CurRate[6]=3.5%、
  CurRate[3]=3.4%、CurRate[1]=3.3%（1M 贴水 30bp 与加点 30bp 恰好抵消，测试 3 断言）。
- **票面锁定规则**（现实同款）：`CDHolding.Rate` 在申购月锁定，之后不随市场浮动；
  月度 `refreshRates`（interbank_cd.go:119-126）仅刷新 `CurRate`（**新发行定价基准**）
  与挂牌展示利率 `Listed[].Rate`。政策利率 +1% 精确传导新发行 +1%（测试 3）。

## 4. 估值模型（线性计息，零 rand）

```
应计价值 AV = 面值(万)×1e4 × (1 + 票面 × min(持有月数, 期限)/12)   // CDAccruedValue:129
到期兑付    = 面值 × (1 + 票面 × 期限/12)                          // 全额应计,无折价
二级卖出    = AV(t) × (1 − 1%)                                     // R6-3 流动性折价
```

**关键取舍 —— 线性计息而非贴现**：单利直线计息，不做市场利率重估。已发行存单的
经济价值不随 SHIBOR 波动（持有到期刚性兑付），只有**提前卖出**才通过 1% 流动性
折价体现期限流动性成本 —— 模型简单、确定性、符合「短端现金管理工具」定位。

## 5. 玩家操作

### 5.1 BuyCD 平价申购（interbank_cd.go:151-185）

- 面值交割：cost = `faceWan × 10000`（元）；下限 `CDBuyMinFaceWan = 1 万元/笔`；
  现金不足 `ErrWealthInsufficientCash`。
- 校验序：玩家存活 → faceWan 下限 → CDMarket 非 nil → 标的存在 → 利率取
  `CurRate[期限]`（≤0 时现场按 SHIBOR 重算兜底）→ 现金。
- 成功后持仓 `H<n>`（seq 自增）追加 `Holdings`（按申购序），事件播报
  `action` 类（发行行 + ID + 面值 + 票面）。

### 5.2 SellCD 二级卖出（interbank_cd.go:188-211）

- 按持仓 ID + seat 双重匹配；应计价值 × 99%（`CDSellDiscount = 0.01`，R6-3）入账。
- 持仓即时移除。折价 ≈ 公允价值 × 1%（测试 4 断言，取整误差 ≤ 1 元）。

### 5.3 到期兑付（CDMonthlyStep ②，interbank_cd.go:222-237）

- 持有月数 `w.Month − BuyMonth ≥ TenureMonths` → 全额应计（**无折价**），
  `bank → seat` CatSell + `market` 类事件；持仓从台账剔除。

## 6. 月度推进（CDMonthlyStep，interbank_cd.go:215-249）

SettleMonth **⑥B** 第 2 位调用（量化引擎之后；settlement.go:166），三步：

1. **refreshRates**：CurRate 按 SHIBOR 月度刷新（新发行基准 + 挂牌展示同步）。
2. **到期兑付**：全量持仓扫描（原地压缩 kept 切片，零分配习惯）。
3. **快照聚合**：`TotalOutstandingWan`（12 只合计）+ `LastAvgRate`（存量加权平均票面）。

`LastStepMonth` 记录最近推进月（§130 接线验证锚点）；nil / w nil 安全。
