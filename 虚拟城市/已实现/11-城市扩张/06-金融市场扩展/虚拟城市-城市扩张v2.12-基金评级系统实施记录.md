## 1. 定位与范围

阶段 6 交付「基金评级引擎」：**5 只虚拟公募基金**的月度收益模拟 + 5 星评级。
这是**信息面**子系统 —— 玩家不可直接申赎这 5 只基金；评级结果经
`fin_market.fund_ratings` 进 view 快照，影响玩家决策信息（哪些资产类别近期表现好）。
F05（量化对冲）与同批落地的量化引擎联动（§3.4）。

- 纯引擎层：无锁、无 goroutine、无 IO、**零 rand 消费** —— 收益由确定性公式生成
  （treasury / 供应链同款纪律，固定种子存量对局回归零偏移）。
- `FundRating` 的 profile 字段（equityW / feeAnnual / lastStockIdx / filled）**未导出且不序列化**，
  `World` 无 JSON 持久化路径，仅存内存。

## 3. 月度收益与评级算法

### 3.1 收益公式（fundMonthlyReturn，fund_rating.go:162-168）

```
r = equityW × stockMom + (1 − equityW) × bondYield/12 − feeAnnual/12   (+ F05 联动项)
F05 联动项 = 0.60 × QuantEngine.LastMonthReturn        // FundQuantAlphaWeight
```

- `stockMom` = 当月股指环比（`Market.StockIndex / lastStockIdx − 1`），防御性 clamp
  **[−0.99, +10]**（fund_rating.go:221-226，防外部改写股指的极端注入）。
- `bondYield` = 当期 `PhaseTable.BondRate`（零息差近似，票息/12 线性）。

### 3.2 年化夏普（fundSharpe，fund_rating.go:112-140）

```
Sharpe = (mean(r) × 12 − rf) / (std(r) × √12)
rf = 当期 PhaseTable.BondRate
```

**关键取舍 —— rf 取当期 BondRate 而非固定 2%**：基金收益公式中债腿是
`(1−equityW)×bondYield/12`，与 rf 同源。若 rf 固定 2% 而市场 BondRate 也是 2%，
零方差的纯债基金（F01 低波动）会因「无波动却稳定跑赢 rf」得到**虚高夏普**，
反超真实承担风险的权益基金。rf 联动 BondRate 后零方差债腿的超额收益 ≈ 0，
**权益仓位才是分层驱动**（测试 1 断言 F04.Sharpe > F02 > F01 结构性单调）。

数值防护：std 下限 1e-6（全常数收益列防除零）；夏普 clamp **[−9, +9]**（零方差
路径夏普爆炸时封顶，仍稳拿 5 星，不污染快照）。

### 3.3 5 星分层与漂移限制（fundStars / rateFundUpdate）

分层阈值（fund_rating.go:93-106，契约 2.0/1.5/1.0/0.5，**严格大于**）：

| 条件 | 星数 |
|------|------|
| 夏普 > 2.0 **且** 近窗最大回撤 < 10% | 5 |
| 夏普 > 1.5 | 4 |
| 夏普 > 1.0 | 3 |
| 夏普 > 0.5 | 2 |
| 其余 | 1 |

- **最小样本 3 月**（`FundRatingMinHistory`）：`filled < 3` 不评级，星数维持初值 3，仅更新 AUM。
- **漂移限制 ±1 星**（fund_rating.go:193）：`f.Stars = clamp(raw, f.Stars−1, f.Stars+1)`
  再 clamp [1,5] —— 单月最多升/降 1 星，防评级跳水（真实评级机构同款约束；
  测试 2 验证 1 星基金优异月最多到 2、5 星基金崩盘月最多降到 4）。
- `MonthlyReturn` 滚动窗口 12 月（未满尾接、满 12 左移）；`fundMaxDrawdown`
  （fund_rating.go:143-158）按窗口累计净值峰值到谷值计算（正数）。
- AUM 月度 `×= (1+r)`，clamp ≥ 0。

### 3.4 F05 量化联动（执行顺序耦合）

⑥B 中 `rateFundsMonthly` 排在 `QuantEngine.MonthlyStep` **之后**（末位），
F05 消费的是**本月**量化收益 `w.QuantEngine.LastMonthReturn`（fund_rating.go:229-231，
nil 安全）。联动系数 0.60（对冲腿吸收 60% 量化月收益）。

## 4. 月度推进入口（rateFundsMonthly，fund_rating.go:209-241）

SettleMonth **⑥B 末位**调用（settlement.go:169），全房 5 只统一推进：

- nil / `Market == nil` 直接返回；空表**惰性初始化**（旧档防御）——
  `NewFundRatings(w.Market.StockIndex)` 播种后**当月继续推进**（环比 0，当月即积累样本）。
- `lastStockIdx <= 0` 的异常条目重锚当期股指并跳过本月（防旧档除零）。
