## 1. 定位与范围

本文覆盖阶段 6 的两个横切交付：

1. **量化基金引擎**（quant_fund.go）—— 虚拟做市商（**非玩家实体**），5 策略加权
   组合，权重随市场周期相位自适应（R6-2）；产出量化指数（基 100）进 view，
   影响市场情绪，并向 F05「量化对冲」基金输出 alpha（见《基金评级系统实施记录》§3.4）。
2. **⑥B 金融市场月度引擎编排 + `fin_market` view 快照** —— 阶段 6 五个子系统
   （量化 / CD / 转债 / 融券 / 评级）在 SettleMonth 的统一接入与统一下发面。

纯引擎层：无锁、无 IO、**零 rand 消费** —— 策略收益是股指环比与周期相位的
确定性函数（固定种子存量对局回归零偏移）。

## 2. 5 策略与自适应权重（R6-2）

### 2.1 策略静态表（quant_fund.go:22-28 / 61-63）

| 策略名 | 含义 | 本月原始收益（quantStrategyReturn:140-165） |
|--------|------|---------------------------------------------|
| `trend` | 趋势跟踪 | `1.6 × mom`（趋势放大） |
| `mean_reversion` | 均值回归 | `−0.9 × mom`（反趋势） |
| `stat_arb` | 统计套利 | `0.4%/月 + 0.05 × mom`（低波动稳定收益） |
| `momentum` | 动量 | `1.3 × mom + 相位增益`（繁荣 +1% / 萧条 −1%） |
| `event_driven` | 事件驱动 | `0.3%/月 + 困境增益`（衰退/萧条 +0.4%） |

`mom` = 股指环比（当期 / lastStockIdx − 1），防御 clamp **[−0.99, +10]**
（quant_fund.go:217-222）。初始权重等权 0.2（`NewQuantFundEngine`:66-72），
指数基 100（`QuantIndexBase`），环比锚 `InitialStockIndex`(3.50)。

### 2.2 相位亲和度（quantPhaseAffinity，quant_fund.go:76-131）

softmax score 基座 —— 繁荣期动量(1.2)/趋势(1.0)亲和高，萧条期均值回归(1.2)/
事件驱动(1.1)亲和高（完整 4 相位 × 5 策略矩阵见源码 switch）：

| 相位 | trend | mean_rev | stat_arb | momentum | event |
|------|-------|----------|----------|----------|-------|
| 繁荣 Boom | 1.0 | 0.2 | 0.4 | **1.2** | 0.3 |
| 复苏 Recovery | 1.0 | 0.4 | 0.5 | 0.9 | 0.4 |
| 衰退 Recession | 0.3 | **1.1** | 0.7 | 0.1 | 1.0 |
| 萧条 Depression | 0.2 | **1.2** | 0.8 | 0.0 | 1.1 |

### 2.3 月度推进四步（MonthlyStep，quant_fund.go:201-256）

```
① 各策略原始收益: r_i = quantStrategyReturn(name, 相位, mom)
② 组合收益: raw = Σ w_i × r_i  →  clamp [−8%, +8%]    // QuantMonthlyClamp, R6-2
③ 指数推进: Index ×= (1+r), 下限 1; MonthsRun++
④ 权重重归一化: score_i = 相位亲和 + 2 × 上月 r_i  →  softmax(τ=0.35)
```

- **±8% 单月 clamp**：极端行情（测试 10 单月 +200% / −60% 注入）下量化指数
  不失真 —— 虚拟做市商不应跑赢/跑输市场一个数量级。
- **softmax 自适应**（quantSoftmax:168-198，数值稳定减最大值；τ=0.35 越小越尖锐）：
  score = 相位亲和（慢变量）+ `QuantPerfFeedback`(2.0) × 上月单策略收益（快变量）
  → 权重 Σ 恒 1。效果：繁荣期动量权重升、切萧条后均值回归权重升（测试 9 断言
  方向性 + 归一化）。
- 状态自愈：策略空表 / Index ≤ 0 / lastStockIdx ≤ 0 时重置（旧档防御）。
- 产出 `LastMonthReturn`（clamp 后，F05 消费）/ `LastRawReturn`（clamp 前，诊断）。

## 3. ⑥B 五连调用（settlement.go:148-170）

SettleMonth 在 **④.6 社会统计之后、⑨ 财政月结之前**插入 ⑥B（economy_enabled
守卫，false 完整跳过）：

```go
if w.EconomyEnabled {
    if w.QuantEngine == nil { w.QuantEngine = NewQuantFundEngine() }
    if w.CDMarket == nil    { w.CDMarket = NewCDMarket(); w.CDMarket.refreshRates(w) }
    if w.ShortBook == nil   { w.ShortBook = NewShortBook() }
    w.QuantEngine.MonthlyStep(w)     // ① 量化(首位 —— F05 消费本月收益)
    w.CDMarket.CDMonthlyStep(w)      // ② CD(利率刷新 + 到期兑付)
    stepConvertibleBonds(w)          // ③ 转债(估值 + 条款 + 补发)
    w.ShortBook.ShortMonthlyStep(w)  // ④ 融券(利息 + 强平)
    rateFundsMonthly(w)              // ⑤ 评级(末位)
}
```

**顺序锁定的原因**：量化必须**首位**（其 `LastMonthReturn` 是 F05 基金当月
alpha 联动输入）；评级必须**末位**（消费全部上游状态）。nil 惰性初始化三件套
（量化/CD/融券）防旧档与异常路径；评级与转债在各自函数内空表惰性播种。
零 rand 消费 —— 固定种子存量对局回归零偏移（测试 12）。

`engine.go` 对应接线：World 五字段（engine.go:170-174：`FundRatings / CDMarket /
CBonds / ShortBook / QuantEngine`）+ NewWorld 装配（engine.go:235-239，评级与
转债置 nil 惰性）+ NewWorld 尾部 `w.CDMarket.refreshRates(w)`（engine.go:251，
首次 ⑥B 前 view/申购即可用 CurRate）。

## 4. `fin_market` view 快照（view.go）

### 4.1 结构（FinMarketJSON，view.go:172-182）

挂 `ClientStateJSON.FinMarket`（view.go:61，`json:"fin_market,omitempty"`）——
**政府/观战者全量可见，无座位隐私**；`economy_enabled=false` 或量化引擎 nil →
omitempty 不下发（view.go:712-715 守卫）。

| 字段 | 类型 | 内容 |
|------|------|------|
| `quant_index` | float | 量化基金指数（基 100） |
| `quant_last_return` | float | 上月组合收益（clamp 后） |
| `quant_strategies[]` | array | 5 策略 `name / weight / last_return` |
| `cd` | obj | `avg_rate`（存量加权票面）/ `outstanding_wan` / `rates{"1","3","6","12"}` |
| `convertibles[]` | array | 可转债 **top3**（市价降序）`id/issuer/issuer_node/price/conv_value/bond_floor/coupon_rate/status/months_left` |
| `short` | obj | `balance_cny / margin_cny / open_count / margin_calls_mon`（R6-1 监测面） |
| `fund_ratings[]` | array | 基金评级 **top5**（星数降序）`fund_id/name/stars/sharpe/max_drawdown/aum_wan` |

### 4.2 确定性排序（buildFinMarketJSON，view.go:229-303）

- 转债 top3：市价降序，`ID` 升序稳定 tie-break；评级 top5：星数降序，AUM 降序
  tie-break —— `sort.SliceStable` 保证同种子 JSON 逐字节稳定（测试 12 直接
  `json.Marshal(buildFinMarketJSON(a/b))` 比对）。
- CD `Rates` 按 `CDTenures` 固定序（1/3/6/12）填充；融券快照复用
  `World.ShortBalanceCNY() / ShortMarginFrozenCNY()` 聚合。
