## 1. 定位

6 个产业集群对应 **16 城区中的产业型城区**（阶段 2 扩展区，`districts.go` v2.12）。
集群 = 城区 + 主导产业 + 入驻企业数 + 税收减免额度的组合体：

- 入驻企业数随经济周期波动（繁荣 +5%/月、萧条 −3%/月，clamp）。
- 集群内企业增值税减免 20%（月上限 = TaxBreakCap/12）。
- R5-3 减免上限：月数年上限 12 / 累计总额上限（默认 50 万元）触顶 → 本年停止减免；
  **每年 1 月额度重置**。
- Treasury 联动（SettleMonth ⑨F，位于 SettleTreasuryMonth **之后**）：减免额从本月
  `VatTotal` 负向扣除，**不直接动 Treasury.Cash**（§4）。

纯引擎层：无锁、无 goroutine、无 IO、**零 rand 消费**（企业数波动走周期阶段确定性公式）。

## 3. 月度调度（ClusterMonthStep / MonthlyClusterStep）

### 3.1 World.ClusterMonthStep（:94-105，SettleMonth ⑨F 钩子）

`w==nil || !w.EconomyEnabled || len(w.Clusters)==0` 整体跳过。先聚合 `totalFirms`
（6 集群企业数合计 = 集群增值税份额分母），再逐个 `MonthlyClusterStep(w, totalFirms)`。

### 3.2 单集群三步（:114-182）

**① 年初重置（R5-3 年度额度，关键取舍 ④）** —— `w.Month > 0 && w.Month%12 == 1` 时
`TaxBreakMonths / TaxBreakUsed / capNotified` 清零。**月数与累计金额同时重置**：
若只重置其一，累计上限一旦触顶，集群整个 420 月对局再也不享受减免，失去
「年度税收优惠」语义。

**② 企业数随周期波动（确定性，零 rand）**：

| CyclePhase | 月波动率 |
|------------|----------|
| PhaseBoom（繁荣） | +5% |
| PhaseDepression（萧条） | −3% |
| 复苏 / 衰退 | 0（仅两端相位有迁徙信号） |

`Firms = clamp(round(Firms×(1+rate)), 10, 500)`。

**③ 税收减免计算**：

```
vat   = Treasury.MonthlyCounter.VatTotal（本月已汇总增值税,元）
gross = vat × (Firms/totalFirms) × 20%          // 集群份额 × 减免率
relief = min(gross, 月上限, 年剩余额度)
  月上限   = TaxBreakCap × 1e4 / 12             // 50 万元 → 41666.67 元/月
  年剩余   = (TaxBreakCap − TaxBreakUsed) × 1e4
R5-3 触顶（Months ≥ 12 或 Used ≥ Cap）→ 本年停止减免(一次性播报)
amt  = int64(relief + 0.5)，再防御性 clamp ≤ VatTotal（负向扣除不破零）
VatTotal −= amt; TaxBreakMonths++; TaxBreakUsed += amt/1e4; LastBreakCNY = amt
```

无税基（vat≤0）或无企业（totalFirms≤0）→ 本月零减免。

## 4. 与 Treasury 联动：负向扣 VatTotal 不动 Cash（关键取舍 ⑤）

⑨F 位于财政月结 `SettleTreasuryMonth`（⑨A 收税 → ⑨B 转移支付 → ⑨C 支出 → ⑨D 国债 →
⑨E 记录）**之后**：

- ⑨A `CollectMonthTax`（treasury.go:116-125）每月**从零重算** `MonthlyCounter`
  （`*c = TaxCounter{}` 月初清零），其中 `VatTotal = Labor.RevenueCNY × VatRate`。
- ⑨F 减免以 `VatTotal −= amt` 负向扣除 —— 政府让利记为**收入减项**，与
  treasury.go「宏口径课税只入国库、不逐笔回溯」的聚合清算口径一致。
- **不直接动 `Treasury.Cash`**：⑨A 已把含 VAT 的总税收入 Cash；⑨F 只削减计税口径，
  避免同一笔钱两次进出（确定性测试断言 Treasury.Cash 在供应链/集群开关前后逐位一致，
  见《供应链调度与确定性验证》§5）。

## 5. 事件播报

额度用尽时一次性 `emitEvent("policy", -1, "<集群名>税收减免额度用尽(已减免 N 个月 / X.X 万元),本年停止新增减免")`
（:161-163）—— `capNotified` 防每月重复刷屏；次年 1 月重置后标志清零可再次播报。
