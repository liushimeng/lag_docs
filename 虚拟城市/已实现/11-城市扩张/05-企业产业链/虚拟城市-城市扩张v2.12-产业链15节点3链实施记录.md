## 1. 定位与范围

阶段 5 交付「企业产业链上下游系统」：**3 条产业链 × 5 节点 = 15 个虚拟企业节点**。
这是**非玩家企业**层 —— 玩家企业经营（`labor.go` 的 `FirmSector` 口径）**完全不变**；
本文件只做产业链层的产能 / 库存 / 价格推演，并通过消费品价格联动（§6）反哺玩家感知。

- 纯引擎层：无锁、无 goroutine、无 IO、**零 rand 消费**（§197 纪律，固定种子存量对局回归零偏移）。
- R5-2 性能：固定 15 节点参与月度调度，**不随玩家数扩展**，全遍历 O(1)。
- 数值单位：**万元**（Capacity / Inventory / baseDemand）；与引擎其余部分（元）的换算
  只发生在 `chainDemand` 边界（× FirmScale/1e4，FirmScale=2.5 表示消费篮子之外的投资+政府+外需）。

## 4. 核心数据结构

### 4.1 SupplyChainNode（supply_chain.go:55-74）

```
ID / Industry / NameCN / Tier(0原材料-1中游制造-2下游零售-3终端服务)
Capacity(月产能,万) / Inventory(库存,万) / UnitCost(0..1 库存估值) / Utilization(0..1)
SafetyStockMons = 2.0（R5-1 安全库存月数）
── 动态状态 ──
baseDemand(稳态月需求,播种后不再改写) / LastDemand / LastShipped
AvgShip(月出货 EMA α=0.2,安全库存基准) / FillRatio(履约率 0..1) / SupplyRatio(上游供给比)
```

- `safetyLine()`（:78）= SafetyStockMons × max(AvgShip, Capacity×5%)—— floor 防节点长期
  零出货时安全线退化为 0。
- `inventoryMonths()`（:87）库存可用月数（快照口径）。
- `UnitCost` 按层固定：`supplyUnitCostByTier = {0.70, 0.75, 0.80, 0.85}`（下游增值率高）。

### 4.2 SupplyChain（supply_chain.go:106-118）

```
Nodes map[string]*SupplyChainNode    // 15 节点
Relations []IndustryRelation          // 12 关系
PriceIndex [4]float64                 // 各层价格指数(基 1.0)
```

## 5. MonthlyTick 传导算法（supply_chain.go:202-211）

```
MonthlyTick(w): ①computeDemand → ②stepProduction → ③stepPrices → ④applyGoodsEffect → LastTickMonth = w.Month
```

### 5.1 ① computeDemand — 需求自下而上传导（:234-278）

- 零售/终端需求取自 **Goods 消费篮子上月口径**：扫描存活玩家 `p.ConsumptionByGoods`
  （②B 在步骤 ③ 之前执行，当月消费尚未入账——与 `LaborMonthStep` 扫描 w.Month−1 同理）。
  全房无消费数据（首月/全员阵亡）→ 契约基准 `goodsBaselineDemandCNY × goodsWeights` 播种。
- `wan(id, share)` 边界换算：篮子值 × share × FirmScale / 10000 → 万元/月。
- 6 个需求入口写入 `base` map；其余纯上游节点 `LastDemand = 0` 起步。
- **订单传导按关系表逆序遍历**（`for i := len(Relations)-1; i >= 0; i--`，:271）：
  每条关系恰好累加一次（下游 LastDemand × SupplyInputCoef → 上游）。逆序保证处理某关系时
  其下游节点的 LastDemand **已含全部更下游订单** —— 同层关系（食品加工 T1→物流仓储 T1）
  不受 tier 分组迭代顺序影响。（设计 bug 修复，详见《供应链调度与确定性验证》§3.1。）

### 5.2 ② stepProduction — 生产/利用率/库存（:286-332）

按 **tier 0→3 分层遍历**（上游先结算，下游才能读到其 FillRatio 施加断供约束）。单节点步骤：

1. **上游供给约束**：取该节点全部流入关系的最小上游 FillRatio（无上游 → 1）→ `SupplyRatio`。
2. **R5-1 断供折算**：有效需求 = LastDemand × (0.5 + 0.5×supply) —— 全断供时仍保 50%
   需求（多供应商简化），**利用率最多降 50% 而非停产**。
3. **强制补产分支（R5-1）**：`replenish = safetyLine() − Inventory > 0` → target += 缺口。
4. **压产去库存分支**：`glut = Inventory − 2×safetyLine() > 0` → target −= min(0.3×glut,
   0.4×demand) —— 超中性带上限的库存每月消化超额 30%，压产幅度 ≤ 40% 骨架需求。
   （防需求回落后库存滞留导致价格单边下跌，设计 bug 修复，详见《供应链调度与确定性验证》§3.2。）
5. **利用率平滑**：targetUtil = clamp(target/Capacity, 0.15, 1.0)；
   Utilization += 0.35×(targetUtil − Utilization)；actual = Capacity×Utilization。
6. **库存滚动**：avail = Inventory + actual；shipped = clamp(demand, 0, avail)；
   Inventory = clamp(avail−shipped, 0, Capacity×3)；AvgShip = 0.8×AvgShip + 0.2×shipped；
   FillRatio = shipped/demand（demand≈0 时 = 1）。

### 5.3 ③ stepPrices — 价格逐层传导（:383-395）

- 层自失衡：`invRatioPriceEffect(tierInvRatio(tier))` —— 层内库存/安全线聚合比
  （`tierInvRatio`，:335）：**紧缺(<1) → 涨价 ≤ +5%**（幅度 = 0.05×clamp((1−r)/0.5,0,1)），
  **过剩(>2) → 降价 ≤ −3%**（幅度 = 0.03×clamp((r−2)/2,0,1)），**中性带 [1,2] → 0**。
- 上游传导：tier>0 时 mom += 上月……本月 cur[tier−1] × `tierAvgElasticityInto(tier)`
  （流入该层关系的平均弹性，:365）—— 自 T0 → T3 单向。
- 总 clamp [−5%, +8%]；`PriceIndex[tier] *= 1 + mom`。

### 5.4 ④ applyGoodsEffect — 消费品价格联动（:400-423）

链 id → 受影响消费篮子类别（`chainGoodsMap`，:214）：food 链→食品烟酒、energy 链→交通通信、
elec 链→生活用品及服务。对每条链聚合链内 Inventory/safetyLine 比 r，直接
`it.PriceIdx *= 1 + invRatioPriceEffect(r)`。**②B 在 ④.5 GoodsMonthStep 之前执行**，
Goods 以调整后的 PriceIdx 为基计算当月 MomChange —— 链条冲击体现在当月环比，
不二次计价（《供应链调度与确定性验证》§4）。

## 6. 价格稳定机制（关键取舍 ③）

稳态世界价格不应无故漂移。三重保证：

1. **稳态播种**（`NewSupplyChain`，:176-199）：Inventory = 2×baseDemand（恰为安全线）、
   AvgShip = baseDemand、Utilization = base/Capacity、FillRatio/SupplyRatio = 1、
   PriceIndex 全 1.0 —— **首月即均衡，无瞬态**；只有需求变化才产生有界瞬态。
2. **中性带 [1,2]**：库存比在 1~2 倍安全线之间时价格效应恒为 0 —— 库存正常波动
   不转化为价格噪音。
3. **单月涨幅双侧 clamp**：自失衡+传导合成后 ∈ [−5%, +8%]。

实测（seed 42，12 月 `SettleMonth` 全链路运行，`TestSupplyChainLinearFoodChain`）：
四层 PriceIndex 收敛至 **[1.0078, 1.0115, 1.0275, 1.0352]** —— 偏离基线均 < 4%，
远低于测试门禁 [0.9, 1.1]（<10%）；食品链 5 节点 Utilization 全部 ∈ (0,1]。

## 7. R5-1 断供防护（关键机制汇总）

| 机制 | 实现 | 效果 |
|------|------|------|
| 安全库存 2 月 | `SafetyStockMons=2.0` + 强制补产分支 | 短期断供靠库存缓冲,不立即缺货 |
| 断供折算 | 需求 × (0.5+0.5×上游FillRatio) | 上游全断 → 下游仍保 50% 需求,不停产 |
| 利用率下限 | `SupplyUtilFloor=0.15` | 惨淡但不停产(与降 50% 配套) |
| 库存上限 | Capacity×3 | 防无限堆积 |
