## 1. 一句话摘要

`SovereignBond` 国债机制：现金 < 3×月支出时触发发行（发行量 = 缺口 × 80%，clamp [10 万, 500 万]，票面 = 5Y LPR + 0.20%，期限 60 月）。**R4-1 政府自持记账**——发行只记 `BondsOutstanding` 不产生现金流入，利息与到期兑付是真实现金流出，使国债成为纯粹的「未来义务/财政纪律」机制而非印钞通道。

## 2. R4-1：禁止央行透支（设计第一约束）

真实世界的财政风险莫过于「财政部直接向央行透支 → 基础货币无限扩张」。虚拟城市在**三个层面**锁死此路径：

| 层面 | 机制 | 落点 |
|------|------|------|
| 引擎层 | 财政四文件对 `CentralBankState` **零写入、零货币操作**；唯一触碰是 `couponRate5Y`（L58–67）**只读** `w.CB.LPR5Y()` 取票面定价基准（CB 为 nil 时回退 3.5% + 0.20%） | treasury.go L9–11 头注释 + sovereign_bond.go L59–63 |
| Ledger 层 | `gov:treasury` 与央行/银行/市场/企业/保险/系统外之间**不存在任何通道**（只允许 → seat + CatWelfare） | ledger.go L169–183 |
| 现金流层 | 发行**不产生**现金流入（无认购方打款）；利息/兑付为真实 Cash 流出 | sovereign_bond.go L7–10 |

**验证**：`TestSovereignBondNoCBOverdraft`（treasury_test.go L322–370）构造存量国债 + 低现金触发全链路（含发行），断言 CB 六字段（M0/BaseMoney/GovBondsHeld/LoansToBanks/Reserves/PolicyRate）逐项零变化，且所有 `gov:treasury` 流水 to ∈ {seat:*}。

### 2.1 R4-1 的机器验证方法（值拷贝对拍）

```go
cbBefore := *w.CB            // 值拷贝快照
```

- `CentralBankState` 含 `History []CBMonthlySnapshot` 切片字段（central_bank.go L101），值拷贝共享底层数组——故测试**不**对 History 做全量 `==` 对拍，只断言标量字段；新增 CB 字段若属货币面，应手工加入对拍清单（测试注释已示范）。
- 引擎层防线是**零写入**而非零引用：定价只读 `LPR5Y()` 不构成透支；`grep -n "CB\." treasury.go fiscal_policy.go transfer_payment.go sovereign_bond.go` 应只命中 sovereign_bond.go 的 `LPR5Y()` 一处。

### 2.2 真实机制 vs 本实现

| 真实世界国债 | 本实现 | 取舍理由 |
|-------------|--------|---------|
| 投资者认购，政府获得现金 | 自持记账，0 现金流入 | 防「发债=免费钱」，保留还本付息的纪律本质（§4） |
| 央行可二级市场购债（QE） | 央行完全不参与 | R4-1 一刀切；OMO 已在阶段 3 工具箱独立建模 |
| 一级/二级市场定价（招标贴现） | 票面 = 5Y LPR + 0.20% 固定加点 | 确定性要求，无市场博弈 |
| 期限结构（1/5/10/30 年） | 单一 60 月 | 60 月在 420 月局内可完整走完发行→兑付周期（§6） |
| 违约风险溢价 / 评级 | 无（国库见底时利息挂账顺延） | 主权货币下的简化 |

## 3. 发行规则（IssueBonds，L73–102）

### 3.1 触发与额度

```
threshold = monthSpend() × 3                 // 月支出基准 = max(上月支出, 20000 下限)
if Cash >= threshold: 不发行                  // 流动性充足
gap      = threshold − Cash
amount   = gap × 80%, clamp [100000, 5000000] // 计算值 < 10 万 → 不发行(不具经济性)
```

| 常量（L20–36） | 值 | 语义 |
|------|----|------|
| `BondIssueTriggerMonths` | 3 | 现金 < 3×月支出触发 |
| `BondIssueGapFill` | 0.80 | 发行量 = 缺口 × 80%（留 20% 自筹压力） |
| `BondMinIssue` / `BondMaxIssue` | 100,000 / 5,000,000 | 单次发行 clamp |
| `BondDefaultTenureMonths` | 60 | 期限 60 月（5 年） |
| `BondCouponSpread` | 0.0020 | 票面 = 5Y LPR + 0.20% |
| `BondCouponFallbackRate` | 0.035 | CB 缺失回退（= InitialPolicyRate 3% + TermPremium 0.5%；正常路径不触发） |

`monthSpend()`（treasury.go L222–228）取 `max(LastMonthExpense, TreasuryMinMonthlyExpense=20000)`——下限防首月 `LastMonthExpense=0` 时「阈值=0 → 永不发行」的退化。

### 3.2 债券结构（L39–45）

```go
type SovereignBond struct {
    ID           string  // "GB<issueMonth>-<seq>",如 GB36-2
    IssueMonth   int     // 发行月(主钟)
    TenureMonths int     // 期限 60 月
    FaceValue    int64   // 面值(元)
    CouponRate   float64 // 票面利率 = 发行时 5Y LPR + 0.20%(锁定票面,不随 LPR 浮动)
}
```

票面利率经 `couponRate5Y(w)`（L58–67）取 `w.CB.LPR5Y() + 0.20%`（`LPR5Y` = `cb.ComputeLPR()`，central_bank.go L352–354；`ComputeLPR` = PolicyRate + TermPremium 0.5% + CreditSpread），负值 clamp 0。**发行时锁定**——后续 LPR 变动不影响存量票息（固定利率债口径）。

初始参数下的推导：PolicyRate = 3%（`InitialPolicyRate`，central_bank.go L18）+ TermPremium 0.5%（L29）+ CreditSpread 0（新局初值，L148）→ LPR5Y = 3.5% → 票面 = 3.5% + 0.20% = **3.7%**——与 `TestSovereignBondNoCBOverdraft` 手工构造的 `CouponRate: 0.037` 及其付息断言（200 万 × 3.7% ÷ 12 = 6,167 元）一致。

发行成功 `w.emitEvent("policy", -1, "财政部发行国债 GB…:面值 ¥…,票面利率 …%,期限 60 个月(自持记账,R4-1 不向央行透支)")`（L98–100）。

### 3.3 单只国债全生命周期走查（发行 16 万 @ 3.7%）

对应 `TestSovereignBondIssue` 场景：`LastMonthExpense = 10 万`、Cash = 10 万 → threshold = 30 万、gap = 20 万、发行 = 16 万，ID = `GB<月>-1`：

| 时点 | 现金流（⑨D 步骤） | BondsOutstanding |
|------|------------------|------------------|
| 发行月 M | **0**（③ 发行在 ①② 之后，自持记账不流入） | 160,000 |
| M+1 … M+59（每月） | −493（① `MonthlyBondInterest`：160,000 × 3.7% ÷ 12 = 493.33 → 493） | 160,000 |
| M+60（到期月） | −493（① 常规付息，债券此时尚在簿）**再** −160,493（② `RepayMatureBonds`：本金 + 末期票息） | 0 |
| **全周期合计** | **−190,073**（本金 16 万 + 票息 30,073 = 61 期） | — |

> **到期月双票息口径**：`MonthlyBondStep` 顺序为 ①付息 → ②兑付——到期月债券仍参与 ① 的常规付息，随后 ② 又支付 `FaceValue + monthlyCoupon()`（L131）。即 60 期常规票息（M+1…M+60）+ 1 期兑付末期票息 = 61 期，总利息 ≈ 本金 × 18.8%。注释「本金 + 最后一期利息」按此实现语义理解。

## 4. 自持记账的设计动机（为什么发行不产生现金流入）

**为什么不模拟投资者认购**（如让银行/居民购买国债、政府获得现金）：

1. **反因果**：若发行即得现金，则「发债 = 免费钱」，与 R4-1 想防的透支只差一层壳——政府永远可以通过发债获得无限流动性，财政纪律形同虚设。
2. **货币侧已覆盖**：央行资产负债表已有 `GovBondsHeld` 字段（央行持有国债的货币政策操作载体）；财政侧再建认购通道会与央行公开市场操作（OMO）语义重叠。
3. **保留纪律的本质**：真实国债对政府的约束是**未来还本付息义务**。自持模型下这一约束完整保留——发行产生 `BondsOutstanding`（义务），每月真实现金流出（利息），到期一次性流出（本金 + 末期利息）。国库必须靠税收覆盖这些流出，否则利息挂账、兑付顺延（§5），赤字压力显性化。

**记账推论**：发行面值**不计入**当月 `History.Expense`（无现金流出，`MonthlyBondStep` L156 注释）；只有利息与兑付计入 `History.BondService`。

## 5. 月度处理（MonthlyBondStep ⑨D，L148–156，顺序锁定）

```
① MonthlyBondInterest()  每月付息: Σ(面值 × 票面利率 ÷ 12)
② RepayMatureBonds(month) 到期兑付: 本金 + 最后一期利息
③ IssueBonds(w)          付息/兑付流出后再评估流动性,缺口更真实
返回 ①+②(当月国债还本付息合计 = History.BondService)
```

- **付息**（L106–120）：逐只 `monthlyCoupon()`（L53–55），`coupon > Cash` 时跳过——**利息挂账顺延**（不透支、不清零、下月重试），国库见底时债务负担自动加重（隐性惩罚）。
- **兑付**（L124–142）：`matured(month)`（L48–50）判定 `month >= IssueMonth + TenureMonths`；应付 `FaceValue + monthlyCoupon()`；现金不足按到期序兑付至见底，未兑付债券**保留在下月再试**（`kept := t.Bonds[:0]` 原地过滤，零分配）。兑付成功同步 `BondsOutstanding -= FaceValue`。
- **③ 在 ①② 之后**：先承受债务流出再评估流动性，发行的缺口口径包含本月债息/兑付压力——不会出现「先发债囤现金、后付息」的时序套利。

## 6. 期限设计与游戏终局对齐

主钟 `Month 1..420`（engine.go L142），国债期限 60 月：

- **第 1–360 月发行的国债**可在局内到期兑付（`IssueMonth + 60 <= 420`）——完整的「发行 → 付息 × 60 → 兑付」周期能被玩家观察到；
- **第 361–420 月发行的**成为终局悬置义务（`BondsOutstanding` 留在最终快照）——末日财政的「击鼓传花」现象可被复盘，而非强迫终局清算。

## 7. 与财政月结其他步骤的协同

| 步骤 | 与国债的关系 |
|------|-------------|
| ⑨A 税收 | 国库现金的主要补充；付息/兑付能力的根源 |
| ⑨B/⑨C 支出 | 先于 ⑨D 执行——支出耗竭现金后发债评估的缺口更真实 |
| ⑨E History | `BondService` 字段记录当月还本付息（TestSovereignBondNoCBOverdraft 断言 200 万 × 3.7%/12 = 6167 实付）；`DeficitRun` 连续 3 月赤字播报「政府考虑发债融资」（treasury.go L213–215） |

**典型债务螺旋**（可复现的涌现行为）：税收不足 → 赤字 → 现金耗竭 → 发债 → 债息加大支出 → 更深赤字。但有三重刹车：支出上限 min(现金×5%, 收入×110%)、紧缩减半（< 100 万）、发行 clamp 500 万/次——国债余额的增长有界，不会数值爆炸。

## 9. 边界与已知简化

1. **不模拟二级市场**：国债不可转让、不可质押、无市价——`Bonds` 明细仅供付息/兑付遍历，玩家无法持有国债（未来若做「居民购债」需新建 `to=gov:treasury` 白名单通道 + 现金流入语义，属破坏 R4-1 简化的后续决策）。
2. **利息挂账无罚息**：现金不足跳过的票息下月原额重试（不滚利）；真实主权债务的违约溢价未建模。
3. **单一期限**：所有国债 60 月，无长短期结构（收益率曲线的财政端简化）。
