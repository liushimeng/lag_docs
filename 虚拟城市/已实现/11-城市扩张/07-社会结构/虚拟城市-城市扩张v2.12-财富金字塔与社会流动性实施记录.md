## 3. 月度社会流动性 MobilityYoung（society_stats.go:238-257）

### 3.1 定义

> 主时钟 **<30 岁**的玩家中，本月财富排名较上月**上升**（rank 变小）的比例
> ∈ [0,1]；无有效样本（首月无基准 / 全员 ≥30 岁）→ 0。

计算依赖两个前置产物：

- `Ranks` 排名缓存（society_stats.go:63-65 / 160-162）：`map[seat]int`，seat →
  财富降序排名（1=最富），**并列按 seat 升序 tie-break**。挂在快照上
  （`json:"-"` 不下发客户端），作为下月对比基准 —— 不存排名就无法定义「流动」。
- 上月快照：`w.SocietyHist.Latest()`（环形历史最后一条）。

### 3.2 年龄口径：主时钟 w.Age() < 30

- 阈值常量 `societyMobilityAge = 30`（society_stats.go:37），**含 29 岁**；
- 年龄用主时钟 `w.Age()`（engine.go:319-323：`startAge + (Month-1)/12`，
  `MasterStartAge = 25`，engine.go:115）—— 与 `settlePlayer` 结算口径一致；
  混龄卡个人 age 仅展示用途，不参与统计；
- **主时钟是全体共享的**：开局 25 岁起算，`Month = 61` 时 Age = 25 + 60/12 =
  **30** → 全员退出样本，MobilityYoung 恒 0。即流动性指标衡量的是**对局前 5 年
  （25-29 岁）年轻世代的洗牌强度**，30 岁后社会结构固化，指标自然退役。

### 3.3 对比与计数细节

```go
if prev := w.SocietyHist.Latest(); prev != nil && len(prev.Ranks) > 0 &&
    w.Age() < societyMobilityAge {
    young, risen := 0, 0
    for seat, curRank := range snap.Ranks {   // map 迭代序无关（纯计数）
        prevRank, ok := prev.Ranks[seat]
        if !ok { continue }                    // 上月不在场不计入
        young++
        if curRank < prevRank { risen++ }      // rank 变小 = 上升
    }
    if young > 0 { snap.MobilityYoung = clamp01(float64(risen)/float64(young)) }
}
```

- **上月不在场不计入**（中途入座 / 破产出局后复活等场景）：分母只数两月都有
  排名的玩家；
- map 迭代顺序随机，但只做**纯计数** → 结果与迭代序无关，不破坏确定性；
- `curRank == prevRank`（持平）不上升也不下降，只占分母。

## 4. SocietyHistory 24 月环形历史（society_stats.go:68-109）

| 方法 | 行号 | 行为 |
|------|------|------|
| `Push(s)` | :76-86 | 追加快照；超 `societyHistoryCap=24` 时 copy 最近 24 条到**新数组**（防 append 底层数组无限增长占内存）；nil 接收者 no-op |
| `Latest()` | :89-94 | 返回最近一条指针（空历史 → nil；nil 接收者安全） |
| `Last(n)` | :97-109 | 最近 n 条**时间升序**副本（不足 n → 全量副本；n ≤ 0 或 nil → nil） |

三方法全部 **nil 接收者安全**：引擎接线处（NewWorld + ④.6B 惰性初始化）已保证
非 nil，方法级 nil 防御是双保险 —— 防直接构造的 `World{}` / 旧档反序列化解引用。

容量 24 月 = 2 个对局年：流动性/基尼的同比观察窗，同时内存上限可控
（24 × 快照 ≈ 数 KB）。

## 6. 确定性纪律

- 金字塔是纯计数 switch、流动性是纯排名对比 —— **零 rand 消费**；
- 排名并列 tie-break 按 seat 升序（§3.1）—— 排名稳定 ⇒ 流动性结果稳定；
- 同种子双世界逐月结算，`Ranks` 用 `reflect.DeepEqual` 逐月比对（测试 8）。

## 8. 关键取舍速查

1. **绝对门槛 4 层 vs 相对圈层 3 层并存**：存量结构 + 现金流结构是两个正交
   问题，不合并、不替换。
2. **流动性限定 <30 岁**：对局第 6 年起指标退役（恒 0）是有意设计 —— 与
   「年轻世代向上流动」的社会学口径对齐，避免成熟期排名噪声稀释信号。
3. **Ranks 挂快照而非 World 字段**：排名与快照同生同灭，历史自洽；`json:"-"`
   不下发，防客户端反推他人排名细节。
4. **环形 copy 而非 slice 头指针滑动**：`append` 滚动截断会泄漏底层数组容量，
   copy 到定长新数组内存上界恒定。
5. **趋势 5 字段子集**：广播帧体积优先，完整数据在引擎侧可查。
