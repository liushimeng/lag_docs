### 4.1 世界尺寸常量块（L43–57）

所有与「40」相关的魔法数收敛为一个派生常量块，后续再扩图只改 `WORLD_SIZE` 一处：

```ts
export const WORLD_SIZE = 80;                                        // L47
export const GROUND_TILE = 8;                                        // L49 与城区底板 8×8 同标尺
export const GROUND_REPEAT = WORLD_SIZE / GROUND_TILE;               // L51 = 10（旧 5）
export const FOG_NEAR = WORLD_SIZE * 0.7;                            // L53 = 56（旧 28）
export const FOG_FAR = WORLD_SIZE * 1.5;                             // L54 = 120（旧 60）
export const CAMERA_START: [number, number, number] =
  [WORLD_SIZE * 0.35, WORLD_SIZE * 0.3, WORLD_SIZE * 0.35];          // L56 = [28,24,28]（旧 [14,12,14]）
export const ORBIT_MAX_DISTANCE = WORLD_SIZE;                        // L57 = 80（旧 40）
```

### 4.2 等比派生的消费点

| 元素 | 位置 | 旧 → 新 |

## 8. 城市背景层面板 `CityStatsPanel.tsx`（273 行）/ `.css`

### 8.1 >12 区紧凑模式（L89–98）

```ts
const COMPACT_THRESHOLD = 12;  // 城区数 > 12 触发
const COMPACT_TOP = 10;        // 紧凑模式仅展示 top 10
const compact = districts.length > COMPACT_THRESHOLD;
const ranked = compact ? [...districts].sort((a,b) => (b.population||0)-(a.population||0)) : districts;
const restRows = compact ? ranked.slice(COMPACT_TOP) : [];
const districtRows = compact ? ranked.slice(0, COMPACT_TOP) : ranked;
```

16 区下显示人口 top 10 + 1 行聚合（`restRows` 人口合计、`dimmed` 灰底样式），面板不再随城区数无限增高。

### 8.2 `DistrictBarCell` 竖条单元（L41–72）

单元格自上而下 = 人口数值 / 底对齐条形（`height = population/maxPop`%，最小 4%）/ 区名。条形为纯装饰通道（`aria-hidden`），数值以显式文字标注——**色盲不依赖颜色判读**（CLAUDE.md §26）。聚合行 `id={-1}` + `dimmed`，标签走 i18n `wealth.cityOtherDistricts`（L205）。

### 8.3 CSS（`CityStatsPanel.css` L140 起）

- `.wealth-citypanel__districts`：`flex column` → `grid; grid-template-columns: repeat(auto-fill, minmax(40px, 1fr)); align-items: end`——窄面板自动换行、竖条底对齐。
- `.wealth-citypanel__district--other .wealth-citypanel__district-fill`：独立灰底 `#64748b` 区分聚合行（§26 disabled 反模式：不用 `opacity` 污染）。
- `.wealth-citypanel__district-name`：11.5px → 10px + ellipsis，适配 16 列窄格。

- 路线图 §3.4 提到的 LOD + InstancedMesh 未做（16 区 mesh 预算实测 ≈92，远低于护栏，无必要）。
- 路线图 §3.4「旧房间仍跑 8 城区」未实现——静态表是全局常量，扩展后**所有房间一律 16 区**（前后端同步发版，无兼容层）。
