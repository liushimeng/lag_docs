## 1. 新增只读 API（`game/virtual_city/room_dimension_status.go`，180 行）

```go
type DimensionStatusView struct { Group string; ActiveScenarios []ScenarioBrief; RecentEvents []WorldEventBrief }
type ScenarioBrief struct { ID, Kind, Name string; Magnitude, RemainingMonths int; Target string; AppliedMonth int }
type WorldEventBrief struct { Title, Kind, Source string; ObservedAt int64; Injected bool }

func (r *VirtualCityRoom) SystemDimensionStatus(dim string) DimensionStatusView // 只读、持 r.mu、不回调房间(§92a)
func ScenarioDimensionOf(kind string) string          // kind → 目录分组;未知 → ""
func WorldEventDimensionOf(rec WorldEventRecord) string // 事件归集;归不到 → ""
func CashDamageScenarioBriefs(w *World) []ScenarioBrief // CashDamageFrac>0 活动场景(不加锁,调用方持锁)
```

- **nil 安全**：未开局（`World == nil`）⇒ 维度名在场的空视图；未知 dim（含空串）⇒ 全空视图（`Group == ""`）。
- **返回副本**：全部按值重建；单测断言调用方篡改不污染内部状态。
- **只读验证**：单测对 `World` 做 JSON 全量快照，调用前后逐字节相等（§92a 可执行化）。
- 事件条数 ≤5（`dimensionRecentEventsCap`，与契约 §3.1.1 同口径）。

## 2. 「本维度」归集判据（宁缺勿滥，绝不编造）

| 对象 | 判据 | 归不到时 |
|------|------|----------|
| 活动场景 | `scenarioDefFor(kind).spec.Group == dim`（L1/L2/L3 目录全覆盖） | 不计入 |
| 世界事件 | 先 `ScenarioKind`（事件注入映射的场景 kind）→ 目录分组；再 `Kind`（事件类型）兜底 | **不计入任何维度**（明说不编造） |

- 场景排序新→旧：`w.Scenarios` 为注入序（旧→新），反转后按 `AppliedMonth` 稳定降序。
- 事件按 `WorldEventLog` 原序（本身新→旧）截取 ≤5 条。
- 名称取目录 `spec.Name`；未知 kind 回退 kind 本身（与 `SystemSummaryText` 同口径）。

## 3. scope → 维度映射与 6 个无维度 scope 的取舍

映射**集中定义**在 `dispatch_ext.go::scopeDimension`（一处 map，防 13 处硬编码漂移）：

| scope | 维度分组 | scope | 维度分组 |
|-------|----------|-------|----------|
| `infrastructure` | 基础设施 | `transport` | 交通物流 |
| `public_health` | 公共卫生 | `culture` | 文化教育 |
| `environment` | 环境生态 | `daily` | 民生日常 |
| `security` | 公共安全 | | |

**6 个无对应维度分组的 scope 的取舍**（本实施记录的决策点）：

- `overview` / `market` / `labor` / `treasury` / `election` ⇒ **全局口径**：段头
  「【全局进行中】」聚合全部维度的活动场景（场景行带 `[维度]` 前缀）+「【相关世界事件】」。
- `all` ⇒ 同全局口径（聚合全部维度），叠加在既有「房间摘要 + 7 个子系统」之后。
- 理由：这 6 个 scope 的语义本就是跨维度总览，硬套单一维度会漏报；全局聚合保证
  「注入了什么都能看见」。全局事件合计同样截 5 条（防回灌膨胀）。

## 4. 13 个 scope 输出形态（改前 → 改后）

**公共规则**：输出末尾追加两段（内容非空才加对应段；两段都空 ⇒ 单行
「当前该维度无进行中场景、无相关事件」）：

```
【本维度进行中】
- 供水管道破裂 L3(剩 4 月,作用范围 全域,注入于 M7)
【相关世界事件】
- 东财行情:沪指收涨 1.2%(已注入)
```

| scope | 改前 | 改后 |
|-------|------|------|
| `infrastructure` | 产业链节点/层级价格指数 + 产业集群 | **一字不动** + 追加两段 |
| `public_health` | 五件套指标 + 公共医疗投入 | **一字不动** + 追加两段 |
| `transport` | 交通类价格指数 + 物流依托产业链 | **一字不动** + 追加两段 |
| `culture` | 教育质量 + 教育投入 + 教育价格指数 | **一字不动** + 追加两段 |
| `daily` | CPI + 8 类价格指数 + 社会结构 | **一字不动** + 追加两段 |
| `environment` | 恒「环境生态子系统未启用」 | **重写**：食品/杂项消费价格指数（供给传导最接近指标，真实 `Goods.Items` 字段）+ 本维度活动场景计数 + 追加两段；无数据明说「暂无该维度指标」 |
| `security` | 「公共安全(治安)子系统未启用」+ 监管罚款 | **重写**：保留「参考:市场监管…累计罚款/上月警告」既有行（零回归），补「居民现金损失类场景」列表（`profile.CashDamageFrac>0`，跨维度如实列出）+ 追加两段 |
| `overview`/`market`/`labor`/`treasury`/`election` | `SystemSummaryText`（未动） | 原文 + 全局口径两段 |
| `all` | 摘要 + 7 个子系统 | 同左 + 全局口径两段 |

⚠ `environment` / `security` **不再出现「未启用」字样**（单测钉死）；其余 scope 的
既有「子系统未启用」行保留（如 `daily` 的「社会结构统计未启用」）——既有内容零回归。
