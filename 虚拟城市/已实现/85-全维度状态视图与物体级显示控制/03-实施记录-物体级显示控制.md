## 3. `set_filter` 类别 → 实例粒度（方案 §3.2.3）

### 3.1 走了哪条路：**退化为「按类别显隐」**（非逐实例调色）

实测结论：车辆 / 行人 / 公园件等 GLB 实例走 `useSharedGLTF` → `scene.clone(true)`，
**跨实例共享材质引用**；逐实例改 `material.color` 会污染同模型全部实例，而安全做法
（每实例克隆材质）= 新建材质实例 ⇒ 违反 draw call 纪律（批次 28/46 教训），且
`DistrictBuildings` 的楼群是**按材质签名合并**的 mesh（几何级无法逐栋调色）。
⇒ 按方案预案退化为「按类别显隐」，并在 `cityShowAdapter` 的 `set_filter` 成功路径
回调 `onNotice({code:'filter_showhide'})` **明示**「当前实现为类别显隐（未做逐实例
调色）」（i18n 三语，窗口内联红条）。**不静默吞**；`engine3d/` 零改动。

### 3.2 类别词汇与匹配（`cityFilterCategories.ts` 新纯叶模块）

词汇（解析优先级：图层名 → 实例词汇 → 未识别）：

1. **图层名**（既有 `CATEGORY_LAYER_MAP` 16 键，**零回归**，命中走图层级显隐）；
2. **物件类别**（objectInfo `ObjectCategory` 枚举值：civic / landmark / road / edge /
   sky / ground / agent …）；
3. **物件种类**（注册表条目 id 的全形 / 族前缀 / 种类后缀：`civic.city-hall` /
   `park` / `bench` / `fire-station`…）；
4. **车辆类型**（`sedan` / `truck` / `bus` / `taxi` = `vehicle.<variant>` 的种类后缀）。

匹配规则（实例 tag = objectInfo id `X.Y`）：`c === X.Y`（全形）∨ `c === X`（族前缀）
∨ `c === Y`（种类后缀）∨ `注册表条目.category === c`。⚠ 宽匹配是刻意口径：
`road` 同时命中 `road.*` 与 `tree.road`（行道树）；`park` 命中 `tree.park` + `park.*`。
`hospital` / `school` 等注册表里不存在的类别 ⇒ `unknown_category` 提示（诚实拒绝）。

mode 语义（退化口径）：`highlight` = 只渲染命中实例（隔离）；`dim` = 隐藏命中实例；
图层级 category 仍由 `effectiveLayerVisible` 收口（实例级 category 不动整层）；
`category` 空 = 取消筛选（既有语义不变）。

### 3.3 实例显隐接线表（visible 闸门，不卸载组件）
