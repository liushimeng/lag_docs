## 2. 与方案的偏差（含理由）

| # | 偏差 | 理由 |
|---|---|---|
| D1 | **`CAP_high` 160 → 110、`CAP_low` 90 → 60** | 方案 §6.1 初稿写 160/90。落地时复核批次 28 性能账：行人**不实例化**（每人一个 GLB clone + AnimationMixer），160 会多约 100 DC，而默认视角 DC 已超预算。110 仍严格满足用户 R6（N≤100 全上街）。方案 §6.1 已回填 ⚠ 注 |
| D2 | `char_formal` 判据排在 `char_business` **之前** | 财富档 = 3 一律读作「高净值/高管」观感；否则金融域高净值者退化成普通白领。方案 §5.1 表已回填优先级说明。前后端同序 |
| D3 | `path` 总长 6~10 世界单位 → **1.5~3.5 世界单位** | 初稿数字过长（60–100 m），会在 8×8 城区底板上走穿。改与 `pathForDistrict` 有效弦长同量级（15–35 m），并把折线每点钳回底板内。方案 §6.2 已回填 |
| D4 | churn 后端传 `b.month` 而非 0 | `Snapshot()` 无 month 入参，但 `Backdrop.month` 锁内可得；`CHURN_PERIOD ≈ 1 城市月`，月数即换班代数 |
| D5 | 后端 churn 为「整代重洗」，前端 `churnCrowd()` 才是 §6.3 的 10% 增量换 | 分层：后端保证同 churn 恒同视图（可测试），前端负责「换人不换人数」的观感节奏 |
| D6 | 未锚定居民 `CardID/Name/Health` 空串、`Gender="u"` | 符合方案 §6.4「若未锚定则留空」；Archetype 由合成特征推 |
| D7 | 财富档阈值用 10 万卡池离线实测分位 | 方案只说「各分 4 分位」无数。实测 income p25/p50/p75 ≈ 9,000/12,750/19,000、savings ≈ 33,000/90,000/200,000，已写入 `crowd.go` 注释可复核 |
| D8 | `ResidentProfile` 额外补 `Employment` / `ChildrenCount` | 初版只补 `Gender` ⇒ `char_service`（平台/灵活就业）与 `char_parent` 两路原型判据**永不命中**（§130「声明了却从不接线」）。补两个字段后全 8 原型可达 |
| D9 | `python-generate-image-tool` 未使用 | 辉光/渐隐贴图用 `CanvasTexture` 更轻更可控；AI 生成贴图在发光类上批次 16 已技术否决（窗口错位）。方案 §9-8 已列不做 |

### 5.1 本次踩到的三个验收环境坑（复用请照做）

| # | 症状 | 根因 | 解法 |
|---|---|---|---|
| E1 | 页面出现「登录」弹层、`document.querySelector('canvas')` 为 null、3D 场景不挂 | **JWT 有效期 7200 s 过期**；注入 localStorage 后服务端仍 401，`AuthModal` 盖住页面 | 验收前先 `POST /api/captcha` + `POST /api/auth/login` 换新 token；别沿用旧 token |
| E2 | `Page.captureScreenshot` / `page.screenshot` 抓到**另一个标签页**的画面（房间号、天气、相机全对不上 JS 读数） | 目标浏览器里残留旧页面，CDP 截图落在「活动目标」上 | 起验收脚本前 `for ctx in browser.contexts: for pg in ctx.pages: await pg.close()`；截图后**用 PIL 算视口均色自检**，别只信肉眼 |
| E3 | 改 `window.__freeViewDebug._rig.current` 的 `radius/pos` 不生效，相机纹丝不动 | 该 debug 句柄是**已卸载实例的 ref**，与在跑的积分器不是同一份；且相机位置每帧由 rig 写出 | 用**真实键盘/鼠标**驱动（`Digit1/2` 切模式、`KeyQ` 下潜、滚轮推近），或读 `__freeViewDebug.position` 回验位移 |

> E1 的连带影响：过期 token 之后的多轮截图全是登录页，一度误判为「相机不生效」。
> **截图必须做像素自检**（视口均色 / 暖光像素占比），否则会被表象误导。
