# 虚拟城市 — 3D 城市渲染深化 · 产品设计（14-3D城市渲染深化 · 01）

> 2026-09-22。前置：13-3D城市渲染优化（阶段 A–F 已交付）。
> 契约文档：02 架构设计 / 03 资产方案 / 04 UI 规范 / 05 路线图。
> 目标一句话：**把「能看的积木城市」推向「可信的真实城市」**——
> 地表不再是裸沥青，建筑有底商与招牌，道路有站台家具，水面会流动，行人会走动。

## 1. 现状差距（13 轮审计结论）

| 维度 | 13 轮已达成 | 距「真实城市」仍缺 |
|---|---|---|
| 地表 | 沥青 tile 全域平铺 | 无草地 / 广场铺装 / 水面；城区像漂浮在马路上的盒子 |
| 建筑 | 5 archetype 体块 + 立面/屋顶贴图 + 暖窗光 | 无底商 / 雨棚 / 招牌广告；塔楼中段偏「素」 |
| 道路 | 车道 + 中线 + 人行道 + 路灯 + 斑马线 + 红绿灯 | 无公交站台 / 消防栓 / 长椅等街道家具；无车道虚线 |
| 人物 | Billboard 行人（原地微抖）| 不会走动，近景「贴纸感」 |
| 渲染 | Sky + ACES + PCFSoft 阴影 + 雾 | 每栋楼独立加载同源贴图（重复 GPU 上传）；轨道相机无阻尼 |
| UI | Tab 分组 + 折叠 + z-index 协约 | 窄屏顶栏可能溢出；waiting 区大面积留白 |

## 2. 产品目标（可感知的 6 条）

1. **有水的城市**：地图开一条城市运河 + 物流港港池，水面缓慢流动。
2. **有绿的城市**：中央公园成片草地；每城区有树池/草坪点缀。
3. **有生活的城市**：楼栋底层有底商雨棚与灯带，塔楼挂广告牌。
4. **有秩序的城市**：城区有马路牙子（curb），主干道有公交站台与街道家具。
5. **有人的城市**：行人沿城区环线漫步，不再原地抖动。
6. **更顺的城市**：同源贴图共享加载，轨道相机带阻尼，帧率与观感同时提升。

| 元素 | 布点 | 形态 |
|---|---|---|
| 公交站台 | 每条主干道 t=0.35 路侧 | 双柱 + 顶棚 + 灯箱（几何） |
| 车道虚线 | 主干道全段 | centerline 贴图已有点线，断续段补 on `Road` 两侧车道分隔 |
| 行人漫步 | 每城区 1–2 人 | 沿城区内半径 1.2–2.0 环线慢速行走（useFrame） |

### 3.5 渲染观感（无新 UI）

- 同源贴图**进程级共享缓存**（约 240 次重复上传 → 约 30 次唯一上传）。
- 轨道相机 `enableDamping`（0.08）——拖拽/缩放手感更接近真实城市漫游。
- 水面流动动画与车辆/行人共用 `REDUCED_MOTION` 开关。

### 3.6 UI 布局加固

- 顶栏 `flex-wrap` + min-width:0，1280×800 不横向溢出。
- waiting-board 占位加载态压缩留白（spinner 区收紧，不空半屏）。
- 既有 Tab 分组 / 折叠 / z-index 协约（13 阶段 E）不动。

## 4. 非目标（本轮不做）

- 昼夜循环 / 夜景点光源（复杂度高，另立专项）。
- 真 3D 人物骨骼模型（保持 Billboard sprite，仅加漫步）。
- 阴影级联（CSM）——2048 单级阴影已覆盖全城，收益不抵复杂度。
- 后端协议 / 经济引擎改动（本轮纯前端 + 资产脚本）。

## 5. 验收体感标准

- 截图巡检 1280×800 / 1920×1080：能看到水面、草地、底商雨棚、公交站台、漫步行人。
- 中央公园远景「绿化为主」不被建筑压盖；运河不与任何城区底板重叠。
- 拖拽轨道相机有阻尼收尾；`prefers-reduced-motion` 下水面/行人/车辆全部静止。
- 全城 mesh 预算 ≤ 2500（13 文档 02 §5 护栏沿用）。
