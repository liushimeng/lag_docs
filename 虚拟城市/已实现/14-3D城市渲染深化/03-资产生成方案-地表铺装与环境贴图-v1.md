## 1. 本轮资产清单（3 张，程序化轨道）

| 文件 | 尺寸 | 类别 | 用途 | 消费点 |
|---|---|---|---|---|
| `ground/grass_tile.png` | 512×512 | ground | 中央公园草地 / 河岸草皮 | DistrictBlock / WaterLayer |
| `ground/plaza_tile.png` | 512×512 | ground | 交通枢纽广场 / 金融 CBD 小广场 | DistrictBlock |
| `ground/water_tile.png` | 512×512 | ground | 城市运河 / 物流港港池水面 | props/WaterPlane |

- 全部 **可平铺**（tileable）：四边纹理连续，RepeatWrapping 无接缝。
- 幂等 skip-if-exists；`--force` 覆盖；确定性 seed = FNV-1a(文件名)（与 13 轮一致）。
- AI 轨道不需要（程序化生成的平铺噪声/砖纹质量已足够；`python-generate-image-tool` 不参与本轮）。

## 2. 程序化规格

### 2.1 `grass_tile.png`

- 底色 `#3f7a3a`，2–3 层高斯模糊噪声斑块（深 `#2f5f2c` / 亮 `#5c9a4f`）。
- 细碎草叶 speckle（短线段 800 根，角度 ±30°，长 2–5px，透明度 0.25–0.5）。
- 轻度 vignette **不要**（平铺会露边）——噪声全部 wrap-safe（生成时对边缘做 32px 环形平铺采样）。

### 2.2 `plaza_tile.png`

- 浅灰石材 `#9aa1ab` 基底 + 4×4 石板网格缝（缝色 `#7c838d`，线宽 2px）。
- 每格微亮度抖动 ±5%（模拟不同石板），中心 2 格允许对角拼花。
- 缝网格必须整除 512（128px/格）保证平铺。

### 2.3 `water_tile.png`

- 深青蓝渐变基底 `#1c4a66` → `#2a6a8a`（低频噪声驱动，非线性渐变）。
- 波纹：60 条正弦扰动横纹（波长 64px，振幅 3–6px，线宽 1–2px，白色 alpha 0.08–0.18）。
- 少量亮点高光 speckle（50 点，alpha 0.2）。
- **纵向可平铺**（水面沿 v 方向滚动）：波纹相位 wrap-safe。

## 3. 代码接线

### 3.1 `ClientWeb/src/assets/images/wealth/index.ts`

```ts
const groundImgs = import.meta.glob<string>('./ground/*.png', { eager: true, import: 'default' });
export type GroundTileName = 'grass_tile' | 'plaza_tile' | 'water_tile';
export function groundTileUrl(name: GroundTileName): string {
  return groundImgs[`./ground/${name}.png`] ?? '';
}
```

- 降级契约（§9）：返回 `''` 时组件走纯色兜底（grass→`#3f7a3a` / plaza→`#9aa1ab` / water→`#1a3a52`）。

### 3.2 生成器扩展（`3d_script/procedural_city_textures.py`）

1. 新增 `GROUND_DIR = WEALTH_DIR / "ground"`。
2. 新增生成函数 `gen_grass_tile()` / `gen_plaza_tile()` / `gen_water_tile()`（纯 Pillow）。
3. `--only` 类别追加 `ground`；默认全量运行时补齐 ground 缺口。
4. 头部 docstring 产物清单同步。

## 4. 验收

1. `python3 3d_script/procedural_city_textures.py --only ground` 产出 3 张 PNG（512×512）。
2. 重跑同命令：全部 `skip`（幂等）；`--force --only ground` 重生成且确定性一致。
3. `groundTileUrl('water_tile')` 非空（grep 接线）；删图后水面/草地/广场均降级纯色不报错。
4. `npm run build` 产物含 ground/*.png（import.meta.glob 打包进 dist）。
