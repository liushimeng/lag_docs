## 1. 硬约束复述（CLAUDE.md §7.1 / 13 轮协约）

1. 控件不得溢出视口；不得互相重叠；不得大面积留白。
2. z-index 协约不变：modal 200 / error banner 50 / 小地图 40 / hover 卡 ≤30 / token 标签 ≤9。
3. 折叠/展开优先于隐藏；`CollapsibleSection` 持久化 localStorage。
4. 对比度 §26.1：正文 ≥4.5:1、徽章 ≥5:1、焦点态 ≥6:1。
5. `wealth.css` 已 1738 行（≤1800 硬上限）——本轮新样式只进 `wealth-city3d.css`。

## 3. 样式契约（`wealth-city3d.css` 增补）

```css
/* ── 阶段 J · 顶栏与占位加固 ─────────────────────── */
.wealth-topbar { flex-wrap: wrap; row-gap: 6px; }
.wealth-topbar__meta { display: flex; flex-wrap: wrap; align-items: center; gap: 4px 10px; min-width: 0; }
.wealth-topbar__actions { flex-wrap: wrap; justify-content: flex-end; }
@media (max-width: 1279px) {
  .wealth-topbar__actions { margin-left: 0; width: 100%; }
}
.waiting-board {
  display: flex; flex-direction: column; align-items: center; justify-content: center;
  gap: 10px; min-height: 160px; padding: 12vh 16px;
}
.wealth-map-area { min-height: 320px; }
@media (max-width: 1279px) { .wealth-sidebar { flex-basis: 300px; } }
```

- 特异度说明：与 `wealth.css` 同选择器同特异度 → 靠链尾顺序胜出（`wealth-city3d.css` 在 `globals.css` 末尾 import）。
- 不改 `@import` 顺序（§2.1 约束 4）。

## 4. 交互不变量（本轮不许破坏）

- Tab 分组折叠、CityStatsPanel/WealthBotPanel 折叠、localStorage 键名不变。
- 小地图点击聚焦、hover 卡 `zIndexRange={[30, 0]}`、error banner 50 不变。
- `prefers-reduced-motion` 下折叠动画关闭（已实现，保留）。

## 5. 验收

1. 1280×800 / 1920×1080：顶栏单行放不下时优雅换行，无横向滚动条。
2. waiting 态不出现「上半屏空白 + 中央 spinner」的疏松布局。
3. 全部面板空态文案可见、无半屏空白。
4. z-index 抽检：hover 卡不盖小地图；error banner 盖住 hover 卡。
5. `tsc --noEmit` + `npm run build` 全绿。
