## 1. 背景与目标

虚拟城市渲染栈经批次 13–20 已逐批演进为真 3D（WebGL 真实感 / PBR / Blender .glb /
32 城区 120×120），但仍有三处「2.5D」残留：

1. **文档语义滞后**：P0 契约与索引仍把现行架构描述为 2.5D。
2. **相机 2.5D 约束**：`maxPolarAngle=1.2`（≈69°）锁定俯视，永远无法压到街面视角；
   无第一人称漫游能力。
3. **架构债**：通用渲染能力（GLB/贴图缓存、PBR 拼装、PMREM 环境、软件渲染器检测、
   feature flag）散落在游戏私有目录，其他 3D 游戏无法复用。

本批次目标：文档 2.5D→3D 收口；抽取 `ClientWeb/src/engine3d/` 通用引擎；
相机升级自由 3D（解锁俯仰 + 街景漫游双模式）。

## 2. engine3d 通用引擎模块

```
ClientWeb/src/engine3d/
├── index.ts                  统一出口（barrel）
├── EngineCanvas.tsx          通用 Canvas 封装（ACESFilmic / PCFSoft / dpr 质量档 / debug renderer.info）
├── Model.tsx                 通用 GLB 渲染组件（children fallback 契约，自 virtualCity 迁入）
├── modelCache.ts             进程级 GLTF 缓存（自 virtualCity 迁入）
├── textureCache.ts           共享贴图缓存 + useSharedPBR + withPBR（迁入通用部分）
├── EnvBinder.tsx             PMREM 天空环境绑定（迁入并参数化）
├── quality.ts                软件渲染器检测 / QualityTier / blenderModelsEnabled()
└── controls/
    ├── CameraViewReporter.tsx   相机视野快照 → ref（自 CityMap 内联 CameraReporter 泛化）
    ├── FocusLerpController.tsx  focusRef → target 平滑聚焦（自 CityMap 内联 FocusController 泛化）
    └── WalkControls.tsx         新增：街景漫游（WASD + 鼠标拖拽环视）
```

**分层硬约束**：`engine3d/` 禁止 import 任何游戏私有模块；游戏私有的资产路径拼接
（synth 材质 stem）留在 `components/virtualCity/cityPbr.ts` 薄适配层。

**收敛点**：
- 8 处 `localStorage.getItem('disable-blender-models')` 直读 → `blenderModelsEnabled()` 单入口。
- `isSoftwareRenderer` 自 EnvBinder 提取为 `quality.ts` 公共函数。
- `?quality=low` URL 覆盖：dpr 降 [1,1]（EngineCanvas 缺省推导）。
- `?debug=1` 挂 `window.__cityRenderInfo` 的行为经 `EngineCanvas debugGlobalName` 保持兼容。
- `scenes/GameScene` / `LobbyScene` 同步切换 EngineCanvas（引擎通用性的首个外部消费者）。

## 3. 2.5D 俯视 → 自由 3D 世界

| 项 | 升级前 | 升级后 |
|---|---|---|
| 俯仰角 | `maxPolarAngle=1.2`（≈69° 锁定俯视） | `1.54`（≈88°，可压到近街面视角） |
| 视角模式 | 仅轨道俯瞰 | orbit 俯瞰 / walk 街景漫游双模式，地图右上角按钮切换 |
| 漫游 | 无 | `WalkControls`：WASD/方向键移动 + 鼠标拖拽环视，眼高 `u(1.7)`=1.7m，Shift ×3 加速，±W/2 边界 clamp，文本输入聚焦时不劫持按键 |
| 模式衔接 | — | orbit→walk：落点=轨道聚焦点、朝向=相机→聚焦点方向；walk→orbit：聚焦点=漫游位置（OrbitControls 按 epoch 重挂载） |
| 小地图 | 上报 orbit target | 漫游模式 `fallbackToCamera` 上报相机自身位置 |
