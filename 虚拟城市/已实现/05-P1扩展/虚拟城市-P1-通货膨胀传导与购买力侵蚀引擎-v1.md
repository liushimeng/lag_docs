## 1. 设计目标

P1 真实经济循环引擎已让 **CPI 内生化**（八大类消费品加权同比），但「通胀传导到
玩家决策」的链路还没接上：

| 现状缺口 | 真实世界对应 | 教育价值 |
|----------|-------------|---------|
| ❌ 玩家净资产只有名义值 | 通胀吃掉储蓄购买力 | 实际净资产 = 名义 ÷ CPI |
| ❌ 现金存款利率固定 | 真实利率 = 名义利率 − 通胀 | 负利率时代的存款迁移 |
| ❌ 工资调薪只走 P1 Phillips | 工资粘性下通胀是隐形税收 | 名义涨薪 ≠ 实际涨薪 |
| ❌ Agent 决策无通胀感知 | 通胀期行为偏差（抢购 / 抛币 / 囤货）| 货币幻觉 / 通胀心理 |

本 P1 增量**只补「传导」**，不引入新市场：
- 派生指标：实际净资产 / 实际月支出 / 实际存款收益率；
- 央行层：1Y LPR − CPI YoY = 实际利率（已在央行引擎；本节负责下发与展示）；
- Agent 工具：新增 `query_purchasing_power` + `hedge_inflation` 决策辅助。

## 2. 派生指标（World 字段，引擎纯状态，无锁）

### 2.1 数据结构（player.go 新增）

```go
// InflationView 玩家侧通胀视图(2026-09-19 §P1-3 新定)。
// 月结末尾刷新,view 层直读 World.LastInflationTick。
type InflationView struct {
    CPIYoY           float64 `json:"cpi_yoy"`            // 8 类加权同比(小数)
    NominalDepositRate float64 `json:"nominal_deposit_rate"` // 央行 1Y LPR 当前值
    RealDepositRate    float64 `json:"real_deposit_rate"`    // = 名义 − CPI YoY
    PurchasingPower    float64 `json:"purchasing_power"`     // 1 / (1 + CPI YoY);基期=1
}

// Player 新增字段(派生,不持久化):
//   RealNetWorthCNY int64   // 实际净资产 = 名义 NetWorth × PurchasingPower
//   RealMonthlyExpense int64 // 实际月支出 = 名义 Monthly.Expense × PurchasingPower
```

### 2.2 计算公式

```
RealNetWorth     = round(NominalNetWorth / (1 + CPI YoY))
RealMonthlyExpense = round(Monthly.Expense / (1 + CPI YoY))
RealDepositRate  = NominalDepositRate − CPI YoY   // 负值 = 实际负利率
PurchasingPower  = 1 / (1 + CPI YoY)               // 1 元现在能买基期 0.95 元的东西 = 0.95
```

CPI YoY 直接读 `World.Goods.CPIYoY`(P1 真实经济循环引擎已有,本节复用)。

### 2.3 货币幻觉警告阈值

| 阈值 | 含义 | UI 提示 |
|------|------|---------|
| `CPI YoY ≥ 0.03` (3%) | 温和通胀 | 黄色徽章 |
| `CPI YoY ≥ 0.05` (5%) | 明显通胀 | 橙色徽章 + Agent prompt 提示 |
| `CPI YoY ≥ 0.08` (8%) | 高通胀 | 红色徽章 + 触发 `hedge_inflation` 推荐 |
| `CPI YoY ≤ 0` | 通缩 | 灰色徽章 + 防御型提示 |

## 3. 月结接入点

```go
// SettleMonth ④.55 通胀传导(2026-09-19 §P1-3 新定)。
// 顺序:GoodsMonthStep 之后(拿到本月最新 CPI YoY),LaborMonthStep 之前。
func (w *World) InflatePurchasingPower() {
    if !w.EconomyEnabled || w.Goods == nil || !w.Goods.CPIYoYReady() {
        return
    }
    cpi := w.Goods.CPIYoY
    nominalRate := w.CB.LPR1Y() // 央行引擎已有;取当前 1Y LPR
    realRate := nominalRate - cpi
    pp := 1.0 / (1.0 + cpi)

    for _, p := range w.Players {
        if p == nil || !p.Alive {
            continue
        }
        p.RealNetWorthCNY = int64(float64(p.NetWorth(w.Market)) * pp)
        p.RealMonthlyExpense = int64(float64(max64(p.Monthly.Expense, 0)) * pp)
    }

    w.LastInflationTick = &InflationView{
        CPIYoY: cpi,
        NominalDepositRate: nominalRate,
        RealDepositRate: realRate,
        PurchasingPower: pp,
    }
}
```

`World` 新增字段:
```go
LastInflationTick *InflationView  // 月度快照;未就绪时 nil
```

接入 `SettleMonth` 末尾,顺序:
```
④.5 GoodsMonthStep     (已有,P1-2)
④.55 InflatePurchasingPower (本节新增)
④.6 ComputeSociety     (已有,P1-2)
④.65 RecordFlowStat    (P2 v2 已有)
```

## 5. Agent 工具扩展（17 工具 → 19 工具）

### 5.1 新增 `query_purchasing_power` 工具（被动查询）

```go
// WealthActionQueryPurchasingPower 查询玩家当前通胀视图。
// 返回:InflationView 子集 + my 实际净资产/支出。无副作用,允许每回合调用。
type QueryPurchasingPowerResult struct {
    CPIYoY           float64 `json:"cpi_yoy"`
    NominalDepositRate float64 `json:"nominal_deposit_rate"`
    RealDepositRate    float64 `json:"real_deposit_rate"`
    RealNetWorthCNY    int64   `json:"real_net_worth_cny"`
    RealMonthlyExpense int64   `json:"real_monthly_expense_cny"`
    Severity          string  `json:"severity"` // "low" | "moderate" | "high" | "hyper" | "deflation"
}
```

### 5.2 新增 `hedge_inflation` 工具（推荐动作,不强制）

```go
// WealthActionHedgeInflation 给 Agent 提供"通胀期建议配置"。
// 返回:3 条候选动作(不强制执行);Agent 可选其中 0~3 条加入 submit_month。
// 设计意图:教育而非约束 —— Agent 仍可自由决策。
type HedgeInflationRecommendation struct {
    Options []HedgeOption `json:"options"`
}
type HedgeOption struct {
    Type        string  `json:"type"`        // "buy_bond" | "buy_gold" | "repay_mortgage" | "increase_savings"
    Rationale   string  `json:"rationale"`   // ≤60 字
    ExpectedImpactCNY int64 `json:"expected_impact_cny"`
}

// 推荐算法(简化):
//   CPI YoY ≥ 5%:
//     - 持有现金 > 3 月支出 → 推荐 buy_bond / buy_gold
//     - 房贷利率 > 实际利率 → 推荐 repay_mortgage(实为抗通胀)
//   CPI YoY ≤ 0%:
//     - 推荐 increase_savings(通缩期现金为王)
```

### 5.3 Prompt 注入

`BuildTools` 在 `agent_runner.go` 中追加这两个工具;Agent system prompt 在通胀
`severity == "high"` 时追加一段"⚠️ 通胀警告:实际购买力已下降 X%"提示。

## 9. 不做的事(写入 P2+)

- ❌ 抗通胀资产(REITs、TIPS、外汇、商品期货):本节只展示指标,不引入新资产。
- ❌ 工资指数化(automatic indexation):工资粘性是 P1 已有教学价值,本节不破。
- ❌ 央行"通胀目标制"(inflation targeting):央行策略太复杂,留 P2 央行决策树。
- ❌ 工资-价格螺旋(wage-price spiral):已通过 Phillips 隐含,本节不显式建模。
