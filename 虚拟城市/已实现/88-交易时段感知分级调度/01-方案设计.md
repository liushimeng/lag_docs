# 批次 88 · 交易时段感知的采集分级调度 — 方案设计

> 2026-11-06 · 职责线 2 / City-Chrome 工作面(`ServerGo/citychrome/` + `ServerGo/config/`)。
> 落地《虚拟城市模拟系统·自迭代优化规范》两条硬指标(§三.2 刷新分级、
> §五.6 交易时段感知),并把 `realworld_info` 的 stale 判定改造为同口径。

## 1. 背景与规范依据

《虚拟城市模拟系统·自迭代优化规范》原文摘引:

- **§三.2**:「刷新分级:行情分钟级、新闻小时级、宏观日级」。
- **§五.6**:「交易时段高频抓取行情,新闻与突发消息走分钟级轮询,宏观数据
  日/周级更新,非交易时段自动降频」。

**改造前现状**(批次 76 分级调度):

- 6 个行情类目(a_share/hk/us/metal/futures/crypto)共用恒定 1800s 轮转间隔;
- 全仓零命中任何交易时段判定(主 Agent 摸底确认);
- `realworld_info op=overview` 的 `stale = age_seconds > 2×categoryRefreshInterval(cat)`
  与恒定间隔强耦合 —— 若只改轮转不改 stale,休市时段会按 600s 档假性报 stale。

**本批次目标**:① 行情开市分钟级、休市自动降频;② news/macro 行为一字不变;
③ stale 判定与档位取同一时刻、同一档位(防假性告警);④ wire/JSON 契约零变更。

## 2. 交易时段模型(`ServerGo/citychrome/market_hours.go`)

**纯函数、零 IO、零 RNG、零全局态**(参照 `game/virtual_city/world_event.go`
文件头纪律);时刻一律作入参,判定一律换算 UTC;时间区间语义统一为
**左闭右开 `[start, end)`**。

### 2.1 时段表

| 类目 | 市场 | 交易时段(市场本地) | UTC 口径备注 |
| --- | --- | --- | --- |
| `a_share` | 上交所/深交所 | 周一~五 09:30-11:30、13:00-15:00(UTC+8) | 01:30-03:30、05:00-07:00 |
| `hk` | 港交所 | 周一~五 09:30-12:00、13:00-16:00(UTC+8) | 01:30-04:00、05:00-08:00 |
| `us` | 纽交所/纳斯达克 | 周一~五 09:30-16:00(美东) | EDT(UTC-4)13:30-20:00 / EST(UTC-5)14:30-21:00 |
| `metal`/`futures` | 外盘 CME Globex 近 24h 口径 | 周日 22:00 开 ~ 周五 21:00 收(UTC) | 周六全天休市、周日 22:00 前休市;两值同表 |
| `crypto` | 加密货币 | 7×24 | 恒开市 |
| `news`/`macro` | — | 不参与时段判定 | 间隔固定(见 §3) |

**区间边界实测口径**(单测锚定):开盘时刻**含**(左闭),收盘时刻**不含**
(右开);`a_share` 午休 11:30-13:00、`hk` 午休 12:00-13:00 均判休市。

### 2.2 美国夏令时(纯函数)

- EDT 期:**3 月第二个周日 07:00 UTC(=02:00 EST)起 ~ 11 月第一个周日
  06:00 UTC(=02:00 EDT)止**(左闭右开);其余 EST。
- `usEasternDaylight(now)` 纯函数判定;基元 `nthWeekdayUTC(year, month, wd, n)`
  按 UTC 日历推算「某月第 N 个星期几」(切换瞬间本地 02:00/03:00,UTC 日期与
  本地日期同日,推算无歧义)。
- 锚点单测:2026-03-08 06:59:59 UTC=EST / 07:00:00=EDT;2026-11-01
  05:59:59=EDT / 06:00:00=EST。UTC 13:45 对照样:EDT 期开市、EST 期未开。

### 2.3 导出 API

```go
// CategoryMarketOpen 报告类目对应市场此刻是否开市;
// news/macro/未知类目恒 true(不受时段约束)。
func CategoryMarketOpen(cat string, now time.Time) bool
// QuoteRefreshSeconds 返回类目当前档位刷新间隔(秒)。
func QuoteRefreshSeconds(cat string, now time.Time) int64
```

## 3. 档位表与调度接线

| 类目 | 开市档 | 休市档 | 可配置项 |
| --- | --- | --- | --- |
| 行情 6 类目 | **600s**(分钟级,与 news 600s 同口径) | **7200s**(降频 12×) | `quote_open_refresh_seconds` / `quote_closed_refresh_seconds` |
| `news` | 600s(不变) | — | `news_refresh_seconds` |
| `macro` | 86400s(不变) | — | `macro_refresh_seconds` |

- **包常量**(`scheduler.go` 常量块):`defaultQuoteOpenRefreshSeconds = 600`、
  `defaultQuoteClosedRefreshSeconds = 7200`(IntervalTiers 零值兜底);
  旧 `defaultQuoteRefreshSeconds = 1800` 降级为 legacy(仅为 `RefreshSeconds`
  字段缺省保留)。
- **单一解析路径 `IntervalTiers`**(批次88 返工核心,见 §5):调度轮转与
  stale 判定共用 `IntervalTiers.Seconds(cat, now)` —— **可配置值优先于包默认**
  (0 值字段 ⇒ 回退 600/7200/600/86400)。`Scheduler.tiers()` 与
  `Service.intervalTiers()` 同构映射各自持有的配置。
- `categoryRefreshInterval(cat, now)` **签名变更**(带 `now`)且用途收窄:
  = 零值 IntervalTiers(包缺省档位)便捷入口/测试锚点,不再承担 stale 判定
  的「唯一事实来源」。
- `Scheduler.categoryInterval(cat, now)` = `tiers().Seconds(...)`;
  `dueCategoryLocked` 档位判定与计时取**同一时刻**。
- **追赶抓取**:开市瞬间档位 7200 → 600,距上次运行 ≥600s 的类目立即到期,
  下一个 tick 即入队(单测 `TestScheduler_QuoteDueCatchUpAtOpen`)。

## 5. stale 判定同口径(防假性告警;批次88 返工后的**真实形态**)

`realworld.go op=overview`:

```
stale = age_seconds > 2 × tiers.Seconds(cat, now)     // tiers = IntervalTiers
```

**同口径的真实形态 = 配置档位优先、包默认兜底、单一解析路径**:

- 初版实现曾让 stale 走包默认档位(600/7200)而调度走配置档位 —— 非默认配置
  下两边不同值,「同一档位」不成立(开市档调 >1200 / 休市档调 <3600 即假性
  告警),被收口 Agent 打回返工;
- **返工后**:`IntervalTiers.Seconds` 是唯一解析入口,`Scheduler.tiers()`
  (调度轮转)与 `Service.intervalTiers()`(stale 判定)同构映射同一份配置
  ⇒ **任意合法配置值下 stale 阈值恒等于 2×调度器真实轮转间隔**(单测
  `TestRealworldStale_ConfiguredTiers` 用 open=300/closed=3600 非默认档位
  与 `Scheduler.categoryInterval` 逐档断言相等);
- `age_seconds` 与档位取**同一时刻**(`compactOverview` 注入 `nowT`);
- `FeedCompactJSON` **签名扩一参** `tiers IntervalTiers`(0 值 = 包默认;
  wire/JSON 输出形状零变更,`age_seconds`/`stale` 字段名不动);
- 休市档 7200s(缺省)⇒ stale 阈值 14400s —— 休市降频时段不假性报 stale;
  开市档 600s(缺省)⇒ 阈值 1200s,分钟级新鲜度要求。

## 6. 已知限制(如实标注)

1. **不做节假日日历(工作日近似)**:各市场节假日一律按普通交易日处理,
   仅周末与固定休市窗口生效;如需节假日感知须接入独立日历数据源(另行批次)。
2. **休市仍低频抓取而非停抓**:休市档 7200s 继续轮转(非 0),保证收盘总结/
   突发消息可采集;若要「休市完全停抓」须另行设计(涉及 stale 语义再演进)。
3. `metal/futures` 采用规范指定的 CME Globex「近 24 小时」口径
   (周日 22:00 UTC ~ 周五 21:00 UTC),不含每日 21:00-22:00 UTC 维护窗细分。
4. DST 只处理美国;`a_share`/`hk` 为固定 UTC+8 无夏令时。

## 7. 零回归红线

- **wire/JSON 契约零变更**:未改任何 `json:` tag、WS 帧、HTTP 端点;前端零改动;
- news(600s)/macro(86400s) 行为一字不变;零 RNG;
- 新函数全部纯函数,不碰 Scheduler 锁内回调(§92a);单文件均 ≤1800 行(§4);
- 手动刷新、熔断退避、空闲降载、同站点 ≥10s 纪律零改动。
