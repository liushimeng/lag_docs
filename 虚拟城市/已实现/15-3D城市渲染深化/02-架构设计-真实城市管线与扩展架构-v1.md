## 1. 总体架构

**单一渲染管线下扩展，无架构重构** —— 14 轮已建立的 `WealthCityMap / DistrictBlock / StreetPropsLayer / textureCache` 管线沿用，本轮仅在 `StreetPropsLayer` 内部扩张道具数量与种类，在 `building_shapes.tsx` 增加细节几何，在 `WealthCityMap` 注入氛围组件。

新增的 V2 组件（如 PedestrianV2 / TreeV2）**不破坏** V1 组件接口；通过命名 `PedestrianV2` 与 V1 并存，迁移完成后 V1 标记 deprecated（不删，留作 fallback）。

## 2. PedestrianV2（阶段 K）

### 2.1 文件

`components/wealth/props/PedestrianV2.tsx`（新，~180 行）。

### 2.2 接口

```ts
interface PedestrianV2Props {
  x: number;
  z: number;
  /** 体型套装（business/casual/bright/khaki），决定身体圆柱颜色 + 头部 sprite 风格 */
  outfit: 'business' | 'casual' | 'bright' | 'khaki';
  /** 步行路径：折线段 [(x1,z1), (x2,z2), ...]，每段匀速，行至端点停顿 0.5s 后返程 */
  path: Array<[number, number]>;
  /** 速度（世界单位/秒），默认 0.4 */
  speed?: number;
  /** 起始相位（决定 path 上初始偏移） */
  phase?: number;
  /** 是否驻足（中央公园部分行人静止，模拟看景） */
  stationary?: boolean;
}
```

### 2.3 几何

- 身体：`<cylinderGeometry args={[u(0.18), u(0.22), u(1.6), 8]} />`（腰→肩高度）
- 头部 Billboard：`useSharedTexture` 加载 `props/pedestrian/head_{outfit}.png`，缺失用 circleGeometry 兜底
- 身体材质：`meshStandardMaterial` color = outfit 主色，roughness 0.7，无 emissive
- y 位置：身体底部 y=0（贴地），头 Billboard y = u(1.6) + u(0.2)

### 2.4 动画

```ts
useFrame((_, delta) => {
  if (REDUCED_MOTION || stationary) return;
  // path 进度累加；端点停顿 0.5s；折返
  pathProgressRef.current += delta * speed;
  // ... 定位到 path 当前位置
  // 微抖（步态）
  g.position.y = Math.abs(Math.sin(timeRef.current * 4)) * u(0.04);
});
```

## 3. TreeV2（阶段 L）

### 3.1 文件

`components/wealth/props/TreeV2.tsx`（新，~150 行）。

### 3.2 接口

```ts
interface TreeV2Props {
  x: number;
  z: number;
  variant?: 'oak' | 'pine' | 'palm';
  scale?: number;  // 默认 0.7（5-10m 真实）
}
```

### 3.3 几何

- 树干：圆柱 r=u(0.06) h=u(0.5)（与 V1 相同），保留 castShadow
- 树冠：3 层 sphere 叠加
  - 主冠：r=u(0.4) (oak) / u(0.35) (pine) / u(0.4) (palm)，颜色 variant 主色
  - 副冠 1：r=u(0.3) 偏移 y=+u(0.15) x=+u(0.1)，颜色 variant 亮色（+30% 亮度）
  - 副冠 2：r=u(0.25) 偏移 y=-u(0.05) x=-u(0.08)，颜色 variant 暗色（-20% 亮度）
- palm 特殊：3-5 片叶子（planeGeometry 弯曲），棕榈型
- 树叶 sprite 兼容：如有 props/tree/oak_tree.png 仍用 Billboard 叠加在前

### 4.3 布点规则（StreetPropsLayer 内部）

```ts
function newFurnitureForDistrict(def, idx, isCore) {
  const furniture = [];
  // 报刊亭：commerce/oldtown/finance/transport_hub 各 1
  if (['commerce','oldtown','finance','transport_hub'].includes(def.id)) {
    furniture.push({ type: 'kiosk', x: ..., z: ..., rotation: ... });
  }
  // 自行车：residential/edu_district/commerce 各 1-2
  if (['residential','edu_district','commerce'].includes(def.id)) {
    furniture.push({ type: 'bicycle', x: ..., z: ..., rotation: ... });
  }
  // 垃圾箱：每城区 1（idx 偶数侧 +1.8 / 奇数侧 -1.8）
  furniture.push({ type: 'trash', x: ..., z: ... });
  // 电话亭：oldtown/commerce 各 1
  if (['oldtown','commerce'].includes(def.id)) {
    furniture.push({ type: 'phone', x: ..., z: ... });
  }
  // 邮筒：每城区 1
  furniture.push({ type: 'mailbox', x: ..., z: ... });
  // 停车牌：transport_hub/commerce/finance/tech 各 1
  if (['transport_hub','commerce','finance','tech'].includes(def.id)) {
    furniture.push({ type: 'parking', x: ..., z: ... });
  }
  return furniture;
}
```

## 9. 性能优化

### 9.1 InstancedMesh（可选优化，超出阶段 K-M 可延后）

树和路灯数量大时考虑 drei `<Instances>` / `<Instance>`，但 V2 几何复杂（多层球冠），instanced 收益有限，**本轮不启用**，留待 P2。

### 9.2 Draw Call 控制

每城区 mesh 数 V2 估算：

- 楼栋 5 × 4 mesh（podium/body/crown/awning/lights）= 20
- 行人 4 × 2 = 8
- 树 4 × 4 = 16
- 家具 4 × 2 = 8
- 总每城区 50 mesh × 16 城区 = 800 mesh + 道路/水/建筑 600 = **1400 mesh**，draw call ≈ 400-600（共享材质后）

### 9.3 阴影范围限制

`WealthCityMap` 阴影相机 half = WORLD_SIZE * 0.6（48），可覆盖全城但有性能损耗。可降至 0.5（40），远景楼阴影略柔化但人眼难辨。
