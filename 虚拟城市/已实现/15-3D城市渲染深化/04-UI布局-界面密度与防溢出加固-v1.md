# 虚拟城市 — UI 布局加固 · 界面密度与防溢出（15-3D城市全面真实感深化 · 04）

> 2026-09-22。读者：frontend-dev。
> 前置：13/04 + 14/04（Tab 分组、折叠、z-index、顶栏 wrap 已落地）。

---

## 1. 现状诊断

14 轮已落地项：
- ✅ Tab 按语义分组（data / trade），组内 wrap
- ✅ 折叠容器 CollapsibleSection + 持久化 localStorage
- ✅ z-index 协约（小地图 40 / 城区卡 30 / error banner 50 / modal 200）
- ✅ 顶栏 flex-wrap + 1280px 响应式
- ✅ waiting-board 占位压缩
- ✅ 地图区 min-height 320px

仍有问题：
- 9 Tab 在窄屏（1280×800）下仍偏密，部分 Tab 文字截断
- 各面板（Financial / Market / Ledger）行高偏松，整体内容密度低
- CityStatsPanel 信息量大但默认展开，主面板被压缩
- BotPanel 默认展开，与 CityStatsPanel 抢高度

## 2. 本轮加固目标

1. **Tab 合并**：9 → 6 个，减少拥挤
2. **面板紧凑**：行高 -10%、padding 收紧、去除冗余分隔线
3. **默认折叠**：CityStatsPanel 默认折叠（信息量大但非核心）
4. **折叠状态一致**：BotPanel 默认展开，StatsPanel 默认折叠
5. **面板空态**：不撑半屏，最小高度 120px
6. **1280×800 边界**：所有面板在该分辨率下无横向滚动、无溢出

## 3. Tab 合并方案

### 3.1 原 Tab 列表

```
data 组：
  - finance
  - market
  - ledger
  - economy
  - survey

trade 组：
  - listing
  - loan
  - infomarket
  - insurance
```

### 3.2 新 Tab 列表（合并后 6 个）

```
data 组：
  - finance（财务）
  - market（行情）
  - ledger（流水）
  - economy（经济 + 调研入口）

trade 组：
  - market-trade（市场：挂单 + 借贷 + 信息）
  - insurance（保险）
```

> 减少 3 个 Tab；合并后 6 个总宽 6×~88px ≈ 528px，1280×800 主区 + 侧栏 320px 下主区 960px 可完整显示。

### 3.3 经济 Tab 内调研入口

`<EconomyPanel />` 内部右上角加小按钮「📋 调研」，点击触发 `<SurveyPanel />` 弹窗或子页面（沿用现有组件，模态打开而非新 Tab）。

### 3.4 市场 Tab 内子导航

`<MarketTradePanel />` 新组件，tabs 内嵌 3 个子按钮：
- 挂单簿（ListingPanel 内容）
- 借贷（LoanPanel 内容）
- 信息（InfoMarketPanel 内容）

> 子导航按钮高 24px，行内显示，不增加 Tab 高度。

## 7. 1280×800 边界用例

| 元素 | 状态 |
|---|---|
| 顶栏（roomId + month + age + cycle + runtime + seats + actions）| wrap 3 行内（4 项/行）|
| 主区地图 | 960×~500px（侧栏 320×800 减去顶栏 + 底部）|
| 侧栏 Tab | 6 个 Tab × ~80px = 480px < 320px → 2 行 wrap |
| 侧栏面板 | 平均 1.5 个面板同时可见 |
| ActionPanel 底部 | 完整显示 |

## 8. 响应式补充

### 8.1 1366×768（更低分辨率）

- 顶栏 wrap 至 4 行
- 侧栏 Tab 3 行
- 地图区 min-height 保持 320px（牺牲顶部滚动）

### 8.2 1920×1080（更宽）

- 顶栏单行
- 侧栏 360px
- 地图区占满
- 多面板可同时显示 2-3 个

## 9. z-index 协约不变

- 小地图：z=40
- 城区 hover 卡：zIndexRange [30, 0]
- error banner：z=50
- modal：z=200
- 广告牌辉光（无 DOM 层）

## 10. 不破坏的契约

- `CollapsibleSection` props 接口不变
- 各 Panel props 接口不变
- i18n 键不变（Tab label 沿用既有翻译，不新增键）
- 后端 / WS / 经济引擎：**完全不动**
