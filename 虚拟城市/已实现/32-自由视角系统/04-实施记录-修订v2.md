## 2. 选中系统（N1）

### 2.1 复用 objectInfo，不另造一套

批次 28 已有 `useObjectInfoProps(id, opts)` 把 `onClick` 绑到任意 mesh，
写 `useObjectInfoStore.selected`。本次：

- `objectInfoStore.setSelected` 改 **toggle**：传入与当前 selected **同 catalog id**
  的目标 = 取消；否则选中。CDP 实测：选中后再次 setSelected 同 id ⇒ `selected: null`。
- `useObjectInfoProps` 新增 `selectDisabled`（仅禁 click，保留 hover 信息卡）。
  地面 `ground.city` 与天空 `sky.cloud` 设 `selectDisabled: true` —— 点空白不再选中
  它们。

### 2.2 通用选中特效 `<SelectionMarker />`

挂在 `VirtualCityCityMap` 的 Canvas 内（单例，不进物体组件），订阅
`useObjectInfoStore.selected`，从 `selectedTargetFor(colliders, pos, fallback)` 检索
聚焦点（世界坐标 + 半径）：

| 检索来源 | 命中 | 未命中 |
|---------|------|--------|
| 建筑 | 盒 XZ 中心 + `max(半宽,半深)/2 + 碰撞半径` | — |
| 非建筑 | — | 命中点 + fallback（地面/水系 6，街具/树 3，城缘/天空 12，城区 8） |

特效分两层（都走 AdditiveBlending + 呼吸脉动）：
1. **地面环**：RingGeometry 躺平，y = groundY + 0.06；
2. **竖环**：外接圆柱的 3/4 截面（顶点在 shader 内弧形扫掠），立在环上。

半径随 colliders 检索，与楼体投影严丝合缝。环是「一个中心点 + 一个半径」，
**与物体形状无关**，因此对所有 objectInfo 接线的物体通用。

### 2.3 为什么不在被选中物体上包盒

353 栋楼的合并 mesh 是多楼共享一个 mesh，单独给某一栋加材质覆盖会破坏合并
（draw call 退化）。非建筑物体形状各异，「包盒」观感差。环 + 竖环是通用几何。

## 6. fly 选中 = 环绕物体（N5）

### 6.1 实现

`FreeViewControls` 新增 `selectedFocusRef` prop（`SelectedFocus | null`）。
`stepFly` 分两种子状态：

| `focus` | WASD 含义 | 朝向 |
|---------|----------|------|
| null | 沿视线前/后/左/右（含俯仰分量），可任意位置 | yaw/pitch 自由 |
| 非空 | W/S = 半径减小/增大（拉近/拉远），A/D = 水平环绕（theta ±） | lookAt(focus) |

- 环绕半径 clamp 到 `[collisionRadius+0.5, maxDistance]`；
- 环绕后仍走 `collide()`（建筑推出 + 边界 + 地面钳制）；
- 垂直升降（Space/E/Q）在两种子状态下都可用。

### 6.2 实测（CDP + SwiftShader 低帧率下）

| 操作 | 期望 | 实测 |
|------|------|------|
| 选中建筑 + 按 A | 绕 focus 公转，到 focus 距离不变 | ✅ 距离 10.59 → 10.58（恒定），角度 +3.7° |
| 选中建筑 + 按 W | 拉近（半径减小） | ✅ 距离 10.58 → 9.90 |
| 选中建筑 + 按空格 | 垂直升降 | ✅（代码路径保留） |
| 再点同一建筑 | 取消选中 | ✅ `selected: null` |

## 7. 选中特效调参

初版环透明度 0.65 + AdditiveBlending 在近距离看时**全遮挡楼体**（截图确认）。
降为 0.30 后，环作为「选中指示」可见但不挡楼体。

## 10. 已知限制

| 项 | 说明 |
|----|------|
| 环在非建筑物体上 | 半径用 fallback（3/6/8/12），可能与物体实际大小有偏差 —— 这是通用设计的取舍，精确到每类物体需扩展 objectInfo catalog |
| 环绕时右键拖拽 | 朝向被 lookAt(focus) 每帧覆盖，改 yaw/pitch 无效 —— 这是「环绕语义不丢」的取舍，想脱离 lookAt 就取消选中 |
| SwiftShader 帧率 | 全城 ~0.7 fps，所有 CDP 用例按 ≥1 帧/秒时间尺度等待；逻辑正确性已由纯逻辑单测保证 |
