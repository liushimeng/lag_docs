### 2.3 平面线形（对照需求清单）

直线形（全部直线段道路，放射/方格/联络线）+ 圆曲线形（一环路 32 段折线近似圆、
CBD 环 16 段、高速环 32 段）。S 形/缓和曲线/竖曲线在 1u=10m 宏观尺度无视觉意义，
不引入（如实记录取舍）。

### 2.4 交叉口处理

- **信号灯**（批次 24 通式扩展）：放射主路 × 一环路交点（26 处，区中心 r>20 的主路），
  每处对角 2 座（A/B 相位对置，与 CBD 环岛路口同风格；实测 24 处——内圈 7 区
  （r≤20：tech/industry/oldtown/commerce/residential/suburb/riverside）不入环交表）；
- **z-fighting 分层**（平面交叉微抬，非立交）：
  路面基准 `ROAD_SURFACE_Y=0.015`；联络线 +0；放射路 +0；
  邻接次干道 **+0.002**；方格骨干 **+0.004**；一环路 **+0.007**（最高，跨越所有下层）。
  同层道路彼此不相交（联络线与放射路共线但段不重叠）。

## 4. 技术设计

### 4.1 新模块 `roadNetwork.ts`（纯函数，单一事实来源）

```ts
export interface RoadSegment {
  key: string;                    // 'spoke-tech' / 'conn-suburb-riverside' / ...
  from: [number, number];
  to: [number, number];
  kind: 'main' | 'side';
  cls: 'spoke' | 'connector' | 'arterial' | 'edgeLink';
  /** 平面交叉微抬（§2.4：0 / 0.002 / 0.004）。 */
  yOffset: number;
}
export interface GateSpot { x: number; z: number; rotation: number; }
export const FIRST_RING = { radius: 20, width: 1.4, yOffset: 0.007, segments: 32 };
export function buildRoadNetwork(): {
  segments: RoadSegment[];        // 全部直线段道路（connector+arterial+edgeLink）
  gates: GateSpot[];              // 17 座收费站（r=55 径向）
  cbdRingJunctionAngles: number[];    // CBD 环交点角（通常空 = 纯环岛）
  firstRingJunctionAngles: number[];  // 一环真实交点角（停止线/信号灯）
  arterialIntersections: RoadJunction[];  // 骨干互交点（信号灯）
}
```

生成规则（全部确定性，无随机）：
- **connector**：对每个非 finance 城区，按表序找 2 最近邻；边长 ∈ [8,34]、
  不重复、不连 finance、**线段距原点 ≥ 5u（CBD 禁入，不穿金融 CBD 建筑区）**
  → kind='side'、yOffset=0.002。上限 36 条（超出截断，防道具爆炸）。
- **arterial**：x=±18、z=±26 四条，from/to=∓48，kind='main'、yOffset=0.004。
  选线已核对 32 区底板（8×8）重叠 ≤1 块/条，穿板段走板下（路 Y < 板 Y）。
- **edgeLink**：中心 r>30 的 17 区，from=区中心，to=径向 r=57.2（高速内缘 58−0.8），
  kind='main'、yOffset=0。
- **gates**：每联络线 r=55 处，rotation=径向角。
- **交点表（真实求交，非放射派生）**：`cbdRingJunctionAngles` /
  `firstRingJunctionAngles` = 线段与环圆的通用 segment-圆求交（端点不生成交点、
  0.05 rad 去重）；`arterialIntersections` = 方格骨干横纵互交点（4 处）。
