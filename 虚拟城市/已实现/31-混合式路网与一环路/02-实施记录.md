## 3. 二轮（draw call 攻坚）

**实测**：2316 → 合并后 **1429~1759**（视相机视锥；默认视角 1429/1480 ≤ 1500 红线；
批次 30 同口径 1654）。

| 动作 | 效果 |
|------|------|
| `Road.tsx` 精简纯路面（1 mesh/段） | 88 段 ×~8 小面片 → 88 路面 + 5 合并层 |
| 新增 `RoadMarkings.tsx`：crosswalk/stopline/arrow/sidewalk_main/sidewalk_side 全城各并 1 mesh（UV 平铺烘焙进几何 + engine3d mergeParts） | 标线/人行道 ~700 mesh → **5 draw call** |
| `FirstRingRoad` 32 段→3 mesh（路面/虚线/停止线，虚线停止线顶点色） | ~88 → 3 |
| `RingRoad`（CBD）16 段→3 mesh（同法） | ~66 → 3 |
| arterial/edgeLink 车流仅 high 档 | low 档（SwiftShader/低配）−25 辆 |

技术要点：
- 合并后贴图只有一份实例，**平铺倍率必须烘焙进几何 UV**（否则与 texture.repeat 叠乘）；
  环路面 UV u×3/u×2、人行道 UV v×round(len/0.25) 均走 `tiledPlane`/`uTiledPlane`。
- 摆放 matrix 与旧 JSX 分层 rotation 同构：T(world) · RotY(路向) · [RotZ(π)] · RotX(−π/2)。
- mergeParts 内部克隆部件几何，调用方 geometry 用后 `dispose()`（RoadMarkings 统一
  `mergeAndDispose`）。
- objectInfo 语义保留：每段路面仍可按路 hover（road.surface），环/收费站各有条目；
  合并的标线/人行道作为路网装饰层不带独立 info（物件信息按批次 28 口径不承诺到标线级）。
