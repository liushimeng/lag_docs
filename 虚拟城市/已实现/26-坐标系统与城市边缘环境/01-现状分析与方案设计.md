## 1. 现状分析

### 1.1 坐标系统现状（已满足「中心点 0/0」）

| 项 | 现状 | 出处 |
|---|---|---|
| 世界标尺 | 1 世界单位 = 10 m（`u()` 换算） | `cityScale.ts` |
| 城市中心 | 金融CBD `finance` 位于 **(0, 0)**，全部放射路指向原点 | `types/virtualCity.ts` `VIRTUAL_CITY_DISTRICTS` |

依据：既有 `FarBuildingSilhouette` 已按 `north → z = -edgeOffset` 布点，本批次沿用并写死为契约。
小地图为固定朝向（上 = 北 = −Z）。

## 2. 总体设计

### 2.1 布局总图（俯视，北 = −Z = 上）

```
                北 · 雪山带  z ∈ [−80, −62]
        ┌──────────────────────────────────┐
        │  ❄ 雪山脊线(z≈−70~−76,x ±90)       │
        │  🌲 山脚针叶植被带(z −62~−70)       │
 西     │ ┌───────────────────────────┐    │  东
 沙漠   │ │   城区 32 区 (±50)          │    │  森林
 x −80  │ │   环城高速 r=58            │    │  x +62
 ~−62   │ │   对角丘陵/风机(±46)       │    │  ~+80
 (沙地+ │ │   农田→仅四角象限 r≤60     │    │ (林地+
  沙丘+ │ └───────────────────────────┘    │  密树)
  仙人掌)│  🏖 沙滩过渡带 z ∈ [58, 64]       │
        │  ⚓ 南港码头 z ∈ [62, 70]          │
        └──────────────────────────────────┘
                南 · 海洋带  z ∈ [+62, +150]（越出地面 plane 无碍）
```

**坐标带契约**（全部世界单位）：

| 带 | 范围 | 内容 |
|---|---|---|
| 城区 | \|x\|,\|z\| ≤ 60 | 不动（游戏逻辑权威） |
| 过渡带 | 60 < max(\|x\|,\|z\|) ≤ 62 | 留白缓冲（地面 urban_base 自然延伸） |
| 北·雪山带 | z ∈ [−80,−62]，x ∈ [−90,+90] | 雪山脊线 GLB ×6~8 + 山脚针叶树 instanced ×~60 + 岩石地表 patch |
| 西·沙漠带 | x ∈ [−80,−62]，z ∈ [−62,+58] | 沙地 patch + 沙丘 ×5（低多面体）+ 仙人掌 instanced ×~24 + 枯木 ×3 |
| 东·森林带 | x ∈ [+62,+80]，z ∈ [−62,+58] | 林地地表 patch + 阔叶树(oak_tree GLB)/针叶树混种 instanced ×~140 |
| 南·海洋带 | z ∈ [+62,+150]，x ∈ [−150,+150] | 海面大 plane（独**立于地面 plane**，可越界）+ 沙滩 z∈[58,64] + 南港（码头面/岸吊×2/集装箱/灯塔 GLB/系缆桩）+ 货船 GLB ×1（慢速巡航动画）+ 帆船 GLB ×2 + 浮标 ×4 |

### 2.5 不做清单（防范围蔓延）

- 不改任何城区坐标 / 游戏逻辑 / ServerGo / proto。
- 不做天气系统、昼夜循环（批次 25 城市时钟属叙事层，不联动）。
- 城内 `PortTerminal`（物流港港池）保留不动——与南港是两个场景。
- 不给边缘带加碰撞/可进入性（walk bounds ±60 不变）。

## 3. 验收标准

1. `tsc --noEmit` + `npm run build` 全绿。
2. CDP 截图（go-web-debug-tool，连 9222 常驻 Chrome）：四个方向各一张（orbit 转向 N/W/E/S），肉眼确认雪山/沙漠/森林/海洋+港口+船只。
3. `?debug=1` 的 `__cityRenderInfo`：draw calls 增量 ≤ 30，GLB 全部命中缓存（每 URL 一次网络请求）。
4. 断网降级：`localStorage 'disable-blender-models'='1'` 时四缘带程序化 fallback 渲染不崩（§27.3 契约）。
5. 文档 `02-实施记录.md` 回填实际坐标/draw call/截图结论。
