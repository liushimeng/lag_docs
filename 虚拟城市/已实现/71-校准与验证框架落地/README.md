## 核心速查

| 项 | 值 |
|---|---|
| 批次定位 | **只补测量层**：不改任何经济数值、不改玩法、不新增 API 端点 |
| 直接前因 | 《校准框架》v2.0（29 项零实现）+ 《蒙特卡洛验收方案 v1》§4.2/§5/§6（零实现） |
| 根因 | 账本边界**从未声明**：国库直改现金、活期↔定期互转、场景伤害、遗产清零 —— 4 处**不经 Ledger** 的现金变动 |
| 解法 | **账外调整账** `OffLedgerBook`：把 4 处账外现金变动登记成**带原因的流水**，I1 得以闭合 |
| 七条不变量 | **I1** 座位现金守恒 ／ **I2** world 注入唯一性 ／ **I3** 国库收支闭合 ／ **I4** 资产负债口径契约 ／ **I5** 引擎状态哈希 ／ **I6** 场景注入留痕 ／ **I8** 系统净流闭合 |
| I1 闭合公式 | `p.Cash == 初始注入 + Ledger 净流 + 账外净流`（三者**独立维护**，非恒真式） |
| StateHash | FNV-1a 64 → 16 位十六进制；覆盖玩家/市场/央行/国库/商品/劳动力/社会/产业链/账本摘要；**排除** transcript/事件文本/时间戳/LLM 产物 |
| 哈希六纪律 | 禁 map 迭代 ／ 禁 `Sprintf("%v")` 浮点 ／ 禁 `hash/maphash` ／ 浮点用 `math.Float64bits` ／ 切片按稳定键排序 ／ 固定 FNV-1a 64 |
| D 指标 | D2 货币扩张倍数（**≠ 央行 M2 口径**）/ D3 结局分布 / D5 破产率 / D6 品类收益率 / D9 状态哈希 |
| 红线子集 | R-E3 / R-E4 / R-E5 / R-E6 / R-B1（**5 条**；R-E1/E2、R-B2–B6 未实现 ⇒ 前端**不显示**） |
| 前端 | 看板**第 12 个维度**「校准」（分组 `city` 末尾）+ `CalibrationPanel.tsx` 5 区块 + 三语言 i18n |
| 批次 70 遗留 | **L1** 删 `lpr5y` 兼容别名 ／ **L6** 删两行死样式 ／ **L8** `last_senses` 补 `month`/`text` ／ **L9** `NeighborBrief` 补 `kind`/`district`/`mood_hint` ／ **L10** 密封提示覆盖 `vickrey` —— **全部结清** |
| 关键纪律 | 新增审计/哈希**零 rand 消费**（不移动既有随机序列）；不变量**不得写成恒真式**；不变量 ID 与 i18n 键**一一对应**（漏项即白屏） |
