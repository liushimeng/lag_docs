## 1. 为什么是车辆

批次 39（建筑）→ 40（地面）收口后，剩余物体中车辆的视觉短板最突出。基线审计证据链：

| 证据 | 来源 | 结论 |
|---|---|---|
| 4 次独立 AI 判读，3 次把「车辆」排第一 | 批次 40 验收旧图（dusk aerial/street）+ 本批次基线（vehicle/vehicle2 近景） | 「平顶直角盒子」「无弧线车顶、无倾斜引擎盖过渡、车窗无玻璃质感、无轮拱」 |

## 4. 阶段 A · 车模重制（art-designer，3d_script/）

> 技术路线：**截面放样（cross-section loft）几何重制** —— 沿车长方向布 8-10 个「圆角矩形
> 截面站」，`from_pydata` 桥接成连续车身面，替代「两盒叠加」。纯色 PBR（金属漆/玻璃/
> 镀铬分层），**不引入贴图**（对齐仓库既有 47 个 GLB 的零贴图风格；车门线/格栅/车牌
> 全部用几何件表达，近景可读）。

### A0 · 共享放样库 `3d_script/vehicle_loft.py`（新建）

| 函数 | 职责 |
|---|---|
| `rounded_rect_loop(half_w, y0, y1, r, n)` | 生成一个截面站的圆角矩形轮廓点列（yz 平面闭合环，n 点/侧） |
| `loft_stations(stations, name)` | 桥接相邻截面站 → 侧面 + 端帽 mesh（`from_pydata` + `shade_smooth` + 法线朝外） |
| `wheel_arch(x, z, r, thick)` | 轮拱罩：半圆环（torus 取 180°）贴车身侧面，外缘 = 车宽 |
| `rim_spokes(...)` | 轮辋：毂盘 + 5 辐条 + 轮缘环 |
| 约束 | 所有部件最终 `join_objects` 合并为单 object（车轮除外，见 C4），`bake_transforms` 烘焙 identity |

## 9. 明确不做

| 项 | 理由 |
|---|---|
| 车漆贴图/彩绘纹理（金属漆颗粒、水转印） | 仓库 47 GLB 零贴图风格；几何+材质分层已满足近景可读；贴图 UV 是另一量级工作量 |
| 车内内饰/驾驶员模型 | 车窗透光率 0.5，内饰不可辨 |
| 转弯/路口转向/变道 AI | 车流是「沿路段直线循环」模型，转弯需路网图寻路，属车流系统重构 |
| 跟车防碰撞（前车检测） | 队列槽位（C3）已覆盖红灯场景；巡航追尾由相位抖动规避概率 |
| 音效（引擎/喇叭） | 音频批次 |
| 行人/树木/街具/建筑任何改动 | 本批次主题限定「车辆」 |
| 一环/高速环车流 | 环路不在 segments 内，无路数据 |

## 10. 风险与回滚

| 风险 | 缓解 | 回滚 |
|---|---|---|
| 放样车身法线朝向/阴影瑕疵 | `loft_stations` 内统一法线朝外 + shade_smooth；预览人眼验收 | git revert build 脚本，GLB 回旧版 |
| modelCache 动画守卫击穿既有 GLB 归并（DC 涨） | C4 已否决，**modelCache 本批次零改动**，风险不存在 | — |
| 信号耦合时间基准与 TrafficSignals 不同源 | 复用其导出的 `signalLitColor` + 同一 `clock.elapsedTime` | C2 独立 commit |
| 队列槽位在多灯同路时排序歧义 | 每车按「最近前方停车线」单目标减速，槽位按整路全局 phase 序 | 退回无槽位版（仍优于现状） |
| 6 GLB 体积超 500 KB | 面数预算硬顶（A1-A4）+ 导出后 `find -size +500k` 门禁 | 降轮辋辐条/楞条密度 |
| 双渲染修复后 fallback 模式（disable-blender-models=1）观感回退 | fallback 分支保留全部附件（只是 GLB 模式不再叠加），几何车身+附件本来就在 | 无需回滚 |
