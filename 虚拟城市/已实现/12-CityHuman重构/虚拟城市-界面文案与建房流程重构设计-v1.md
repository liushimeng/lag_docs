## 2. 建房弹窗重设计（`WealthCreateRoomModal.tsx`）

**标题**：创建房间 → **创建城市**（`wealth.create.title` 改值，键名不变）。

| 字段 | 控件 | 说明 |
|---|---|---|
| 城市名称 | 文本框（可选，≤30 字） | 原「房间名称」改名 |
| 焦点居民数 | 档位按钮 1–12，默认 **12** | 原「Agent 座位数」改名；这 12 位居民由 LLM 全工具深度驱动 |
| 背景居民规模 | 预设档 12 / 1千 / 1万 / 10万 + 数字输入（clamp 1–100000，默认 10000） | 原「城市居民数量」，文案强调「数据模拟 + 抽样发声」 |
| LLM 线路池信息行 | 只读 | 保留；0 条时黄色警示保留 |
| 月节拍速度 | 预设 3000/8000/15000ms + 滑杆 | 保留，文案「月节拍」→「模拟月节拍」 |
| 职业卡池 | curated / docs + 职业卡一览 | 保留，说明文案改为「居民档案来源：人物卡知识库 ≈10 万张」 |
| 随机种子 | 可选数字 | 保留 |

**删除的 UI 元素**：
- 「创建者身份」展示行（原「入座玩家 / 全 Agent 房降级观战」）—— 创建者**一律为观察者**，
  不再展示该字段；`full_agent: true` 隐藏常量提交（现状已是固定 true，仅删除展示与相关文案键）。
- 「Agent 座位数 = 0 档」—— 焦点居民最少 1 位（全 Agent 城市的焦点层不能为空）。

**提交载荷不变**：`{name, agent_seats→focus_residents(同一字段), resident_count, month_ms, pool, seed, full_agent:true}` —— 仅前端字段标签与默认值变化，HTTP 契约不动。

1. `grep -rn "玩家\|对局" ClientWeb/src/i18n/locales/zh-CN.ts ClientWeb/src/i18n/wealthP2-zh.ts` 在 `wealth.*` / `minsky.*` 键范围内零命中（其他游戏的键不动）。
2. en/ja 键值同步替换，`tsc --noEmit` + `npm run build` 通过。
3. 建房弹窗渲染「创建城市」标题，无「入座玩家/创建者身份」行；提交载荷字段与旧版一致（契约零回归）。
4. 主界面观察者徽章、城市之声、居民思维、感知小节均可见；三语切换无缺失键（i18n fallback 检查）。
