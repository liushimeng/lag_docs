## 4. 遗留与后续

1. **名牌/气泡高度**:人形真实身高 0.167 单位(1.67 m),名牌 y=0.85/气泡 y=1.7 沿用旧 token 量级 —— 俯瞰视角可读性优先;街景近景下偏「气球感」,若用户反馈可下调至 ~0.35/0.6(纯前端常量)。
2. **行人不实例化口径不变**(批次 28 A5):+12 个座位人形 GLB clone 的 DC 增量在默认视角预算内;若后续抬行人上限,座位人形一并纳入实例化专项。
3. **city_voice 锚定按 name 匹配**:同名居民极小概率错锚(未命中回落市政厅);后续可在 EventRecord 增 resident_id 字段彻底消除。
4. **旧客户端兼容**:新字段全部可选;旧名工具调用仅在同月决策中途部署的极端场景出现「未知工具」回喂,LLM 下轮自愈。
