## 1. 目标

把虚拟城市（Wealth）对局页的 WebGL 3D 场景从「贴图盒子城市」升级为「接近真实的城市」：

1. **建筑有形态** —— 不再是单一 box：高层有裙楼+塔楼+收分，郊区有坡屋顶，工业区有厂房+烟囱，中央公园以绿化为主。
2. **16 城区贴图全覆盖** —— v2.12 新增的 8 个城区（物流港/高新园区/教育园区/医疗城/产业基地/中央公园/交通枢纽/文创区）目前**零贴图**，全部补齐底板/立面/屋顶。
3. **有天空与空气感** —— 天空穹顶、色调映射（ACES）、柔和阴影、远景雾协同，消灭「纯黑背景 + 平光」。
4. **街道细节闭环** —— 已生成但未接线的 `crosswalk.png` 斑马线接入路口；车辆有车轮与车灯；路口有红绿灯。
5. **UI 不溢出** —— 右侧栏 9 个 Tab 折叠分组，任何面板不跑出可视区、不重叠、不大面积留白。

## 4. 阶段划分（与 05-路线图一一对应）

- **阶段 A · 资产补齐**：`3d_script/` 程序化纹理管线 + `generate_wealth_city_assets.py` 扩展新 8 城区清单（AI/PIL 双轨，skip-if-exists）。
- **阶段 B · 建筑形态**：`BuildingMesh` 升级为体块组合（裙楼/塔楼/收分/坡屋顶/厂房），按城区 archetype 分派；中央公园绿化特化。
- **阶段 C · 环境氛围**：天空、ACES 色调映射、PCFSoft 阴影 2048 + bias、雾/光照协同。
- **阶段 D · 街道细节**：crosswalk 接线、红绿灯 prop、车辆车轮/车灯、行道树增密。
- **阶段 E · UI 布局**：Tab 折叠分组、面板 max-height、窄屏断点回归。
- **阶段 F · 验证交付**：`tsc --noEmit` + `npm run build` + 截图巡检 + `./rebuild_restart_app.sh` + 中文提交推送。

## 5. 非目标（本批次不做）

- 不做昼夜循环动态切换（光照按「傍晚暖光」定帧，夜景 emissive 留接口）。
- 不引入 GLTF 外部模型（全部程序化几何 + PNG 贴图，保持构建自包含）。
- 不改服务端、不改 WS 协议、不改游戏逻辑（纯表现层）。
- 不做 LOD 动态切换（80×80 场景 mesh 预算内，实例化即可）。

## 6. 验收摘要（详见 05 文档）

1. 16 城区每区 `districts/<id>.png`、`facades/<id>_{base,mid}.png`、`roofs/<id>.png` 全部存在。
2. 高楼城区肉眼可见裙楼+塔楼两段体块；郊区可见坡屋顶；中央公园绿化率 > 60%。
3. 场景有天空渐变，阴影边缘柔和无 acne/条纹。
4. 路口斑马线可见；车辆有车轮；主干道至少 1 处红绿灯。
5. 1280×800 与 1920×1080 下右侧栏 Tab 不溢出、面板不重叠。
6. `tsc --noEmit` / `npm run build` / `go test ./...` 全绿。
