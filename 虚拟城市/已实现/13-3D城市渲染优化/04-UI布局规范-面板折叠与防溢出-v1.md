# 虚拟城市 — 面板折叠与防溢出 · UI 布局规范（13-3D城市渲染优化 · 04）

> 2026-09-22。职责线：frontend-dev。缺口 G6：右侧栏 9 Tab 一字排开窄屏溢出；
> 面板无折叠；hover 卡可能压住小地图。遵守 CLAUDE.md §26 对比度规范。

## 1. 问题清单

| # | 现象 | 根因 |
|---|---|---|
| U1 | 9 个 Tab（财务/行情/流水/经济/调研/挂单/借贷/信息/保险）单行排布 | `.wealth-tabs` 无 wrap，侧栏 320-380px 宽必然溢出 |
| U2 | 侧栏自上而下 Tab面板+CityStats+BotPanel+Chat 堆叠，超高屏正常、矮屏互相挤压 | 各段无 `min-height:0` / max-height 协约 |
| U3 | 城区 hover 卡（Html）z-index 可能盖过小地图 | 未声明 `zIndexRange` 上限 |
| U4 | `wealth.css` 1738 行逼近 §4 上限（1800） | 新样式必须另起文件 |

## 2. Tab 分组折叠设计

9 个 Tab 按语义分两组，组标签为小标题（不可点击），组内按钮 `flex-wrap`：

```
▸ 数据  [财务] [行情] [流水] [经济] [调研]
▸ 交易  [挂单] [借贷] [信息] [保险]
```

- 实现：`WealthGamePage.tsx` 的 `tabs` 数组加 `group: 'data' | 'trade'` 字段，
  渲染时按组分两段 `.wealth-tabs__group`。
- 样式：`.wealth-tabs { flex-wrap: wrap }`；组标题 `.wealth-tabs__group-label`
  （12px、70% 明度灰、`letter-spacing` 加宽）；tab 行整体 `max-height: 96px;
  overflow-y: auto`（极端窄屏可滚动而非挤压地图）。
- i18n：新增 `wealth.tabgroup.data` / `wealth.tabgroup.trade`（zh/en/ja 三语，
  同步 `i18n/wealthKeys.ts` 与 locales 文件，§12 规约）。

## 3. 侧栏纵向空间协约

`wealth-sidebar` 为 flex 列容器，各段协约：

| 段 | 规则 |
|---|---|
| Tab 行 | `flex: 0 0 auto; max-height: 96px` |
| 主面板 `.wealth-sidebar__panels` | `flex: 1 1 auto; min-height: 160px; overflow-y: auto`（弹性吃剩余空间） |
| CityStatsPanel | `flex: 0 1 auto; max-height: 30%; overflow-y: auto`，**可折叠**（标题行点击收合，状态存 localStorage `ui-storage` 既有工具） |
| WealthBotPanel | 维持 `max-height: 220px`，可折叠（同上） |
| ChatPanel | 维持 `flex: 0 0 240px` |

折叠组件：新增轻量 `components/wealth/CollapsibleSection.tsx`（标题栏 + 箭头 +
children），复用于 CityStats / BotPanel。折叠态持久化键
`wealth.ui.collapsed.<section>`（走 `shared/utils/ui-storage`，禁止裸 localStorage）。

## 4. hover 卡与小地图叠层秩序

- `DistrictBlock` 的 `Html` hover 卡：`zIndexRange={[30, 0]}`（现状未声明，
  默认 [16777271, 0] 会盖住一切）。
- 小地图容器 CSS `z-index: 40`；error banner 50；modal 200（既有层级表不变）。
- AgentToken 名牌维持 `zIndexRange={[9, 0]}` 不变。

## 5. 断点回归要求

| 视口 | 预期 |
|---|---|
| 1920×1080 | Tab 两行内排完；侧栏各段无滚动条（内容少时） |
| 1280×800 | Tab wrap 不溢出；主面板可滚动；地图不被压缩至 < 40vh |
| ≤1024（既有 media query） | 侧栏转到底部整宽，Tab 横向滚动条可接受 |

## 6. CSS 落点

新增 `ClientWeb/src/styles/wealth-city3d.css`（本批次全部新样式集中于此），
`globals.css` 在 `wealth-residents.css` **之后**追加一行 `@import`（只追加不改序，

## 7. 验收

1. 1280×800 / 1920×1080 截图巡检：无控件跑出视口、无重叠、侧栏无大面积留白。
2. hover 任意城区，信息卡不遮挡小地图。
3. 折叠 CityStatsPanel 后刷新页面仍保持折叠。
4. 新增文案三语齐全（zh-CN / en / ja）。
5. 对比度：组标题/按钮满足 §26.1（正文 ≥ 4.5:1，active ≥ 6.0:1）。
