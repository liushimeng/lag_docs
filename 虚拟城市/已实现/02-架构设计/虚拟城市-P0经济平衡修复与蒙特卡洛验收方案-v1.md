## 1. 问题定位

### 1.1 观测事实

| 指标 | 历史 / 本轮观测 | 设计判断 |
|---|---:|---|
| M21 存活 | 6/12 | 开局即出现流动性崩溃 |
| M97 存活 | **2/12** | 社会模拟失效，财富分化被破产淘汰主导 |
| M137–M226 破产出局 | 10–11/12（83%–92%） | 明显超出可接受破产率 |
| FI | 多轮长期为 0 | Agent 未进入被动收入循环，经济目标失效 |
| 破产时间 | 集中在 32–40 岁前 | 与真实社会“长期低频风险”不符 |

### 1.2 数值根因

1. **租房成本与收入结构失衡**：P0 将 `房价 × 0.16%` 直接作为玩家月租。
   以 M1 房价推算：
   - P01 外卖骑手：commerce 市租约 ¥7,040，工资 ¥5,000，仅房租已达工资 141%；
   - P12 金融/技术专家：finance 市租约 ¥16,640，税社保 + 标准生活支出后月现金流仍约 **−¥10,880**。
   低收入与高薪职业均存在结构性赤字，Agent 决策只能延缓、不能消除。
2. **通胀与工资曲线剪刀差**：P0 生活成本按 5%/年膨胀，工资仅 3%/年增长；35 年后
   生活成本乘数约 5.5，工资乘数约 2.8，必然造成晚期全桌贫困化。
3. **失业冲击无社会缓冲**：失业期工资为 0，但房租、生活、家庭与贷款照付；
   复苏/繁荣 5%/月、衰退 15%/月、萧条 25%/月的独立 hazard 也显著高于目标模拟。
4. **破产判定过窄且过罚**：只看现金连续 3 月 < 0；即使净资产为正也进入清算，
   随后清空资产、信用分归零、停赛 3 月且停发主动收入，容易从“流动性危机”直接变为终局淘汰。
5. **被动收入没有可达路径**：开局现金只够短时生存，Agent 缺少“应急金 → 国债 / 出租房 → FI”
   的决策阶梯；FI=0 不是公式错误，而是数值与引导均未形成通路。

> 结论：这不是单纯“给 Agent 加钱”，而是要把系统从 **结构性赤字 + 无保险 + 即死破产**，
> 调整为 **基本生存可平衡 + 风险可吸收 + 失败可重组 + 被动收入可累积**。

## 2. 修复目标

1. 任何精选职业在 M1 采用“新手生存档”时，基础生存预算可覆盖 6 个月；
   非波动收入卡当月基础现金流不为负；P16 波动低收入月允许消耗自带储备，
   但 M1–M6 流动性不得低于 3 个月 `SurvivalCore`。
2. M97 平均存活 ≥ 10/12；35 岁前正式破产出局 < 20%（设计目标 < 12%）。
3. 终局 60 岁正式出局率 5%–15%，破产清算事件可作为风险教育保留在 12%–25%。
4. 被动收入从 M60 起可见：M120 至少 6/12 Agent FI > 0。
5. 不放宽会计与账本纪律：I1、I2、I4、I6、I8 全月零失败。

### 3.2 初始现金：6 个月生存底线

#### 公式

```text
BasicRent(card, market) =
    min(MarketRent(card.home_district),
        clamp(0.25 × HouseholdRegularGrossIncome,
              1,800  # 月租下限
              12,000))

SurvivalCoreM1 = BasicRent + 0.6 × card.expense

EffectiveStartCash =
    ceil_1000(max(card.savings, 6 × SurvivalCoreM1))
```

规范化说明：

- `BasicRent` 是月租，下限 ¥1,800，上限 ¥12,000；`clamp` 的三个参数均为月租口径。
- 文档池卡缺 `savings_stock` 时，不再使用“工资 × 6”兜底，统一使用上式。
- 开局只允许 **一笔** `world → seat` 初始注入，金额为 `EffectiveStartCash`。
  I2 从“金额 = 卡面 Savings”改为“金额 = 生效初始现金”，仍禁止后续 `from=world`。
- 高储蓄卡不做削减，保留初始阶层差异；低储蓄卡只抬到生存底线。

### 3.3 支出：基础住房与新手生存档

#### 3.3.1 基础住房租金

玩家未自住时，支付的是“基础合租 / 保障房合同租”，不是投资房市场租：

```text
TenantBasicRent =
    min(Market.HouseRent(district),
        clamp(0.25 × HouseholdRegularGrossIncome, 1,800, 12,000))
```

约束：

- 失业期 `HouseholdRegularGrossIncome` 不取 0，使用 **裁员前 12 个月平均常规收入**
  （不含加班）+ 配偶收入；P16 取裁员前 3 个月波动收入均值。
- 投资房产的租金收入仍按 `Market.HouseRent` / `Market.ShopRent` 计算，不受本上限影响。
- 自住房仍免租金、计物业费；迁区后下月按新区重新计算基础租。
- 该规则只改变租房者支出，不改变资产市价、租金资产收益或税费。

设计意图：保留“CBD 更贵”的区位教学，同时防止单月房租超过家庭收入 25%–40% 的结构性死亡。

#### 3.3.2 新手默认节俭档

- M1–M6 或直到 `流动性储备 ≥ 6 × SurvivalCore` 前，默认 `consumption_level=0`（生活支出 ×0.6）。
- 以下情况强制回到节俭档：
  1. 失业期；
  2. `Cash + 可免费赎回债券 < 3 × SurvivalCore`；
  3. 破产宽限期 / 重组观察期。
- 从节俭档升回标准档必须同时满足：
  1. 预计本月基础现金流 ≥ 0；
  2. 升档后仍保留 ≥ 6 个月 `SurvivalCore` 流动性。
- 职业卡标准 `expense` 不下调；用档位表达生活质量，用基础租修正住房错配。

### 3.4 失业保险与就业风险

#### 3.4.1 月度失业 hazard 下调

旧 P0 hazard 在月度口径下过高。Balance v2 使用：

| 市场阶段 | 旧月度 hazard | 新月度 hazard | 近似年化至少一次 |
|---|---:|---:|---:|
| recovery / boom | 5% | **0.8%** | 9.2% |
| recession | 15% | **3.0%** | 30.6% |
| depression | 25% | **5.0%** | 46.0% |

`EconomyEnabled=true` 时仍可乘劳动力市场倍率，但单月最终概率封顶 **8%**：

```text
p_unemploy = min(base(phase) × labor_factor × negative_guard(cognition), 0.08)
```

失业时长保持 U(2,6) 月；再就业比率建议：

| 劳动力市场 | 再就业工资率 |
|---|---|
| 高失业（U > 10%） | 0.75–0.90 |
| 正常 | 0.85–1.05 |
| 用工紧俏（U < 4%） | 1.00–1.10 |

#### 3.4.2 失业保险金

```text
ReferenceGross = 裁员前 12 个月常规月薪均值（不含加班；P16 用 3 个月均值）
UnemploymentBenefit = clamp(0.50 × ReferenceGross, 1,800, 8,000)
```

规则：

- 每失业月发放，最长 6 个月；`gov → seat`，Ledger 类目 `unemployment_benefit`。
- 不计入工资，不缴个税 / 社保，不计入养老金，不影响再就业工资基数。
- 失业期自动节俭档，基础租房参考裁员前家庭收入。
- 配偶收入照常发放；副业若精力允许可保留，作为主动策略而非生存兜底。

### 3.5 工资与生活成本曲线

旧 P0 “支出 5%、工资 3%”的长期剪刀差必须移除。

#### 3.5.1 统一生活成本指数

```text
CostIndexAnnual =
    clamp(market.CPI, 2.0%, 4.0%)   # EconomyEnabled
    3.0%                             # P0 fallback / 无央行
```

生活支出、基础租下限、子女 / 赡养固定支出随同一 `CostIndex` 复利。
市场 CPI 仍可展示极端值，但 P0 必需生活篮子用上述 clamp 防止数值失控。

#### 3.5.2 工资曲线

```text
WageGrowthAnnual =
    clamp(CostIndexAnnual + CareerRealGrowth(age) + BrassDelta, -1.0%, 8.0%)
```

| 年龄段 | CareerRealGrowth |
|---|---:|
| 25–34 | +1.5% |
| 35–44 | +1.0% |
| 45–54 | +0.5% |
| 55–60 | 0.0% |

Brass 信用贷副作用从“名义工资直接改为 1%/0%/−1%”改为压低真实成长：

| 未清偿信用贷 | BrassDelta |
|---|---:|
| 无 | 0 |
| tier1（≤5 万） | −0.5% |
| tier2（≤10 万） | −1.5% |
| tier3（≤20 万） | −2.5% |

`EconomyEnabled=true` 时可叠加原有 Phillips 差分：

```text
g = CostIndexAnnual + CareerRealGrowth + BrassDelta
    + 0.5 × (NaturalUnemployment − LaborUnemployment)
```

要求：

- 工资年度调整仍在 M12 / M24 / ... 执行。
- 失业月不累计成长；再就业后按新基数恢复成长。
- 主动收入仍按现行个税与社保公式计算，不借平衡理由改税率。

### 3.6 破产宽限与重组

#### 3.6.1 三阶段模型

```text
H1 Hardship（困难期，不记破产）
    触发：月末现金 < 0，且现金 ≥ GraceFloor
    时长：首次 6 月；24 月内重复触发 3 月
  ▼
R1 Assisted Reorganization（协助重组，仍不必然出局）
    触发：H1 到期仍负 / 现金 < GraceFloor / 连续两月无法支付利息
    动作：出售非核心流动资产、降档、调整贷款期限；尽量保留自住房
  ▼
B1 Formal Bankruptcy（正式破产 / 出局）
    触发：R1 后预测基础月现金流仍 < 0，且清算后资不抵债
```

`GraceFloor`：

```text
GraceFloor = −min(max(30,000, 3 × SurvivalCore), 100,000)
```

#### 3.6.2 H1 困难期规则

- 强制节俭档、停发加班、禁止新增贷款与买入非债券风险资产。
- 消费贷 / 信用贷可只付利息，本金延期；不记逾期、不扣信用分、不产生 5% 罚息。
- 房贷可申请一次 12 月期限延长或利率重定价，前提是调整后月供 ≤ 家庭常规收入 35%。
- 失业保险、基础租上限自动生效。

#### 3.6.3 R1 重组规则

1. 先使用现金与流动资产补足欠息；**不得因现金短暂为负直接清空房产**。
2. 消费贷 / 信用贷首次重组：本金减 50%、免息、60 期；24 月内重复重组为 36 期。
3. 保留自住房条件：重组后房贷 + 物业 + 基础生活 ≤ 常规收入 55%，且保留 3 个月生存金。
4. 信用分下限设为 400，不归零；24 月内新杠杆禁用，之后按期还款每 6 月 +10，最高回 550。
5. 动作冻结 1 月（仅禁止非还款 / 非保险动作），**不得冻结工资、失业保险与被动收入**。

#### 3.6.4 B1 正式破产

- 仅在 R1 后仍无法形成非负基础现金流，且清算后 `总资产 < 总负债` 时 `Alive=false`。
- 清算顺序：流动资产 → 非自住房产 / 商铺 → 自住房；房产仍按市价 70% 强制变现。
- 出局者保留终局净资产曲线与历史 Ledger，财富分布统计必须将其终值纳入。
- `BankruptCount` 表示清算事件次数；正式出局需额外满足 B1 条件，避免“一次流动性危机 = 死亡”。

### 3.7 被动收入引导

#### 3.7.1 流动性与投资阶梯

| 阶段 | 条件 | 引导策略 |
|---|---|---|
| 生存期 | 流动性 < 3 月 `SurvivalCore` | 节俭、还高息债、不买风险资产 |
| 应急期 | 3–6 月 | 优先国债 / 随时可赎回理财；债券计入流动性储备 |
| 积累期 | ≥ 6 月 | 每月新增储蓄的 30% 配置债券 / 出租房，30% 成长资产，40% 补储备与教育 |
| 自由期 | FI ≥ 0.5 | 控制单一资产 ≤ 50% 可投资净资产，房产 ≤ 70% |

新增投资与贷款护栏：

- 买入风险资产后仍需保留 ≥ 6 月 `SurvivalCore` 流动性；国债可计入该储备。
- 新增房贷后总月供 ≤ 常规收入 35%，且首付后保留 6 月储备。
- tier3 信用贷仅允许 FI ≥ 0.3 且储备 ≥ 12 月者使用；默认提示为“危机工具”。

#### 3.7.2 Agent prompt / bot context 提示

每月给 Agent 增加只读 `passive_income_hint`：

```text
if reserve < 3m: " survival_mode: 建立应急金，禁止加杠杆"
elif reserve < 6m: "bond_ladder: 可把应急金转为可赎回债券"
else: "invest_surplus_30: 将 30% 盈余投入债券/出租资产；FI 目标见年龄线"
```

年龄目标：

| 年龄 / 月份 | FI 目标 |
|---|---:|
| 30 岁 / M60 | ≥ 0.05 |
| 35 岁 / M120 | ≥ 0.15 |
| 40 岁 / M180 | ≥ 0.30 |
| 45 岁 / M240 | ≥ 0.50 |
| 50 岁 / M300 | ≥ 0.75 |
| 55 岁 / M360 | ≥ 1.00 |

不强制代 Agent 买入资产。但若 bot 连续 2 月无有效动作且流动性 ≥ 9 月生存线，
允许执行一次“最小国债包 ¥1,000–¥3,000”的教程型兜底；人类玩家不启用。

## 4. Ledger 与会计不变量

### 4.1 现金流入口

所有现金变化必须继续通过 `World.Pay`：

| 变化 | Ledger |
|---|---|
| 生效初始现金 | `world → seat`，`inject`，全局每座仅 1 条 |
| 基础房租 | `seat → world/firms`，`rent_pay` |
| 失业保险 | `gov → seat`，`unemployment_benefit` |
| 工资 / 配偶 / 副业 | `bank/market → seat` |
| 债券利息 / 租金 | `market → seat` |
| 清算卖出 | `market → seat`，70% 折价只作用于金额 |
| 清算还贷 | `seat → bank` |

禁止直接改 `p.Cash`；禁止负数金额；禁止 `from == to`。

### 4.2 不变量验收

1. **I1 座位现金守恒**：逐月、逐座位
   `期末现金 − 期初现金 = Σ(to=seat) − Σ(from=seat)`。
2. **I2 world 注入唯一性**：`from=world` 仅开局一次，金额 = `EffectiveStartCash`；
   失业保险不得用 world 造钱。
3. **I4 资产负债恒等**：每月重算
   `净资产 = 现金 + Σ资产市值 − Σ贷款余额`。
   债务展期 / 减免只改 Loan 状态与事件记录，不伪造现金 Ledger。
4. **I6 FI 公式不变**：`FI = 月被动收入 ÷ max(月总支出, 1)`；
   `月总支出` 使用实际基础租与当期消费档，支出为 0 时仍封顶 2.0。
5. **I8 系统财富守恒**：Monte Carlo 同时汇总 seat / bank / market / gov / insurer / world
   的 Ledger 净流，任意切口总净流为 0；政府转移支付只改变分配，不凭空增加社会总财富。

## 5. 蒙特卡洛验收

### 5.1 运行设计

| 项 | 要求 |
|---|---|
| 局数 | PR smoke ≥ 200 局；合入门禁 **1,000 局 / 配置** |
| 每局 | 12 座、curated 14 卡无重复抽取、M1→M420 |
| 种子 | `20260919_0000` 起连续固定种子，重复 3 欀结果一致 |
| LLM | 禁止调用真实 LLM，使用确定性策略代理 |
| 输出 | 均值、P05、P50、P95、逐月时间序列、失败种子 |

策略代理：

1. `safety_net_only`：不投资、不主动动作，仅接受自动节俭与保险；
2. `minimum_effort`：达到 6 月储备后每月把 20% 盈余买国债；
3. `balanced`：按 §3.7 的 40/30/30 储备 / 被动 / 成长配置；
4. `aggressive_leverage`：繁荣期买房 / 买股，贷款上限用满；
5. `stress`：M25–M37 强制 recession，M61–M73 depression，并各注入一次失业与健康事件。

## 7. 分阶段落地顺序

1. **第一步（只救命）**：生效初始现金、基础租、新手节俭档、失业保险、hazard 下调。
2. **第二步（防误杀）**：H1 / R1 / B1 三阶段破产、债务重组、信用分下限。
3. **第三步（修长期）**：CostIndex 与工资曲线、Brass 真实成长 delta。
4. **第四步（通路）**：被动收入提示、投资 / 贷款护栏、教程型国债兜底。
5. **第五步（验收）**：Monte Carlo smoke 200 → gate 1000 → 真实 12 Agent 房 M1–M120。

真实房回归最低要求：

- M1–M120 无卡死；
- M97 存活 ≥ 10/12；
- M120 FI > 0 ≥ 6/12；
- Ledger / 资产负债不变量零失败；
- 财富分布仍显著分化（Gini 0.25–0.50），不得用“全员躺平”换取生存率。

## 8. 明确不做

1. 不修改个税、社保、资产交易税费公式来掩盖生存曲线问题。
2. 不在破产或失业时直接 `world → seat` 发钱。
3. 不直接改资产价格或随机 seed 来“保送”某个 Agent。
4. 不用 `eval_js` / 后门修改现金、贷款或市场状态。
5. 不把破产率压到 0：正式出局仍必须存在，用于表达高杠杆与财务失败。
