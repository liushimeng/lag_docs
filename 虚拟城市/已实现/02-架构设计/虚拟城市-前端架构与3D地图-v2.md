分层约束（批次 22 新增）：`engine3d/` **禁止** import 任何游戏私有模块
（`components/<game>/`、`types/<game>`、`assets/images/<game>`）；游戏侧经 `@/engine3d`
单点引入。游戏私有的资产路径拼接（如 synth 材质 stem）留在 `components/virtualCity/cityPbr.ts`。

## 2. 类型与状态

- `types/virtualCity.ts`：`VirtualCityGameState`（协议 §3 全字段）等，字段名 / 可空性与协议
  **逐字一致**，禁止 camelCase 转写偏差。
- `store/virtualCity.store.ts`（zustand）：`state` / `applyFrame(type, payload)` /
  `ui: { panelTab, selectedDistrict, actionModal }`。
- `hooks/useVirtualCity.ts`：WS 连接由 `AppLayout` 唯一持有（§16 约束），本 hook 只订阅
  `game.*` 帧 + 提供 `sendAction(action)`；断线恢复走 `useSessionRestore`；观战 `useSpectatorMode()`。
- 错误展示（§7.1）：弹窗内动作用内联 `formError`；面板级 / 帧错误 `reportGlobalError(e)`。

## 3. 3D 城市场景规范

`VirtualCityCityMap.tsx`（@react-three/fiber + @react-three/drei，渲染栈经批次 13–22
演进为**真 3D 世界**；世界标尺 `cityScale.ts`：1 世界单位 = 10 米，世界 120×120 = 1200m² 城区）：

| 项 | 规范 |
|----|------|
| Canvas | `<EngineCanvas>`（engine3d）：`shadows` + `dpr=[1,1.75]`（`?quality=low` 降 [1,1]）+ ACESFilmic toneMapping(exposure 1.05) + PCFSoft 阴影；`?debug=1` 挂 `window.__cityRenderInfo` |
| 相机 | 透视 `position=CAMERA_START(W×0.35, W×0.3, W×0.35) fov=45` |
| 视角模式 | **orbit 俯瞰**（OrbitControls，`maxPolarAngle=1.54` ≈88°——批次 22 从 2.5D 锁定俯视 1.2 解锁，可压到近街面视角；`minDistance=W×0.1`、`maxDistance=W`）/ **walk 街景漫游**（engine3d `WalkControls`：WASD + 鼠标拖拽环视，眼高 `u(1.7)`，Shift ×3 加速，活动范围 clamp ±W/2）。地图右上角按钮切换，互斥挂载、切换时衔接位姿（orbit target ↔ 漫游落点） |
| 天空/雾 | drei `<Sky>`（sunPosition 与主方向光同向）+ `<fog #aeb8c6, W×1.0, W×2.0>` |
| 光照 | ambient 0.45 + hemisphere(#7a93b8/#1a1f2a, 0.5) + 主方向光 #fff2e0 ×1.15（2048 shadow map，阴影相机 ±W×0.5 覆盖全城）+ 冷色填充光 #b8cce8 ×0.3 |
| 环境反射 | `<EnvBinder>`（engine3d，PMREM 烘焙 Sky → scene.environment，intensity 0.35；软件渲染器自动跳过） |
| 地面 | 160×160 `planeGeometry`，RepeatWrapping `urban_base` 城市底色（缺失 → asphalt_main → 纯色 #141a24） |
| 城区 | 32 × `DistrictBlock`：底板贴图 + 楼群（building_shapes 各 archetype，PBR 三件套经 `cityPbr.useSynthPBR`），高度映射 `price_index`（繁荣期楼变高 = 可视化周期） |
| 道路 | 分层 `<Road />`（主干道/次干道按 len > W×0.15 判定）+ `RingRoad`（CBD 环路）+ 全局路灯 InstancedMesh（3 draw call） |
| 水系 | `WaterLayer`：城市运河（z=+17，x∈[-48,48]）+ 物流港港池 + 岸草皮 + 岸雾 WaterMist |
| 氛围 | `AtmosphereLayer`（远景剪影/落叶）+ `CloudLayer`（Billboard 云）+ `LandmarksLayer`（喷泉/塔吊/停车场）+ `CivicLayer`（市政补全）+ `StreetPropsLayer`（车/树/行人，Blender .glb 经 engine3d `<Model>`，缺失自动回退程序化几何） |
| Token | `AgentToken`：职业色圆柱 + Billboard 头像 sprite + `Html` 名牌；`useFrame` 中 `position.lerp(target, 0.06)` 迁区平滑动画 |
| hover/选中 | `DistrictBlock` 悬停浮层信息卡；小地图或面板点击城区 → `FocusLerpController` 平滑聚焦（仅 orbit 模式） |

职业色（Token 圆柱与名牌底色，对比度 ≥4.5:1 于深色地图）沿用 v1 色板不变。

## 4. 小地图

`VirtualCityMinimap.tsx`：主地图左上角**绝对定位**（Canvas2D，**不开第二个 r3f Canvas**）：

- 绘制：120×120 世界 → 120px 坐标；32 城区色块（透明度 0.35）+ agent 点（职业色）+
  当前相机视野框（主 Canvas `CameraViewReporter` 每帧写 `viewRef`）。
- 视角模式联动：orbit 模式上报 `OrbitControls.target`；walk 模式上报相机自身位置
  （`fallbackToCamera`，固定小视野框）。
- 交互：点击城区 → 触发主地图聚焦；`requestAnimationFrame` 与主 Canvas 同频重绘。

## 8. 样式与对比度

- 虚拟城市样式经 `styles/globals.css` `@import` 链接入（§2.1 硬约束 4：顺序不可调，
  只追加不改序）。
- 命名空间：选择器前缀 `.virtualCity-`（批次 21 由 `.wealth-` 迁移），杜绝与既有样式互染。
- 对比度（§26 硬阈值）：正文 ≥4.5:1；徽章 ≥5.0:1；selected 档 ≥6.0:1。**禁止**红底红字 /
  `color:inherit`+半透明底 / `opacity:0.4` 表 disabled（§26.2 五反模式一票否决）。
- 视角切换按钮等地图浮层控件：显式白字 + ≥45% 不透明底（批次 22 街景漫游按钮同规）。
- 状态徽章三件套（§26.3）：`income-band-*`、`cycle-*`、`ending-*` 的 JSX 拼接与 CSS 规则
  **同提交**完成；写完 JSX 立即 `grep -rn "income-band-" src/styles/` 验证非零命中。
- 触控 44px；`prefers-reduced-motion` 下关闭 token lerp 与数字滚动。

## 9. 降级策略

| 缺失 | 降级 | 构建影响 |
|------|------|---------|
| 职业头像 PNG | 职业色圆环 + 职业 emoji（`AgentToken` 内 `onError` 切换） | 无 |
| 城区/地面/道路贴图 | 纯色材质（贴图缓存返回 null，各组件降级链） | 无 |
| Blender .glb 模型 | 程序化几何（`<Model>` children fallback；`disable-blender-models=1` 强制） | 无 |
| 软件渲染器（SwiftShader 等） | 跳过 PMREM 环境反射（engine3d `quality.ts` 检测）；`?quality=low` 再降 dpr | 无 |
| banner PNG | CSS 渐变（accent 金 → 深蓝） | 无 |

美术生成脚本 `python-generate-image-tool/`（贴图）与 `3d_script/build_*.py`（Blender .glb）
**skip-if-exists 可续跑**；前端构建**不依赖**生成成功（`import.meta.glob` 引用 + 运行时
降级链），CI 无图也能 `npm run build` 通过。
