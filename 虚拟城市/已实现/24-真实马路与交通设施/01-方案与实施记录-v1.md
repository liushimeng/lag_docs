## 1. 背景与现状问题

2026-09-26 用户反馈：主游戏界面马路需增加贴图显示、改为真实马路，补齐红绿灯 / 路灯 / 垃圾桶 / 斑马线 / 左右车道线等符合中国交通规则的标线与设施。逐项核查现状：

**规模标尺**（`cityScale.ts`）：1 世界单位 = 10 米。主干道宽 1.4u = 14m，次干道 0.9u = 9m；车流实际占用两条行车道（车道中心 ±0.34u），按**双向两车道**做标线。

## 2. 目标与验收标准

1. 马路铺装为**真实沥青贴图**（程序化噪声颗粒 + PBR 法线/粗糙度），彻底替换占位符。
2. 标线**烘焙进整幅路面贴图**（中心黄色虚线 + 白色边缘实线），符合 GB 5768 道路交通标线风格，与车辆右行车道对齐。
3. 每条道路**两端均有斑马线** + **来向半幅停止线** + **直行导向箭头**。
4. 红绿灯升级为**竖式三色灯 + 相位动画**（绿→黄→红循环），主干道两端 + CBD 环岛路口布设，全城 InstancedMesh 化。
5. **Blender 真实 3D 垃圾桶**（分类双色）沿主干道人行道布设，GLB + 实例化渲染。
6. 人行道换**真实砖纹贴图**。
7. 验收门禁：`tsc --noEmit` + `npm run build` 通过；CDP 截图目视验证贴图/标线/红绿灯/垃圾桶；draw calls 预算内（§7）；`.glb ≤ 500KB`。

```
    ↓ 产出

    ↓ useSharedGLTF + 按 (geometry, material) 对抽离

```

**设计取舍**：
- **标线烘焙 vs 独立面片**：烘焙进 1.4u×1.4u 整幅贴图（dash 周期 = 贴图宽度整除，平铺无缝），减少 draw call，且标线随路面颗粒自然磨损。独立面片仅保留斑马线 / 停止线 / 箭头（尺寸非整周期）。
- **贴图程序化 vs AI 生成**：标线需要 GB 精确几何（等宽、等距、直线），AI 文生图无法保证；沥青颗粒用多倍频噪声 + 斑点 + 轮迹带即可达到真实感，且离线确定性可复现。故 `generate_virtual_city_road_assets.py` 为**纯 Pillow 程序化**（沿用 python-generate-image-tool 工具目录与规约），不调用方舟 API。
- **红绿灯程序化 vs GLB**：灯泡需要逐实例亮灭动画（instanceColor），GLB 材质无法逐实例切 emissive；杆件/灯箱程序化几何在本比例（1u=10m）下已足够。**Blender 只交付垃圾桶**（静态、单/少材质、实例化友好），避免再造"生成了却不接线"的 GLB（§130 教训）；`road_props.glb` 维持现状不动（19 批次遗留债务另案处理，本批次不扩散）。

### 6.1 车道与标线对齐推导（实现依据）

- `Vehicle.tsx:173-178`：行进方向 `(dx,dz)` 的右侧 = `(dz,-dx)/len`；**双向车流都传正 laneOffset**（方向反转世界侧自动翻转）。
- Road 局部系（group 旋转 `atan2(dx,dz)`，local +z = from→to）：正向车（district→origin，行进 local +z）占 **local x>0** 车道（中心 +0.34）；反向车（origin→district）占 local x<0。
- 因此：**原点端（t≈0.92）停止线/来向设施服务于正向车 → 铺 local x∈[0.05,0.65] 半幅**；**城区端（t≈0.08）服务于反向车 → 铺 x∈[-0.65,-0.05] 半幅**。斑马线全宽，紧贴停止线外侧（更靠近路口端）。
- 中国规则锚点：右侧通行、双向两车道中心为黄色虚线（可越线超车）、边缘白色实线、导向箭头指示行进方向、停止线只画来向车道半幅。

### 6.2 红绿灯布点与相位

- **主干道**（len ≥ 18）：t=0.90 与 t=0.10 各 1 座，立于受控车道右侧路缘（sideOffset ≈ 0.95u），灯面朝向来车（沿车道行进反方向）；相位组 = 道路索引奇偶 → A/B。
- **环岛路口**（半径 5.6 与主干道放射线交点，仅主干道放射）：对角 2 座 —— 1 座面向放射来车（组 A），1 座面向环岛来车（组 B）；替代原 IntersectionSignals 的 `len<=12` 硬编码。
- 相位周期 16s：A 组 0s 起 绿6/黄2/红8；B 组 +8s。灯泡亮色 `#ff2d2d`/`#ffc40f`/`#2ecc71`，暗色为对应 15% 亮度深色。
