## 3. 关键根因（实施中发现）

### 3.1 `OffLedgerBook.total` 未导出 ⇒ 快照 round-trip 后 StateHash 漂移

**现象**：`TestWorldSnapshot_RoundTrip` 失败 —— 快照恢复后 `StateHash` 与快照前不一致。

**根因**：`hashLedgerScope` 纳入 `OffLedger.Total()`，而 `OffLedgerBook.total` 是**未导出字段**（`json:"-"` 语义），JSON 落盘丢失 ⇒ 恢复后 `Total()` 恒为 0 ⇒ 哈希漂移。`Entries` 是 200 条环形缓冲，**无法由 Entries 重算全量累计**。

**修复**：`total` → 导出 `TotalNet`（`offledger.go`）。同时 `startAge`（未导出）由 `unmarshalWorld` 恢复为 `MasterStartAge`。

**教训**：**任何进入 `StateHash` 的派生量，其依赖字段必须可序列化**。新增派生量时须 grep `hash*.go` 确认。

### 3.2 测试房 id 复用 ⇒ 灾难恢复「串房」

**现象**：`seats12_test.go` 的 `newRoomWithSeats` 固定用 `"room-seats"`。批次86 起 `Start` 会按 roomID 读 `./virtual_city_saves/<roomID>/recovery.json`，`trySettle` 会写该文件 ⇒ 同 ID 的下一个测试房**恢复到上一个测试的月结点**。

**修复**：测试房 id 加 `atomic.AddUint64` 自增序列（`seats12_test.go`）。

**教训**：**任何「按 id 落盘」的机制都要审视测试的 id 复用**；生产 roomID 来自 DB 不复用，测试必须自造唯一 id。

### 3.3 `view_json_tags_test.go` 的 `assertKeysExact`

`ClientGameState` 的键集合断言是**全等**（`assertKeysExact`），新增 `key_metrics` / `event_lifecycle` 必须同步补期望键，否则红。已补。

## 5. 偏差与遗留

| 项 | 说明 |
|----|------|
| `SendWithRetry` 暂无内部调用方 | outbox（持久化）已接线；`SendWithRetry` 作为公共 API 供可靠性敏感调用方使用。后续可在 `ask_agent` / `collect` 路径按需接入 |
| 前端「回滚」为客户端组合 | 前端取留痕环最新 `success` + `snapshot_id` → 调 `restore`；与后端 `RollbackLastScenario` 语义等价，但 UI 更透明（用户看到将回滚哪条）。后端 `POST /snapshot/rollback` 作为公共 API 保留 |
| 留痕 gate 名原样展示 | `idempotency` / `magnitude_limit` 等是技术标识符（与 `trace_id` / `state_hash` 同性质），不翻译；触发来源 / 决策 / 结果均已三语 |
| 快照恢复非「逐位等价」 | `Rand` 内部态不可序列化 ⇒ 恢复后重新播种（同 `Seed`）。**⚠️ 实测口径比方案 §3.2.2 更宽**：`GoodsMarket.history` / `lastDistrictIdx` / `baselineDemand` 与 `Player.biasHitsSampled` 亦为未导出字段，恢复后丢失 ⇒ **未来 CPI / 需求演化与未恢复的对局分叉**（`StateHash` 不受影响，10 个 scope 已逐一对拍）。若需「精确续跑」，须把这些字段一并导出或改为可重算 |
| `metricHistory`（批次84）恢复后清空 | 该环是「逐月追加」的观测缓冲，回档后会残留未来月份样本 ⇒ 恢复/回放时清空。方案未提及，属实施期修正 |
| 房间层拦截 `ResultErrCode = 0` | 安全阀拦截（幂等 / 每月条数 / 强度 / kind 去重 / 活动上限）无专属错误码，原因写在 `ResultErrMsg` |
| 35002（未开局）不留痕 | `applyScenarioFromSource` 在房间未开局时提前返回，不构造 trace |
| `RollbackLastScenario` 无成功留痕时返回 35066 | 复用 `ErrVirtualCitySnapshotNotFound`，无独立「无回滚点」码 |
| 快照在「校验通过后、首次改写前」拍 | 不是字面意义的步骤①；`StateHashBefore` 两种时机相同（校验无副作用），且避免为被拒注入白写 46 KB |
| `ExecutionDuration` = `durationMonths` | 字段位于 `ExecutionMagnitude` 与 `ExecutionTarget` 之间，语义为「注入参数」而非墙钟耗时 |
