## 2. 架构总览（三层）

```
┌─ 真实金融网站（56 个国内可直连公开站点，见 §10 源清单）
│     ▲ HTTPS
├─ L1 Chrome 层：go-web-debug-tool 子模块（独立进程，HTTP :29008）
│     │  6 端点：NewChromePage / ControlChromePage / LookChromePageInfo
│     │          / BatchEval / ListChromePages / CloseChromePage
│     ▼ HTTP REST（JSON 信封 {code,message,data}）
├─ L2 ServerGo 层：ServerGo/citychrome/（新包，全局单例）
│     ├─ webuse_client.go   HTTP client + 健康探测 + 超时
│     ├─ mcp_tools.go       MCP_Web_Use 工具定义（→ LLM tools）
│     ├─ agent.go           City-Chrome Agent 循环（LLM 规划→工具执行）
│     ├─ feed_store.go      FeedStore（行情/新闻/历史环，线程安全）
│     └─ scheduler.go       类目轮转调度 + 熔断退避 + 任务队列
│     │   ├─ WS 广播 game.realtime_feed（节流合并，≥10s 间隔）
│     │   ├─ HTTP GET  /api/virtual_city/realtime_board（快照）
│     │   ├─ HTTP POST /api/virtual_city/realtime_board/refresh（人工触发）
│     │   └─ City-Human 工具 realworld_info（读 FeedStore）
│     ▼ WS / HTTPS
├─ L3 前端层：components/virtualCity/RealtimeBoard/
       侧栏新 Tab「实时」→ 子 Tab（总览/A股/港股/美股/贵金属/期货/比特币/新闻）
```

**关键决策**：
1. **数据是全局的**（与房间无关）——FeedStore 为 server 级单例；广播时枚举 Hub 内所有 `virtual_city` 房间推送。
2. **ServerGo 不直接依赖 chromedp**——只通过 HTTP 调 go-web-debug-tool；服务不可达时通道降级为 `offline`，看板显式展示，**绝不阻塞对局**。
3. **LLM 只在 City-Chrome Agent 一处消费**——City-Human 读 FeedStore 是纯本地工具调用，零额外 LLM 成本。
4. **一切契约以本文档为准**——前后端 SubAgent 并行实现，字段名/帧名/URL 不允许漂移。

## 3. L2 服务端设计（`ServerGo/citychrome/`）

### 3.1 配置（`LsmAgentGame.conf` 新增顶级段，example 同步）

```json
"city_chrome": {
  "enabled": true,
  "debug_tool_url": "http://127.0.0.1:29008",
  "auth_token": "",
  "model_key": "DeepSeek-model",
  "refresh_seconds": 1800,
  "max_steps_per_mission": 14,
  "symbols_per_category": 12,
  "news_limit": 20,
  "request_timeout_ms": 90000
}
```

- `enabled=false` 或 debug tool 不可达 ⇒ 服务空转，接口返回 `channel.status="offline"`。
- 密钥类（auth_token）只进 `LsmAgentGame.conf`（已 gitignore），example 用占位符。

### 3.2 FeedStore 数据模型（唯一事实来源）

```go
type RealtimeQuote struct {
    Symbol     string    `json:"symbol"`      // 站点口径代码或名称，如 "000001"/"上证指数"/"BTC"
    Name       string    `json:"name"`
    Price      float64   `json:"price"`
    ChangePct  float64   `json:"change_pct"`  // 百分比，-100~+100
    Currency   string    `json:"currency,omitempty"`
    UpdatedAt  int64     `json:"updated_at"`  // Unix 秒
    Source     string    `json:"source"`      // 采集来源站点名
}
type RealtimePoint struct { T int64 `json:"t"`; P float64 `json:"p"` } // 自采价点（服务端入环）
type RealtimeCategory struct {
    UpdatedAt int64             `json:"updated_at"`
    Source    string            `json:"source"`
    Quotes    []RealtimeQuote   `json:"quotes"`              // ≤ symbols_per_category
    History   map[string][]RealtimePoint `json:"history"`    // symbol → 最近 ≤48 点
}
type RealtimeNews struct {
    ID          string  `json:"id"`           // md5(title+url) 前 12 位
    Title       string  `json:"title"`
    Source      string  `json:"source"`
    Category    string  `json:"category"`     // 见 Category 常量；综合新闻用 "general"
    PublishedAt int64   `json:"published_at"`
    URL         string  `json:"url"`
}
type ChannelStatus struct {
    Status   string `json:"status"`    // "online" | "offline"
    Detail   string `json:"detail"`    // 离线原因/最近错误
    LastOKAt int64  `json:"last_ok_at"`
}
type Feed struct {                          // WS 帧与 HTTP 快照共用的载荷
    Channel    ChannelStatus                  `json:"channel"`
    UpdatedAt  int64                          `json:"updated_at"`
    Categories map[string]RealtimeCategory    `json:"categories"` // key: a_share/hk/us/metal/futures/crypto
    News       []RealtimeNews                 `json:"news"`       // ≤ news_limit，新→旧
}
```

Category 常量：`a_share` / `hk` / `us` / `metal` / `futures` / `crypto` / `general`。

### 3.3 WS 帧契约

| 方向 | 帧 | 载荷 | 时机 |
|---|---|---|---|
| S→C | `game.realtime_feed` | `{feed: Feed}` 全量快照（体积小：≤72 条报价 + ≤20 新闻） | 每次成功 mission 后；**节流合并：距上次广播 <10s 则挂起合并**，全局单飞（上一个广播未落地不叠） |

-  late-joiner 靠 HTTP 快照（§3.5）补齐，不在 `game.state` 里塞 feed（防 state 膨胀）。
- 前端在 `useVirtualCity.ts` 帧 switch 新增 case，写 store 新 slice（§8.2）。

### 3.4 City-Chrome Agent（LLM 驱动）

**注册**：`ServerGo/agent/class_names.go` 追加 `AgentClassCityChrome AgentClassName = "LsmAgentGame-City-Chrome"` + 入 `AllAgentClassNames()`；§24 两步走（常量 + 构造点断言非空单测）。

**Agent 循环（agent.go）**：
```
Mission{Category, TargetURL, Sites[]备选, Goal描述}
  → system = sysprompt.EnsureHead(角色段, AgentClassCityChrome)   // 三段式自动注入
  → user   = mission JSON + 输出 schema 说明 + 站点备选清单
  → for step < max_steps_per_mission:
        LLM 规划 → 工具调用（mcp_tools） → tool result 回灌
        工具 web_done{payload} ⇒ 解析校验 ⇒ break
  ⇒ 无 web_done：最后一条 assistant 文本按 JSON 提取兜底；仍失败 ⇒ mission 失败计熔断
```

**输出 schema（web_done.payload，LLM 必须严格产出）**：
```json
{
  "category": "a_share",
  "source": "东方财富",
  "quotes": [{"symbol":"000001","name":"上证指数","price":3221.5,"change_pct":0.82,"currency":"CNY"}],
  "news": [{"title":"...","url":"https://...","published_at":1729300000}]
}
```
服务端校验：quotes ≤ symbols_per_category、price/change_pct 数值合法、未知 category 拒绝；**单条脏数据丢弃不整包失败**。

**角色段要点**（agent.go 内常量文本）：你是虚拟城市的数据采集员；只用工具操作浏览器；**优先 `web_eval`（BatchEval 单次多条提取）减少往返**；每条数据必须来自页面真实 DOM 文本，注明 source；遇拦截/验证码/超时 → 换备选站点（Sites 列表），最多换 3 次；**禁止登录、禁止提交表单、禁止绕过验证码**，只读公开页面；完成后必须调 `web_done`。

### 3.5 HTTP API（router 注册，需登录）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/virtual_city/realtime_board` | 返回 `{code:0, data:{feed: Feed}}`（快照，late-joiner 首屏用） |
| POST | `/api/virtual_city/realtime_board/refresh` | body `{category?: string}`；入任务队列立即调度一次 mission；限流：同 category 60s 内重复请求返回 429 语义错误码；返回 `{code:0, data:{accepted:true, queued_category:"..."}}` |

### 3.6 调度器（scheduler.go）

- **轮转**：6 个类目按 `refresh_seconds` 间隔轮转（a_share→hk→us→metal→futures→crypto→回卷）；news 随各类目 mission 顺带采集。
- **单飞**：全局同时只跑 1 个 mission（队列串行）；LLM 调用走既有 llmSema 节流。
- **熔断**：连续 3 次 mission 失败 ⇒ channel=offline + 指数退避（5m→10m→20m→封顶 30m），任一成功即复位 online。
- **空闲降载**：Hub 内无 `virtual_city` 房间 ⇒ 调度暂停（HTTP 手动刷新仍可用）。

### 3.7 City-Human 工具 `realworld_info`

- 落点：`ServerGo/agent/vcplayer/tools.go`（ToolNames + dispatch case，沿批次 35「单工具+op」范式）+ 引擎只读桥。
- 入参：`{op:"quotes"|"news"|"overview", category?: string}`。
- 返回：FeedStore 紧凑 JSON（overview=channel 状态+各类目最近更新时间+头条 3 条；quotes 默认全部类目各前 5；news 最近 10 条）。
- 引擎语义零改动——只读真实世界快照，不产生任何游戏内动作。

## 4. MCP_Web_Use 工具集（mcp_tools.go → LLM tools 定义）

统一前缀 `web_`；每个工具=一次/多次 go-web-debug-tool HTTP 调用。**所有返回保留 `page_id`（需求 #8：点击/开新页后回传 page_id 保持连贯）**。

| 工具 | 入参 | 映射到底座 | 覆盖需求 |
|---|---|---|---|
| `web_open` | `{url, wait_until?}` | POST /NewChromePage | 打开页面；返回 `{page_id,title,url}` |
| `web_control` | `{page_id, action, params}` | POST /ControlChromePage 透传 | click / right_click / double_click / hover / scroll(滚轮) / scroll_to / key_press / press_sequence / input_text / human_input / clear_input / upload_file / select_option / drag / navigate / back / forward / reload / new_tab(返回 spawned_page_id) / close_tab / screenshot / add_script / **eval_js** |
| `web_eval` | `{page_id, items:[{label,expression,await_promise?}]}` | POST /BatchEval（1–64 条） | DOM 数据批量提取；**下载文件=eval_js 内 fetch→base64 返回**（同源限制内） |
| `web_look` | `{page_id, info, params}` | POST /LookChromePageInfo 透传 | console / network / elements / dom / localstorage / sessionstorage / cookies / performance / screenshot |
| `web_list` | `{}` | POST /ListChromePages | 页面索引 |
| `web_close` | `{page_id}` | POST /CloseChromePage | 关页回收 |
| `web_done` | `{payload}` | 本地（不走 HTTP） | mission 结束标记 + 结构化数据（§3.4 schema） |

- `web_control` 的 action 白名单即上表（**服务端校验拒绝表外 action**）；截图统一走 `web_look info=screenshot`（支持 save_path 落盘，防数 MB base64 在上下文里往返）。
- client 侧公共逻辑：信封 `{code,message,data}` 非 0 抛错；`request_timeout_ms` 超时；`auth_token` 非空时带 `Authorization: Bearer`。

### 5.3 布局契约（遵守批次 63 基线 + §26）

- 面板内容 `flex column + gap:8px`；报价表行高 ≥36px 触达；空态=图标+说明占位块（同 BehaviorPanel 范式）。
- 通道徽章三色：`online`=绿（≥5:1）、`offline`=灰底深字（禁 opacity 表禁用）、`updating`=黄；徽章文字 ≥5:1。

- 所有样式进新文件 **`styles/virtualCity-realtime.css`**（virtualCity.css 1777/1800 触顶），`globals.css` **链尾追加** `@import`（硬约束：只追加、不改序）。

## 8. 非目标 / 已知边界

- 不做 tick 级高频行情（分钟级自采环已足够看板叙事；未来批次可加后端 OHLC 持久化）。
- 不引入任何图表库（沿全项目纯 SVG 传统）。
- 不做自动交易联动（真实行情 → 游戏内价格映射是行为金融批次 62 的后续候选，本批只到「展示+Agent 可读」）。
- 56 站点中个别可能改版/失效 ⇒ mission 有备选源轮换 + 熔断兜底；源清单文档定期人工刷新。
- 3D 场景/模型细节优化（需求 12/15）不在本批；由后续批次按「每阶段一种物体」推进。
