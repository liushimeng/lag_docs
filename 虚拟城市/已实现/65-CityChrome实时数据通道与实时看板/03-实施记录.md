## 3. 关键教训（本批新增）

- **L1 WS 信封嵌套**：C→S 帧必须 `{type, payload:{...}}`；散拍顶层字段会被 `json.Unmarshal(env.Payload)` 拒成 20001，且观战者不进入房间广播集 → 永远收不到推送。E2E 驱动器已按此修正。
- **L2 东财 push2 API 不稳**：非浏览器 UA/高频访问触发 IIS 403（实测 curl 与连续 Chrome 访问均被拒）；SPA 页面 DOM 提取一次 mission 耗 14 步不收敛。→ a_share/hk/us/metal/futures 首选源改为**腾讯行情 qt.gtimg.cn 直读**（免登录纯文本，A股/港股/美股 `~` 分隔、外盘 hf_ 逗号分隔，E2E 实测全部 200 且有真实数据），备选保留东财系。Agent 按「确定性提取配方」（navigate→读 body→按位解析）2-9 步即可 web_done。
- **L3 涨跌幅口径**：模型曾把 0.12% 误写为 12.0（×100）。已在全部配方注明「百分数口径，原样填写不要乘 100」；快照实证修正后待下一 mission 复核。
- **L4 可观测性**：Agent 循环工具调用补 Info 级日志（step/工具/结果预览 200 字/失败末条文本 500 字）+ 步数预算回灌（`[step n/14]`）——首次 E2E 靠它定位「模型不收敛」根因。
- **L5 调度单飞排队**：自动轮转 mission 占用队列时，手动 refresh 排队等待属预期；验收脚本需按 mission 真实时长（2-4 分钟）等待，不能用 HTTP accepted 当完成信号。
