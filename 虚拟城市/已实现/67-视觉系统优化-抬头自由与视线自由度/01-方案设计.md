## 2. 现状分析（代码事实）

### 2.1 相机链路（批次 32 之后）

```
  └─ VirtualCityCityMap.tsx
       └─ <EngineCanvas camera={{position: CAMERA_START, fov:45, near:0.05, far:800}}>
            ├─ <CityEnvironmentLayer />   （DayNightCycle + DayNightSky 渐变天穹 + WeatherFX）
            ├─ <FreeViewControls … />     （engine3d 单控制器，orbit / fly 两态）
            └─ <CameraViewReporter … />   （视野快照 → 小地图）
```

`FreeViewControls`（`ClientWeb/src/engine3d/controls/FreeViewControls.tsx`，1123 行）内部：

| 模式 | 位置由谁决定 | 朝向由谁决定 | 能否抬头 |
|---|---|---|---|
| `orbit`（默认，俯瞰归零点） | `target + sphericalOffset(radius, φ, θ)` | **`lookAt(target)`**（硬编码） | **否** |
| `fly` · 未选中 | 速度积分 | `(yaw, pitch)` 自由欧拉 | 是（±89°） |
| `fly` · 已选中物体 | `focus + sphericalOffset(radius, φ, θ)` | **`lookAt(focus)`**（硬编码） | **否** |

### 2.2 根因清单

| # | 根因 | 代码证据 | 用户观感 |
|---|---|---|---|
| **R1** | **orbit 的视线被聚焦点锁死**：`lookAtTarget(camera, s.target)` 每帧覆写朝向，且球坐标上限 `maxPolar = 1.54 rad (88.2°) < π/2` ⇒ 相机**永远在 target 之上** ⇒ 视线恒指向下（最平也只到 −1.8°） | `FreeViewControls.tsx:447` `lookAtTarget`；`:440` `clamp(…, maxPolar ?? 1.545)`；`VirtualCityCityMap.tsx:601` 传 `maxPolar={ORBIT_MAX_POLAR_ANGLE /* 1.54 */}` | 俯瞰怎么拖都是俯视，看不到天 |
| **R2** | **fly-选中态的视线被 focus 锁死**：同上，`lookAt(focus)` 每帧覆写 | `FreeViewControls.tsx:518-519` | 点选任何物体后立刻失去抬头能力（最常见的触发路径） |
| **R3** | **唯一能抬头的 fly-未选中态不是默认**：默认模式 `orbit`（`freeViewStore.ts:58` fallback `{ mode: 'orbit' }`，且 localStorage 持久化） | `freeViewStore.ts:58` | 玩家绝大多数时间处于不可抬头态 |
| **R4** | **orbit 的右键被平移占用**：无任何输入通道留给「视线」 | `FreeViewControls.tsx:921-925`（orbit 分支 `d.button === 2` → `panOrbit`） | 想抬头只能靠切模式，路径断裂 |
| **R5** | **φ 越不出水平线**：即便把 `maxPolar` 放到 > π/2，相机也要沉到地面以下才能形成向上视线 —— 与 `groundY` 钳制（`FREE_VIEW_GROUND_Y = 0.25`）**直接冲突** | `cameraCollision.ts:111-114` 地面钳制 | 「抬头」与「不穿地」二选一，无法同时满足 |
| **R6** | 玩家**无法感知**当前仰角 | HUD 只有模式/速度/碰撞三态（`FreeViewHud.tsx`） | 修复后也难自证「现在能抬头了」 |

### 2.3 结论

> **「抬头」不是「把 `maxPolar` 调大」能解决的**（R5：相机必须低于锚点 → 穿地）。
> 正确解法是**把「相机位置」与「视线方向」解耦**：
> 位置仍由各模式的锚定/积分机制决定（保持碰撞、边界、地面钳制、贴地行走等既有语义零回归），
> **视线 = 基朝向（锚点朝向 / 自由欧拉） + 一个独立的俯仰偏移 `lookPitch`**。
> 抬头时相机**不移动**，因此不触碰地面钳制、不穿楼、不出界 —— R5 自然消解。

## 3. 总体方案

### 3.1 核心不变式

```
                 ┌─ 位置求解器（既有，零改动语义）─────────────────┐
输入 ──► 目标量 ─┤   orbit : target + spherical(r, φ, θ)            │
                 │   fly   : 速度积分 / focus + spherical(r, φ, θ)  │
                 └─────────────────────────────────────────────────┘
                                   │ 相机位置（碰撞 / 边界 / 地面钳制）
                                   ▼
                 ┌─ 视线求解器（本批新增）─────────────────────────┐
                 │   基朝向 base = lookAt(anchor) | (yaw, pitch)   │
                 │   视线 = base ∘ 绕相机局部 +X 旋转 lookPitch     │
                 └─────────────────────────────────────────────────┘
                                   ▼
                             camera.quaternion
```

**`lookPitch` 语义**：绕**相机右向量**（局部 +X）的正向旋转 = **抬头**（右手定则，
`forward = (0,0,-1)` 绕 +X 转 `a` 后为 `(0, sin a, −cos a)` ⇒ 仰角 +a）。

| 模式 | 基朝向 `base` | `lookPitch` 是否生效 |
|---|---|---|
| `orbit` | `lookAt(target)` | **是** |
| `fly` · 选中 | `lookAt(focus)` | **是** |
| `fly` · 未选中 | `(yaw, pitch)` 自由欧拉 | 否（该模式的 pitch 本身即自由视线） |

### 3.2 视线解算的数学（三处共用，`cameraMath.ts` 纯函数）

1. **基朝向求视线**：`forward₀ = (0,0,−1)` 经 `base` 变换。
2. **叠加抬头**：绕右向量 `k = base · (1,0,0)`（世界系）作 Rodrigues 旋转
   （`k ⟂ forward₀` ⇒ 末项 `k(k·v)(1−cos a)` 为零）：
   `forward = forward₀·cos a + (k × forward₀)·sin a`。
3. **视线 → (yaw, pitch)**（供 WASD 复用既有 `inputVelocity`）：
   `pitch = asin(clamp(forward.y))`，`yaw = atan2(−forward.x, −forward.z)`
   （与 three YXZ 欧拉约定一致：`forward = (−sinY·cosP, sinP, −cosY·cosP)`）。

> **WASD 跟随真实视线**：批次 36 起 WASD 是「沿视线位移」；抬头后 W 必须沿**抬起的**视线走，
> 否则「抬头看天 + 向前走」会互相打架。故 WASD 的基向量由**相机实际世界方向**反解，
> 而非由 `θ/φ` 解析推导（后者不含 `lookPitch`）。

### 3.3 输入通道重映射（统一「左=轨道 · 中=平移 · 右=视线」）

| 模式 | 左键拖 | 中键拖 | 右键拖 | 滚轮 |
|---|---|---|---|---|
| `orbit` | 绕 target 公转（`θ` 水平 / `φ` 垂直） | **平移 target**（← 从右键迁移） | **视线**：水平 = 转身（`θ`）／垂直 = **抬头**（`lookPitch`） | 缩放视距（`radius`） |
| `fly` · 未选中 | *（不劫持，留给点选）* | 视口平移（朝向不变） | **视线**：`yaw` / `pitch`（既有） | 变焦（FOV） |
| `fly` · 选中 | **绕 focus 公转**（`θ` / `φ`，本批新增） | 视口平移 | **视线**：水平 = 绕 focus 转身（`θ`）／垂直 = **抬头**（`lookPitch`） | dolly（半径） |

**为什么这样切**：

- **右=视线**是 3D 交互的通用约定（右键拖拽转视角），也让「抬头」在**所有**模式都有固定入口；
- **中=平移**与 fly 既有语义完全一致（fly 中拖即视口平移），orbit 的平移只是从右键迁到中键；
- **左=轨道**保留 orbit 的既有肌肉记忆（左拖公转），并把 fly-选中态原本由右键垂直承担的
  `φ` 环绕能力**平移到左键**，避免功能倒退（`lookPitch` 接管右键垂直后，`φ` 需有处可去）。

> **兼容性说明**：orbit 的「右键平移」→「中键平移」是一次**键位迁移**（非删除）。
> HUD 键位帮助表与本批文档同步更新（§6）。

### 3.4 限位表（本批新增项加粗）

| 项 | 缺省 | 虚拟城市传值 | 说明 |
|----|------|------------|------|
| `lookPitchLimit`（**新**） | **1.40 rad（80.2°）** | 同缺省 | 抬头上限。orbit 默认 `φ=0.85`（基仰角 −41°）⇒ 满抬头后视线仰角 **+39°**（正对天空上部）；`φ→1.54`（基仰角 −1.8°）⇒ 满抬头 **+78°**（近天顶） |
| `lookPitchMin`（**新**） | **−0.35 rad（−20°）** | 同缺省 | 允许比基朝向再低一点（低头看地面近处），与 `φ` 轨道俯仰互补 |
| `minPolar` / `maxPolar` | `0.02 / 1.545` | `0.02 / 1.54` | **不变**（R5：φ 不得越 π/2，相机永在锚点之上，永不穿地） |
| `pitchLimit`（fly-未选中） | `±1.553`（89°） | 同 | **不变** |
| `radius` / `minDistance` / `maxDistance` | `2 / 100` | `7.2 / 42 / 180` | **不变** |

### 3.5 状态与生命周期

| 事件 | `lookPitch` 行为 |
|---|---|
| 拖拽右键上下 | `lookPitchGoal` 按 `rotateSpeed` 增减，钳制到 `[lookPitchMin, lookPitchLimit]`；`lookPitch` 以 `LAMBDA_ROT` 指数阻尼跟随（帧率无关） |
| `R`（复位视角） | `lookPitchGoal = 0`（随复位过渡平滑归零）；**顺带修掉既有缺陷**：`beginTransition` 的「从相机位姿播种」只在**跨模式**时执行 —— 原实现连 `R`（同模式复位）也播种，导致 fly 模式的复位是空操作 |
| `C`（新增：视线归正） | 锚定类模式：`lookPitchGoal = 0`（**不**动位置，只回正视线）；自由飞行模式：`pitchGoal = 0`（把地平线摆平）。**不动位置** |
| 模式切换 `→ fly` | `lookPitch` 归零并**烘焙进** `yaw/pitch`（`beginTransition` 已用相机四元数反解 yaw/pitch ⇒ 视觉连续，无跳变） |
| 模式切换 `→ orbit` | `lookPitch` **保留**；`poseFromGoals` 的目标四元数 = `lookAt(targetGoal) ∘ lookPitch` ⇒ 切回俯瞰时保留抬头姿态 |
| fly 选中态 ↔ 未选中态 | 选中态下 `s.yaw/s.pitch` 由**最终**四元数（含 `lookPitch`）反解 ⇒ 取消选中后自由飞行继承抬头姿态；未选中态**不**叠加 `lookPitch` ⇒ **无双重叠加** |

### 3.6 与碰撞 / 边界 / 地面钳制的关系

**抬头不移动相机** ⇒ 碰撞推出、地图边界（`FREE_VIEW_BOUNDS`）、地面钳制（`FREE_VIEW_GROUND_Y`）
全部零影响。反之，位置移动（WASD / 公转 / dolly）依旧走既有钳制链。**零回归保证**。

## 7. 风险与回归控制

### 7.1 风险

| 风险 | 缓解 |
|---|---|
| 抬头后 `WASD` 沿视线走 ⇒ 抬头时 W 会「爬升」，可能误以为是漂移 | 符合 FPS 直觉（批次 36 已确立「沿视线位移」语义）；`Space/E/Q` 仍提供纯垂直升降 |
| fly-选中态左拖公转与「左键点选物体」手势冲突 | 沿用批次 32 既有解法：位移 > `DRAG_THRESHOLD_PX`(4) 判定为拖拽 ⇒ 捕获阶段吞掉紧随的 `click` ⇒ **纯点击（不拖）仍正常选中** |
| `lookPitch` 与 `yaw/pitch` 双重叠加导致视角跳变 | §3.5 逐事件定义 + 单测锚定「fly 自由态不叠加 `lookPitch`」 |
| 引擎层新增实时量污染 React 渲染 | 独立 `freeViewRuntime` 单例（非 zustand），HUD 轮询读取 |

### 7.2 回归点（逐条 CDP 验收）

| # | 回归点 | 判据 |
|---|---|---|
| G1 | orbit 左拖公转（`θ`/`φ`） | 拖拽后 `phiGoal` 变化、相机位置随之变化、**视线仍看向 target**（未抬头时） |
| G2 | orbit 中拖平移 | target 平移，相机跟随 |
| G3 | orbit 右拖上下 → 抬头 | `lookPitch` 增大；`camera.quaternion` 的视线仰角由 −41° → 转正 → 正值 |
| G4 | orbit 右拖水平 → 转身 | `θ` 变化，视线方位随之变化 |
| G5 | fly-未选中 右拖 → yaw/pitch | 与批次 32 行为一致（`yawGoal/pitchGoal` 变化），且 **pitch 仍可达 ±89°** |
| G6 | fly-选中 左拖 → 绕 focus 公转 | `θ`/`φ` 变化，相机绕 focus 移动 |
| G7 | fly-选中 右拖上下 → 抬头 | 视线仰角转正（**本批核心修复**） |
| G8 | `C` 键 → 视线归正 | `lookPitchGoal → 0`，视线回到基朝向 |
| G9 | `R` 复位 | 位置 + 视线一并回位 |
| G10 | 模式切换 orbit ⇄ fly | 600 ms 过渡无跳变（首帧与末帧视角连续） |
| G11 | 左键点选物体 | 未拖拽的点击仍能选中（吞 click 逻辑不误伤） |
| G12 | 地面钳制 | 抬头时相机高度不变；贴地行走时 `camera.y ≥ FREE_VIEW_GROUND_Y` |
