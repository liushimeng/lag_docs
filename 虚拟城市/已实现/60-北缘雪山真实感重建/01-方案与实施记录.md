## 1. 真实形态调研（§27.0-1）

以北京周边中山（小五台/海坨，海拔 1500~2500 m、相对高差 200~500 m，
与本资产前端 scale 6~10 × 基准 25 m = 150~250 m 视觉高差同量级）与阿尔卑斯
山前带为参照：

| 真实规律 | 旧资产违背点 | 本批处理 |
|---|---|---|
| 山形是**不规则脊线**：主峰 + 侧峰 + 刃脊，山坳为侵蚀沟槽，绝非圆锥 | 8 棱圆锥 + 1 个小肩锥，剪影几何感重 | 高度场多峰叠加（主峰 2.5u + 侧峰 1.55u + 丘 1.05u，高斯 σ 错落）+ 双八度值噪声 |
| 垂直带谱按**海拔 + 噪声**渐变：山脚针叶林 → 林线以上草甸/裸岩 → 雪线以上积雪 | 三段材质**硬水平环带**（GreenBelt 截锥套），雪线是一条直线 | 逐面按 `hn + 噪声` 分带：林/草/岩/雪四区，雪线与林线均锯齿破碎 |
| 雪线**破碎**：迎风脊棱雪薄见岩、沟槽雪厚（雪檐/冰斗），雪不盖陡崖 | 雪顶是独立锥套，与山体无空间关系 | 雪区判据含坡度门（`slope > 1.7` 出露岩石）+ 脊棱因子（局部高点雪薄） |
| 基座有**裙坡/倒石锥**：山体底部比中腰宽，与自然地面过渡 | 锥体直落地，与地表硬切 | 径向裙坡函数：r>0.95 高度平滑衰减至 0，足迹半径 1.5u（≥ 中腰 1.0u） |
| 远景山是** darkest 自然面**：针叶林冠远看深墨绿近黑 | 山腰用街区行道树亮绿 `#4a7a3f`，跳到前景 | 新增调色板 `forest_alpine #2c4030`（比 `needle_pine` 更暗冷） |

色板新增一族（`__common__.py::CITY_PALETTE` §自然地物·雪山）：
`snow_cap #eef2f5` / `rock_alpine #6f757d` / `forest_alpine #2c4030` /
`meadow_alpine #55663c`——雪/岩/高山植被是「自然地物语义」，不复用建筑/街具族。

## 2. 方案

### 2.1 几何（确定性，禁随机）

- 高度场网格：65×65 顶点（4225 点 / 8192 四边面），域 x,z ∈ [−1.5, 1.5]，
  面法线逐面计算（flat shading，低多边形风格化但与旧资产一致）。
- 高度函数（世界单位，u = 0.1，基准高 2.5u = 25 m，与旧契约一致）：
  `h(x,z) = Σᵢ Aᵢ·exp(−dᵢ²/2σᵢ²) × skirt(r) × (1 + 0.16·n1 + 0.06·n2)`
  - 主峰 (−0.05, 0.02, A=2.50, σ=0.52)、侧峰 (−0.62, 0.30, 1.55, 0.40)、
    丘 (0.55, −0.48, 1.05, 0.36)；`skirt(r)=1 (r≤0.95)` 平滑衰减至 `0 (r=1.5)`；
  - `n1/n2` = 双八度值噪声（整数格点哈希 + smoothstep 插值，固定种子），
    振幅随高度缩放（山体上段扰动相对更大，脊线破碎感）。
- 顶点归一化：`max(h) = 2.5u`（前端 scale 契约不动）。

### 2.2 分带（逐四边面，四网格节点）

按面心 `hn = h/2.5`、归一化坡度 `slope`、噪声采样：

| 区 | 判据 | 调色板 | 节点/材质名 |
|---|---|---|---|
| 雪 Snow | `hn > 0.80 + 0.10·n1` 或（`hn > 0.66 + 0.14·n2` 且 `slope ≤ 1.7` 且非脊棱） | snow_cap（rough 0.55） | `SnowMt_Snow` |
| 岩 Rock | 未判雪且 `hn > 0.44 + 0.13·n2`，或脊棱，或**山麓带**（面心 r>0.98，裸岩倒石锥接地） | rock_alpine（rough 0.97） | `SnowMt_Rock` |
| 草甸 Meadow | 其余且 `hn > 0.38` | meadow_alpine（rough 0.95） | `SnowMt_Meadow` |
| 林 Forest | 其余 | forest_alpine（rough 0.92） | `SnowMt_Forest` |

- 脊棱因子：面心为 3×3 邻域局部最高且高出 >0.10 → 判岩（刃脊见岩）。
- 节点/材质命名遵守 [[glb-material-name-must-match-node]] 约定：
  节点 `SnowMt_*` ↔ 材质 `SnowMt_*_Mat`（apply_pbr 自动派生），
  与 pine_tree（`PineTree_Bark` ↔ `PineTree_Bark_Mat`）同规。
- 无 UV、无贴图：材质仅 baseColorFactor，实测 268 KB，远低于 500 KB 上限
  （法线主导；旧资产 8.5 KB 但形状不可用——质量优先）。

### 2.3 契约不变量

- 世界 bbox ≈ 3.0 宽 × 2.5 高 × 3.0 深（旧 2.8×2.5×2.8，略宽 7% 系裙坡，
  `NorthMountains.tsx` 布点间隔 ≥12u 不受影响）；`minY=0` 贴地、X/Z 居中。
- `NorthMountains.tsx` **零改动**：7 实例 × scale 6~10 的脊线错落布局是
  批次 26 验收过的（远山层次正依赖多 scale 混合），本批只换资产本体。
- 旧程序化 fallback（`ProceduralMountains` 三段锥）保留语义不动——它只在
  `disable-blender-models=1` 或 GLB 加载失败时兜底。

### 2.4 显式不做的

- 不动山脚针叶树带（pine_tree ×60 是独立资产，属另一物体）。
- 不加雪顶粒子/云雾（AtmosphereLayer 是独立层）。
- 不重建批次 26 的坐标带/布点契约。

## 5. 验收 tooling 教训（已沉淀 [[cdp-visual-verification-workflow]]）

- **noon-guard 配方**：探针就绪后挂 `setInterval(30ms)` 循环
  `setCityClockAnchor(NOON, Date.now(), 0)` + `setCityEnv(season,'clear',0)`，
  压住 WS game.state 每帧重锚的时钟污染——比「注入→等 rAF→校验」轮询可靠一个
  数量级（轮询方案在 WS 高频重锚下 40 轮全耗尽）。
- **收敛判据要用 useFrame 写过的量**：时钟 `sample().timeOfDay01` 只证明锚在，
  不证明 uniforms 已更新（rAF 回调序不稳定，可能读到注入后、useFrame 前的窗口）。
  判据用 `__cityScene.background.g`（DayNightCycle 逐帧写的天穹色）：
  昼穹 #aeb8c6 g≈0.72、秋晴正午实测 g≈0.44~0.47、夜 #16294a g≈0.16 —
  阈值 g>0.35 且 tod≈0.5。
- 资产类改动（GLB）**必须 rebuild 后再做 in-game CDP 验收**——dev server 从
  `ServerGo/static` embed 产物出资产，改 `ClientWeb/src/assets` 不重建则游戏里
  还是旧 contenthash 资产（本批首验即此坑：游戏里仍是批次 26 旧雪山）。

|---|---|
| 面数 ×10（70 → ~8k tris）×7 实例 | 同屏 +5.6 万 tris，对 tris 预算（约 120 万）无感；DC 不变（3 节点 ×7 实例合并由 GlbInstanced 保证） |
