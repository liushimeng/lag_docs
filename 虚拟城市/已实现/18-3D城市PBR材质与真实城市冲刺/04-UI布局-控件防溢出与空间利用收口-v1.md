## 2. 底部动作条折叠（阶段 AB-1）

### 2.1 交互

| 状态 | 形态 |
|---|---|
| 展开（默认） | 现状整条 `.wealth-actionbar`；右上角 24×24「⌄」toggle |
| 折叠 | 同位 32px 高 pill「📋 行动」，点击展开 |
| 持久化 | `localStorage['wealth.ui.actionbar']` = `'0'`（折叠）/ 缺省展开 |
| 观战者 | 本就不渲染 `ActionPanel`（`WealthGamePage` 已有 `!spectator` 门控），不受影响 |

### 2.2 结构（`ActionPanel.tsx` 顶部）

```tsx
const [expanded, setExpanded] = useState<boolean>(
  () => localStorage.getItem('wealth.ui.actionbar') !== '0');
// 根 class 追加 wealth-actionbar--collapsed
// expanded === false → 只渲染 <button className="wealth-actionbar__pill">
```

- 折叠态**必须保留**月结倒计时的最短提示（把 `MonthTicker` 的进度条本就在下方，
  不重复渲染——pill 只是入口，不含状态）。
- `aria-expanded={expanded}`；pill 的 `aria-label` 复用 `wealth.tab.finance` 之外的
  **既有** i18n 键（本批不新增 i18n 键，用 `title="📋"` 亦可）。

### 2.3 CSS（`wealth-city3d.css` 链尾追加）

```css
.wealth-actionbar { position: relative; }
.wealth-actionbar--collapsed { padding: 0; min-height: 0; border: none; background: none; }
.wealth-actionbar__toggle {
  position: absolute; top: 4px; right: 6px; z-index: 42;
  width: 24px; height: 24px; border-radius: 6px;
  background: rgba(10,14,20,0.72); color: #dfe5ec; border: 1px solid #3a414c;
}
.wealth-actionbar__pill {
  height: 32px; padding: 0 12px; border-radius: 16px;
  background: rgba(10,14,20,0.85); color: #dfe5ec;
  border: 1px solid #3a414c; font-size: 12.5px;
  display: inline-flex; align-items: center; gap: 4px;
}
```

对比度：`#dfe5ec` 对 `rgba(10,14,20,.85)` 合成底 ≈ 12:1（§26.1 ≥4.5:1 ✓）。
**§26.3 三件套自检**：JSX 类名 `wealth-actionbar__toggle` / `__pill` / `--collapsed`
写完立即 `grep -rn "wealth-actionbar__" ClientWeb/src/styles/`，零命中即 P1 缺陷。

## 3. 弹层高度统一（阶段 AB-2）

## 4. 图表与横向溢出（阶段 AB-3）

| 项 | 规则 |
|---|---|
| `FundFlowSankeyPanel` SVG | 根 SVG 加 `viewBox="0 0 <w> <h>"` + CSS `width: 100%; height: auto; max-width: 100%;`；外层 `.wealth-sankey-scroll { overflow-x: auto; min-width: 0; }` |
| `LorenzCurvePanel` SVG | 同上 |
| 任何 `grid-template-columns` 里的固定列 | 追加 `minmax(0, <N>fr)` 参与收缩（现有 `130px 1fr` / `42px 1fr 46px` / `1fr auto auto` 三处，`1fr` → `minmax(0, 1fr)`） |
| `MonthTicker.__events` | 父行补 `min-width: 0`（`.wealth-ticker__countdown` 已有）；`.wealth-ticker__events` 保持 `overflow-x: auto` |

**全局溢出断言**（验收脚本 / 手动 Console）：

```js
document.documentElement.scrollWidth <= window.innerWidth
// + 可视区内所有 .wealth-modal / .wealth-sidebar / .wealth-topbar 的
//   getBoundingClientRect().right <= window.innerWidth
```

## 7. 验收清单

1. **动作条**：1280×800 展开 → 折叠，地图可视高度增加 ≥ 120px；刷新后保持折叠态；再点 pill 恢复。
2. **弹层 6 类**：逐个打开 → 内容超长时内滚、头部/底部按钮可见、右上关闭可点、**不超出视口**。
3. **图表**：侧栏 380px 与 300px 两档下，桑基图 / 洛伦兹曲线不横向溢出（可滚动查看全宽）。
4. **溢出**：1280×800 / 1920×1080 / DevTools 375px 三档 `scrollWidth <= innerWidth`。
5. **重叠**：小地图（z40）不遮城区 hover 卡（z30）、不被 error banner（z50）盖住、不与动作条 pill 重叠。
6. **留白**：任一竖向连续空白区块 < 25vh（waiting / 空态 / 加载态三处重点测）。
7. **死规则**：`grep -n ":global(" ClientWeb/src/styles/wealth.css` **零命中**。
8. **§26.3 三件套**：`grep -rn "wealth-actionbar__\|wealth-modal__" ClientWeb/src/styles/` 命中 ≥ 8 行。
9. `npx tsc --noEmit` + `npm run build` 通过。
