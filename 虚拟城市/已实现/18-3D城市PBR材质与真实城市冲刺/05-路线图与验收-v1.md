## 2. 编译门禁

| 命令 | 要求 |
|---|---|
| `cd ClientWeb && npx tsc --noEmit` | 0 error |
| `cd ClientWeb && npm run build` | 成功 |
| **`ls ClientWeb/dist/assets/ \| grep -c -- '_n-'`** | **≥ 76**（实测 76/81）—— 防 `import.meta.glob('./pbr/**/*.png')` 静默失配（失配只得到空对象，PBR 会被无声关闭且构建照样成功）。源端 81 = 法线张数（facades 32 + roofs 16 + streets 6 + ground 4 + districts 16 + synth 7）；被 Vite `assetsInlineLimit`（默认 4096 字节）内联为 base64 的小法线（≤4KB）进入 JS bundle 而**不**出现在 `dist/assets/`，故 dist 实测数可能略小于源端数。**重要**：`grep -c` 数到 0 才算真正的 glob 失配；差几帧属预期 |
| `cd ServerGo && go build ./... && go test ./...` | 通过（本批预期零改动，跑通即行） |
| `python3 3d_script/procedural_pbr_maps.py --force` 重跑两次 | `md5sum` 全量一致（已实测：facades 64 张 md5 全等、synth 13 张 md5 全等） |

## 4. 视觉验收方法（沿用 16 批次实证流程）

> 依据项目记忆 `cdp-visual-verification-workflow`：tsc/build 全绿 ≠ 画面正确。

1. **WebGL 入口**：GoWebDebugTool 的无头 Chrome（:29011）**无 WebGL**；须复制 conf 设
   `remote_debug_url: http://127.0.0.1:9222` 指向常驻 Chrome（SwiftShader WebGL2）另起实例。
2. **登录注入**：`POST /api/captcha`（SVG `<text>` 直读）→ `/api/auth/login` 拿 JWT →
   写 `localStorage['lsm.auth']`（zustand persist 格式）+ `lsm.token` → reload。
   JWT 7200s 过期，长验收中途重登。
3. **建城**：走大厅「+ 创建城市」新建房间（同账号重复 `game.spectate` 报 30001 且地图不挂载）。
4. **截图窗口**：只信 **T+0 ~ T+90s**（SwiftShader 长寿命 RT / 画布合成在 ~2 分钟后退化）。
5. **像素采样定位**：`PIL` 采截图像素与雾色/云白/材质色比对；页面里挂
   `window.__cityDebug = { scene, camera }`（**必须在 Canvas 内组件的 useEffect 里挂**，
   Canvas 外 `useThree` 直接崩）可直读相机/雾/env 真值。
6. **软件渲染器**：EnvBinder 已按 `swiftshader|software|llvmpipe` 跳过 PMREM——
   验收时**幕墙反射项按「真机才验」标注**，不因软件渲染无反射判失败。
7. **相机缩放**：CDP 合成滚轮对 OrbitControls 无效；要改视角就改 `CAMERA_START` 常量重构建。

## 6. 已知边界

- 幕墙 / 车窗的环境反射在 SwiftShader 软件渲染下不出现（PMREM 被跳过），真机 GPU 正常。
- 建筑构造件是**低多边形刚体**，不含倒角/圆角；近景到 1 单位以内仍可见硬棱。
- 行人是 3 关节刚体摆臂，非骨骼动画；快速转视角时肢体有轻微「翻面」感（可接受）。
- 外围农田是纯色块 + 草地法线，不是作物几何。
- 轻轨列车静止停靠，无进出站动画（城市「有设施」优先于「有调度」）。
- 路口信号灯是静态灯组（不做红绿灯循环相位——那属于交通系统专项）。
- 单文件若逼近 1800 行（`building_shapes.tsx` 现 515 行 + 构造件），按 CLAUDE.md §4
  拆 `building_details.tsx`（同目录、纯搬移、re-export 保持签名）。
