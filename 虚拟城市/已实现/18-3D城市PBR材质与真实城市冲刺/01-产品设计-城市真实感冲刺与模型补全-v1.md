> 2026-09-23。前置：13/14/15/16 四轮 3D 优化已交付（体块形态 / 共享贴图 / 街景家具 /
> 环路桥梁 / 地标云层 / 软件渲染器 PMREM 跳过）。
> 契约文档：02 架构设计 / 03 资产方案 / 04 UI 布局 / 05 路线图。
> 目标一句话：**从「城市有骨架」迈向「城市像真的」**——
> 让每一块表面有凹凸与光泽差（PBR），让每一栋楼有可辨构造（女儿墙 / 门厅 / 锯齿屋顶），
> 让街道上的人和车不再是色块，并把一座真实城市必备的生产与公共设施补齐到地图上。

## 2. 产品目标（可感知的 10 条）

1. **表面会呼吸**：贴近地面看沥青有颗粒凹凸；侧看楼体窗洞内凹、窗框凸起；水面有细波光斑。
2. **楼有构造**：楼顶一圈女儿墙；每栋楼底层有门厅（门 + 小雨棚）；阳台线四面可见。
3. **厂房是厂房**：锯齿屋顶（北向采光带）取代人字顶，一眼可辨工业建筑。
4. **人会走**：行人有头/躯干/双臂/双腿，走路摆臂摆腿（`prefers-reduced-motion` 下静止站立）。
5. **车有表情**：车窗反光、车灯亮起、轮毂可辨，20 辆车各有形态。
6. **港口在作业**：物流港有岸吊 + 集装箱堆 + 系缆桩，不再是空水面。
7. **城市在运转**：教育园区有 400m 跑道操场；北部有高架轻轨与车站；医疗城有直升机坪；街区有加油站。
8. **城市有生命线**：变电站 / 水塔 / 通讯塔 / 消防站 / 警局 / 市政厅各就各位。
9. **城市有腹地**：建成区之外是农田、丘陵、环城高速与风机——城市坐落在一片土地上，不再漂浮在虚空。
10. **界面不添乱**：底部动作条可折叠；弹窗/抽屉/图表一律不溢出、不重叠、不留大片空白。

## 3. 功能规格（按用户可感知点）

### 3.1 PBR 材质系统（阶段 X · PBR）

| 项 | 规格 |
|---|---|
| 贴图 | 每种材质 3 张：颜色（既有）+ **法线**（凹凸）+ **粗糙度**（光泽）。共 161 张新 PNG，由 `3d_script/procedural_pbr_maps.py` 程序化生成（确定性、重跑字节一致） |
| 对齐 | 法线/粗糙度**从既有颜色贴图求高度场派生**（窗暗→内凹、砖缝→凹陷），与颜色图天然像素对齐，零错位风险 |
| 覆盖面 | 立面 / 屋顶 / 路面 / 人行道 / 地面 / 草地 / 广场 / 城区底板 / 水面 / 砖 / 混凝土 / 压型钢板 / 瓦 / 树冠 = **14 类材质全接线** |
| 水面 | 双层滚动法线（`pbr/synth/water_n.png`），两层不同速率 `offset` 漂移 → 细波交错；`prefers-reduced-motion` 静止 |
| 降级 | 任意法线/粗糙度缺失 → 该材质保持现状（纯色/单贴图），**不报错、不闪黑** |
| 显存预算 | 法线半分辨率、粗糙度 1/4 分辨率 + 灰度 PNG → 新增 ≈ 9.2 MB 磁盘 / ≈ 24 MB 显存（原贴图 35 MB） |

### 3.5 渲染调校（阶段 X 附带）

| 项 | 现值 | 新值 | 理由 |
|---|---|---|---|
| 阴影边缘 | PCFSoft 无 radius | `shadow-radius={4}` + `shadow-blurSamples=8` | 法线细节上来后硬边阴影会「抢戏」 |
| 材质 roughness | 硬编码常量 | 有 `roughnessMap` 时 **乘子 1.0**（由贴图全权决定） | 窗滑墙糙靠贴图表达 |
| 材质 metalness | 0.05–0.6 | 保持常量（不引入 metalnessMap） | 现有 emissive/envMap 已够，避免第三张贴图 |
| 曝光 | 1.05 | 1.0 | 法线后明暗层次变多，略压曝光防高光溢出 |
| `envMapIntensity` | 立面 0.5 / crown 0.9 | 不变 | 16 批次已调校 |

## 5. 验收体感标准

### 5.1 视觉验收

1. 低角度看主干道：沥青有颗粒凹凸，掠射角下车道线边缘清晰。
2. 侧看金融城塔楼：窗洞内凹、窗框凸起（转动相机时明暗随法线变化）。
3. 任一楼栋屋顶边缘有一圈女儿墙；底层可见门厅（玻璃门 + 小雨棚）。
4. 阳台线四面可见（转到任意朝向都有横向层线）。
5. 厂房为锯齿屋顶（北向采光带），不是人字顶。
6. 近景行人有头/躯干/四肢，行走时摆臂摆腿。
7. 车辆有反光车窗、亮起的大灯与尾灯、可辨轮毂。
8. 物流港可见岸吊与集装箱堆；教育园区可见赭红跑道；北部可见高架轻轨与车站。

## 8. 硬约束

- 单文件 ≤ 1800 行（CLAUDE.md §4）；Markdown ≤ 800 行（§3）
- 纯前端 + `3d_script/`，**ServerGo/ 零改动**
- 确定性伪随机（`hashStr` + `mulberry32`），**禁 `Math.random`**——刷新布局稳定
- 同源贴图走 `textureCache.ts`；禁组件自建 `TextureLoader`

- 降级链完整：任何 PBR 贴图缺失 → 保持现状材质，不报错
- `prefers-reduced-motion` 全局兼容（水波 / 摆肢 / 风机 / 游船 / 车辆）
- 所有新 helper / 字段 / 组件 **grep 验证接线**（CLAUDE.md §130）
- 材质类名 / CSS 类写完立即 `grep -rn "<新class前缀>" ClientWeb/src/styles/`（§20260808-02）
- `styles/globals.css` 的 `@import` 顺序不可调整（§2.1 约束 4）——新样式只追加进 `wealth-city3d.css` 链尾
