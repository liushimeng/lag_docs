## 2. 关键实现口径

- **计数器接线点**：`TradesMade`/`TradeRealizedCNY` = listing.go dealAsset/dealBuy + auction.go finalizeAuction；`AuctionsJoined` = auction.go 英式有效出价/荷兰成交/密封出价 3 处；`BiasHits` = bias.go `biasEffectMulOf` m≠1 分支（**偏离设计**：设计说 applyBias detected 分支，但 applyBias 被展示路径每次 game.state 重建调用会灌水 ⇒ 改经济应用唯一漏斗）；`LoanMaxCNY`/`CreditMin` = calibration.go 月结采样（审计同节拍）。
- **R-B4 基线表实测初值**（2026-10-22 gate 千局 365,283 模拟月逐事件统计）：loan 0.11 / bias 4.42 / bankruptcy 2.08 / market 1.39（每百月）；trade/auction 实测恒 0 ⇒ 基线 0 跳过不判（防除零）。
- **MCOverride 生效点**：InitialCashMul = NewWorld 后 StartGame 前缩放 Cash+Savings（Ledger 注入同比例）；StockBoomMonthly = market.go MonthStep 繁荣相位「覆盖值优先于 const」；RecessionMinMonths = RerollPhase 衰退期下限 clamp。`MCRunOneWith(seed, strategy, nil)` ≡ MCRunOne 逐字段相等（T-AB1 双策略钉死）。
- **χ² 算例勘误**：设计 §8.3 原写「a=30/100 vs b=18/100 ⇒ χ²≈3.23, p≈0.0726」系笔误，真实无 Yates 校正值 χ²=3.9474 / p≈0.0470，方案文档已更正，测试断言真实数学值。

## 5. 破产快照修正（主 Agent 验收打回项 → 已修复）

初版分类器用**终局状态**判 NEG 侧，但清算会清掉贷款/资产 ⇒ gate 千局实测 NEG-1/2/4 恒 0、undetermined 89–99%（工具失效）。修正：

- `settlement.go::liquidate` 开头 `captureBankruptSnapshot(p)`（破产事件记录后、清偿/重组/清资产**之前**采样）；二次破产不改写首因上下文。
- 修正后 20 局 aggressive_leverage 抽样（240 座）：**NEG-4=201、undetermined=29（12%）**、NEG-1/2/3 各 2–3，单测断言 undetermined <60% 钉死。

**随之的校准发现（供批次 74 §5.4 决策树，B72-1 主战场）**：破产座债务月供均值 ¥834 vs 非债务生活支出 ¥15,271——当前引擎破产由**现金断流（NEG-4，占已分类成因 86%）**驱动，「高杠杆月供压垮」在该经济基线下几乎不构成破产成因；杠杆策略出局（G11 89%）是首付抽干现金而非月供。⇒ 批次 74 决策树主线应为 **NEG-4 流动性枯竭**（对应原文「加长 T1–T4 交易窗口频次 / 降首付门槛」分支），辅以 O5 成对对照验证。
