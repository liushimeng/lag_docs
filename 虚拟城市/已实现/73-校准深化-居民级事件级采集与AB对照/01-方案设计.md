## 3. 通用纪律（全部新增代码）

1. **零 rand**：新增计数器/采集器/分类器/统计工具绝不调用 `w.Rand` 或任何随机源（批次 72 §3.1-1 同一纪律；策略同种子双跑逐字段一致必须保持）。
2. **零账目语义改动**：采集是纯旁路观测；不改 `ApplyAction` / `SettleMonth` / Ledger 的任何现有语义（批次 71 审计纪律）。
3. **零 panic、零阻断**：落盘失败 zap warn（`calibration_runs.go` 同款）；MC harness 采集失败静默降级为 `undetermined` / 空聚合。
4. **确定性覆盖生效**：`MCOverride` 只允许改常量类参数（见 §7.2），禁止向世界注入新 rand 消费；`MCRunOneWith(seed, strategy, nil)` 与 `MCRunOne(seed, strategy)` 逐字段相等（T-AB2 钉死）。

## 6. O3 结局成因 8 类分类器（§4.4）

新文件 `mc_cause.go`。对**每座位**输出单主因，规则按 §4.4 判定依据实现为确定性优先级：

```
良好结局（Good，winner/affluent）：
  POS-1  passive_income ≥ expense 且 FI ≥ 1          （FIRE 正解，最先判）
  POS-4  被动收入中合伙/分红/副业占比 > 50%
  POS-2  已实现价差盈利 > 净资产增量的 50%           （需 O1 价差追踪）
  POS-3  其余良好结局                                 （兜底归为周期/择时，文档标注此兜底口径）
不良结局（出局/破产）——**破产座用「破产发生时刻快照」判定**（清算扣减前采样，快照字段见 `mc_cause.go`/`player.go` Bankrupt*；终局态贷款/资产已被清算清掉，用期末状态判会全落空）：
  NEG-1  破产月贷款月供 > 非债务支出 × 1.5               （高杠杆爆仓，最先判）
         ⚠ 口径裁决（2026-10-22）：字面规则「月供 > 总支出×1.5」是恒假式——
         引擎月结总支出已含月供自身（settlement.go 步骤6）。比较基准改为
         非债务支出 = 总支出 − 月供（下限 0）；快照字段仍存总支出原值。
  NEG-2  破产快照：单一品类占净资产 > 50% 且回撤 > 50%  （单一资产崩盘；回撤=1−市值/买入成本）
  NEG-4  破产快照：非现金资产 > 0 且现金 < 非债务支出   （流动性枯竭，被迫折价）
  NEG-3  破产快照：BiasHits > 0                          （偏差致损，最后判）
未破产的不良结局（意外身故等）⇒ 期末状态回退判一遍再 undetermined；   
中立/未终局/unclassified：
  undetermined                                        （兜底 + 计数，绝不空白）
```

- 价差盈利（POS-2 输入）：`Player.TradeRealizedCNY` 累计器（成交结算处分买卖记已实现盈亏，零 rand）；无成交 ⇒ 0。
- 优先级固定（良好：1→4→2→3；不良：1→2→4→3），单测逐条钉死边界与互斥。
- 聚合：`RunRecord.OutcomeCauses map[string]int`（含 `undetermined` 桶）。

## 8. O5 A/B 成对对照（§6.3）

### 8.1 统计工具 `ab_stats.go`（纯函数，零依赖）

| 函数 | 口径 |
|------|------|
| `ChiSquareTwoProp(aYes, aN, bYes, bN int) (chi2, p float64)` | 2×2 列联表 χ²（无 Yates 校正，与 §6.3「两比例用卡方检验」字面一致）；χ²₁ 精确 p = `erfc(√(x/2))`（标准库 `math.Erfc`，无需自写 CDF） |
| `WelchTTest(a, b []float64) (t, df, p float64)` | Welch–Satterthwaite 自由度；t 分布双侧 p 经**不完全贝塔函数** `I_x(df/2, 1/2)` 计算（~60 行 continued fraction，参考 Numerical Recipes `betai`）；n<2 / 方差皆 0 ⇒ p=1 不 panic |

### 8.2 参数覆盖与配对 harness `mc_ab.go`

```go
// MCOverride 单参数覆盖(全部指针,nil = 引擎默认)。只允许常量类参数,
// 禁止触碰 rand 序列(纪律 §3-1/§3-4)。
type MCOverride struct {
    InitialCashMul   *float64 // §6.2 行2:初始现金 ±20%
    StockBoomMonthly *float64 // §6.2 行1:股票景气期月收益率(现 +10%)
    RecessionMinMonths *int   // §6.2 行3:衰退期最短持续月数(现 2–4 年)
}
func MCRunOneWith(seed int64, strategy string, ov *MCOverride) MCRunStats
func MCCompare(strategy string, base, variant MCOverride, n int) ABReport
```

- `MCOverride` 生效点：初始现金在世界构建后按乘数缩放（`StartGame` 前，零 rand）；股票景气收益/衰退月数挂到市场相位参数的应用点（backend-dev 定位具体 const 消费处，做「覆盖值优先于 const」的最小侵入读取）。
- `MCCompare`：同策略、同种子带（`MCSeedFor` 前 n 个）双侧各跑 n 局 ⇒ 配对样本；主指标 **D5 破产率**（χ²）与 **D6 品类年化均值**（Welch，取 stock 品类）；护栏 D2（任一侧 >7 倍或 <2 倍 ⇒ 报告标 `guard_breach` 不判胜负）；`n<20` 出报告但标 `underpowered`（§6.3 最小样本 20）。
- `ABReport`：{strategy, n, base/variant 的 D5/D6 均值, Δ, chi2/p, t/df/p, guard_breach, underpowered, verdict(`significant_better`/`significant_worse`/`no_difference`/`guard_breach`)}，JSON tags，供批次 74 调参决策与报告落盘。

### 8.3 测试

- 已知值：χ² 经典算例（a=30/100 vs b=18/100 ⇒ χ²≈3.947、p≈0.0470，无 Yates 校正）；Welch 用解析锚点钉死（df=2 闭式 p=1−|t|/√(2+t²)、I_x(1,1)=x、I_x(½,½)=2/π·asin√x）。
- T-AB1 覆盖语义：nil override ≡ 默认（逐字段相等）；T-AB2 配对确定性；T-AB3 `InitialCashMul=1.2` ⇒ D5 不降（单调方向）；T-AB4 n=0/1 边界。
