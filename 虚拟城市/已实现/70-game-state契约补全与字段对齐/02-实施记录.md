## 5. 实现取舍

| 取舍 | 选择 | 理由 |
|---|---|---|
| **A 类修哪一侧** | **改前端**（后端 tag 为真值） | 后端 tag 语义无歧义（`wealth_pct` / `wealth_score` / `lpr_5y`），且已被其它文档与口径引用；改后端会制造新的分叉面 |
| **枚举对齐方式** | **改键**（`takeIt` → `dutch`），**不做语义映射** | `dutch`（荷兰式逐月降价）与 `take_it`（二手一口价）语义不同 ⇒ 映射会把历史语义说错 |
| **挂单簿私密字段的实现** | `omitempty` + `viewer` 过滤 ⇒ 非卖家帧内**键都不存在** | 比「发 0 值」更安全：发 0 会被前端误读成「底价 0 元」；不发键则前端 `undefined` 明确表示「不可见」 |
| **密封拍卖出价** | 进行中下发**空数组**（不是 `null`、不是省略键） | 前端 `bids.length` / `.map` 不炸；且「有字段但为空」与「字段缺失」语义可区分 |
| **明斯基三字段的来源** | **同帧从 `minsky_overview` 赋值**，不另算 | 单一事实来源，避免两处口径漂移（代价：`cycle.ponzi_ratio` 与 `minsky_overview.ponzi_ratio` 同形不同源 ⇒ 已登记 L4） |
| **提前还款资格是否含预算** | **不含** | 预算是本回合临时额度，不该让入口整月消失；动作仍由 `actEarlyRepay` 拒绝 |
| **感知富形状是否回流推理** | **不回流** | 只进 `game.state` 视图层 ⇒ 零 Agent 行为变更（零回归优先于信息完整） |
| **感知 `people[].seat`** | 视图层另立 `SenseNeighborBrief`（`seat` 不带 omitempty） | `vctypes.NeighborBrief.Seat` 的 `omitempty` 会把 **0 号座位**吃掉 ⇒ 前端拿不到座位号 |
| **类型文件拆分** | 拆 `virtualCityStages.ts` + `export *` | 外部 import 路径不变 ⇒ **零迁移债**；`virtualCity.ts` 回到 1797 行 |
| **空数组 vs null** | 全部数组恒 `[]` | 前端 `.map` / `.length` 的 P0 纪律；且避免 store 残留上一局旧数据 |
