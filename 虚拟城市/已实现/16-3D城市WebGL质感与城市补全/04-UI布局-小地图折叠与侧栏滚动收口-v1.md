## 2. 小地图折叠（阶段 V-1）

### 2.1 交互

- 展开态：现状不变（左上角 160×160 附近）；右上角 24×24「⤫」toggle。
- 折叠态：同位置 pill 按钮「🗺 地图」（高 32，含文字），点击展开。
- 持久化：`localStorage['wealth.ui.minimap']` = `'0'`（折叠）/ 缺省展开。
- 默认：**展开**（不改变新用户第一眼体验）。

### 2.2 结构（WealthMinimap.tsx 内部）

```tsx
const [expanded, setExpanded] = useState<boolean>(() =>
  localStorage.getItem('wealth.ui.minimap') !== '0');
```

- `expanded === false` → 渲染 `<button className="wealth-minimap__pill">`；
- `true` → 现有画布 + `<button className="wealth-minimap__close">⤫</button>`。
- 组件根 class 追加 `wealth-minimap--collapsed` 控制定位盒。

### 2.3 CSS（wealth-city3d.css 追加）

```css
.wealth-minimap__close {
  position: absolute; top: 4px; right: 4px; z-index: 42;
  width: 24px; height: 24px; border-radius: 6px;
  background: rgba(10,14,20,0.72); color: #dfe5ec; border: 1px solid #3a414c;
}
.wealth-minimap__pill {
  height: 32px; padding: 0 10px; border-radius: 16px;
  background: rgba(10,14,20,0.85); color: #dfe5ec;
  border: 1px solid #3a414c; font-size: 12.5px;
}
```

对比度：#dfe5ec 对 rgba(10,14,20,.85) 合成底 ≈ 12:1（§26.1 ≥4.5:1 ✓）。

## 3. 侧栏滚动收口（阶段 V-2）

### 3.1 flex 收缩链

三层都要 `min-height: 0`（缺一层即溢出）：

```css
.wealth-main  { min-height: 0; }   /* 若 grid 则 1fr 行内收 */
.wealth-sidebar { min-height: 0; }
.wealth-sidebar__panels {
  flex: 1 1 auto;
  min-height: 160px;
  overflow-y: auto;
}
```

- tabs 区保持 `flex: 0 0 auto`（常显，不参与滚动）。
- CityStatsPanel / BotPanel / ChatPanel 位于 panels 区**之后**：改为包进一个
  `.wealth-sidebar__aux`（同样 `overflow-y:auto; flex:0 1 auto; min-height:96px`）？
  ——**不**。15 轮把 stats/bot/chat 放 panels 区外是因为三者自带折叠；本轮
  维持外置，但给 `aside.wealth-sidebar` 整体 `overflow-y: auto` 作兜底 +
  panels 区自身滚动。双层滚动只激活一层（内容不超时不出现滚动条）。

### 3.2 验收断言

1. 1280×800 / 1920×1080 两档下：tabs 与「💰 聊天」标题始终可见。
2. panels 区滚动条独立，不带动地图区。
3. 无水平溢出（`document.documentElement.scrollWidth <= innerWidth`）。
