- 确定性 seed = FNV-1a(文件名)，重跑产物字节一致。

## 3. 贴图规格

### 3.1 sky/cloud_puff.png（256×128 RGBA）

- 背景 alpha 0。
- 5–8 个白色（250–255）椭圆 random 布点（中心密集、边缘稀疏），每椭圆
  alpha 60–140 叠加；整体 GaussianBlur(6)。
- 底部 15% 做 alpha 渐隐（云底平感）。
- 消费端：Billboard transparent，alphaTest 0.01；材质 opacity 0.85。

### 3.2 ground/urban_base.png（512×512 RGB 可平铺）

- 基色 #3a3f47（中性偏暖灰，介于沥青与混凝土之间）。
- 噪点：±6 亮度 per-pixel 噪声 + 12 处大块淡色补丁（alpha 0.06，模拟修补路面）。
- 四边 32px 镜像混合保证可平铺（与 grass_tile 同法——实现时参考既有
  `_make_tileable` 逻辑复用）。
- 语义：城市「建成区底色」，城区底板 / 道路 / 广场全部压在其上。

## 4. 技术否决记录：`facades/<id>_emit.png` 发光窗贴图

**结论：不做。**

- 16 城区立面现有 2 种来源：AI 生成（老 8 区，finance 等为等距角视构图）
  + 程序化窗格（新 8 区）。AI 图窗位不可程序对齐 → emit 贴图必然错位。
- 运行时 canvas 亮度阈值派生 emit：等距图上「窗/墙」亮度关系不稳定（finance
  玻璃偏暗、edu 窗格偏亮），阈值误判率不可控。
- 现状 emissiveMap=facade 在 ≤0.35 强度下已读作窗体微光；升级收益 < 错位风险。
- 若未来引入昼/夜切换专项，可按「程序化立面全量重绘 + 同源窗位导出」重启此方案。
