## 2. EnvBinder（阶段 R）

### 2.1 文件

`components/wealth/EnvBinder.tsx`（新，~70 行）。

### 2.2 实现

```tsx
import { useEffect } from 'react';
import { useThree } from '@react-three/fiber';
import * as THREE from 'three';
import { Sky } from '@react-three/drei';

/** 与 WealthCityMap.SKY_SUN_POSITION 同源（避免跨文件循环 import，本组件自持常量）。 */
const SKY_SUN: [number, number, number] = [51.6, 82.6, 41.3];

export function EnvBinder() {
  const scene = useThree((s) => s.scene);
  const gl = useThree((s) => s.gl);
  useEffect(() => {
    let disposed = false;
    try {
      const sky = new Sky();
      sky.scale.setScalar(1000);
      const mat = sky.material as THREE.ShaderMaterial;
      mat.uniforms.sunPosition.value = new THREE.Vector3(...SKY_SUN);
      mat.uniforms.turbidity.value = 6;
      mat.uniforms.rayleigh.value = 1.2;
      const pmrem = new THREE.PMREMGenerator(gl);
      const env = pmrem.fromScene(sky, 0.04);
      if (!disposed) scene.environment = env.texture;
      // 离屏 sky 场景与 pmrem 立即释放（env.texture 归 scene 所有）
      pmrem.dispose();
      sky.geometry.dispose();
      mat.dispose();
      return () => {
        disposed = true;
        scene.environment = null;
        env.dispose();
      };
    } catch {
      return () => { scene.environment = null; };  // WebGL 上下文异常时静默降级
    }
  }, [scene, gl]);
  return null;
}
```

要点：
- **一次性生成**（frames=1 语义），无每帧开销；`fromScene(sky, 0.04)` 第二参 sigma 轻微模糊。
- 旧 three Sky 构造在 effect 内 new（不进 React 树），与 `<Sky />` 主天空视觉一致（同 uniforms）。
- 材质侧只改 `envMapIntensity`（见 §3），three 自动把 `scene.environment` 接到所有 PBR 材质。

### 3.2 楼宇色相分化（building_shapes.tsx）

```ts
/** 确定性楼宇色差：占地 (w,d) hash → 0.92~1.08 明度乘子（不引随机源，同楼同色）。 */
export function buildingTint(w: number, d: number): string {
  let h = Math.imul((w * 4096) | 0, 2654435761) ^ Math.imul((d * 4096) | 0, 2246822519);
  h = (h ^ (h >>> 13)) >>> 0;
  const k = 0.92 + ((h % 1000) / 1000) * 0.16; // 0.92..1.08
  const c = Math.round(255 * k);
  return `rgb(${c},${c},${c})`;
}
```

`BoxFaces` 侧材质 `color`：贴图存在时 = `buildingTint(w,d)`（原 `#ffffff`）；
贴图缺失时 fallback 主色不变（分化只作用于有贴图路径，避免双重变色）。


```
const RING_WIDTH = 1.0;
const RING_Y = 0.017;         // 主干道 0.015 之上，交叉处不 z-fight
```

- 每段：`planeGeometry([RING_WIDTH, segLen])`，rotation [-π/2,0,0] + 朝心旋转。

  组成虚线环。
- 交叉停止线：放射 main 干道与环相交角度 = 该城区 `angleToFinance`；在
  半径 RING_RADIUS 处、道路外侧半幅画白条（≤ 12 处）。
  实现：RingRoad 接收 `junctionAngles: number[]`（WealthCityMap 用
  `WEALTH_DISTRICTS` 计算 len>12 城区的 atan2 角传入）。

位置计算（WealthCityMap 内）：

```
for d of [edu_district, medical_city]:
  c = districtCenter(d.id); t = c.z / (c.z - 0) 处 z=17 → 比例 t = 17/c.z
  x = c.x * (1 - t);  z = 17;  rotation = atan2(-c.x, -c.z)
```

> 通式（避免硬编码）：对每条 len>12 放射路，解与 z=17 交点，|x|≤32 即建桥。
> 当前数据恰好命中 edu/medical 两条。

## 7. 双向车道（阶段 S）

### 7.1 Vehicle laneOffset

```ts
interface Props { ...; /** 行进方向右侧偏移（世界单位）：>0 右行。默认 0 = 中线。 */ laneOffset?: number; }
// useFrame 定位段（offset = 行进方向右侧 r = (-dz, dx)/len 取反）：
g.position.x = px + (dz / len) * off;
g.position.z = pz + (-dx / len) * off;
```

> **双向同正值原则**：offset 定义为「行进方向右侧」，from/to 反转后同一正值
> 自动落到世界另一侧 → 两方向各占一侧车道。若对向传负值会落回同侧（对撞）。
> bus/truck offset 0.36，sedan/taxi 0.32。

### 7.2 编排（StreetPropsLayer::vehiclesForRoads 重构）

- 每条 main 干道：正向 1 辆（district→origin，laneOffset 0.32/0.36）。
- len > 15 的 main 干道：追加反向 1 辆（origin→district，**同样正值**，variant 错开）。
- 产量：12 main → 正 12 + 反 ~8 = 20 辆（原 12），mesh +~64，预算内。
