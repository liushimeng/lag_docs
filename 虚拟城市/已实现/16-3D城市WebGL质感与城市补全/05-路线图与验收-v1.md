## 3. 功能验收清单

### 3.1 渲染质感（R）

- [ ] 旋转相机时金融城幕墙高光随视角移动（env 生效）。
- [ ] 背光面楼体可辨细节（填充光生效，非死黑）。
- [ ] 低角度看主干道，车道虚线边缘清晰（anisotropy 生效）。
- [ ] 同城区相邻同贴图楼深浅有别（分化生效）；刷新后布局不变（确定性）。
- [ ] 地面为中性城市底色（非满城沥青）；urban_base 缺失时回退沥青不报错。

### 3.2 路网骨架（S）

- [ ] 环路闭合无断缝，与 ≥6 条放射路相交；交点无 z-fighting 闪烁。
- [ ] 运河 2 桥：桥面高于水面、栏杆在位、车辆通过不沉水。
- [ ] 同一主干道对向 2 车并行，均不压中线。
- [ ] 环路交点可见停止线（≤12 处）。

### 3.3 功能地标（T）

- [ ] 中央公园：喷泉（+水花）居中，十字园路贯穿，4 组花坛。
- [ ] 文创区东南角：围挡 + 塔吊（臂/钩/操作室可辨）。
- [ ] 商业中心东北角：划线停车场 + 3 静态车。
- [ ] 郊区/老城屋顶：≥2 块太阳能板（确定性布点）。

### 3.4 天空（U）

- [ ] ≥4 团云漂移，出界回绕无跳变；reduced-motion 静止。
- [ ] cloud_puff 缺失时白雾球兜底（删文件验证一次后恢复）。

### 3.5 UI（V）

- [ ] 小地图可折叠成 pill，刷新保持；展开恢复。
- [ ] 1280×800：tabs 常显、panels 独立滚动、聊天入口可见、无水平溢出。
- [ ] 全控件不重叠不出界。

### 3.6 性能（W）

- [ ] mesh 总数 ≤ 3000（估算 ~1160）。
- [ ] PMREM 只建 1 次（React StrictMode 双 effect 下 dispose 幂等）。
- [ ] 1080p 中端 GPU ≥ 45fps。

## 6. 视觉验收回归实录（2026-09-22，Chrome CDP + SwiftShader 软件渲染）

验收中发现「页面运行数十秒后整城泛白」三级根因，全部修复并回归：

| 轮 | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 贴图材质全城过曝 | Sky PMREM 直挂 `scene.environment`（默认强度 1.0） | `scene.environmentIntensity = 0.35`（r163+） |
| 2 | 俯瞰/最大缩放全城盖白 | 云层（初始 y=14-20，后 26-34）低于最大缩放相机高度 45，插进视线；opacity 0.85 × 3-4 层叠加近不透明 | 云抬到 y=60-80（相机全程下方）+ opacity 0.35 |
| 3 | 软件渲染器下运行 2 分钟后画面退化泛灰白 | SwiftShader 长寿命 PMREM RT 失效（运行时 `scene.environment = null` 实验即恢复暗色，证实）；另见画布合成降级 | EnvBinder 检测 `swiftshader/llvmpipe/software` 直接跳过 PMREM（真机 GPU 正常启用） |

> 附带结论：雾 100/200（0.85×/1.9× 亦同）在任何缩放下对城市主体雾感 ≤20%，
> 非泛白根因（像素采样亮度超过雾色上限，数学排除）；CDP 合成滚轮对
> OrbitControls 缩放无效（相机距离探针证实），此前「滚动后泛白」实为
> 运行时长相同时段的软件渲染退化。

验收证据：新建城市 T+0 全功能渲染正确（16 色城区 / 环路 / 运河 2 桥 /
天际线剪影 / 街灯 / 车流），tsc + build + go build 全绿。
