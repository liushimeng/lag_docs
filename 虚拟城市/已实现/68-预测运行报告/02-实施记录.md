## 2. 关键实现取舍（相对方案的偏离）

1. **`satisfaction` 现算**：`CivicElection` 无 `Satisfaction` 存储项——按 `ComputeVotes` 既有公式 `100−gini×100+SentimentBias`（clamp 0..100）从既有字段现算，Election nil → 0。零平行账本。
2. **`house_idx` 全区均值**：`DistrictDefs` 已扩至 32 区（非方案写的八区），按 >0 项全区均值，与 `scenario.go` 房价冲击同口径。
3. **`pyramid_shift` 补取数**：报告 §4 需要金字塔位移，`PredictionIndicators` 追加 `Pyramid [4]int`（取自既有 `SocietySnapshot.Pyramid`）。
4. **外推聚焦**：3 视野 × 4 核心指标（unemployment / goods_price_idx / stock_index / gini_wealth）共 12 条；`first_month_impact`/`peak_recovery` 只收有偏离的指标。
5. **35058 口径**：显式 `?run_id=` 不存在即 35058；缺省查询无 run 返回 `runs:[] report:null`（不报错）。
6. **前端不渲染 transmission/distribution 两节**（类型已完整对齐，后端有数据，后续可加节）；状态行数据源 = `GET /prediction` 的 `runs[]`。
