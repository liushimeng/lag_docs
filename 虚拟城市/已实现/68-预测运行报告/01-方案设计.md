## 1. 批次背景与缺口

《推演设计》§5.1 定义了预测运行五步：

```
① 基线快照 → ② 条件注入 → ③ N 月演化 → ④ 指标对比 → ⑤ 预测报告
```

| 步骤 | 2026-10-21 前状态 | 本批次 |
|---|---|---|
| ① 基线快照 | **无代码** | ✅ T0 平直基线（注入时点观测快照） |
| ② 条件注入 | ✅ `scenario.go`（2026-10-21 §场景推演） | 无改动（只接线） |
| ③ N 月演化 | ✅ `scenarioMonthStep` 逐月演化 | 无改动（只接线） |
| ④ 指标对比 | **无代码** | ✅ 偏离序列 + 峰值/谷值/恢复月（±5% 带） |
| ⑤ 预测报告 | **无代码** | ✅ 结构化 JSON + R1 边界声明 |

本批次把「注入 → 观测 → 对比 → 报告」闭环成**一条可复用的预测运行链路**：
注入场景时自动开启 run、逐月记录指标点、按需生成结构化预测报告，前端与观察者可读。

## 2. 复现层级裁决（先于一切实现）

《推演设计》§1.3 定义 R0/R1/R2 三层可复现性；本批次在实现前裁决如下：

| 层级 | 定义 | 本批次 |
|---|---|---|
| **R0 同种子孪生** | 同基线/同种子反事实对照运行，决策缓存重放，逐位一致 | **不做**（居民 LLM 决策缓存不存在；World 全量 fork + 离线推进风险高） |
| **R1 观测对照** | 基线 = 注入时点(T0)观测快照（平直基线）；对比 = 实际轨迹 − 基线 | **✅ 本批次交付** |
| R2 方向性 | 只谈方向不给数 | 兜底（数据不足时报告自动降级标注） |

**裁决理由**：R0 依赖《推演设计》§5.2 的「决策重放缓存」（`key = (seed, resident_id, month, prompt_hash)`）——该缓存**当前不存在**，且 World 全量 fork + 离线推进的工程风险高。因此本批次的对照基线取**注入时点的观测值**（平直基线，非反事实孪生轨迹），报告元数据与「边界与限制」章节**显式声明 R1**：

- 对照基线为注入时点观测值而非反事实孪生轨迹；
- 含 LLM 居民决策噪声；
- 结论用于情景分析与教学，不作现实决策唯一依据。

报告元数据恒标 `tier: "R1"`；R0 落地（决策缓存 + 同种子孪生）留待后续批次，届时报告方可升级 `tier`。

## 3. 数据口径（指标事实来源）

`PredictionIndicators`（逐月一个点，T0 也记一点）——**全部既有字段，不引入平行账本**：

| 字段 | 来源 | 说明 |
|---|---|---|
| `month` | `w.Month` | 主钟月份 |
| `goods_price_idx` | `Goods.Items[*].PriceIdx` 按 `goodsWeights` 加权均值 | 消费篮子价格水平 |
| `cpi_ann` | `w.CB.CPI`（年化小数；CB 为 nil 记 0） | 内生通胀 |
| `unemployment` | `w.Labor.Unemployment`（nil 记 0.05） | 失业率 |
| `stock_index` | `w.Market.StockIndex` | 股指 |
| `gold_price` | `w.Market.GoldPrice` | 黄金 |
| `house_idx` | `w.Market.DistrictIdx` 八区均值 | 房价指数 |
| `treasury_cash` | `w.Treasury.Cash`（nil 记 0） | 国库 |
| `avg_resident_cash` | 存活玩家现金均值 | 居民现金 |
| `gini_wealth` | `SocietySnapshot.GiniWealth`（最新） | 财富基尼 |
| `gini_income` | `SocietySnapshot.GiniIncome` | 收入基尼 |
| `top10_pct` / `bottom50_pct` | `SocietySnapshot.Top10Pct/Bottom50Pct` | 分布 |
| `satisfaction` | `w.Election.Satisfaction`（nil 记 0） | 社会满意度 |
| `bubble_leverage` | `w.BubbleLeverage` | 杠杆率 |

**确定性**：纯算术取数，**零 rand 消费**（固定种子存量模拟回归零偏移，与 scenario/exogenous 同款契约）。

## 4. 运行生命周期

- **启动**：`applyScenarioToWorld` 注入时，若无 active run → 先拍 `Baseline`（T0 指标点，**在冲击生效之前**）再生效冲击；run `ID = "PR"+seq`（`World.PredictionSeq` 自增，与 `ScenarioSeq` 同款）。
- **active 定义**：`w.Month - StartMonth < predictionHorizonMonths(=24)`；期间新注入**并入**当前 run（记 `Injections []string`）。
- **逐月记录**：SettleMonth 内、`scenarioMonthStep` 与 `SocietyHist.Push`（④.6B）**之后**调用 `w.predictionMonthStep()`，向 active run 追加当月指标点（`predictionTrajectoryCap=36`，超出滚动丢最旧）。
- **环形容量**：`World.PredictionRuns []*PredictionRun` 保留最近 3 个（run 结束 = 超出 horizon 后被新 run 挤出）。
- **零接口面变化**：不改 `ScenarioAppliedRecord` / 注入响应形状。

## 5. 预测报告结构与生成规则

`PredictionReport`（全部 JSON snake_case；数值小数保留 6 位内，金额整数元）——**前后端共同遵守的契约**：

```jsonc
{
  "meta": {
    "run_id": "PR1", "tier": "R1", "baseline_snapshot_id": "b-<hex16>",
    "seed": 12345, "start_month": 40, "months_observed": 12,
    "generated_at": 1730000000000,
    "injections": [ /* ScenarioAppliedRecord 子集: id/kind/magnitude/applied_month/note */ ]
  },
  "scenarios": [ { "kind": "earthquake", "name": "地震", "group": "自然灾害",
                   "magnitude": 3, "duration_months": 6, "target": "", "note": "",
                   "applied_month": 40, "decay": "线性衰减(remaining/total)" } ],
  "first_month_impact": [ { "metric": "unemployment", "baseline": 0.05, "value": 0.062,
                            "delta_pct": 24.0, "unit": "ratio", "text": "失业率 +24.0%" } ],
  "trajectory": [ { "month": 40, "values": { "unemployment": 0.05, "stock_index": 3.5, "...": 0 },
                    "baseline": { "unemployment": 0.05, "stock_index": 3.5, "...": 0 } } ],
  "peak_recovery": [ { "metric": "unemployment", "peak_dev_pct": 24.0, "peak_month": 41,
                       "trough_dev_pct": -2.0, "trough_month": 48,
                       "recovery_month": 52, "recovered": true } ],   // ±5% 带内视为恢复
  "transmission": { "chains": [ { "chain": "⑥资产→③就业→④消费",
                                  "contribution": 0.52, "dominant": true,
                                  "evidence": "失业率偏离峰值 +24%、消费篮子 +3%" } ],
                    "note": "贡献度按各链路代表指标的 |偏离| 归一启发式估计,非计量因果分解" },
  "distribution": { "gini_wealth_delta": 0.012, "top10_delta_pct": 1.8,
                    "bottom50_delta_pct": -2.1, "pyramid_shift": [0, 0, 0, 0],
                    "text": "财富集中度上升,底层份额下降" },
  "extrapolation": [ { "horizon_months": 3, "metric": "unemployment",
                       "point": 0.052, "lo": 0.049, "hi": 0.058 },
                     { "horizon_months": 6, ... }, { "horizon_months": 12, ... } ],
  "resilience": { "applicable": true, "recovery_score": 62, "adaptation_score": 55,
                  "transform_score": 40, "basis": ["恢复:GDP/失业回正速度", "..."] },  // 仅灾害/未知灾难
  "boundaries": [ "R1 观测对照:基线为注入时点观测值,非同种子反事实孪生(R0 未实现)",
                  "含 LLM 居民决策噪声,复现层级 R1",
                  "未知域压力测试(meteorite/alien_invasion):不承诺预测精度",
                  "外推基于最近 3 月偏离斜率/几何半衰期拟合,置信带随视野线性放宽" ]
}
```

**生成规则**（全部确定性）：

1. `baseline_snapshot_id = fnv/hash`（基线点字段序列化）。
2. `first_month_impact` = T0+1 点 vs 基线；T0 即基线 ⇒ delta 0。
3. `peak_recovery`：逐指标找 |dev| 峰值月与反向谷值月；`recovery_month` = 偏离回落到基线 ±5% 且其后所有月保持在带内的首月；无 → `recovered:false, recovery_month:null`。
4. `extrapolation`：取最近 ≤3 个观测点的偏离序列——若 |dev| 单调收敛按几何半衰期外推，否则按线性斜率外推；`lo/hi` = point ± (1.5×近 3 月残差带 + 0.02×|point|×horizon/3)。
5. `transmission.chains`：静态表 kind→链路组（《推演设计》§4.2 传导表），`contribution` = 该链路代表指标 |dev_pct| 归一；`dominant` = 最大者。
6. `resilience.applicable` 仅 `group ∈ {自然灾害, 未知灾难}`；评分 = f(恢复速度、失业/物价是否脱钩恢复、长期水平位移)，∈ [0,100]。
7. `trajectory` 全量逐月点（≤36 月），前端可画双线（baseline 恒为 T0 值）。

> 报告章节与《推演设计》§5.3 的十章一一对应；本表是其**字段级契约**（§5.3 只定章节与必填性）。

## 6. API 契约

```
GET /api/games/virtual_city/rooms/:id/prediction            // 最新 run
GET /api/games/virtual_city/rooms/:id/prediction?run_id=PR2 // 指定 run
→ {code:0, data:{
     runs: [{id, start_month, months_observed, tier, injections:["SC1","SC2"]}],
     report: <PredictionReport> | null     // 该房无任何 run → runs:[] 且 report:null
  }}
```

- **权限**：任意登录用户（观察者/条件触发者同口径，AuthRequired）。
- **错误**：房间不存在 35001；run_id 不在该房 → `35058`（`ErrVirtualCityPredictionRunNotFound`）。
- **无 run 不报错** —— 返回 `runs:[]` 且 `report:null`（前端展示「暂无预测运行」）。
- 新错误码：`ErrVirtualCityPredictionRunNotFound = 35058`（`errcode/errcode.go` 35055–35057 之后，中文文案同步 DefaultMessages）。
- 路由注册位置：与 `virtual_city_scenario_api.go` 三端点同处（跟随现有 VirtualCityScenarioAPI 注入方式 `VirtualCityRoomSource`）。
- view 层增量：`game.state` 增加 `prediction` 小结（可空）：
  `{ "run_id": "PR1", "start_month": 40, "months_observed": 7, "tier": "R1", "active_scenarios": 1 }`。

## 8. 边界声明与限制

报告 `boundaries` 章节（必填）显式声明：

1. **R1 观测对照**：基线为注入时点观测值，非同种子反事实孪生（R0 未实现）。
2. **含 LLM 居民决策噪声**，复现层级 R1。
3. **未知域压力测试**（`meteorite` / `alien_invasion`）：不承诺预测精度（《推演设计》§2.4）。
4. **外推基于最近 3 月偏离斜率/几何半衰期拟合**，置信带随视野线性放宽。

其余边界沿用《推演设计》§9 风险清单（强度-响应未标定、复合场景归因难、外盘漂移污染、存量损伤不可逆等），本批次不重复展开。结论用于**情景分析与教学，不作现实决策唯一依据**（《推演设计》§1.2）。

## 9. 验收要点

- `go build ./...` + `go test ./...`；`tsc --noEmit` + `npm run build`。
