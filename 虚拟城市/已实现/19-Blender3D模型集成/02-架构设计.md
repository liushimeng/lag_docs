## 1. 三层数据流（与 §27.1 一致）

```
.blend（本地美术，不入库） → 3d_script/build_*.py（headless 导出脚本，入库）
  → ClientWeb/src/assets/models/{civic|vehicles|nature|characters|road}/*.glb（入库，≤500KB/个）
  → assets/models/index.ts import.meta.glob → modelUrl(category,name)
  → components/wealth/modelCache.ts useSharedGLTF(url)（缓存 key=url，每实例 scene.clone(true)）
  → Model.tsx <primitive/> → vite contenthash → rebuild rsync → ServerGo/static（embed）
```

## 3. 关键决策记录

1. **推翻 13 批次「不引入 GLTF 外部模型」非目标**：v19 以「保留原程序化几何为 fallback」
   （§27.3-3：`<Model url>{原几何}</Model>` 包裹 + `disable-blender-models` localStorage 强切）
   化解构建自包含与加载失败风险后引入 .glb；13:72 该条非目标自本批次起失效。
2. **体积控制**：单 .glb 15–64 KB（≤500 KB 硬线），DRACO/Meshopt 不启用（§27.6，gzip 后等效 4–20 KB）。
3. **缓存口径**：GLB 缓存 key 只用 url（贴图缓存需含 wrap/repeat 参数，GLB 无此维度）。
4. **Blender 版本锁定** 5.2.1 LTS（`/usr/local/bin/blender`）；脚本 headless 无头确定性输出。
5. **`.blend`/`.blend1` gitignore**（commit `05c0571d43`）：git 只入 `.py` + `.glb`，源工程留本地美术机。
