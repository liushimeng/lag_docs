## 1. 创建城市弹窗（`ClientWeb/src/components/wealth/WealthCreateRoomModal.tsx`）

### 1.1 字段总表

| # | 字段 | 控件 | 缺省 | 说明 |

| 4 | 模拟月节拍 | 预设 3000/8000/15000ms + 滑杆 3000–30000 | 8000 | 不变 |

### 1.3 提交载荷（新）

```jsonc
POST /api/games/wealth/rooms
{
  "name": "我的城市",
  "resident_count": 10000,          // 背景居民规模,clamp [10,100000]
  "wealth": { "month_ms": 8000, "seed": 42 },
  "full_agent": true
}
```

- **不再发送** `agent_seats` 与 `wealth.pool`（后端忽略 wealth 请求中的 `agent_seats`，见 03 §2）。
- `CreateRoomOptions`（`types/api.ts`）补声明 `full_agent?: boolean`（现状漏声明但实际在发，一并修正）。
- `WealthRoomOptions`（`types/wealth.ts:1072-1079`）删除 `pool` 字段。
