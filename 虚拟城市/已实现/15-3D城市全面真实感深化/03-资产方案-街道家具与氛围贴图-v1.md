## 2. AI 轨道生成规格

### 2.1 行人头部 sprite（256×256 透明）

每套 1 张，**3 视角兼容**（轻微偏左 + 正面 + 偏右混合，正面为主）：

#### head_business.png
- 主体：商务人士头像（西装领带感）
- 配色：深蓝西装（#2a4a6e）/ 白衬衫 / 肤色（#d9b48a 系）
- 简洁线条，**不要面部细节**（抽象化方块脸），保持低多边形感与 3D 场景融合
- 透明背景，头发深色（#2a2e36）

#### head_casual.png
- 主体：休闲 T 恤/卫衣
- 配色：浅灰（#7a7d82）/ 米白（#e5e2d4）
- 帽衫风格（连衣帽可见）

#### head_bright.png
- 主体：亮色外套
- 配色：红（#c8453a）/ 橙（#e08840）/ 黄（#e8b930）任选一种
- 运动感配色

#### head_khaki.png
- 主体：户外卡其
- 配色：卡其（#8a7a5a）/ 棕色（#6b4f32）
- 户外风格

### 2.2 报刊亭（vendor_kiosk.png，256×256 透明）

- 主体：报刊亭正面（玻璃窗 + 报刊架可见）
- 配色：木色（#6b4f3a）/ 红色顶棚（#c8453a）/ 蓝色招牌（#3a78c8）
- 玻璃窗显示报刊层叠效果
- 透明背景

### 2.3 停车牌（parking_sign.png，256×256 透明）

- 主体：白色停车牌（蓝边白底 + 字母 P）
- 配色：蓝色（#3a78c8）/ 白色（#ffffff）/ 灰色杆
- 透明背景

## 3. 程序化资产（无 AI 依赖）

### 3.1 `TreeV2` 不依赖贴图

V2 立体树冠由 3 层 sphere 叠加，**不需要 tree PNG**。V1 的 `props/tree/{variant}_tree.png` 仍可叠加做树叶 sprite 装饰。

### 3.2 6 种街道家具（不依赖贴图）

全部纯几何 + 颜色块，**不需要 PNG**：
- BicycleRack：圆轮 + 细车架
- TrashCan：圆柱 + 顶盖
- PhoneBooth：玻璃盒（BoxGeometry + 半透明材质）
- Mailbox：圆柱 + 投信口
- ParkingMeter：立柱 + 表盘（box）

## 4. AI 资产生成脚本（独立）

`python-generate-image-tool/generate_wealth_v2_props.py`（新）：

```python
"""
虚拟城市 V2 道具贴图生成器（15-3D城市全面真实感深化 · 阶段 M）
使用 python-generate-image-tool 的 LLM 图像生成 API

产物（6 张，写入 ../ClientWeb/src/assets/images/wealth/）：
  props/pedestrian/head_{business,casual,bright,khaki}.png
  props/vendor/vendor_kiosk.png
  props/sign/parking_sign.png

  - 256×256 透明 PNG
  - skip-if-exists（已存在不覆盖）

"""
```

> 若 AI 资产生成失败，组件降级到几何兜底，**不影响功能完整性**。

## 5. 代码接线

### 5.1 `ClientWeb/src/assets/images/wealth/index.ts` 扩展

```ts
export type PedestrianHeadName = 'head_business' | 'head_casual' | 'head_bright' | 'head_khaki';
export type VendorName = 'vendor_kiosk';
export type SignNameExt = 'parking_sign';

/** 行人头部 sprite URL（缺失 → null → 几何兜底） */
export function pedestrianHeadUrl(name: PedestrianHeadName): string {
  return propImgs[`./props/pedestrian/${name}.png`] ?? '';
}

/** 报刊亭 / 商铺贴图 URL */
export function vendorUrl(name: VendorName): string {
  return propImgs[`./props/vendor/${name}.png`] ?? '';
}

/** 扩展标识牌贴图 URL */
export function signUrlExt(name: SignNameExt): string {
  return propImgs[`./props/sign/${name}.png`] ?? '';
}
```

### 5.2 `import.meta.glob` 兼容

新增文件后自动被现有 `import.meta.glob<string>('./props/**/*.png', ...)` 捕获（pattern 含子目录）。

## 6. 验收

1. `python3 python-generate-image-tool/generate_wealth_v2_props.py` 产出 6 张 PNG（如 AI 可用）。
2. **失败也通过验收** —— 组件降级到几何，不影响 build。
3. `pedestrianHeadUrl('head_business')` 返回字符串（'' 表示缺图）。

6. `npm run build` 产物包含新 PNG（被 glob 打包）。

## 8. 不生成贴图的决定（rationale）

- **V2 树冠**：3 层 sphere 叠加足够立体，不再需要 sprite；避免和几何叠层导致 z-fighting。
- **V2 家具**：全部纯几何小件，几何感统一，更贴近 2.5D 抽象风格。
- **行人身体**：圆柱 + 颜色已能体现体积感，头部 sprite 解决面部辨识。
- **远景建筑剪影**：纯几何 plane + 灰度色块，shader-less。

> 资产总数控制在 6 张以内，避免拖累构建。
