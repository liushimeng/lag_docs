## 2. 方案

### 2.1 L1/L3：Tab 条改为「分组块」结构

**结构**：每个 `TabGroup` 是**一个独立块**，内部两行——
- 第 1 行：分组小标签（`数据` / `交易`），`font-size:11px`，`letter-spacing:0.08em`，深色；
- 第 2 行：该组的按钮，`flex-wrap: wrap`，每行最多 4 个（380px 侧栏 ÷ ~86px 按钮）。

```css
.virtualCity-tabs            { display:flex; gap:6px; padding:6px 8px 0; flex: 0 0 auto; }
.virtualCity-tabs__group     { display:flex; flex-direction:column; gap:2px; flex:1 1 0; min-width:0; }
.virtualCity-tabs__group-btns{ display:flex; flex-wrap:wrap; gap:2px 4px; }
.virtualCity-tabs__btn       { flex: 0 0 auto; }   /* 不再 flex:1 撑满（会溢出） */
```

- 分组块 `flex: 1 1 0; min-width: 0` ⇒ 两组平分宽度，**换行只发生在组内**，标签永远与自己的按钮同块。
- 批次 62 的 `flex: 0 0 auto` 防压扁**保留并合并**进 `.virtualCity-tabs`。
- **触达性**：每按钮保持 `--virtualCity-touch-target`（≥44px）高度；标签行不计入触达高度。

### 2.2 L2：侧栏弹性收口

- `.virtualCity-sidebar__panels` 保持 `flex: 1 1 auto; overflow-y: auto`（可滚动不溢出）。
- **新增「面板骨架最小占位」**：面板区内容不足时，用 `display:flex; flex-direction:column; gap:8px`
  让各 section 之间间距**固定且紧凑**，并把多余空间**收口到最后一项的下方**（不放大中间间隙）。
- **空态占位**：观战/无数据时，`BehaviorPanel` 空态显示**带说明的中性占位块**（图标 + 一行说明），
  而不是整块空白；占位块与面板其它 section 同宽度同内边距。
- **城市背景层（`CityStatsPanel`）与 Bot 面板（`VirtualCityBotPanel`）改为可折叠**
  （复用既有 `CollapsibleSection`），默认**展开**；窄侧栏/小视口下用户可收起。
  这样主面板区（Tab 内容）始终能拿到最大高度。

### 2.3 L4：底部区域收口

- 动作条 `.virtualCity-actionbar`：**消费档位 4 按钮与动作按钮分组之间加分隔线**，
  每组独立换行（已是 `flex-wrap`），并在组首加小标签行（`消费档位` / `动作`），
  让用户知道自己在哪一组，避免「两排按钮不知道区别」。
- **月度节拍条 + 事件流**：`.virtualCity-monthticker` 固定高度（进度条 + 一行摘要），
  事件流最多显示 **3 条**，超出走滚动；不再无限增高。
- 3D 视口因此稳定拿到 `100dvh − header − actionbar(固定) − ticker(固定)` 的高度。

### 2.4 L6：文本兜底

- 小指标卡统一 `min-width: 0; overflow-wrap: anywhere;`；
  金额用既有 `formatCny`（批次 62 已拆到 `types/virtualCityFormat.ts`）保证短格式；
  超长数字 `font-variant-numeric: tabular-nums`。

### 2.5 折叠/展开（用户明确要求）

- 所有侧栏 panel 的**可折叠 section 默认展开**；
- 折叠状态用既有 `localStorage` 键约定（`virtualCity.ui.<name>` = `'0'|'1'`），
  与 `ActionPanel` / `Minimap` 既有做法一致；
- 折叠后**只收起 section 主体、保留标题行**（标题行可点）。

## 4. 验收标准（可判定）

1. **Tab 条永不塌缩**：任意视口高度（≥640px）下 `.virtualCity-tabs` 的
   `scrollHeight === clientHeight`（无溢出），且每个分组标签与其按钮**同块**
   （DOM 上在同一 `.virtualCity-tabs__group` 内）。
2. **无控件重叠**：侧栏内 `getBoundingClientRect` 两两不相交（除有意叠层如 toggle）。
3. **无大片留白**：面板区「内容结束 → 最后一个 section 底部」的空白 ≤ 48px（或全部走滚动）。
4. **底部区域定高**：`actionbar + ticker` 合计 ≤ 220px，3D 视口拿到其余全部高度。
5. **折叠可用**：`CityStatsPanel` / `BotPanel` 折叠后主面板区高度增加，展开/收起状态持久化到 `localStorage`。
6. **文本不溢出**：小指标卡内任意金额/百分比不撑破容器（`scrollWidth <= clientWidth`）。
7. **对比度**：新增 UI 元素遵守 §26（正文 ≥4.5:1、徽章 ≥5:1、选中态 ≥6:1；禁用态不用 `opacity`）。
8. `cd ClientWeb && npx tsc --noEmit` + `npm run build` 通过。
9. **CDP 整页截图**：1680×940 与 1366×768 两种视口各一张，肉眼确认无溢出/重叠/大片留白。

## 5. 风险与兜底
