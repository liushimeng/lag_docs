### 5.1 相机驱动：解决了批次 43/44/45 遗留的 L2「近景相机不可控」

前几批用 `H.camera.position.set(...)` + `lookAt()` 注入，**每帧被 `FreeViewControls`
的 `update()` 覆写**，截图永远拍到默认全景。本批改为**驱动控制器自身的 rig 状态**：

```js
const r = window.__freeViewDebug._rig.current;
r.mode = 'orbit'; r.pendingMode = null; r.transitioning = false;
r.target.set(tx,ty,tz);  r.targetGoal.set(tx,ty,tz);
r.radius = dist;        r.radiusGoal  = dist;
r.phi    = phi;          r.phiGoal     = phi;
r.theta  = theta;        r.thetaGoal   = theta;
```

约定（THREE.Spherical）：`theta = atan2(offX, offZ)`、`phi = acos(offY/dist)`。
写完即可稳定停在该姿态，近景截图全部命中。另配合
`Page.captureScreenshot{clip:{x:208,y:100,w:757,h:635,scale:2}}` 只截 3D 视口、
绕开左右 UI 面板，2× 放大便于判读。

## 6. 本批抓到的 §130 缺陷（已修 + 加防回归）

**首版 `GasStation` 的加油机屏材质永远不会被调制。** 根因是同一语义的两个名字漂了：

| 位置 | 首版写的 |
|---|---|
| 节点名（`join_objects`） | `GasStation_PUMP_Screen` |
| 材质名（`make_material`） | `GasStation_PUMPScreen_Mat` ← **少了第二个下划线** |
| 前端 `litMaterials` 键 | `GasStation_PUMP_Screen`（`.includes()` 匹配材质名）⇒ 永不命中 |

只有 **CDP 数值审计**（读场景里 `emissiveIntensity`）查得出来 —— 单测、`tsc`、
Blender 导出、`verify_glb_aabb`、`crosscheck` 全部无感。

**两处修复**：
1. `build_gas_station.py` 的材质名改为 `GasStation_PUMP_Screen_Mat`，与节点名同源，
   并在脚本里写明「材质名必须与节点名同源（+`_Mat` 后缀）」。
2. **加可执行护栏**：`CivicGlbPiece` 在 dev 态遍历 GLB 材质，若某个 `litMaterials`
   键**未命中任何材质**即 `console.warn('[CivicGlb] xxx：litMaterials 键未命中任何 GLB
   材质（§130）')`。下次再漂，浏览器控制台直接报，而不是等 CDP。
