### 3.1 程序化 fallback 的处置（关键取舍）

§27.3 硬约束 7 要求「GLB ≡ 程序化 fallback 同尺寸」。但本批三件的现有 fallback
**在几何上与新设计差距过大**（变电站围栏 4×3 m vs 新 18×14 m），若强行同尺寸，
要么把 fallback 重写成完整的新几何（本批体量翻三倍），要么让 fallback 与 GLB 长期漂移。

**处置：按「改造量」分档。**

| 件 | fallback 处置 | 理由 |
|---|---|---|
| `Substation` | **重写** fallback 至新尺寸 | 现有 66 行、纯 box/cyl 合并，重写成本低；且 4×3 m 的围栏在新 GLB 旁是硬伤 |
| `GasStation` | **重写** fallback 至新尺寸 | 现有 88 行；罩棚/便利店/加油机结构本就存在，只需换常量 + 补件 |
| `HeliPad` | **保留** fallback 现状 | 现有几何（⌀28 圆坪 + H + 风向袋 + 边灯）**与新 GLB 同尺寸**，无需重写；只补材质槽与 GLB 接线 |

即：**三件都满足双路径包围盒一致**，其中 HeliPad 以「现状即合规」方式零改动对齐。

### 3.2 接线范式

复用批次 45 `civic/ParkExtras.tsx:154-191` 的 `useSharedGLTF + scene.clone(true)` 范式
（**不用** drei `<Model>`，因为要挂 `sizeTargetFor` 尺寸守卫）：

```tsx
const url = blenderModelsEnabled() ? modelUrl('civic', glbName) : '';
const sizeTarget = useMemo(() => sizeTargetFor(dimsKey, { label: `civic/${glbName}` }), [glbName]);
const { scene } = useSharedGLTF(url, sizeTarget);
const cloned = useMemo(() => (scene ? scene.clone(true) : null), [scene]);
// ↓渲染
{cloned ? <primitive object={cloned} /> : <mesh geometry={fallbackGeo}>…</mesh>}
```
