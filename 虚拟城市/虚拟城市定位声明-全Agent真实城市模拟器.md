## 1. 定位声明

「虚拟城市」**不是一款游戏**。它是一个**由人类 Agent（居民 Agent）组成的真实城市模拟器**：

1. **全 Agent 城市运行**：城市中的居民由大模型驱动的 Agent 扮演。每位居民 Agent 依据一张全息人生档案
   （75,115 张人物卡，Schema v1.1，65 字段：行业 / 收入 / 资产 / 负债 / 健康 / 情感 / 人格 / 家庭 /
   出生 / 人生经历 / 行为特征 / 风险偏好等）获得身份、记忆与行为倾向。
2. **真实人类生活**：居民在城市中持续生活——就业与晋升、消费与储蓄、投资与创业、借贷与信用、
   婚姻与家庭、购房与养老、社交与博弈，一切决策由居民 Agent 自主做出并留下可追溯的轨迹。
3. **城市级涌现**：市场周期、资产价格、利率通胀、社会信用、公共财政与治理，不由剧本预设，
   而由全体居民行为与制度规则**交互涌现**。
4. **真实中国经济底座**：个税七级累进、五险一金、居民收支与社保、LPR/CPI 区间、八类投资品风险收益
   等参数全部锚定真实数据（见《虚拟城市真实世界经济与财商理论底座》与年度数据锚点文档），
   使模拟尽可能高保真地复现真实中国的经济与社会运行。
5. **没有胜负**：不存在胜利条件与竞技排名。模拟以人生的时间推进为轴，终了时做多维人生结局评定
   （财务自由度 / 人生满意度 / 社会贡献），如同真实人生没有标准答案。

**一句话定位**：虚拟城市是一个全 Agent 模拟城市运行、人类真实生活的系统——用真实数据与制度规则，
让十万级居民 Agent 在其中过完真实的一生。

| 人生结局评定 / 模拟结果 | 胜利条件 / 获胜 / 通关 | |
| 模拟机制 / 模拟校准 | 游戏机制 / Playtest 测试 | 校准阈值与数值本身沿用原设计 |

「模拟机制的具象化载体」；线上化后由城市引擎承担同等职能（时间步推进、事件触发、结算）。

## 4. 禁改与保留边界

- **禁改区**：`已实现/`（实现档案，以该目录为唯一事实来源）、`玩家职业设计/`
  （人物卡只能经 `scripts/虚拟城市知识库/` 管道修改，禁止手工编辑）。
- **永久保留**：全部「模拟现实世界、真实社会、真实城市」的设计与数据——三表联动、五维资源、
  市场周期（LPR/CPI 校准）、八类投资品、税制社保、行为金融偏差、社交信用、拍卖交易机制、
  年度真实数据锚点、新兴职业调研。
- **外部对标资料**（`其他类似游戏资料/` 48 份）：对外部游戏/沙盘的调研为客观事实记录，
  作为本模拟器机制设计的借鉴来源长期保留，目录与文件名不改。
