## 0.1 v5.0 变更记录（2026-09-22，上一版）

> **定位声明**：「虚拟城市」**不是一款游戏**，而是一个**由人类 Agent（居民 Agent）组成的真实城市模拟器**——
> 每位居民 Agent 依据一张全息人生档案在城市中持续生活（就业 / 消费 / 投资 / 社交 / 成家 / 养老），
> 城市经济、社会与公共治理由全体居民行为与制度规则交互涌现；以真实中国经济为底座，没有胜负，
