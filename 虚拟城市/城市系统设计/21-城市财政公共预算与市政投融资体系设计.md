## 1. 财政观：政府是"替居民管钱的管家"

真实城市的财政不是数字游戏。它有收入端（谁交的钱）、支出端（办了什么事）、平衡纪律（不能乱花）、
问责端（居民怎么知道钱花得值）。本模拟器把财政设计成一个**有硬约束、可被居民监督、会因政绩被奖惩**的公共账：

> 一句话：**市长再想做好事，也得先问市民兜里的钱和债主——这就是真实城市财政的精髓。**

---

## 2. 收入端：城市的钱从哪来

| 收入科目 | 来源 City-Human / 企业 | 弹性 | 说明 |
|----------|------------------------|------|------|
| **税收** | 居民个税、企业税、契税、增值税分成 | 中 | 经济越好税基越宽；减税让利于民（04 政策） |
| **土地出让金** | 居民购房、企业拿地（01/09） | 高 | "土地财政"：新区开发时一次性大额流入 |
| **公共事业收费** | 水电气热、公交、停车、垃圾费（02/03） | 低 | 准公共品，定价受居民满意度约束 |
| **罚没收入** | 违规罚款（04 执法、14） | 低 | 执法强度的副产品，不能当正经财源 |
| **上级转移支付** | 中央/省对本市补贴 | 低 | 与本市财政健康度、老少边穷身份挂钩（17） |
| **市政债/国债** | 向居民/金融市场借（已实现国债纪律） | 中 | 有利息与还本，不能无限发 |
| **国资经营收入** | 市属国企分红 | 低 | 城投、公交、水务等公共资产 |

> **城市特征**：一座成长型新城靠"土地财政"（卖地搞建设）；一座成熟老城靠税收与转移支付；
> 一座衰退城则面临税基流失、债务压力——财政结构随 05 城市生命周期演变。

## 3. 支出端：钱花到哪去

| 支出科目 | 对应系统 | 财政倾向（受市长政绩偏好影响） |
|----------|----------|--------------------------------|
| **教育** | 11 学校/学位/教师工资 | "学区政绩"型市长会超投 |
| **医疗** | 11 三级医院/医保补助 | 民生型市长优先 |
| **基建** | 02 水电气热、03 道路地铁 | 建设型市长大搞形象工程 |
| **住房保障** | 09 保障房/棚改 | 平抑房价型政策 |
| **治安应急** | 07/08 公安、消防、救灾 | 刚性支出，不可压缩 |
| **公务员薪酬** | 26 公职队伍 | 刚性，编制内人员工资 |
| **债务付息** | 金融系统 | 借得多则付息吃掉支出空间 |
| **转移救助** | 15 低保/养老金补贴 | 社会公平型施政 |

> **硬接线**：所有支出受已实现财政纪律约束——月支出不超过 `min(现金×5%, 上月收入×110%)`，
> 国债不越 R4-1 不透支红线。本文只把"钱花向哪些系统"结构化，不放松任何财政红线。

## 4. 预算年度与政绩周期

```
选举年（48 个月一届，已有）
   │
   ▼ 新市长上台 → 形成施政偏好表（教育派 / 基建派 / 民生派 / 减税派）
   │
   ▼ 每年编制预算：收入预测 → 按偏好分配各科目
   │
   ▼ 月度执行：超支科目暂停施政，结余结转
   │
   ▼ 年末决算：实际收支 vs 预算 → 居民满意度项（04 闭环）
   │
   ▼ 满意度低 → 下次选举得票下降（基尼/满意度公式）
```

> **预算博弈**：市长若连年寅吃卯粮、靠借债搞短期形象工程，会推高债务付息、压低公共服务质量，
> 最终在选举中被 City-Human 用选票惩罚——财政纪律由此被居民"用脚和用票"监督。

## 5. 居民如何看住这笔钱（人类管理财政）

这是"城市由人类管理"在财政上的落地。City-Human 不只是纳税者，还是财政的监督者：

| 监督通道 | 居民行为 | 后果 |
|----------|----------|------|
| **纳税感知** | 每月工资条个税、消费税感 | 税负高→要求更高公共服务，否则不满 |
| **公共服务质量** | 上学/看病/通勤体验（02/03/11） | "交了税却没服务"→ 满意度降 |
| **财政公开** | 公共舆论（16）、信访（04）议论"钱花哪了" | 贪腐/形象工程被曝光→满意度骤降 |
| **投票** | 用选票淘汰"乱花钱"的市长 | 财政问责的最终落点 |
| **用脚投票** | 高税负低服务→搬去邻市（28 区域竞争） | 城市税基流失，财政自我惩罚 |

## 6. 财政与城市系统的闭环

```
经济繁荣 → 税基宽 → 财政富余 → 多投公共服务 → 居民更满意
     ▲                                              │
     └── 人口/企业流入（28）← 服务好、房价合理 ←───┘

经济衰退 → 税基缩 → 债务压力 → 砍支出/加税 → 满意度降 → 改选
```

> 财政不是孤立账本，它是城市"经济—治理—民生"三角的资金转换器，一头连着 City-Human 的收入与税负，
> 一头连着 02/03/09/11/15 的公共服务质量。

---

## 7. 非目标

- 不做逐笔政府采购仿真；财政到"科目—月度—年度"粒度。
- 不放松已实现的任何财政红线（支出上限、国债纪律）；本文只解释钱的来源去向与问责。
- 不引入独立"政府 Agent"；市长、公务员仍是 City-Human（见 26），财政是他们替全体居民管的公共账。
