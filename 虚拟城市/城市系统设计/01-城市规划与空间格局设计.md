## 1. 空间即设计语言

一座真城的空间不是随机摆点：就业岗位、居住人口、公共服务、交通枢纽之间有「职住关系」。
本模拟器的 80×80 地图上 16 个城区，按「中心—外圈—轴带」三级布局，形成可被居民 Agent 感知的空间语义。

### 1.1 三级圈层

| 圈层 | 城区 | 空间角色 | 地价锚（万元/套） |
|------|------|----------|-------------------|
| **核心圈层**（原点附近） | 金融CBD(finance)、商业中心(commerce)、老城区(oldtown)、居住区(residential) | 就业/消费/老城生活中心 | 800 / 400 / 180 / 300 |
| **近郊区**（±10~14 单位） | 科技园(tech)、工业区(industry)、郊区(suburb)、滨河新区(riverside)、物流港(logistics_port)、高新园区(hightech_park)、文创区(cultural_creative) | 产业/居住外溢/新兴板块 | 500 / 200 / 120 / 450 / 250 / 600 / 380 |
| **远郊与节点**（±20~24 单位） | 产业基地(industrial_park)、中央公园(central_park)、教育园区(edu_district)、医疗城(medical_city)、交通枢纽(transport_hub) | 大型公共设施/低成本制造/生态留白 | 150 / 500 / 350 / 450 / 280 |

> 基准房价梯度（120 万~800 万）对应真实中国「一线核心—远郊制造」的房价落差；
> 居民 Agent 的 `buy_house` 决策（《规则》§6.2）直接受此梯度约束。

### 1.2 两条发展轴

- **产业轴（西—西北）**：科技园 → 高新园区 → 物流港 → 产业基地。企业沿轴聚集（对应
  `已实现/11-城市扩张/05-企业产业链` 的 6 大产业集群），就业岗位集中在城市西侧。
- **生活轴（东—南）**：老城区 → 商业中心 → 居住区 → 滨河新区 → 交通枢纽。居住与消费向东、南外溢。

> 这意味着：住郊区(suburb)在产业轴上的居民，通勤到金融CBD 距离远、时间成本高（见 [`03-城市交通与人员流动设计.md`](03-城市交通与人员流动设计.md)），
> 这是居民 Agent 必须真实权衡的空间代价。

## 2. 土地分区与容积率

代码中每个城区只有 `BasePriceWan`（房价）与 `Beta`（周期敏感度）。设计层补一套**功能分区**语义表，
供感知工具 `see` 与规划执法（见 [`04-城市治理与公共行政设计.md`](04-城市治理与公共行政设计.md)）引用：

| 城区 | 主导用地 | 允许用地 | 禁建 | 容积率基调 |
|------|----------|----------|------|------------|
| 金融CBD | 商务办公 | 商业、酒店 | 工业、高密度住宅 | 高（摩天楼） |
| 老城区 | 老旧居住 | 小商业、文创 | 大体量新建 | 低（拆改结合） |
| 工业区/产业基地 | 工业 | 仓储、园区配套 | 居住、学校 | 中 |
| 居住区/郊区 | 居住 | 社区商业 | 有污染工业 | 中低 |
| 中央公园 | 绿地生态 | 公园配套 | 经营性开发 | 极低 |
| 医疗城/教育园区 | 公共设施 | 配套居住 | 高污染工业 | 中 |

**分区如何影响居民**（机制接口，不写死数值）：
- 居民 `see` 本区时，`Things` 列表按主导用地返回（CBD 看到写字楼、郊区看到住宅）。
- 某区违规开发（如在中央公园盖商业）触发规划执法事件（04 系统），罚款走 `CatRegulatoryFine`（已实现已有通道）。

## 3. 地价的空间决定模型

`BasePriceWan` 是静态锚；真实地价随模拟推进动态变化。设计层定义四个空间因子，作为
`已实现/09 财富可视化` 与房价结算的参考权重（权重为设计建议，实现时校准）：

| 因子 | 含义 | 抬高/压低 |
|------|------|-----------|
| **就业可达性** | 到产业轴核心的通勤便利度 | 近就业区溢价 |
| **公共服务等级** | 学区（教育园区辐射）、医疗（医疗城辐射） | 名校/三甲周边溢价（→ 09 学区房） |
| **环境因子** | 邻中央公园、滨河；邻工业区/物流港噪声 | 环境好溢价，污染折价 |
| **周期 Beta** | 城区周期敏感度（代码已有） | 繁荣期高 Beta 区涨更多，衰退期跌更多 |

> 与《真实世界底座》房地产章节一致：房价 = 基本面（收入/利率）× 空间因子 × 周期 Beta。

## 4. 城市增长边界与留白

- **中央公园(central_park)** 是永久生态留白，不参与商业开发，承担城市"绿肺"——
  其存在抬高相邻居住区的环境因子（邻公园溢价）。
- **远郊产业基地** 是城市未来扩张的储备用地（→ 05 建设演进系统）：城市繁荣、人口流入时，
  远郊可启动"新城区开发"事件；衰退期则闲置。
- **交通枢纽(transport_hub)** 是对外门户：高铁/长途汽车站语义，影响跨城流动与物流成本。

## 5. 与居民 Agent 的接口

| 居民动作 | 空间后果 |
|----------|----------|
| `buy_house` 选区 | 决定居住成本、通勤链、环境因子（03/09） |
| `move` 跨区（bus/metro/taxi） | 按 `03` 定价与耗时结算；taxi 最快最贵 |
| `see` 本区 | 返回主导用地的"人/物/事"，空间感由分区表驱动 |
| 创业/开店 `start_side_business` | 选址受分区约束：餐饮去商业中心，工厂去产业基地 |

---

## 6. 非目标

- 不做逐地块的 GIS 级精细建模；分区到"城区"粒度即止。
- 不实时计算每栋楼的朝向/采光；环境因子只到"邻公园/邻污染"二值/等级。
- 不改 `DistrictDefs` 的 ID 与顺序（代码硬契约）。
