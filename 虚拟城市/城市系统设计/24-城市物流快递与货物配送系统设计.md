# 虚拟城市 · 城市物流、快递与货物配送系统设计

> **版本**：v1.0 ｜ **日期**：2026-09-22 ｜ **上游**：[`00-城市系统设计总览.md`](00-城市系统设计总览.md)
> **关系**：[`03-城市交通与人员流动设计.md`](03-城市交通与人员流动设计.md) 管"**人**怎么在城里移动"；
> 本文管"**货**怎么在城里流动"——现代城市里，物流量不亚于人流：网购包裹、外卖餐食、超市补货、
> 工地建材、垃圾清运。物流是商业生态（22）背后的血管，也是大量 City-Human（骑手、仓管、司机）的饭碗。

---

## 1. 物流动观：看不见的城市血脉

你在街上看到的是人和车，看不到的是每秒都在发生的货物位移：

- 居民在手机上下单（22 电商外卖）→ 仓库/门店出库 → 骑手/货车运输 → 家门口签收；
- 餐馆后厨缺食材 → 批发市场/供应商配送；
- 工地（05 建设）需要钢筋水泥 → 建材货车进城；
- 居民扔垃圾 → 环卫清运 → 垃圾处理厂（02）。

> 一句话：**人流看 03，物流看 24；现代城市一旦物流停摆，比堵车更致命——外卖断、超市空、工地停。**

## 2. 物流网络的层级

| 节点 | 位置 | 功能 | 经营/从业（City-Human） |
|------|------|------|--------------------------|
| **物流园区/分拨中心** | 远郊交通枢纽（01/03） | 包裹分拣、区域中转 | 仓管、调度、货车司机 |
| **仓储/前置仓** | 近郊区、社区周边 | 短时效备货、生鲜前置 | 仓管、分拣员 |
| **门店/商家库存** | 各商圈、社区底商（22） | 即时零售、自提 | 店主 |
| **末端配送** | 全城社区 | 最后一公里送货上门 | 快递员、外卖骑手（12 灵活就业） |
| **批发市场** | 物流板块 | 餐馆/小店进货 | 批发商、小老板 |

## 3. 几类典型物流场景

| 场景 | 触发 | 时效/成本 | 城市影响 |
|------|------|-----------|----------|
| **外卖/即时配送** | 居民 22 点外卖 | 30 分钟级，骑手密集 | 高峰时段非机动车流，安全（07） |
| **快递网购** | 居民线上购物 | 当日/次日达 | 分拣中心用电、配送压力 |
| **生鲜冷链** | 居民买菜/生鲜 | 温控、高频 | 冷链就业、损耗 |
| **货运进城** | 工地（05）、商铺补货 | 夜间错峰 | 货车与拥堵（03）、限行政策（04） |
| **逆向物流** | 退货、旧物回收、垃圾清运（02） | 周期 | 与环卫系统衔接 |

> **骑手经济**：外卖/快递骑手是 12 里"灵活就业/零工经济"的最大就业池之一。他们的收入、时效压力、
> 交通安全，直接体现一个城市对新业态劳动者的态度——这也是城市运行真实感的重要来源。

## 4. 物流与其他系统的接口

| 接口 | 关系 |
|------|------|
| ↔ 22 消费零售 | 消费越旺，单量越大，物流越忙；物流时效决定消费体验 |
| ↔ 03 交通 | 货车、配送车占路，影响拥堵；限行/错峰政策调节 |
| ↔ 12 劳动力 | 骑手、仓管、司机是重要灵活就业岗位池 |
| ↔ 02 基础设施 | 仓储用电、配送用水、垃圾回收共用城市血脉 |
| ↔ 05 建设 | 建材运输决定建设进度；新工地拉动货运需求 |
| ↔ 13 环境 | 配送车辆尾气/噪音、包装垃圾（外卖盒） |

## 5. 物流作为城市韧性环节

- **旺季冲击**：促销/节庆（23 活动）单量暴增 → 爆仓、骑手不足、配送延迟 → 居民不满（22 体验下降）。
- **中断风险**：极端天气/疫情（08 应急）下，物流先于一切受冲击——封控期间"菜能不能送进来"
  是城市韧性的直接体现，也是居民最焦虑的事。
- **恢复**：应急响应中，恢复物流配送 = 恢复城市心跳（接 08 韧性指标）。

## 6. 非目标

- 不做逐包裹路径规划与实时地图寻路；物流到"网络节点 + 单量 + 就业 + 时效影响"粒度（呼应 00.3.3 不做物理模拟）。
- 不新增"物流公司"独立 AgentClass；企业是已实现产业链的延伸，骑手/司机/仓管都是 City-Human。
- 不与 03 交通重复：03 管人通勤，24 管货位移；共用路网但各有统计口径。
