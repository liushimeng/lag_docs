## 1. 治理观：城市是居民的，政府是受托的

真实城市不是只有"市长"一个人。它由一套公共行政体系运转：决策（政府/人大）、执法（公安/城管/规划）、
裁决（法院）、基层（街道/社区）。本模拟器把这些设计成**职能机构 + 居民参与通道**，
与已有的选举、监管、财政系统咬合，形成"居民选举 → 政府施政 → 服务质量 → 满意度 → 下次选举"的治理闭环。

## 2. 行政架构设计

| 机构 | 职能 | 与既有系统的关系 |
|------|------|------------------|
| **市政府/市长** | 行政首长，统筹财政预算方向 | 已有 `civic_election` 选举产生；施政影响 `fiscal_policy` 预算分配倾向 |
| **规划局** | 土地分区、新城开发、拆改审批 | 引用 `01` 分区表；审批违规开发（→04.3） |
| **公安局** | 治安、交通、户籍、刑侦 | 接入 `07` 犯罪事件；治安质量影响居民安全感与房产环境因子 |
| **法院/司法** | 纠纷裁决、债务破产、离婚析产 | 已有破产三阶段重组（P0 Balance）；离婚析产（P1 事件）走司法叙事 |
| **市场监管局** | 已有消协/反垄断/证监会等监管 | 复用 `regulators/` 子包 |
| **街道办/社区** | 基层服务、矛盾调解、民生登记 | 背景层居民的日常治理接口；影响邻里信任（→07） |
| **城管** | 市容、违建、占道经营 | 接入 `02` 垃圾/夜间施工投诉；执法有度影响居民满意度 |

## 3. 政策工具包（政府可施政）

市长/政府在选举周期内，可在财政约束下推出**政策**，以政策参数形式调整城市环境：

| 政策 | 方向 | 影响 | 财政成本 |
|------|------|------|----------|
| **加大学区投入** | 教育预算↑ | 学区房溢价↑、下一代收入↑（已实现 EducationSystem） | 高 |
| **医疗扩容** | 医疗预算↑ | 居民健康事件发生率↓、满意度↑ | 中高 |
| **保障房/公租房** | 住房保障 | 低收入居民住房负担↓（→09） | 中 |
| **最低工资上调** | 劳动力市场 | 底层居民工资↑、企业成本↑（就业↓） | 低（传导） |
| **限行/治堵** | 交通 | 通勤时间↓、出行成本↑（远期私家车） | 低 |
| **污染治理** | 环境 | 工业区周边环境因子修复、健康↑ | 中 |
| **减税** | 企业/居民税 | 经济活跃↑、财政收入↓（→财政纪律约束） | 负 |

> **硬约束**：所有政策受 `已实现/11-城市扩张/04` 的财政支出上限（min(现金×5%, 上月收入×110%)）
> 与国债纪律（R4-1 不透支）约束。政府不能无限发福利——这是真实财政的精髓。

## 4. 执法与规则

### 4.1 执法场景
| 违规 | 执法机构 | 后果 |
|------|----------|------|
| 内幕交易/操纵市场 | 证监会（已有） | 罚款封顶月收入 5% |
| 企业垄断 >40% | 反垄断（已有） | 强制分拆 ×0.5 |
| 中央公园违建 | 规划局/城管 | 限期拆除 + 罚款，走 `CatRegulatoryFine` |
| 夜间施工扰民 | 城管 | 停工 + 罚款 |
| 盗窃/斗殴 | 公安 | 治安事件，记录个人信用（→社交信用系统） |

### 4.2 规则的涌现
真实城市的规则不是凭空定的：它由居民行为触发。例如
- 某区违规开发频发 → 居民投诉 → 舆论（→07）→ 政府收紧规划审批；
- 某类诈骗高发（已有反诈机制）→ 监管加强 → 处罚加重。

## 5. 居民参与通道

这是"城市是居民管的"的直接体现。居民 Agent 除了投票，还能通过以下渠道影响城市：

| 通道 | 居民行为 | 后果 |
|------|----------|------|
| **选举投票** | 48 月一届（已有） | 决定市长，进而决定政策倾向 |
| **信访/投诉** | 对停水/污染/治安 `speak` 或提诉求 | 触发对应部门施政优先级 |
| **公共舆论** | 在城区 `speak` area 发言、参与社会调研（已有 `answer_survey`） | 聚合为城市舆论倾向，影响选举满意度项 |
| **社区参与** | 邻里互助、业委会（远期） | 提升社区信任与治安质量 |
| **竞选** | 高知名度居民可参选市长（远期，接财富+人脉+满意度三项得票） | 居民自己当管理者 |

> 已有 `已实现/11-城市扩张/05 社会调研系统`：居民作答零 LLM 成本，聚合后 `game.survey_result` 广播——
> 这正是民意的数字化通道，本文把它接入治理闭环。

## 6. 治理的内生反馈环

```
居民生活体验（02/03/07 的质量分）
        │
        ▼
居民满意度 + 舆论（调研/发言聚合）
        │
        ▼
市长选举得票（满意度 = 100 − 基尼×100，已有公式）
        │
        ▼
政府施政（03 政策工具包，受财政约束）
        │
        ▼
公共服务/基础设施质量变化（02）
        └──────────────► 回到居民生活体验
```

## 7. 非目标

- 不做完整议会/人大立法流程；政策工具包到"参数旋钮"粒度。
- 法院不做逐案庭审仿真；只做事件级叙事与既有破产/离婚规则的裁决引用。
- 不改已有选举/监管/财政的代码契约。
