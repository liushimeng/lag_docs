# 虚拟城市 · 城市家庭、婚姻与代际关系系统设计

> **版本**：v1.0 ｜ **日期**：2026-09-22 ｜ **上游**：[`00-城市系统设计总览.md`](00-城市系统设计总览.md)
> **关系**：[`06-CityHuman居民Agent全生命周期与日常行为设计.md`](06-CityHuman居民Agent全生命周期与日常行为设计.md) 讲"一个人"怎么活；
> 本文讲"**一家人**"怎么活——城市的基本单元不是孤立的个人，而是由 City-Human 组成的家庭。
> 所有家庭成员**无一例外都是 `LsmAgentGame-City-Human`**，只是各自承担夫/妻/父/母/子/女/祖辈角色。
> **已实现锚点**：P1 婚姻叙事、代际继承（50% 配偶 + 50% 子女均分）、家庭抚养支出、随迁子女（→17）。

---

## 1. 为什么单独设计家庭

《规则与经济系统》的三表是"个人账"，《06》的需求与时间预算是"个人的"。但真实城市里，
一个人的绝大多数重大决策——结婚、买房、生子、换工作、搬家、赡养、遗产——都是**家庭决策**，
收入与支出在家庭内部合并，风险与情绪也在家庭内部传染。不把家庭作为一等公民，城市就只是"一群合租的陌生人"。

> 一句话：**City-Human 一个个是居民，合起来是家庭；城市先是被一个个家庭住满的，才是被个人住满的。**

## 2. 家庭单元的结构

| 家庭类型 | 结构 | 典型阶段 | 经济特征 |
|----------|------|----------|----------|
| **单人** | 1 名 City-Human | 20~30 岁未婚 / 离异 / 丁克 | 收支简单，储蓄率高，迁移成本低 |
| **二人世界** | 夫妻 2 人 | 新婚未育 | 双收入无抚养，购房主力，消费力强 |
| **核心家庭** | 夫妻 + 1~2 子女 | 25~50 岁 | 一笔收入养家，教育/房贷支出最重 |
| **主干家庭** | 夫妻 + 子女 + 老人 | 35~55 岁 | 上有老下有小，"三明治"抚养比高 |
| **单亲家庭** | 1 家长 + 子女 | 离异/丧偶 | 单收入，抗风险弱，多领救助（→15） |
| **隔代抚养** | 祖辈 + 孙辈 | 父母外出务工（→17 流动人口） | 老人持家，父母异地汇款 |
| **空巢家庭** | 老年夫妻 | 子女成年离家 | 以养老金/资产为主要收入，医疗支出高 |

> 家庭结构由全息档案的 `birth_family`（出生家庭）与生命周期婚姻/生育/死亡事件动态生成，开局即按
> 2025 真实家庭户抽样（见《虚拟城市2025居民收支与社保数据锚点》家庭画像），不是清一色"二人世界"。

## 3. 婚姻市场与择偶

| 环节 | City-Human 行为 | 机制 |
|------|------------------|------|
| **相遇** | 在工作/社交/社区（→07/18）场景 `socialize`，产生关系强度 | 关系达到阈值进入候选 |
| **择偶比较** | 各自的 `life_goals`、收入、资产、风险偏好、健康进入"般配度"打分 | 门当户对会提高成婚概率（代际与阶层复制） |
| **彩礼/嫁妆/婚房** | 男方/双方家庭协商一次性支出，购房前置 | 直接消耗家庭储蓄，影响买房时点（→09） |
| **领证合并** | 结婚事件触发：两本个人账合并为**家庭联合账** | 共同财产、共同债务、共同购房 |
| **离异** | 关系破裂或长期冲突触发 | 走司法析产（→14）：财产分割、抚养权、抚养费 |

> **涌现**：高房价与重彩礼会推迟结婚、压低生育率（→10 人口动力学）；闪婚闪离会推高法院案件量
> 与单身家庭比例。这不是剧本，是 City-Human 在经济约束下的选择结果。

## 4. 家庭内部的钱与账

```
           家庭联合账（一个 Ledger 实体）
   ┌───────────────┬───────────────┬───────────────┐
   │ 夫妻双方收入   │ 共同刚性支出   │ 共同资产/负债   │
   │ （各自工资）   │ 房贷/房租/教育 │ 房产/存款/投资  │
   │               │ 伙食/水电/赡养 │ 共同贷款        │
   └───────────────┴───────────────┴───────────────┘
            ▲ 每月家庭财务会议（家庭决策事件）
            │
   谁管钱？——一方主理 / AA 制 / 共同决策（由人格与风险偏好决定）
```

- **内部转移**：配偶间可无息调拨；代际转移（父母给子女首付、成年子女给父母赡养费）是真实的资金流，
  全部走既有 Ledger，不新增游离的钱（呼应《00》"钱闭合"）。
- **家庭风险共担**：一方失业/重病时，家庭另一方可成为"安全网"——这是 15 社保之外的第一道缓冲，
  也是家庭相对单身居民抗风险更强的原因。
- **家庭消费决策**：大额支出（换房、买车、送孩子出国、买保险）是家庭决策事件，双方 Agent 共同权衡。

## 5. 代际：上一代与下一代

| 方向 | 内容 | 与既有系统接线 |
|------|------|----------------|
| **父母 → 子女（向下）** | 抚育支出、教育投资（→11）、首付支援、创业启动金 | 影响下一代起始资产与人生起跑线（阶层代际复制） |
| **子女 → 父母（向上）** | 赡养老人、医疗陪护、养老安排 | 成年子女家庭的刚性支出（三明治负担来源） |
| **遗产继承** | 离世事件触发：50% 配偶 + 50% 子女均分（已实现） | 家族财富跨代传递，贫富差距的时间放大器 |
| **隔代** | 祖辈带孙辈、随迁老人 | 与 17 流动人口、18 社区生活交织 |

> **设计意图**：家庭与代际是"阶层为何固化、财富为何传承"的微观引擎。City-Human 不只是活自己一生，
> 他的开局起点来自父辈，他的终点遗产传给子辈——城市的不平等因此有了时间厚度。

## 6. 家庭与城市系统的接口

| 家庭事件 | 牵动的城市系统 |
|----------|----------------|
| 结婚/购房 | 住房市场（09）、建材消费（22）、登记（04/14） |
| 生育 | 人口（10）、教育学位（11）、母婴消费（22）、产假福利（15） |
| 子女入学 | 学区房重估（09/11）、通勤链（03） |
| 赡养老人 | 养老服务（27）、医疗（11）、护理消费 |
| 离异析产 | 司法（14）、房产分割（09）、单亲救助（15） |
| 搬家 | 社区融入（18/17）、通勤重构（03） |

## 7. 非目标

- 不模拟夫妻吵架的逐句对话；家庭矛盾到"状态/概率/支出影响"粒度。
- 不做复杂的血缘基因图谱；代际只追踪配偶—子女—父母三代核心关系。
- 不改已实现的继承比例（50/50）与婚姻叙事契约；本文定义家庭单元的经济与社会结构。
- 不把"家庭"做成新 AgentClass——家庭成员仍然全部是 City-Human，只是共享一个家庭账与关系图。
