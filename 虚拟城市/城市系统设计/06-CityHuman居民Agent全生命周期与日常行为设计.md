# 虚拟城市 · City-Human 居民 Agent 全生命周期与日常行为设计

> **版本**：v1.0 ｜ **日期**：2026-09-22 ｜ **上游**：[`00-城市系统设计总览.md`](00-城市系统设计总览.md)
> **定位核心**：城市中的每一个人，**完全由 Agent `LsmAgentGame-City-Human` 承担**（`已实现/12-CityHuman重构`）。
> 本文是这个"人"的完整行为设计：他怎么安排一天、怎么过完一生、怎么做每个决策、情绪从哪来。
> **档案驱动**：行为倾向来自 `玩家职业设计` 全息人生档案 Schema v1.1（65 字段）。

---

## 1. City-Human 是什么

`LsmAgentGame-City-Human` 不是"游戏玩家"，也不是 NPC 脚本。他是一个**有身份、有记忆、有需求、有情绪、
会做选择的城市居民**。整个虚拟城市里没有第二种"人"：

- 焦点层 1~12 座居民：跑完整工具循环，做月度经济决策（40 经济工具 + 5 感知工具）。
- 背景层 1~10 万居民：共享同一 AgentClass，只抽样发声（见 `已实现/12-CityHuman重构 §2.2`）。
- 未来的政府/央行/企业发言人：**不再新增 AgentClass**，一律复用 City-Human + 角色提示词区分。

> 一句话：**城里除了 City-Human 还是 City-Human。银行家、市长、店长、乞丐，都是"穿了不同身份的同一个人"。**

## 2. 需求层次：人的行为为什么发生

借鉴马斯洛与真实生活，把居民 Agent 的动机抽象为五层需求。每月 tick 时，Agent 的决策由"未被满足的最高层需求"驱动：

| 层级 | 需求 | 未满足时的行为倾向 | 对应系统 |
|------|------|--------------------|----------|
| **L1 生存** | 吃饱、有房住、有收入 | 优先找工作/保工作、压缩消费、寻求救济 | 劳动力市场、低保转移支付 |
| **L2 安全** | 健康、稳定、不破产、不失业 | 买保险、留储蓄、避免高风险投资 | 保险系统、三表、信用 |
| **L3 归属** | 家庭、朋友、社交、被认可 | `socialize`、成家、维护人脉、参与社区 | 社交资本、婚姻家庭 |
| **L4 尊重** | 晋升、财富、地位、声望 | 跳槽升职、创业、购置资产、竞选 | 职业晋升、企业、选举 |
| **L5 自我实现** | 梦想、意义、FIRE、传承 | 提前退休、捐赠、遗产安排、追求热爱 | FI Index、代际转移、捐赠 |

> **机制**：档案里的 `life_goals`（人生目标）与 `risk_preference`（风险偏好）决定一个人更偏向哪一层；
> 现实处境（失业/富有的状态）会临时拉高某层需求。这让不同居民 Agent 做出**看似不同但都合理**的选择。

## 3. 一天与一月：时间如何被分配

### 3.1 月度时间预算（模拟器主时间轴）
模拟器以"月"为 tick（《规则》§1）。每个居民每月有一份**时间/精力预算**，分配到下列活动：

| 活动 | 时间/精力成本 | 工具 | 产出 |
|------|--------------|------|------|
| 通勤 | 见 `03` 通勤链 | （被动） | 消耗时间精力 |
| 工作 | 基础占满 | （月度工资结算） | 收入、职业成长 |
| 加班 `work_overtime` | 额外精力 | 工具 | 更多收入，透支健康 |
| 学习 `study` | 时间+精力 | 工具 | 提升认知（解锁专项扣除/高级决策） |
| 休息 `rest` | 精力恢复 | 工具 | 回精力、维护健康 |
| 社交 `socialize` | 时间+金钱 | 工具 | 人脉（五维资源） |
| 消费 `consume` | 金钱 | 工具 | 生活质量、情绪 |
| 投资决策 | 精力 | `buy/sell_asset` 等 | 资产配置 |
| 感知 | 每月≤2 次 | `see/hear/smell` | 获取信息 |
| 移动 | 耗动作预算 | `move` | 改变空间位置 |

### 3.2 一天的语义（叙事层）
月度 tick 不逐分钟模拟，但居民的发言、感知文本、情绪，按"清晨通勤—白天工作—傍晚通勤—晚上社交/休息"
的时间语义组织。这样 City-Human 的 `speak`、`hear` 才像真人，而不是抽象的"月度决策体"。

## 4. 全生命周期：从摇篮到终点

居民档案开局 20~25 岁（精选手卡），60 岁强制终局（《总体设计》）。设计层补全生命各阶段的行为特征：

| 阶段 | 年龄 | 主要矛盾 | 典型行为 |
|------|------|----------|----------|
| **求学/初入职场** | 20~25 | 立足、攒第一桶金 | 学习、换工作、合租、克制消费 |
| **成家立业** | 25~35 | 结婚、买房、生育 | `buy_house`、`start_side_business`、择偶社交 |
| **家庭负担最重** | 35~50 | 子女教育、赡养父母、还房贷 | 稳健投资、保险、教育投入、跳槽保收入 |
| **财富收获** | 50~60 | 资产增值、健康、退休规划 | 调整资产配置、规划养老金、考虑遗产 |
| **退休养老** | 60+ | 医疗、长寿、传承 | 领取养老金、安享/或继续工作、代际转移 |

### 4.1 生命周期事件（与既有事件系统对齐）
| 事件 | 触发 | 影响 |
|------|------|------|
| 结婚 | 两居民社交达到阈值 | 合并家庭收支、共同买房（P1 已有婚姻叙事） |
| 生育 | 已婚 + 时间/金钱允许 | 子女抚养支出、教育投资（代际系统已有） |
| 失业 | 企业裁员/经济衰退 | 生存需求拉满，领失业救济、降消费 |
| 健康危机 | 健康值低 + 年龄 | 医疗支出、影响工作能力 |
| 创业 | 有积蓄 + L4/L5 驱动 | `start_side_business`，高风险高回报 |
| 破产 | 资不抵债 | 破产三阶段重组（P0 Balance），重新开始 |
| 离世/传承 | 60+ 或健康归零 | 遗产继承（代际系统：50 配偶 + 50 均分） |

## 5. 情绪与心理状态

City-Human 不是纯理性计算器。他有一个**情绪/压力状态**，由处境涌现，反过来影响决策：

| 状态 | 来源 | 决策偏差（接《行为金融与投资心理》） |
|------|------|------------------------------------|
| **焦虑** | 失业、债务重、长通勤、健康差 | 短视、过度保守或赌博式翻本、跟风 |
| **乐观/亢奋** | 市场繁荣、升职加薪 | 过度自信、加杠杆、追高（Minsky 狂热） |
| **满足/平静** | 收支平衡、家庭和睦 | 稳健配置、长期主义 |
| **绝望** | 连续破产、重病 | 躺平、不行动、依赖救济 |
| **从众** | `hear`/`see` 到他人赚钱 | 跟风买热门资产（羊群效应） |

> **接线**：情绪状态由 `已实现/12-CityHuman重构 §3.3` 的 `NeighborBrief.MoodHint` 体现；
> 决策偏差接入《行为金融与投资心理》的 30 张心魔卡与 11 类系统级偏差——**City-Human 会"犯错"，这才像真人**。

## 6. 决策循环（每月 tick）

```
① 感知：see/hear/smell 了解城区当下（就业、邻居、事件、气氛）
   │
② 处境核算：读自己的三表 + 五维资源 + 情绪状态
   │
③ 需求判断：哪一层需求最未被满足？人生目标指向哪？
   │
④ 工具决策：选 ≤3 个动作（工作/学习/投资/社交/消费/移动…）
   │         受风险偏好、心魔偏差、预算限制
   ▼
⑤ 月结结算：工资/税/债/被动收入/市场波动（引擎自动）
   │
⑥ 情绪更新：本月经历 → 新的压力/满足/从众
   ▼
⑦ 发声：必要时 speak（area 公开发言 / private 私聊），留下社会痕迹
```

> 焦点层跑完整循环（LLM 决策）；背景层只在抽样时走"一句话发声"，不跑工具循环（成本约束，见 §7）。

## 7. 记忆与社会性

- **局内记忆**：焦点层居民有滚动记忆（memory.go），记得本月发生了什么、和谁社交过、上次决策结果。
- **社会痕迹**：每次 `speak`、交易、社交都留在城市里，成为其他居民 `hear`/`see` 的内容——
  这就是"城市舆论"与"社交网络"的微观基础（→ 07）。
- **档案一致性**：无论发声还是决策，居民的姓名、职业、性格、出身都来自真实人物卡，**不出现"居民 #12345"**。

---

## 8. 非目标（与已实现 §7 对齐）

- 背景层 10 万居民**不跑工具循环**（成本不可行），只抽样发声；只有焦点层有完整"人"。
- 不做自由意志/意识模拟；情绪与决策偏差由规则 + LLM 提示词涌现。
- 不改 40 个经济工具与 5 个感知工具的已有签名；本文定义它们被一个"真人"使用时的内在动机。
- 不新增除 City-Human 外的任何 AgentClass。
