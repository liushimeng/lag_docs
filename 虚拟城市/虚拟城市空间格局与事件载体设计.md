## 1. 城市空间格局

### 1.1 整体结构

城市空间为**三层同心空间带**，对应人生三段（20–30 岁 / 30–45 岁 / 45–60 岁）：

```
┌─────────────────────────────────────────────────────────────┐
│  自由段空间带（外环，24 个节点）— 45~60 岁，财务自由后          │
│  ┌───────────────────────────────────────────────────┐      │
│  │  积累段空间带（中环，30 个节点）— 30~45 岁，家庭与事业  │      │
│  │  ┌───────────────────────────────────────┐        │      │
│  │  │  生存段空间带（内环，24 个节点）— 20~30 岁 │        │      │
│  │  │                                       │        │      │
│  │  │   中央中枢：市政厅 / 市场 / 结算引擎     │        │      │
│  │  └───────────────────────────────────────┘        │      │
│  └───────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────┘
```

- **空间方向**：居民沿环带**顺时针**推进（时间轴在空间上的投影）。
- **中央中枢**：事件载体池、结算引擎、市场周期指示器、场景注入台的逻辑所在。
- **节点总数**：24 + 30 + 24 = **78 个空间节点**。
- **空间与行政区映射**：三层空间带在 16 城区地图上投影为「内城 / 主城 / 外城」三档；
  节点落位由城区产业与地价决定（详见《城市系统设计/01-城市规划与空间格局设计》）。

### 1.2 空间尺度参数（建模口径）

| 空间带 | 空间直径 | 节点尺度 | 节点数 |
|------|------|---------|------|
| 生存段（内环） | 40 单位 | 约 10 × 4 单位 | 24 |
| 积累段（中环） | 60 单位 | 约 12 × 4 单位 | 30 |
| 自由段（外环） | 80 单位 | 约 14 × 4 单位 | 24 |
| 全域 | 约 90 单位 | — | 78 |

> 该表是**空间布局的建模参数**（用于地图生成与 3D 呈现的尺度基准），非物理尺寸。

### 1.3 空间风貌基调

- **生存段**：冷灰色调，节点以蓝/灰为主，体现职场起步的平凡。
- **积累段**：暖棕色调，节点以绿/金为主，体现奋斗与积累。
- **自由段**：金红色调，节点以金/紫为主，体现财富自由。
- **中央中枢**：深蓝星空 / 城市天际线，象征「城市时间轴的原点」。

### 1.4 节点类型分布审查（v2.0 保留 v1.2 结论）

> 参照 The Game of Life 的 162 格交织轨道与四色格（White=普通 / 绿=加薪 / 红=人生事件 / 蓝=选择）
> 设计，审查本模拟器三层 78 节点的类型分布。**该对照仅为外部设计经验引用，不代表本模拟器是桌游。**

**Game of Life 四色格经验**：普通格约 40%–50%，事件格约 20%–25%，奖励格约 20%，选择格约 10%–15%。
本模拟器三层合计 78 节点对照：

| 节点大类 | 本模拟器数量 | 占比 | Game of Life 参考占比 | 审查结论 |
|---------|---------|------|-------------------|---------|
| 结算 / 现金流节点（黄色） | 26 | 33% | 普通格 40%–50% | ⚠️ 偏高：结算节点过多会稀释事件密度。建议生存段 8 个发薪节点中 2 个改造为「混合功能节点」 |
| 机会节点（绿 / 深绿 / 紫） | 19 | 24% | 奖励格 20% | ✅ 合理 |
| 事件节点（红 / 粉） | 12 | 15% | 事件格 20%–25% | ⚠️ 偏少：人生事件密度偏低。建议在积累段增加 1–2 个人生事件节点 |
| 随机扰动节点（粉） | 4 | 5% | — | ✅ 合理 |
| 休息 / 学习 / 社交节点（青 / 紫 / 橙） | 8 | 10% | 选择格 10%–15% | ✅ 合理 |
| 银行 / 金融节点（棕 / 深蓝） | 4 | 5% | — | ✅ 合理 |
| 政策 / 过渡 / 慈善 / 梦想节点 | 5 | 6% | — | ✅ 合理 |

**两条优化建议**（v1.2 提出，待标注运行验证）：

1. **生存段发薪节点压缩**：8 个发薪节点中，将 S10/S20 改造为「发薪 + 小机会」混合节点——
   居民经过时既结算工资，也可选择支付 100 元采样 1 条小机会载体。既保留结算功能，又增加决策密度。
2. **积累段人生事件节点扩充**：在 A15（社交）与 A21（失业）之间增加 1 个「晋升/跳槽」事件节点，
   对应 Game of Life 的职业选择格。

## 5. 空间阶段切换规则

### 5.1 生存段 → 积累段（自动）

- **触发条件**：30 岁节点到来时，所有仍在生存段的居民自动升入积累段。
- **切换动作**：
  1. 居民位置从 S24 移至 A01。
  2. 保留全部财务状态（资产、负债、现金、资源）。
  3. 获得「新起点」状态：精力 +2。
  4. 随机扰动仍为 1 颗六面抽样。
- **设计意图**：30 岁是中国职场的关键转折点，自动升入体现人生阶段的自然过渡。

### 5.2 积累段 → 自由段（主动申请）

- **触发条件**（同时满足）：
  1. FI Index ≥ 1.0（被动收入 > 总支出）。
  2. 精力 ≥ 3 点。
  3. 无高息消费贷（信用卡 / 消费贷余额为 0）。
- **申请时机**：任意模拟月的 S1 阶段，向结算引擎申请。
- **切换动作**：
  1. 居民位置从 A30 移至 F01。
  2. 随机扰动从 1 颗变为 2 颗六面抽样。
  3. 不能再申请消费贷。
  4. 账本视图简化：支出与负债栏折叠，只记现金与被动收入。
  5. 获得「自由人」状态标记。
- **注意**：若 FI Index 跌破 0.8，将触发跌落（见 §5.3）。

### 5.3 自由段 → 跌回积累段

- **触发条件**（任一）：
  1. 被动收入因市场周期崩盘，FI Index 跌破 0.8。
  2. 停留在 F23「跌落风险」节点且抽样结果 ≤ 2。
  3. 触发重大投资失败事件（亏损 > 总资产 50%）。
- **跌落动作**：
  1. 居民位置移回积累段 A01。
  2. 现金损失 50%。
  3. 精力 −3。
  4. 随机扰动变回 1 颗六面抽样。
  5. 账本视图恢复完整版本。
- **设计意图**：财务自由不是一劳永逸，自由段的空间里仍会让人跌回积累期。

| 自由段项目载体 | 20 | 7% | — | ✅ 合理 |

此项为 v1.2 建议，待标注运行验证后落地。

**职业档案规格对照**：财富流沙盘约 24 张职业卡，本模拟器 v1.4 扩展至 18 张（核心 12 + 扩展 6）。
差异合理——本模拟器职业档案是「起点财务定义」（含月薪 / 支出 / 初始资源），而非财富流的
「职业能力进阶卡」；18 张覆盖 4,500–40,000 月薪区间 + 1,500/12,000 个体户 / 自由职业 / 网约车等
非主收入者场景，更贴近真实中国职业光谱。

### 6.1.2 股票/企业载体定价梯度审查（保留 v1.2 结论）

> 参照 Acquire 的三档股价表（低价区 / 中价区 / 高价区，每档价格跳幅约 50%）审查股票池定价梯度。

### 7.4 随机扰动源（原骰子）

> 所有随机性统一为**带种子的抽样**，保证同种子可复现（《校准框架》D9 / R-I5）。

| 扰动源 | 原载体 | 用途 | 引擎实现 |
|--------|--------|------|---------|
| 步长扰动 | 标准六面骰 ×3 | 居民移动步长（生存/积累段 1–6，自由段 2–12） | `rand.Intn(6)+1`，种子派生 |
| 市场周期转移 | 市场周期骰 ×1 | 每 5 年决定下一阶段经济周期 | 转移概率矩阵（见下） |
| 事件结果扰动 | 事件骰 ×1 | 部分载体需要随机结果（收益率/是否离婚等） | 载体模板声明的分布抽样 |

**市场周期转移概率**（原骰面设计）：

| 下一阶段 | 概率 |
|---------|------|
| 复苏期 | 2/6 |
| 繁荣期 | 2/6 |
| 衰退期 | 1/6 |
| 萧条期 | 1/6 |

### 7.5 干预工具集（条件触发者使用）

| 工具 | 对应场景 `kind` | 作用 | 限制 |
|------|----------------|------|------|
| **商品价格冲击器** | `goods_price_shock` | 指定商品类目与涨跌幅，作用期为 N 月 | 单次幅度 ≤ 场景目录上限 |
| **政策杠杆** | `policy_shock` | 调整税率 / 基准利率 / 补贴 / 限购参数 | 只改参数值，不改税制结构 |
| **市场崩盘触发** | `market_crash` | 注入流动性冲击，触发杠杆强平链 | 需目标市场处于可交易状态 |
| **问卷脉冲** | `survey_pulse` | 向指定人群投放问卷情境，观测反馈分布 | 不指定个体回答 |
| **舆情议题注入** | `election_sentiment` | 设置议题、媒体倾向、候选人曝光 | 候选人与议题须在白名单 |
| **灾害注入器** | `earthquake` / `tsunami` / `extreme_disaster` | 指定城区、震级/淹没带/复合灾害参数 | 造成存量资产状态改写，需重建恢复 |
| **未知灾难注入器** | `meteorite` / `alien_invasion` | 注入超出模型标定范围的全局冲击 | 仅用于韧性压力测试，报告须标注「未知域」 |
| **居民位置/档案标记** | — | 观察用，不改变状态 | 只读 |
| **账本视图** | — | 观察用，显示三表与勾稽结果 | 只读 |
| **时间控制** | — | 暂停 / 单步 / 加速（运维与房主） | 不开放给观察者 |

> 干预工具的完整协议、配额与审计见《虚拟城市人类角色与场景触发协议设计》§3；
> 场景强度分级见《虚拟城市场景推演与预测运行设计》§3。

## 9. 引擎承载与呈现

### 9.1 城市空间呈现

| 元素 | 实现方式 |
|------|---------|
| 三层空间带 | 3D 城市地图分区着色，可缩放、可拖拽平移 |
| 节点高亮 | 当前居民落点节点发光高亮 |
| 居民移动动画 | 移动时平滑过渡，结婚/生子有小动画 |
| 市场周期指示器 | 地图顶部显示当前周期，颜色随周期变化 |
| 年龄进度条 | 顶部进度条显示 20→60 岁进度 |

### 9.2 账本自动结算

- **实时更新**：每笔交易实时更新三表，可展开查看完整明细。
- **自动计算**：月薪、月供、个税、社保全部自动计算。
- **勾稽校验**：每次结算后自动校验 `资产 = 负债 + 净值`，不平则红色提示并中止。
- **历史曲线**：净资产、FI Index、月现金流三条曲线，展示人生轨迹。

### 9.3 事件载体数字化

- 事件载体以卡片式面板呈现，点击展开。
- 机会类载体可「收藏」在手中，随时查看。
- 触发时自动播报（TTS），线下演示亦可用音箱播放。

### 9.4 结算引擎与教练交互

| 组件 | 交互方式 | 界面元素 |
|-------|---------|---------|
| 结算引擎 | 自动结算，播报式确认 | 右侧面板：最近交易记录、现金余额 |
| 复盘教练 | 对话式，可随时提问（周期后） | 底部聊天框 |
| 雇主 Agent | 事件触发，提供工作选择 | 弹窗：新工作机会（工资 / 工作时长） |
| 投资人 Agent | 自由段触发，报价收购 | 弹窗：收购报价单 |

### 9.5 复盘与预测报告

终局后自动生成报告，包含：
1. 净资产变化折线图。
2. FI Index 变化曲线。
3. 资产配置饼图。
4. 关键决策时间线。
5. 与平均水平对比雷达图。
6. 复盘教练的 3 条改进建议。
7. **若含场景注入**：与同种子无注入基线的指标差值、传导链归因、恢复期估计
   （格式见《虚拟城市场景推演与预测运行设计》§5）。
