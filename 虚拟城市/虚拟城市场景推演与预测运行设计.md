## 1. 定位与边界

### 1.1 它是什么

虚拟城市不只是「会自己运行的城市」，还是一台**可干预、可复现、可观测的预测机器**：

```
条件注入 → 城市状态演化（N 个模拟月）→ 指标观测 → 结果预测
```

一次完整的「如果……会怎样」研究，由**同种子的一对运行**构成：
`基线运行（不注入）` vs `场景运行（注入一个条件）`，两者逐月指标之差即为该场景的**因果效应估计**。

### 1.2 它不是什么

| 边界 | 说明 |
|---|---|
| **不是脚本演出** | 注入只改世界条件，不改居民行为；结果必须由 Agent 自主响应涌现，禁止写死「地震后一定恐慌」 |
| **不是数值改配置** | 场景是「事件」，不是「后台改参」；税制结构、会计恒等式、结算函数不可被场景修改 |
| **不是占卜** | 预测报告必须给出置信区间与适用边界；未知灾难类场景明确标注「未知域压力测试」 |
| **不是单人操纵模式** | 无人类座位；人类只能是观察者或条件触发者（见 §7 / 《人类角色》） |
| **不替代真实计量模型** | 本系统输出的是**机制一致的模拟预测**，用于情景分析、政策预演与教学，不用于现实决策的唯一依据 |

### 1.3 三层可复现性

LLM 驱动的居民决策天然带非确定性，因此「可复现」必须分层定义：

| 层级 | 定义 | 实现手段 | 适用 |
|---|---|---|---|
| **R0 轨迹可复现** | 同基线 + 同种子 + 同场景 ⇒ 逐月状态哈希一致 | 决策重放缓存：`key = (seed, resident_id, month, prompt_hash)`，命中即复用决策 | 论文引用、事故复盘 |
| **R1 分布可复现** | 关闭重放时，同种子下决策分布与指标分布的统计检验无显著差异 | 种子派生 + 温度/采样参数固定 | 批量蒙特卡洛 |
| **R2 结论可复现** | 多次运行的效应方向与量级落在置信区间内 | 多样本重复 + 报告置信区间 | 对外结论 |

> **默认口径**：面向研究的预测报告采用 **R0**；参数扫描与压力测试采用 **R1/R2**，并在报告中注明层级。

## 2. 场景目录

场景目录是**唯一可注入集合**（白名单）。共 4 群 10 类，`kind` 为协议字段，不可扩展未登记的类型。

### 2.1 市场与经济

| `kind` | 名称 | 核心参数 | 直接作用对象 | 默认持续 | 主要观测指标 |
|---|---|---|---|---|---|
| `goods_price_shock` | 商品价格冲击 | 商品类目、涨跌幅、作用范围（全域/城区/行业） | 商品篮子价格 → CPI → 消费选择 | 6 月（线性退坡） | CPI、消费篮子结构、替代/囤积率、零售营业额 |
| `policy_shock` | 政策冲击 | 政策工具（税率 / 基准利率 / 补贴 / 限购 / 首付比例）、调整幅度 | 财政参数、信贷条件、购房门槛 | 12 月（阶跃，到期复位） | 税负、可支配收入、信贷投放、购房意愿 |
| `market_crash` | 市场崩盘 | 初始跌幅、波及市场（股票/房产/黄金/债）、杠杆清算阈值 | 资产价格 → 抵押品价值 → 强平链 | 3 月冲击 + 12 月修复 | 指数回撤、强平笔数、信用利差、流动性折价 |

### 2.2 社会与舆情

| `kind` | 名称 | 核心参数 | 直接作用对象 | 默认持续 | 主要观测指标 |
|---|---|---|---|---|---|
| `survey_pulse` | 调研问卷反馈推演 | 问卷 ID / 议题、投放人群、情境提示 | 居民态度抽样（不改变世界状态） | 1 月（一次性） | 分项回答分布、阶层差异、与基线偏移 |
| `election_sentiment` | 选举舆情 | 议题设置、媒体倾向、候选人曝光、事件冲击 | 议题显著性 → 满意度 → 得票率 | 至选举日（≤24 月） | 候选人支持率、投票率、议题关注度、满意度分项 |

> **注意**：`survey_pulse` 是**观测型场景**：它不制造冲击，而是给定情境后读取居民回答，
> 用于校准「问卷设计 → 反馈分布」的映射；其结果不进入世界状态，只进入预测报告。

### 2.3 自然灾害

| `kind` | 名称 | 核心参数 | 直接作用对象 | 默认持续 | 主要观测指标 |
|---|---|---|---|---|---|
| `earthquake` | 地震 | 震级（里氏）、震中城区、震源深度、建筑抗震等级 | 城区建筑损毁、基础设施功能、人口伤亡/迁移 | 瞬时冲击 + 6–36 月重建 | 直接经济损失、伤亡、迁移、重建支出、产能恢复率 |
| `tsunami` | 海啸 | 淹没带（沿海城区）、浪高、预警提前量 | 沿海基础设施瘫痪、港口/物流中断、人口疏散 | 瞬时冲击 + 3–24 月恢复 | 淹没面积、物流中断时长、保险赔付、供应链缺口 |
| `extreme_disaster` | 极端灾难事件 | 复合灾害组合、持续时间、次生灾害开关 | 全城功能降级 + 财政极限 + 社会秩序 | 1–24 月（可分段） | 城市功能瘫痪度、财政赤字率、治安事件、人口净流出 |

### 2.4 未知灾难

| `kind` | 名称 | 核心参数 | 直接作用对象 | 默认持续 | 主要观测指标 |
|---|---|---|---|---|---|
| `meteorite` | 陨石撞击 | 撞击当量、撞击点、破坏半径、尘霾系数 | 局部毁灭 + 全城气候/信心冲击 | 瞬时 + 6–60 月 | 破坏半径内资产归零率、尘霾对农业/物价的传导、重建能力 |
| `alien_invasion` | 外星人入侵 | 不可预期度、冲击强度、制度应急开关 | 全局信心崩塌 + 城市功能停摆 + 制度应激 | 1–12 月 | 信心指数、资本外逃、财政极限、制度响应时延、长期产出缺口 |

> **未知灾难的定位**：不追求「预测得准」，而是**韧性压力测试**——在模型已知边界之外注入不可标定冲击，
> 观察系统的自适应、崩溃与恢复能力，输出「韧性画像」。报告中必须标注「未知域，结果仅具方向性」。

## 3. 强度分级与持续/衰减语义

### 3.1 强度分级 L1–L5

`magnitude` 取 1–5 的整数，代表**冲击量级档位**，而非线性倍数。每类场景在目录中声明自己的锚点：

| 档位 | 语义 | 市场类 | 灾害类 | 舆情类 |
|---|---|---|---|---|
| **L1 轻微** | 可忽略，用于噪声对照 | 商品 +2% / 政策 0.5pp | 震级 3.0 / 局部轻微 | 议题热度 +5% |
| **L2 明显** | 可观测但不改变结构 | 商品 +5% / 政策 1pp | 震级 4.5 / 局部损毁 | 议题热度 +15% |
| **L3 显著** | 改变季度指标与部分决策 | 商品 +10% / 政策 2pp | 震级 6.0 / 城区受损 | 议题热度 +30%，支持率 ±5pp |
| **L4 严重** | 改变年度指标与阶层分布 | 商品 +20% / 政策 5pp | 震级 7.0 / 多城区重创 | 支持率 ±12pp，投票率显著变化 |
| **L5 极端** | 结构性断裂，触发制度应急 | 商品 +50% / 政策 10pp+ | 震级 8.0+ / 全城功能降级 | 支持率重排，舆情失控 |

**强度约束**：

1. **单调性**：同一场景在相同基线上，`L(n+1)` 的峰值影响不得小于 `L(n)`（允许随机波动容差）。
2. **饱和性**：L5 不得出现「数值爆炸」（如价格指数发散、资产价格负值）；引擎须有硬边界。
3. **可标定性**：L1–L4 的映射必须由《校准框架》§6.2 敏感度扫描标定；L5 允许基于文献/情景假设，
   但报告中须注明「未标定」。

### 3.2 持续与衰减语义

| 模式 | 语义 | 适用场景 | 数学形态 |
|---|---|---|---|
| **瞬时冲击（impulse）** | 一次性改写存量（资产损毁、伤亡），随后进入恢复过程 | 地震、海啸、陨石、市场崩盘首月 | 冲击月一次性施加，恢复由重建/修复机制内生 |
| **阶跃持续（step）** | 条件在整个 `duration_months` 内保持不变，到期复位 | 政策冲击、选举舆情 | `effect(t) = A`，`t ∈ [0, D]`；到期归零 |
| **线性退坡（linear decay）** | 冲击按月线性衰减至 0 | 商品价格冲击 | `effect(t) = A × (1 − t/D)` |
| **指数衰减（exponential decay）** | 半衰期式衰减，尾部拖长 | 舆情热度、信心冲击 | `effect(t) = A × exp(−λt)`，`λ = ln2 / 半衰期` |
| **复合（composite）** | 冲击 + 持续 + 次生灾害分段 | 极端灾难、外星人入侵 | 分段函数，段间可切换模式 |

**统一约束**：

- `duration_months ∈ [1, 24]`；缺省取场景目录默认值。
- 场景在同一房间同时生效数 ≤3（《人类角色》§3.6），避免归因不可分。
- 衰减只作用于**流量**（价格、信心、热度）；**存量改写**（建筑损毁、人口伤亡）不可「衰减回滚」，
  只能经重建/迁移机制恢复。
- 每次注入必须声明 `decay_mode`（缺省由目录给定），报告须给出实际衰减曲线。

## 4. 连锁传导模型

### 4.1 主链

```
价格 ─→ 消费 / 就业 ─→ 财政 ─→ 信用 ─→ 资产 ─→ 社会指标
 ↑                                                  │
 └──────────────── 反馈（舆情/选举/政策）────────────┘
```

### 4.2 各环节机制（均复用既有子系统，不新增平行模型）

| 环节 | 机制 | 关键参数 / 状态 | 观测指标 |
|---|---|---|---|
| **① 价格** | 商品篮子分类（食品/居住/交通/医疗/教育/娱乐）加权成 CPI；输入型成本向终端价格传导 | 类目权重、传导系数、价格粘性 | CPI、类目价格指数 |
| **② 消费** | 按收入阶层的边际消费倾向（MPC）与替代弹性；必需品刚性、可选品收缩；预防性储蓄上升 | 各阶层 MPC、替代弹性、储蓄率 | 消费篮子结构、零售营业额、储蓄率 |
| **③ 就业** | 企业营收 → 用工需求（劳动力市场 12）→ 招聘/裁员；工资粘性；灵活就业作为缓冲池 | 用工弹性、工资粘性、灵活就业占比 | 失业率、工资增速、灵活就业人数 |
| **④ 财政** | 税收（增值税/个税）随经济活动变化；支出端失业救济、补贴、重建（财政 21）；赤字与市政债 | 税率结构、转移支付规则、债务上限 | 财政收入/支出、赤字率、债务余额 |
| **⑤ 信用** | 银行资产质量（不良率）、信贷标准、利差；明斯基融资阶段迁移；抵押品价值下降触发收缩 | 不良率、拨备、LTV、强平阈值 | 不良率、信用利差、信贷增速、强平笔数 |
| **⑥ 资产** | 股票/房产/黄金价格；财富效应；抵押品渠道；泡沫反身性引擎放大 | 漂移、波动率、杠杆率、泡沫状态 | 指数、房价收入比、成交量、换手率 |
| **⑦ 社会** | 满意度、基尼、信任、迁移意愿（社会生态 07 / 舆论 16）；选举得票（04）；问卷回答 | 满意度分项、基尼、信任指数 | 满意度、基尼、支持率、净迁移、问卷分布 |

### 4.3 反馈回路（模型的「放大器」）

| 回路 | 路径 | 效果 | 既有机制 |
|---|---|---|---|
| **金融加速器** | 资产跌 → 抵押品缩水 → 信贷收缩 → 消费/投资降 → 资产再跌 | 放大下行 | 银行信贷 + 泡沫引擎（批次 62） |
| **财政自动稳定器** | 失业升 → 救济支出升 + 税收降 → 赤字升 → 债券供给升 → 利率升 | 抑制下行但积累债务 | 财政 21 + 货币政策工具箱 |
| **预期自实现** | 舆情悲观 → 预防性储蓄 → 需求降 → 企业营收降 → 失业升 | 放大冲击 | 舆论 16 + 行为金融偏差 |
| **政策反馈** | 满意度降 → 选举压力 → 政策转向 → 价格/信贷条件变化 | 可能逆转或加剧 | 选举 04 + `policy_shock` |
| **迁移出清** | 失业/灾害 → 人口净流出 → 住房需求降 → 房价降 → 财政税基缩 | 长期结构性损伤 | 人口动力学 10 + 住房 09 |

### 4.4 场景 → 链路入口映射

| 场景 | 主入口 | 主要经过的链路 | 典型终点 |
|---|---|---|---|
| `goods_price_shock` | ① 价格 | ①→②→③→⑤→⑥→⑦ | 消费降级、失业上升、满意度下降 |
| `policy_shock` | ④/⑤ | ④→②→③→⑤→⑥ | 可支配收入、信贷投放、购房意愿 |
| `market_crash` | ⑥ 资产 | ⑥→⑤→②→③→④→⑦ | 强平链、信用收缩、财政救助 |
| `survey_pulse` | ⑦ 社会（观测） | 无传导（只读） | 问卷分布 |
| `election_sentiment` | ⑦ 社会 | ⑦→④→①/⑤ | 得票率、政策转向 |
| `earthquake` / `tsunami` | ⑥ 资产（存量损毁）+ ③ 就业 | ⑥→③→④→⑤→⑦ | 重建支出、迁移、长期产出缺口 |
| `extreme_disaster` | 全链路 | ①–⑦ 同时受压 | 城市功能降级、财政极限 |
| `meteorite` | ⑥ 存量 + ① 气候 | ⑥→①→②→③→④→⑦ | 区域归零、物价冲击、重建瓶颈 |
| `alien_invasion` | ⑦ 信心 + 全链路 | ⑦→⑥→⑤→②→③→④ | 资本外逃、制度应激、长期缺口 |

## 5. 预测运行流程

### 5.1 五步流程

```
① 基线快照 → ② 条件注入 → ③ N 月演化 → ④ 指标对比 → ⑤ 预测报告
```

| 步骤 | 动作 | 产物 | 关键约束 |
|---|---|---|---|
| **① 基线快照** | 冻结当前世界状态（`snapshot_id` + `seed` + `state_hash` + 月份） | 基线快照 | 快照必须完整（含居民档案、资产、财政、信贷、舆情、空间损毁状态） |
| **② 条件注入** | 按 §2 选 `kind`、`magnitude`、`duration_months`、`target`、`note` | 注入记录 + 首月直接冲击 | 走《人类角色》§3 协议；同月 ≤2 次、同时生效 ≤3 个 |
| **③ N 月演化** | 从快照起推进 N 个模拟月（默认 12；灾害类 24–36） | 逐月状态轨迹 | 同种子可复现；每月记录指标与事件流 |
| **④ 指标对比** | 与同种子基线运行逐月对齐，计算差值 | 差值序列 + 峰值/谷值/恢复月 | 必须成对（同基线、同种子、只差注入） |
| **⑤ 预测报告** | 归因 + 外推 + 置信区间 + 边界声明 | 报告（见 §5.3） | 未知灾难须标注「未知域」；未标定场景须标注 |

### 5.2 确定性与种子口径

| 机制 | 规则 |
|---|---|
| **种子派生** | `run_seed = hash(baseline_seed, scenario_id, attempt_index)`；基线运行使用 `baseline_seed` 本身 |
| **决策重放** | R0 模式下，`(seed, resident_id, month, prompt_hash)` 命中缓存即复用决策，保证逐位一致 |
| **外盘锚** | 预测运行默认**冻结外盘锚**（`Active=false` 或固定快照），避免真实行情漂移污染对照；如需研究外盘影响，另设「锚开启」对照组 |
| **LLM 采样** | 预测运行固定温度与采样参数；模型版本写入报告元数据 |
| **浮点容差** | 指标对比允许 ≤1e-9 相对误差；超出即判 R0 失败 |

### 5.3 预测报告结构

| 章节 | 内容 | 必填 |
|---|---|---|
| **元数据** | `run_id` / `baseline_snapshot_id` / `seed` / 模型版本 / 复现层级（R0/R1/R2） / 注入记录 | ✅ |
| **场景描述** | `kind` / `magnitude` / `duration` / `target` / 衰减模式 / 操作者备注 | ✅ |
| **首月直接冲击** | 各指标相对基线的即时变化 | ✅ |
| **逐月轨迹** | 关键指标时间序列（含基线与场景两条线） | ✅ |
| **峰值与恢复** | 最大偏离、触底月、恢复至基线 ±5% 所需月数 | ✅ |
| **传导归因** | 各链路贡献度（§4.2 环节分解），标注主导链路与共振放大 | ✅ |
| **分布影响** | 按收入阶层 / 城区 / 职业的差异化影响（基尼、迁移、破产率） | ✅ |
| **外推 3–12 月** | 基于恢复曲线与反馈回路的延伸预测 + 置信区间 | ✅ |
| **韧性画像**（灾害/未知灾难） | 恢复力、适应力、转型力三项评分与依据 | 灾害类必填 |
| **边界与限制** | 未标定参数、未知域声明、模型已知偏差 | ✅ |

### 5.4 多场景对比

| 模式 | 定义 | 用途 | 输出 |
|---|---|---|---|
| **单场景对照** | 基线 vs 单场景 | 估计单一条件因果效应 | 差值序列 + 报告 |
| **多场景并列** | 同基线 + 多场景分别运行 | 比较不同冲击的相对严重度 | 对比矩阵（场景 × 指标） |
| **组合场景** | 同基线 + 多个场景叠加 | 研究复合冲击与共振 | 叠加效应 vs 各自效应之和（交互项） |
| **参数扫描** | 同场景 × 不同 `magnitude` | 建立「强度—响应」曲线 | 剂量反应曲线，用于校准 L1–L5 |

**对比规则**：所有对比必须共享同一 `baseline_snapshot_id`；不同快照之间的比较只能做「方向性」讨论，
不得作为因果结论。

## 6. 与既有子系统的关系

| 子系统 | 既有能力 | 场景推演如何复用 | 不得越界 |
|---|---|---|---|
| **社会调研（`survey.go`）** | 任意登录用户发起问卷，样本池 200–384，回答聚合 | `survey_pulse` 复用同一套投放与聚合链路，额外记录「情境参数」以支持反事实对比 | 不得指定个体回答；不得把问卷结果直接写回世界状态 |
| **市长选举（`civic_election.go`）** | 48 月一届，30-40-30 得票结构，满意度 = 100 − 基尼×100 | `election_sentiment` 注入议题显著性与媒体倾向，观察得票率变化 | 不得直接改写得票；只能改议题与曝光 |
| **外盘情绪锚（`exogenous.go`，批次 66）** | 真实行情 → `tanh` 情绪分 → 股票 ±0.3% / 黄金 ±0.2% 微偏置 | 作为「现实先验」：预测运行默认冻结；可显式开启作为对照 | 锚是锚不是驱动；注入不得绕过锚的封顶与过期规则 |
| **泡沫反身性引擎（批次 62）** | 居民偏差 → 羊群/杠杆 → 泡沫 → 破裂 → 反馈决策 | 作为 §4.3 金融加速器的放大器；`market_crash` 通过它放大 | 不得在场景里写死崩盘路径；只注入初始冲击 |
| **货币政策工具箱（`policy_toolbox.go`）** | 利率/准备金/流动性投放 | `policy_shock` 与之共用参数面；场景注入记录独立审计 | 不得绕过财政/货币约束 |
| **城市应急（城市系统设计 08）** | 六类危机、政府响应、居民避险 | 灾害类场景复用应急响应与重建机制 | 不得跳过恢复过程直接「复原」 |
| **事件流（`EventRecord` / `emitEvent`）** | 统一事件广播 | 场景注入与内生事件共用事件流，注入事件带 `scenario_id` | 事件类型不得混淆（据此区分内生/外生） |

**关键区分**：

- **内生事件**：市场周期、企业生灭、舆情扩散、行为偏差——由城市机制自然产生。
- **注入场景**：带 `scenario_id` 与操作者元数据的外部条件——注入后仍走同一套传导机制。
- 两者叠加时，报告须标注「共振放大」，并给出「仅内生」「仅注入」「叠加」三组对照。

## 7. 人类角色：条件触发者

> 完整协议见《人类角色》§3；本节仅列预测运行视角的要点。

### 7.1 谁能做

- **任意登录用户**（与调研同权限口径）即为**条件触发者**，无需特殊角色。
- 观察者天然具备该能力；**无人类座位**，任何人不得以「居民」身份入座（`35036`）。

### 7.2 能做什么 / 不能做什么

| 能做 | 不能做 |
|---|---|
| 从白名单目录选择场景与强度 | 自定义未登记场景 |
| 指定城区 / 行业 / 商品类目 / 候选人 | 指定单个居民 |
| 设置持续月数与备注 | 直接改写税率结构、会计恒等式、结算函数 |
| 查看注入记录与效果 | 撤销已造成的存量损毁（只能等待重建） |
| 并行做多场景对比 | 同月无限叠加（受配额约束） |

### 7.3 审计与限额

| 项 | 规则 |
|---|---|
| 审计字段 | `scenario_id / actor / kind / magnitude / target / duration / applied_month / seed / snapshot_id / note / created_at` |
| 速率 | 单房间单月 ≤2 次注入；同时生效 ≤3 个；同 `kind` 冷却 ≥3 月；单用户单房间每日 ≤20 次 |
| 留痕 | 注入记录不可变；与事件流一一对应；预测报告引用时必须附 `scenario_id` |
| 越权 | 观察者发送输入帧一律 `30011`；人类入座一律 `35036` |

## 8. 验收与指标

### 8.1 功能验收

| # | 验收项 | 判据 |
|---|---|---|
| 1 | 场景目录完整 | 4 群 10 类 `kind` 与 §2 完全一致，`magnitudes` 均为 1–5 |
| 2 | 注入生效 | `POST /scenario` 返回 200，事件流出现对应事件，首月指标有可测变化 |
| 3 | 注入留痕 | `GET /scenarios` 返回最近 20 条，字段完整率 100% |
| 4 | 无人类座位 | 房间列表无「加入」；`join` 返回 `35036` |
| 5 | 观察者可操作 | 观察态可见并可使用场景推演台 |
| 6 | 可复现 | 同种子双跑状态哈希一致（R0） |
| 7 | 对比正确 | 基线与场景运行共享 `baseline_snapshot_id`，差值可复算 |

### 8.2 质量指标

| 指标 | 定义 | 目标 |
|---|---|---|
| **归因可解析率** | 3 个月内能定位主导传导链的注入占比 | ≥90% |
| **强度单调率** | 满足「L(n+1) ≥ L(n)」的场景-指标对占比 | ≥95% |
| **饱和越界率** | 出现数值发散或负价格的运行占比 | 0% |
| **报告完整率** | §5.3 必填章节齐全的报告占比 | 100% |
| **冻结锚隔离率** | 预测运行未受实时外盘漂移影响的占比 | 100% |
| **平均响应时延** | 注入提交到首月效果回传 | ≤2 秒（不含 LLM 排队） |

## 9. 风险与已知限制

| 风险 | 表现 | 缓解 |
|---|---|---|
| **LLM 决策非确定** | 同种子结果漂移 | R0 决策重放；R1/R2 分层声明 |
| **强度-响应未标定** | L4/L5 可能失真 | 先跑 §5.4 参数扫描建立剂量反应曲线；未标定项在报告标注 |
| **复合场景归因难** | 多场景叠加后无法拆分贡献 | 限 3 个同时生效；提供「仅 A / 仅 B / A+B」三组对照 |
| **未知灾难不可验证** | 无真实基准可比 | 定位为韧性压力测试，只输出方向性与相对比较 |
| **外盘漂移污染** | 真实行情在对照运行间变化 | 预测运行默认冻结外盘锚 |
| **存量损伤不可逆** | 灾害后无法快速复原 | 明确「恢复靠重建机制」，报告给出恢复期而非撤销 |
| **模型版本漂移** | 跨版本结果不可比 | 报告写入模型版本；跨版本比较标注「非严格可比」 |
