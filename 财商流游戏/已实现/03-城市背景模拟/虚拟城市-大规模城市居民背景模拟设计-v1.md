# 虚拟城市 — 大规模城市居民背景模拟设计 v1

> 状态：实现契约（2026-09-21）。上游总纲见 01；LLM 线路契约见 02。
> 本篇定义 `game/wealth/city/` 新包：校准表、背景居民、月度演化、城市之声。

## 1. 目标与边界

- 一城 **1 ~ 100,000+** 居民（`resident_count`），身份分布源自
  `lag_docs/虚拟城市/玩家职业设计/`（100,174 张职业卡，26 个 L1 行业域 × 8 城区）。
- **背景居民是数据，不是 goroutine**：紧凑结构 + 数值规则逐月演化；
  LLM 深认知只给「焦点座位」（≤12，全量引擎不变）与「城市之声」抽样居民。
- 性能预算：100K 居民初始化 < 200ms；月度 tick < 100ms；常驻内存增量 < 32MB。

## 2. 包结构（`ServerGo/game/wealth/city/`）

## 3. 校准表（calibration.go）

### 3.1 结构

```go
type CalibTable struct {
    Domains     []DomainStat // 按 L1 行业域（A-农林牧渔 … Z-新兴交叉，26 个）
    Districts   [8]float64   // 城区人口权重（和为 1）
    Employment  float64      // 基线就业率（默认 0.94）
    Source      string       // "docs"|"curated"|"synthetic"
    Ready       bool         // 后台预热完成标志
}
type DomainStat struct {
    Name             string  // L1 域名（路径首段，如 "A-农林牧渔"）
    Weight           float64 // 域人口权重
    IncomeMean, IncomeStd float64
    ExpenseRatioMean float64 // 月支出/月收入
    SavingsMonths    float64 // 储蓄≈月收入×该系数
    AgeMean          float64
}
```

### 3.2 构建

- 触发：wealth manager 初始化后**后台 goroutine 预热**（`sync.Once`，不阻塞启动）。
- 抽样：`docLoader.Draw(K, rng)`，K = `cfg.Wealth.CityCalibSampleSize`（默认 512）；
  L1 域名从卡来源路径首段提取（`Card.Source` 或 loader 侧随卡返回，实现侧择一，契约不变）。
- 兜底链：docs 池不可用 → curated 14 卡统计（`Source="curated"`）→ 再兜底内置合成默认
  （`Source="synthetic"`：Weight 均匀、IncomeMean=6800、ExpenseRatio=0.72、SavingsMonths=6、AgeMean=36）。
- **房间创建不等预热**：未 Ready 时用合成默认即时建城，Ready 后**下一房**生效
  （进行中房间不回填，避免中途分布漂移）。

## 4. 背景居民（backdrop.go）

### 4.1 数据结构（紧凑，≈40B/人）

```go
type resident struct {
    income   float32  // 月收入（元）
    expense  float32  // 月支出（元）
    savings  float64  // 累计储蓄
    domain   uint8    // L1 域索引 0..25（255=未知）
    district uint8    // 城区 0..7
    age      uint8    // 岁（每年 12 月 +1）
    flags    uint8    // bit0=employed bit1=stressed bit2=voiced(本月已发声)
}
```

### 4.2 合成（`NewBackdrop(n int, rng *rand.Rand, calib *CalibTable)`）

逐人：按 `Domains[i].Weight` 选域 → 按 `Districts` 选城区 →
`age ~ clamp(round(N(AgeMean,6)), 18,70)` → `income ~ clamp(lognormal(ln(IncomeMean),0.55), 500, 200000)`
→ `expense = income × ExpenseRatioMean × U(0.85,1.15)` →
`savings = income × SavingsMonths × U(0.5,2.0)` → 按 `Employment` 置 employed 位。
**房间 seed 传入 rng，同 seed 同城**（确定性，测试断言）。

### 4.3 月度演化（`TickMonth(cpi float64, rng *rand.Rand)`）

| 规则 | 参数 |
|---|---|
| 就业者现金流 | `savings += income - expense`；`expense *= (1+cpi)`（cpi 由引擎传入，默认 0.002） |
| 失业冲击 | 就业者每月 0.8% 失业（income 置 0，记原值不存——简化：失业即收入 0） |
| 再就业 | 失业者每月 15% 再就业，收入 = 域均值 × U(0.8,1.1) |
| 压力位 | `savings < 3×expense` → stressed 置位；回升后清除 |
| 年龄 | 每 12 个 tick 全员 +1 岁 |
| 清除 voiced 位 | 每月初重置（供城市之声去重抽样） |

### 4.4 聚合快照（`Snapshot() Snapshot`，随 `game.state.city` 下发）

```go
type Snapshot struct {
    ResidentCount int            `json:"resident_count"`
    EmploymentRate float64       `json:"employment_rate"`
    MedianIncome  float64        `json:"median_income"`   // 抽样 4096 人取中位数
    TotalSavings  float64        `json:"total_savings"`
    AvgAge        float64        `json:"avg_age"`
    StressedRate  float64        `json:"stressed_rate"`
    Districts     []DistrictPop  `json:"districts"`       // [{id,name,population}]
    Voices        []VoiceRecord  `json:"voices,omitempty"`// 最近 20 条城市之声
}
```

## 5. 城市之声（voice.go）——LLM 认知抽样

- **目的**：让背景居民「活着」——每月少量真实 LLM 发声，全城可见，且严格受线路池约束。
- 每月结后：从** stressed/失业优先、其余随机**的居民中抽 `cfg.Wealth.CityVoicePerMonth`
  （默认 4，clamp 0..32；0 或 `city_voice_enabled=false` 关闭）名。
- 每名居民构造一次**极短**对话（无工具、无 Memory、`max_tokens` 小）：
  - system：你是虚拟城市居民 `<域名>·<城区>`，本月状态一句话（就业/储蓄/压力）。
  - user：用一句话说出你本月的感受或打算（≤60 字）。
- 调用必须经 `LinePool.Acquire(ctx)`（ctx 15s 超时）；失败/超时丢弃本条（下月再抽），
  **绝不阻塞月结**。AgentClassName = `LsmAgentGame-Wealth-CityVoice`（§24 两步注册 + 单测）。
- 产物：`VoiceRecord{Month, Name(域·城区 代号), Text(截 100 字), ModelKey(服务线路)}`：
  1. 追加房间事件流（EventRecord type=`city_voice`，随 `game.event` 广播）；
  2. 存入 Backdrop 环形缓冲（最近 20 条，随 Snapshot 下发）。
- 命名：背景居民不解析真实姓名卡（10 万卡全量解析不可行），用代号
  `<域字母><序号>`（如 `A1024·华东城东`）；**真实姓名只属于焦点座位**（Start 时抽真卡）。

## 6. 与房间/引擎的接线

| 接线点 | 契约 |
|---|---|
| `WealthRoom` | 新增 `ResidentCount int`、`City *city.Backdrop`（resident_count>0 时创建） |
| 月结顺序 | `SettleMonth()`（既有 12 座引擎）→ `City.TickMonth(cpi, rng)` → 广播 `game.month`（city 快照并入 `game.state`） |
| cpi 来源 | 引擎通胀参数（P1 通胀传导）已有值则传入；缺省 0.002 |
| 观战/隐私 | city 块无座位隐私，随 BroadcastRoom 全量下发 |
| 重启恢复 | Backdrop 由 `ResidentCount + room seed` 确定性重建（同城同人）；城市之声缓冲不持久化（可丢） |

## 7. 配置（`config/config.go` → `[wealth]`）

| 键 | 默认 | 说明 |
|---|---|---|
| `max_residents` | 100000 | 建房 resident_count 上限（clamp） |

## 8. 测试要求

| 用例 | 断言 |
|---|---|
| 合成确定性 | 同 seed 两城逐字段相等 |
| 容量/性能 | `NewBackdrop(100000)` < 200ms；`TickMonth` < 100ms（放宽 CI 2×） |
| 快照合理 | employmentRate∈(0.5,1)；medianIncome∈(1000,50000)；Σdistricts=n |
| 演化守恒 | 无冲击随机种子下 totalSavings 单调性与就业率漂移在界内 |
| 城市之声 | fake pool 注入：产出条数=配置；Acquire 失败时不 panic、不阻塞、缺数下月补 |
| 校准兜底 | docs 缺失 → curated → synthetic，Source 字段正确 |
