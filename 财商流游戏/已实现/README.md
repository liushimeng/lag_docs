## P0 一句话摘要

- **城市居民层**：一城 1 ~ 100,000 名居民，身份全部来自
  `lag_docs/虚拟城市/玩家职业设计/`（100,174 张职业卡）。背景居民由轻量数值规则逐月模拟；
  至多 12 个「焦点座位」走既有全量引擎（WealthPlayer Agent + 39 工具）。
- **LLM 线路层**：`LLM 模型管理` 每行 provider 带 `concurrency_lines`（1~64），
  **启用 provider 的线路总和 = Agent 调用大模型的全局并发数**。`agent_name` 从管理语义废弃。
- **解耦铁律**：居民（职业卡）与 LLM（线路池）分属两层，建房不再给座位挑选/绑定模型；
  任何 Agent 的 LLM 调用统一 `LinePool.Acquire()` 排队。
