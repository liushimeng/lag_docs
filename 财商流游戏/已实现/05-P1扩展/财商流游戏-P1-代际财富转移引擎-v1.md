## 1. 设计目标

**财富的代际转移是社会不平等的核心传动机制**——父母给孩子首付、遗产，孩子
给父母赡养、医疗费。游戏内如果只让 12 个 Agent 从 25 岁到 60 岁独立打拼，会
**完全错过**真实世界最关键的一条财富流动路径。本 P1 增量把这条路径补上：

| 缺口 | 真实世界对应 | 教育价值 |
|------|-------------|---------|
| ❌ 父母没"父母",Agent 是原子化个体 | 家庭/家族/赡养责任 | 赡养支出 vs 资产积累的取舍 |
| ❌ 遗产不存在 | 房产/股票/企业股权继承 | 富二代 vs 穷二代的起点差 |
| ❌ 婚姻只是事件,无共同账户 | 婚后财产共有/AA 制 | 婚姻法经济后果 |
| ❌ 子女只是事件,无教育投入 | 教育投资回报率(ROI) | 内卷 vs 放养的长期回报 |

本 P1 增量聚焦**遗产 + 赡养**两条核心链路；婚姻共同账户 / 教育投入留 P2 后续补。

## 2. 父母与子女的模型

P0/P1 的 Player 没有「父母」「子女」概念。引入 4 个**纯派生**字段(不持久化,只
在月结时根据开局种子计算):

```go
// Player 派生字段(2026-09-19 §P1-3 新定;不落库,Engine 通过 start_age 推算)。
type PlayerFamily struct {
    ParentsAlive       bool    // 父母是否在世(50 岁后衰减)
    ParentsAge         int     // 父母当前年龄(开局 = 玩家 + 25)
    ParentsHealth      string  // "good" | "fair" | "poor"
    ChildrenCount      int     // 子女数(开局 seed 决定)
    ChildrenAges       []int   // 各子女当前年龄
    ChildrenEducation  []string // 各子女教育档:"none"|"public"|"private"
}
```

**算法**:
- 开局时,每个 Player 的父母年龄 = `Player.start_age + 25`(典型 25 岁开局 → 父母 50 岁)
- 父母寿命按"全国人均预期寿命 78 岁"模型线性衰减:50 岁起每年 5% 离世概率
- 子女数按开局种子 + 卡池 birth_rate 抽样(0~2 名,P0 已用 `fertility` 字段)
- 子女教育档默认 `public`(公立免费);财富圈层为 `freedom` 时可自费升级 `private`

## 3. 遗产继承(Inheritance)

### 3.1 触发条件

玩家死亡(`Player.Alive = false` 且非破产) → 进入遗产清算流程。

### 3.2 遗产算法

```go
// DistributeInheritance 遗产分配(2026-09-19 §P1-3 新定)。
// 调用时机:玩家死亡的当月月结末尾(SettleMonth 末)。
//
//   - 总遗产 = Cash + ΣAssets.Value − ΣLoans.Balance
//   - 先扣除丧葬费(¥5000 一次性)
//   - 配偶得 50% (Player.HasSpouse == true)
//   - 剩余 50% 按子女数均分(0 子女 → 100% 归配偶;无配偶无子女 → 归世界 world)
//   - 玩家侧:继承人新增"InheritanceCNY"字段(本月一次性入账),下月归入 Income
func (w *World) DistributeInheritance(deadSeat int) error
```

### 3.3 数据流

```
玩家 5 死亡
   │
   ├─ 遗产池 = NetWorth = ¥1,200,000 - 30,000(丧葬) = ¥1,170,000
   ├─ 配偶得 50% = ¥585,000
   ├─ 2 子女均分 50% = ¥292,500 / 人
   │
   ▼
Ledger 双式记账(seat:5 → seat:配偶 / seat:child:X)
   │
   ▼
继承人下月 Income 增量 InheritanceCNY = ¥585,000 / ¥292,500
```

### 3.4 现实化考量

| 真实世界细节 | 游戏实现 | 简化理由 |
|--------------|---------|---------|
| 遗产税(中国暂无,但有其他税) | 暂不引入 | 教育价值偏低 |
| 遗嘱/指定继承人 | 按法定继承 | 12 Agent 无法律复杂度 |
| 房产继承的按揭延续 | 房贷一并转移 | 已有 Loan 体系,自然继承 |
| 保险理赔 | P0 insurer 预留 | 留 P2 补 |

## 4. 赡养支出(Family Support)

### 4.1 触发条件

玩家父母任一在世 + 父母年龄 ≥ 60 → 月度赡养支出。

### 4.2 算法

```go
// MonthlyFamilySupport 月度赡养支出(2026-09-19 §P1-3 新定)。
// 调用时机:SettleMonth ② MonthlyEvents 之后,⑤ LivingExpense 之前。
//
//   BaseSupportCNY = 1500  // 基础赡养(覆盖父母基本生活)
//   MedicalBoost   = 父母健康 == "poor" → ×2.5;"fair" → ×1.5
//   AbilityAdjust  = 玩家 NetWorth < 中位数 → ×0.5(贫困减免,体现社会兜底)
//
//   计入 Monthly.Expense + Ledger CatSocialEv
func (w *World) MonthlyFamilySupport(seat int) int64
```

### 4.3 现实化考量

- **赡养是真实世界最大的「财富流出」之一**(尤其在中国,医疗+养老)。游戏内
  把这条流显式化,让玩家体验"上有老下有小"的现金压力。
- **富裕家庭的赡养≠贫困家庭的赡养**——富裕者会送养老院(月费 ¥8000+),
  贫困者只能给基本生活费(¥500)。`AbilityAdjust` 体现这一分层。

## 5. 教育投资(Education Investment)

### 5.1 触发条件

玩家子女年龄 ∈ [3, 18] 且教育档 == "public" → 可自费升级到 "private"。

### 5.2 算法

```go
// UpgradeChildEducation 教育升级(2026-09-19 §P1-3 新定)。
// 一次性支付 ¥200,000(私立学校 12 年教育总成本);后续月度 +¥3000 教育支出。
// 教育回报:子女成年后(age=18)开局获得 +20% 初始 SalaryBase。
//
// 在 ProductiveCapacity 公式中引入 education_multiplier:
//
//   SalaryBase_adult = base_salary × (1 + 0.20 × private_education_count)
func (w *World) UpgradeChildEducation(seat, childIdx int) error
```

### 5.3 教育 ROI 算账

| 决策 | 投入 | 回报 | 净现值(35 年) |
|------|------|------|---------------|
| 不投 | ¥0 | ¥0 | ¥0 |
| 1 子女投 | ¥200,000 + ¥36,000/年×n | +20% 初始薪资 | 视职业,程序员家庭 ROI ≈ 1:8 |
| 2 子女投 | ¥400,000 + ¥72,000/年×n | +40% 初始薪资(线性叠加) | 视家庭,高 ROI 但流动性吃紧 |

## 8. Agent 工具扩展(17 工具 → 19 工具)

### 8.1 新增 `query_family` 工具

返回本人父母/子女状态、健康、教育档;无副作用。

### 8.2 新增 `pay_family_support` 工具

返回本月赡养支付明细;不可超过 NetWorth × 30%(防刷)。

### 8.3 新增 `upgrade_child_education` 工具

仅当玩家现金 ≥ ¥200,000 时可调用;Agent prompt 在余额不足时自动隐藏该工具。

### 8.4 新增 `plan_inheritance` 工具(纯查询)

返回"如果你现在死亡,你的遗产如何分配"的预览;用于 Agent 决策参考。
